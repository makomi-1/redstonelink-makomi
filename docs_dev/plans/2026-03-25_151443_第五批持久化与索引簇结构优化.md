# 第五批持久化与索引簇结构优化

生成时间：2026-03-25 15:14:43
文件名：2026-03-25_151443_第五批持久化与索引簇结构优化.md

## 任务背景

第四批已完成 crosschunk data 与 retire 事件簇收口，当前剩余最大的全局结构债集中在持久化与索引中枢：

- `LinkSavedData.java` 同时承担序号治理、在线节点索引、链接双向索引、NBT 编解码、审计视图；
- `InternalDispatchDeltaEvents.java` 同时承担 pair 归一、去重聚合、回放解析、事件分发。

这两处继续放大会反向拖累命令层、网络层、测试层可读性，也会让后续持久化/同步问题定位越来越慢。

## 方案详情

### 现状分析

- `LinkSavedData` 当前约 863 行，内部职责至少可分成 4 组：
  1. 序号分配/退役；
  2. 链接索引读写；
  3. 存档编解码；
  4. 查询/审计视图。
- `InternalDispatchDeltaEvents` 当前约 737 行，内部职责主要分成：
  1. delta 聚合规则；
  2. 事件投递壳；
  3. sync replay 解析；
  4. 去重缓存。
- 现有测试对 `LinkSavedData.load(...)`、`InternalDispatchDeltaEvents.normalizeLinkPairsForTesting(...)`、`resetForTesting()` 等入口已有稳定依赖，不适合直接改外观。

### 技术方案

本批继续坚持“结构变、行为不变、测试入口尽量不动”的策略。

1. `LinkSavedData` 拆成四层 helper
   - `LinkSavedDataSerialSupport`
     - 负责：序号分配、放置解析、allocated/retired 集合治理、nextSerial 修正。
   - `LinkSavedDataLinkIndexSupport`
     - 负责：按钮/核心双向索引写入、替换、清理、只读遍历。
   - `LinkSavedDataCodecSupport`
     - 负责：NBT load/save、节点/链接/serial set 编解码、旧格式兼容统计。
   - `LinkSavedDataQuerySupport`
     - 负责：查询视图、集合读取、audit snapshot。
   - 主类保留：
     - `SavedData` 外壳；
     - 公开 API；
     - 既有内部记录类型名；
     - `load/save`、`createAuditSnapshot` 等原方法名，但改为委托。

2. `InternalDispatchDeltaEvents` 拆成两层 helper
   - `InternalDispatchDeltaRuleSupport`
     - 负责：source/target pair 归一、attach/detach/invalidation 聚合、sync replay 解析与 strength 解析。
   - `InternalDispatchDeltaPublishSupport`
     - 负责：去重键、recent cache、防重发布、listener 投递。
   - 主类保留：
     - 对外静态 API；
     - `normalizeLinkPairsForTesting(...)`、`resetForTesting()` 等测试入口；
     - 内部记录/接口类型名。

3. 访问级别策略
   - helper 需要复用的数据结构、内部记录、缓存集合，按包内可见开放；
   - 不新增继承层，不改变 `LinkSavedData` / `InternalDispatchDeltaEvents` 的对外契约。

### 影响范围

- `src/main/java/com/makomi/data/LinkSavedData.java`
- `src/main/java/com/makomi/data/InternalDispatchDeltaEvents.java`
- 新增若干 `com.makomi.data.*Support` helper
- 受影响验证：
  - `LinkSavedData*` 测试
  - `InternalDispatchDeltaEventsTest`
  - 游戏内 `f02/f03/f04 + r02`
