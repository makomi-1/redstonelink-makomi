# graph自动聚焦上下文优先级修复

生成时间：2026-04-18 21:10:09
文件名：2026-04-18_211009_graph自动聚焦上下文优先级修复.md

## 任务背景

当前 graph 视图存在自动聚焦不稳定的问题：某些情况下本应聚焦到目标节点或展开块附近，但最终视口又跳回整图中心。用户观察到这是“有时候”发生，说明并非目标节点解析错误，而更像是多条视口控制逻辑互相覆盖。

本轮目标是在不改变 graph 真值、布局算法和交互语义的前提下，只修前端视口控制优先级，让“节点/聚合块的上下文聚焦”优先于“整图 fitView”。

## 方案详情

### 现状分析

- 普通节点聚焦通过 `focusNode(...)` 触发，最终走 `setCenter(...)`。
- 聚合块展开后会走局部 `fitView(...)`，只聚焦展开块与成员节点。
- 同时组件内还存在两条整图 `fitView(...)` 逻辑：首帧/节点数量变化归位，以及结构刷新后的整图归位。
- 当一次操作既触发上下文聚焦，又让画布节点集合变化时，后续整图 `fitView(...)` 会覆盖前面的上下文聚焦，导致视口落回整体中心。

### 技术方案

- 引入“下一次自动整图归位抑制”控制，只在需要上下文聚焦的操作中启用。
- 普通节点聚焦、聚合块展开聚焦会先开启抑制，再执行各自的 `setCenter(...)` 或局部 `fitView(...)`。
- 两条整图 `fitView(...)` effect 在执行前先检查该抑制标记；若当前轮存在上下文聚焦，则直接跳过本轮整图归位，避免覆盖。
- 抑制标记在上下文聚焦完成后的下一帧释放，保证后续真正需要的整图归位不被长期屏蔽。

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- `docs_dev/reviews/`
