# QTL渲染器更名与死代码清理

生成时间：2026-04-27 09:07:02
文件名：2026-04-27_090702_QTL渲染器更名与死代码清理.md

## 任务背景
当前 `QuickLinkOutlineRenderer` 已不再只负责 outline。它同时承接 quick-link tool 的命中描边、频道预览线框，以及智能眼镜 third-person visualize 的世界连线渲染与本地缓存。现有类名容易误导后续维护者，且链路中存在至少一处已无引用的旧兼容别名，需要顺手清理。

## 方案详情

### 现状分析
- `QuickLinkOutlineRenderer` 仍是活跃链路的一部分，已在客户端初始化阶段注册世界渲染事件。
- 该类被 `RedstoneLinkClient`、`QuickLinkNetworkClientHandlerSupport`、`LinkSerialHudOverlayRenderer` 直接引用。
- 类内私有方法与字段已复核，当前未再发现新的无引用私有成员。
- `SmartGlassesAccessSupport.canUseQuickLinkVisualization(...)` 全仓仅剩声明，属于可安全删除的旧别名。

### 技术方案
- 将 `QuickLinkOutlineRenderer` 更名为 `QuickLinkWorldOverlayRenderer`，使类名覆盖 preview 与 visualize 两条世界渲染职责。
- 同步修改直接调用方的 import、类型引用和静态方法调用。
- 删除 `SmartGlassesAccessSupport` 中已无引用的旧兼容别名，保留实际仍在使用的显示、操作和修改门槛方法。

### 影响范围
- `src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java`
- `src/client/java/com/makomi/RedstoneLinkClient.java`
- `src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java`
- `src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java`
- `src/main/java/com/makomi/data/SmartGlassesAccessSupport.java`

## 原子步骤清单

### 步骤 1：更名世界渲染类
- **操作对象**：`QuickLinkOutlineRenderer` 及其直接引用方
- **具体动作**：将类/文件更名为 `QuickLinkWorldOverlayRenderer`，同步更新 import、静态调用与类注释
- **预期结果**：类名与当前“preview + visualize 世界外显”职责一致
- **关键里程碑**：是

### 步骤 2：清理稳定死代码
- **操作对象**：`SmartGlassesAccessSupport`
- **具体动作**：删除全仓无引用的 `canUseQuickLinkVisualization(...)`
- **预期结果**：减少一处旧兼容死代码，不改变现有行为
- **关键里程碑**：是

### 步骤 3：回归验证与审查留痕
- **操作对象**：当前工作区与 `docs_dev/reviews/`
- **具体动作**：执行全量自动化测试，并生成五段式审查文档
- **预期结果**：验证更名与清理未引入编译或行为回归
- **关键里程碑**：是
