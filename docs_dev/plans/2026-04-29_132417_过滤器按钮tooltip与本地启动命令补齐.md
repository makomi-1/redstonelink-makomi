# 过滤器按钮tooltip与本地启动命令补齐

生成时间：2026-04-29 13:24:17
文件名：2026-04-29_132417_过滤器按钮tooltip与本地启动命令补齐.md

## 任务背景

当前 `release/no-mixin` 分支的过滤器编辑器仍保留旧中文按钮文案“过滤上界 / 过滤下界”，且缺少 `1.21.11` 版已经具备的上下界按钮 tooltip。与此同时，当前工作区只保留了 `withLithium` 本地运行时开关，还没有把 `JEI / Sodium / Iris` 的本地 `runClient` 可选依赖和简短命令补齐。用户还要求把版本号更新到 `1.9.1`。

## 方案详情

### 现状分析

- `LinkFilterEditorScreen` 当前只有按钮文案刷新逻辑，没有“上界 / 下界”按钮的悬停 tooltip。
- `zh_cn.json` 中文按钮名称仍为“过滤上界 / 过滤下界”；当前 `en_us.json` 也没有对应 tooltip 行。
- `build.gradle` 只支持 `-PwithLithium=true` 的本地运行时依赖，`gradle.properties` 也只有 `lithium_version`。
- `docs_dev/references/开发命令.md` 目前只有“带锂/不带锂”的本地启动示例，没有带 `JEI / Sodium / Iris` 的简短命令。

### 技术方案

1. 对照 `migration/fabric-1.21.11` 分支，把过滤器 signal mode 按钮 tooltip 迁回当前 `LinkFilterEditorScreen`。
2. 更新 `zh_cn.json / en_us.json`：
   - 中文按钮改为“通过上界 / 通过下界”
   - 新增中英文按钮 tooltip 两行说明
3. 在 `build.gradle` 补最小运行时依赖开关：
   - `withJei`
   - `withSodium`
   - `withIris`
   - `withIris` 自动补 `withSodium`
4. 在 `gradle.properties` 补对应版本号，并把 `mod_version` 更新为 `1.9.1`
5. 在 `docs_dev/references/开发命令.md` 增加带 `Lithium / Sodium / JEI / Iris` 的简短 `runClient` 命令

### 影响范围

- 客户端 GUI：`LinkFilterEditorScreen`
- 本地化文案：`zh_cn.json`、`en_us.json`
- 本地运行配置：`build.gradle`、`gradle.properties`
- 开发文档：`docs_dev/references/开发命令.md`
