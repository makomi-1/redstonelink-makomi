# 录制选集与状态面板曲线页问题修复

生成时间：2026-04-16 19:37:44
文件名：2026-04-16_193744_录制选集与状态面板曲线页问题修复.md

## 任务背景

当前 `P2` 录制链路已经具备录制子集选择、导出后跳转网页端和独立曲线查看能力，但在实际使用中还存在几处影响体验的细节问题：

1. 录制选集列表中，节点展示文本已经包含序号时，界面又额外追加一次 `[]` 序号，导致重复显示。
2. 状态面板列表中“状态”列在 `15,15` 这类常见功率值组合下显示不全，说明当前 GUI 宽度和列间距仍偏紧。
3. 曲线页在关闭全部曲线后再次打开其中一条时，时间窗会缩小到异常范围，影响继续查看。
4. 曲线图下方的具体数据表默认展开，会挤压首屏观察区域；本轮希望默认收起，按需展开。

本轮目标是按最小改动原则修复上述问题，不调整 recording 数据结构、不扩展新的前后端协议。

## 方案详情

### 现状分析

- 录制选集按钮文案在 `StatePanelRecordingScreen` 中由 `subscription.displayText()` 再拼接 `[`序号`]` 组成，而 `displayText` 本身已经采用统一展示格式，因此会重复。
- 状态面板列表列宽在 `StatePanelToolScreen` 中通过固定常量和动态收缩算法分配，当前主面板宽度与列配置对长状态文本支持不足。
- 曲线页图表由 `RecordingChart` 基于 `uPlot` 重建。当全部曲线关闭后，图表实例会销毁；再次开启曲线时若未把已有视窗稳定回灌到新图实例，就可能退回异常小窗口。
- 数据表在 `RecordingViewer` 中直接常驻渲染，缺少默认收起的展示层。

### 技术方案

1. 录制选集按钮直接复用已规范化的 `displayText`，不再手工追加第二份序号。
2. 状态面板采用“适当加宽主面板 + 微调列宽常量与列间距”的方式改善状态列可见范围，保留原有状态文本格式不变。
3. 曲线图在每次建图完成后立即应用当前 `xWindow`，保证“全关再开”时仍延续已有时间窗，而不是回退到异常窗口。
4. 将样本数据表包进 `details` 折叠块，默认关闭，仅在用户主动展开时显示。

### 影响范围

- `src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java`
- `src/client/java/com/makomi/client/screen/StatePanelToolScreen.java`
- `webapp/src/components/RecordingChart.tsx`
- `webapp/src/components/RecordingViewer.tsx`
- `webapp/src/app.css`

### 技术取舍

- 不修改 `displayText` 的生产逻辑，只修消费侧拼接错误，避免影响其他展示入口。
- 不缩写状态文本内容，而是先扩大可用宽度，保证信息完整性优先于极限压缩。
- 不新增复杂状态管理或缓存层，仅在图表重建路径补回当前时间窗，满足最小可用修复。
- 数据表默认收起使用原生 `details`，实现简单、离线兼容稳定、维护成本低。

### 语义对齐说明

- 本轮不新增 `triggerSource/core` 相关输入输出结构。
- 与 `LinkNodeType.TRIGGER_SOURCE/CORE` 的映射关系保持不变。
- 不新增旧术语写入路径，也不调整持久化字段。
- 兼容层无新增改动。
- 残余风险：无。

### 步骤 1：修复录制选集重复序号
- **操作对象**：`StatePanelRecordingScreen`
- **具体动作**：移除录制子集按钮文案中对序号的重复拼接，仅显示已有展示文本与勾选前缀。
- **预期结果**：节点在录制选集列表中不再出现重复序号。
- **关键里程碑**：否

- **操作对象**：`StatePanelToolScreen`
- **具体动作**：适当增大 GUI 主面板宽度，并同步调整状态列相关列宽/间距常量与布局算法。
- **预期结果**：状态列在常见功率值下可完整显示或明显改善截断问题。

- **操作对象**：`RecordingChart.tsx`
- **具体动作**：在 `uPlot` 重建后重新应用当前 `xWindow`，确保曲线显隐切换不会破坏已有视窗。
- **预期结果**：关闭全部曲线后再次启用任一曲线，时间窗保持稳定。

- **操作对象**：`RecordingViewer.tsx`、`app.css`
- **具体动作**：将具体样本表改为折叠面板，默认关闭，并补充必要样式。
- **预期结果**：曲线页默认首屏更聚焦图表，数据表按需展开。
- **关键里程碑**：否
