# hide节点命中门槛与箭头增强

生成时间：2026-04-28 12:50:30
文件名：2026-04-28_125030_hide节点命中门槛与箭头增强.md

## 任务背景

当前 `hide` 节点已经具备智能眼镜下的幽灵模型和手持面编辑器时的启用面箭头，但仍有两个交互问题：

- 未佩戴智能眼镜时，`hide` 节点仍可能被普通准星命中，并出现 vanilla 选中框。
- 启用面箭头在游戏内观感过弱，表现为尺寸偏小、透明度偏低或被深度测试吞掉，导致几乎不可见。

本轮需要继续收紧 `hide` 节点的“只在智能眼镜语境下存在”表达，同时把箭头可视化调到可读状态。

## 方案详情

### 现状分析

- `HideCoreBlock` 与 `HideSyncTriggerSourceBlock` 目前已配置 `noCollission()`，但还没有按智能眼镜状态改写命中/轮廓形状。
- `HideNodeGhostRenderer` 已能在智能眼镜下渲染幽灵模型和启用面箭头，但箭头仍使用保守的局部参数与普通线渲染表达。

### 技术方案

- 对两个 `hide` 节点方块统一增加“智能眼镜感知形状”：
  - 未佩戴智能眼镜：返回空形状
  - 佩戴智能眼镜：返回完整方块形状
- 该规则同时覆盖命中、选中白框和普通交互准星入口，从而实现“未戴眼镜即不可选中、不可普通破坏”。
- 继续保留方块实体真实存在的服务端语义，不改节点真值或配对图。
- 重做启用面箭头显示：
  - 使用更粗的专用线渲染层
  - 关闭深度测试
  - 增大箭杆长度和箭头头部尺寸
  - 箭头伸出方块外，避免被幽灵模型遮住

### 影响范围

- `src/main/java/com/makomi/block/HideCoreBlock.java`
- `src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java`
- `src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java`
- `docs_dev/reviews/` 本轮审查文档

## 预期结果

- 未佩戴智能眼镜时，`hide` 节点对普通玩家近似不存在：不再出现选中框，也不能普通准星命中或挖掘。
- 佩戴智能眼镜后，`hide` 节点恢复正常命中、编辑与回收语义。
- 手持面编辑器时，启用面箭头能稳定可见。
