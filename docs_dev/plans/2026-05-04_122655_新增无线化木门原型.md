# 新增无线化木门原型

生成时间：2026-05-04 12:26:55

## 任务背景

现有无线化原型已经覆盖了拉杆、按钮、压力板、活塞、红石灯、海晶灯等基本件。当前需要继续补一个“无线化木门”原型，要求它属于 `core`，保留玩家右键直接开关门的原版交互，同时不再读取原版邻居红石输入，而是只把无线链路输入转接成原版木门的开关表现。

## 方案详情

### 现状分析

- 现有无线 `core` 原型统一走 `WirelessBlockNodeSupport + WirelessCoreBlockEntity` 路径，负责 serial 继承、掉落回写、节点注销与无线输入到原版表现的同步。
- 原版木门是双半块结构，真正的逻辑状态由 `OPEN/HINGE/HALF/FACING/POWERED` 等属性共同承载，因此节点实体不能像普通整块一样简单挂在“任意半块”上。
- 当前实现边界是：
  - 保留玩家右键开门；
  - 不保留原版从邻居读取红石输入；
  - 无线输入只驱动原版“开/关门”表现，不额外承担原版红石输出职责。

### 技术方案

1. 新增 `WirelessOakDoorBlock`，继承原版 `DoorBlock`：
   - 保留原版木门的玩家交互；
   - 覆写邻居更新入口，屏蔽原版邻居红石输入；
   - 放置、掉落、移除与配对界面复用 `WirelessBlockNodeSupport`；
   - 节点实体只挂在下半块。
2. 新增 `WirelessOakDoorBlockEntity`，继承 `WirelessCoreBlockEntity`：
   - 把无线解析出的 `active` 同步到门的 `OPEN` 可见态；
   - 同步上下半块状态，保持原版双半块表现一致；
   - 不把 `POWERED` 重新接回原版邻居红石语义。
3. 接通注册与资源：
   - 新增 block/item/block entity 注册；
   - 客户端远外显 HUD、GUI 上下文 token、短名称文案接线；
   - 复用原版橡木门模型、贴图和 item 模型；
   - 加入无线化转化配方、loot、挖掘标签与测试白名单。

### 影响范围

- 方块/方块实体：无线化木门原型
- 注册表：`ModBlocks / ModItems / ModBlockEntities / ModItemGroups`
- 客户端：远外显 HUD 与配对界面上下文
- 资源：blockstates / item model / lang / loot / recipe / tags
- 测试：运行时配方资源布局白名单
