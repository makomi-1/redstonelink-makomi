# 箭头外移与hide物品单层模型

生成时间：2026-04-28 20:01:14
文件名：2026-04-28_200114_箭头外移与hide物品单层模型.md

## 任务背景

上一轮已让可见节点与隐藏节点共享定向箭头，并修正了 `hide` 物品对 `_hide` 贴图的引用。实机验证后又发现两个显示问题：

1. 方向箭头虽然已经能看见，但大部分几何仍位于方块体积内部，观感上会被方块贴图遮挡。
2. `hide` 节点物品虽然已改为块显示，但当前仍是双层模型；本轮要求只保留最外层。

本轮继续保持“只修表现层，不动定向真值”的约束。

## 方案详情

### 现状分析

- 公共箭头几何位于 `DirectionalFaceVectorRenderSupport`，当前箭杆起点和终点仍从方块内部起笔。
- `hide` 物品模型当前引用 `redstonelink:block/dual_layer_cube`，因此依然会渲染内层。

### 技术方案

1. 将公共箭头整体外移到方块表面之外：
   - 保留现有主题色、线宽和方向映射。
   - 只调整箭杆起点/终点，让整根箭头落在方块体积外，避免和方块贴图重叠。

2. 将 `hide core` / `hide sync triggerSource` 物品改为单层块模型：
   - 继续保持 3D 块显示。
   - 从双层 `dual_layer_cube` 改为单层 cube。
   - 仅使用 `item/*_hide.png` 作为外层纹理。

### 影响范围

- 客户端渲染：
  - `src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java`
- 资源模型：
  - `src/main/resources/assets/redstonelink/models/item/hide_core.json`
  - `src/main/resources/assets/redstonelink/models/item/hide_sync_trigger_source.json`
- 文档：
  - `docs_dev/plans/`
  - `docs_dev/reviews/`
