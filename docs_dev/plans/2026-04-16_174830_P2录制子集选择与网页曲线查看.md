# P2录制子集选择与网页曲线查看

生成时间：2026-04-16 17:48:30
文件名：2026-04-16_174830_P2录制子集选择与网页曲线查看.md

## 任务背景

当前 `P2` 已完成状态面板录制入口、录制会话导出与网页端基础结果浏览，但还缺少两项直接影响可用性的能力：

- 录制 GUI 还不能从“当前状态面板订阅列表”里选出本次要录制的节点子集。
- 网页端还只能查看单节点样本表，不能以多条曲线进行录制结果分析。

本轮目标是在不引入实时推流、不扩展到全世界自由选点、不提前做网络编辑器的前提下，补齐“录制子集选择 + 结束后网页曲线查看”的最小可用闭环。

## 方案详情

### 现状分析

- 录制 GUI 当前只展示订阅预览，没有子集选择状态。
- 服务端录制开始逻辑会直接读取状态面板工具中的全部订阅并挂载采样。
- `RecordingBundle` 已包含 `tick`、`inputPower`、`outputPower`、`online`、`active` 等样本字段，足够支撑曲线绘制。
- 网页端当前已具备本地 recording bundle 读取能力，但没有图表组件和多曲线状态管理。

### 技术方案

#### 1. 录制 GUI 子集选择

- 在录制 GUI 中为当前订阅列表维护本地“已选集合”。
- 默认全选，补 `全选` / `清空` 操作，并在界面中显示“已选 / 总数”。
- 开始录制时，将“已选节点 key 列表”随开始录制请求发送到服务端。
- 若未选择任何订阅，则在客户端拦截并给出反馈。

#### 2. 服务端录制会话过滤

- 扩展开始录制协议与 `StartRequest`，新增“选中节点 key 列表”字段。
- 服务端仍读取状态面板工具中的真实订阅列表作为真值来源。
- 以“真实订阅列表 ∩ 已选节点 key 集合”得到本次录制对象，再进入挂载流程。
- 若过滤后为空，则拒绝开始录制。
- 会话快照新增 `selectedCount`，供 GUI 展示当前“已选 / 总订阅 / 已挂载”状态。

#### 3. 网页曲线图查看

- 延续当前 `React + Vite` 底座，引入轻量图表库 `uPlot`。
- 仅围绕功率曲线实现最小可用图表页：
  - 支持多条曲线同时显示
  - 支持逐条显示 / 隐藏
  - 支持左右平移与缩放
  - 支持横坐标模式切换：`relative` 与 `raw`
- `relative` 模式仅在前端派生：`sample.tick - manifest.startedTick`。
- 原始 bundle 继续保留原始 `tick` 真值，不改导出结构。
- 原有样本表保留，作为调试和兜底视图。

### 技术取舍

- 不把一次性录制子集写回 NBT，避免把短期 UI 状态混入长期订阅真值。
- 不改 `RecordingBundle` 存储结构，避免破坏当前导出链路与后续兼容性。
- 不引入重型图编辑框架，只补轻量图表能力，确保 `P2` 范围稳定。
- `online/active` 暂不做单独轨道，先聚焦用户最关心的功率曲线。

### 影响范围

- 客户端状态面板录制 GUI 与录制开始请求
- 服务端录制会话服务与录制协议编码解码
- 网页端 recording viewer、前端依赖与样式
- 录制会话文案、前端文案与必要验证逻辑

## 原子步骤清单

### 步骤 1：扩展开始录制协议
- **操作对象**：`StatePanelNetwork`、`StatePanelNetworkPayloadSupport`、`StatePanelNetworkServerHandlerSupport`
- **具体动作**：给开始录制请求新增“选中节点 key 列表”，并贯穿编码、解码与服务端处理入口
- **预期结果**：客户端可把本次录制子集明确传给服务端
- **关键里程碑**：是

### 步骤 2：补齐服务端过滤与会话快照
- **操作对象**：`StatePanelRecordingSessionService`
- **具体动作**：在 `StartRequest` 中加入选中集合，按真实订阅执行交集过滤、空集校验，并扩展会话快照
- **预期结果**：录制对象仍受当前订阅列表约束，同时支持本次子集录制
- **关键里程碑**：是

### 步骤 3：实现录制 GUI 子集选择
- **操作对象**：`StatePanelRecordingScreen`
- **具体动作**：把订阅预览改成可勾选列表，补选择按钮、计数展示与开始前校验
- **预期结果**：玩家可以从当前订阅列表中选择录制子集
- **关键里程碑**：是

### 步骤 4：实现网页多曲线查看
- **操作对象**：`webapp/package.json`、`webapp/src/App.tsx`、新增图表组件与样式
- **具体动作**：接入图表库，建立多曲线状态模型，实现显隐、平移、缩放与横坐标模式切换
- **预期结果**：录制结果可在网页端以多条曲线分析查看
- **关键里程碑**：是

### 步骤 5：构建验证与审查文档
- **操作对象**：`webapp` 构建、Gradle 测试、`docs_dev/reviews`
- **具体动作**：执行网页构建与项目测试，整理本轮五段式审查文档
- **预期结果**：形成可追溯验证结果与实现审查记录
- **关键里程碑**：是

## 预期结果

- 状态面板录制 GUI 可以基于当前订阅列表选择录制子集。
- 服务端录制只会挂载当前订阅列表内且被选中的节点。
- 录制结束后，网页端可以以多条功率曲线查看结果，并支持显隐、平移、缩放与 `relative/raw` 横坐标切换。
- 原有录制导出结构保持稳定，不引入实时推流和额外持久化格式。
