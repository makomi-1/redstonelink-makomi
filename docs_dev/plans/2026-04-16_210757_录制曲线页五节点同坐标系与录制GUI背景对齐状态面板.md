# 录制曲线页五节点同坐标系与录制GUI背景对齐状态面板

生成时间：2026-04-16 21:07:57

## 任务背景
- 当前 recording 曲线页只能单节点查看，无法在同一坐标系下同时对比多个节点的曲线。
- 用户希望最多支持 5 个节点同时显示在一个坐标系窗口里，而不是拆成多个独立图表。
- 录制 GUI 的背景显示还没有完全对齐状态面板，希望改成参考状态面板的 alpha 风格显示方式。

## 方案详情

### 现状分析
- `RecordingViewer` 当前维护的是单个 `selectedRecordingNodeKey`，只会给图表组件传入一个节点的样本。
- `RecordingChart` 当前只渲染一组 `samples`，图例关闭，时间窗按单节点样本域计算。
- `StatePanelRecordingScreen` 当前在 `renderBackground()` 里先调用 `renderTransparentBackground()`，再叠加 `STATE_PANEL` 区域背景；状态面板自身没有这层额外遮罩。

### 技术方案
- 将 recording 页节点选择改为“最多 5 个节点”的多选模型，默认仍选中第一个节点，允许用户继续增减选择。
- 图表组件保持单个 `uPlot` 实例和单个坐标系，但输入改为多节点样本组，统一计算联合横坐标范围，并在一张图里渲染多节点曲线。
- 视觉编码采用“节点颜色 + 指标线型”：
  - 同一节点共用一组基色
  - `inputPower` 使用实线
  - `outputPower` 使用虚线
- 录制样本表改为按“已选节点”分组展示，继续默认折叠，避免与主图争夺空间。
- 录制 GUI 背景渲染去掉额外整屏透明遮罩，仅保留和状态面板一致的 `STATE_PANEL` 区域背景。
