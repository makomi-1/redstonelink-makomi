# sync持久兜底默认关闭

生成时间：2026-03-31 17:53:33
文件名：2026-03-31_175333_sync持久兜底默认关闭.md

## 任务背景

当前 `crosschunk.syncSignalPersistent` 默认值仍为 `true`，但现有 `sync` 跨区块恢复主链已经是目标上线 replay 与来源快照恢复。无限期持久队列更多承担兜底补投递职责，默认开启会放大其在语义上的存在感，不利于和当前实现行为保持一致。

## 方案详情

### 现状分析

- 配置解析器将 `crosschunk.syncSignalPersistent` 缺省值解析为 `true`。
- 配置模板和使用说明均将其描述为默认开启。
- 配置解析测试也以默认 `true` 为断言基线。
- 现有运行逻辑无需改动，本次只需调整默认值与说明文案。

### 技术方案

- 将 `crosschunk.syncSignalPersistent` 的默认解析值从 `true` 调整为 `false`。
- 同步更新配置模板，将该项描述为“仅用于无限期兜底/补投递，默认关闭”。
- 同步更新使用说明，明确主恢复路径是目标 attach replay，持久 `sync` 队列仅作兜底。
- 调整配置解析测试默认断言与非法值回退断言。
