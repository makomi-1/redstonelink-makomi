# graph节点标签精简与布局去重叠优化

生成时间：2026-04-17 22:01:08
文件名：2026-04-17_220108_graph节点标签精简与布局去重叠优化.md

## 任务背景

当前 graph 视图里，普通节点卡片仍然会在主标题下方显示一行副字段；同时自动布局虽然已经做了分块和横向利用率优化，但整体坐标分布仍然偏规则，导致多条连线在某些横段或竖段上出现明显重叠。  
本轮目标是在不改变 `triggerSource/core` 真值语义的前提下，继续优化图内节点标识与自动布局观感。

## 方案详情

### 现状分析

- 普通节点标签由 `buildNodeLabel` 构造，当前仍渲染两行文本。
- 自动布局由 `buildLaneLayout`、`buildComponentLayout`、`buildAutoLayoutPositions` 共同完成，内部使用规则网格和固定层间距，因此结构稳定，但线段重叠偏多。
- 聚合块标签仍承担“分组数量/展开态”说明职责，不适合跟普通节点一起收成单行。

### 技术方案

- 普通节点图内标识只保留一行主标题，移除副字段渲染。
- 自动布局不采用随机扰动，而采用“确定性微偏移 + 略增间距 + 列/块错位”：
  - 同一结构每次刷新仍保持稳定位置
  - 通过基于节点标识的固定偏移，打散过度规则的横纵对齐
  - 轻微放大列距、行距和块间距，减少边长段重叠
- 如有必要，微调节点标签样式，让单行标题下的卡片高度与留白仍然自然。

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- `webapp/src/app.css`

## 原子步骤清单

### 步骤 1：精简普通节点标签
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：修改 `buildNodeLabel`，移除副字段，仅保留主标题
- **预期结果**：图内普通节点只显示序号/别名展示文本
- **关键里程碑**：是

### 步骤 2：优化布局分布
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：为 lane 与 component 位置计算增加稳定微偏移、列间错位与略增间距
- **预期结果**：布局稍微散开，节点不再过于整齐，多条边的完全重叠减少
- **关键里程碑**：是

### 步骤 3：收口标签样式
- **操作对象**：`webapp/src/app.css`
- **具体动作**：微调节点标签的 gap/对齐，匹配单行主标题效果
- **预期结果**：普通节点卡片更紧凑自然
- **关键里程碑**：否

### 步骤 4：本地验证
- **操作对象**：前端构建链路
- **具体动作**：执行 `npm.cmd run typecheck` 和 `.\gradlew.bat buildWebapp --no-daemon`
- **预期结果**：确认改动可编译、可打包
- **关键里程碑**：是

## 预期结果

完成后，graph 里的普通节点标签会更简洁；自动布局在保持稳定可复现的前提下，视觉上更松弛，连线完全重叠的情况减少，主画布阅读性提升。
