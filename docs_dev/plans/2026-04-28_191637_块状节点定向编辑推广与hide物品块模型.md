# 块状节点定向编辑推广与hide物品块模型

生成时间：2026-04-28 19:16:37
文件名：2026-04-28_191637_块状节点定向编辑推广与hide物品块模型.md

## 任务背景

当前定向面编辑已经覆盖 `hide core / hide sync triggerSource` 与可见 `core / sync triggerSource`，但仍未推广到其它块状节点。与此同时，`hide` 节点物品仍使用平面物品贴图渲染，不符合当前“作为块物品展示”的预期。本轮需要在不改变既有 `triggerSource -> core` 方向语义的前提下，把块状节点统一纳入定向面集体系，并把 `hide` 物品改回块模型渲染。

## 方案详情

### 现状分析

- `LinkCoreBlock` 与 `LinkSyncEmitterBlock` 已具备 `NodeFaceSetBlockStateSupport` 面集属性与运行时裁剪逻辑。
- `DirectionalFaceEditorItem` 当前只支持 `LinkCoreBlock` 与 `LinkSyncEmitterBlock`。
- `LinkSignalEmitterBlock`、`AbstractLinkFilterBlock`、`LinkChunkActivatorBlock`、`LinkRepeaterBlock` 仍未接入面集属性。
- 过滤器与区块激活器的输入采样分别散落在 block 与 block entity 内，当前都按 `getBestNeighborSignal(...)` 全向读取。
- `hide_core.json` 与 `hide_sync_trigger_source.json` 仍是 `minecraft:item/generated`，没有沿用块物品模型。

### 技术方案

- 将块状 `triggerSource` 的定向输入能力下沉到 `LinkSignalEmitterBlock`，覆盖 `toggle/pulse/sync/hide sync` 这一支。
- 将过滤器与区块激活器统一接入面集属性，并把“邻居最大输入采样”改为共享 helper：若存在面集属性，则只对启用面取 `max`；否则保持原全向逻辑。
- 将转发器接入面集输出能力，并与 `core` 一样在编辑器里按“点击面反向写入”处理。
- 将 `DirectionalFaceEditorItem` 的支持范围扩大到：
  - `LinkSignalEmitterBlock`
  - `AbstractLinkFilterBlock`
  - `LinkChunkActivatorBlock`
  - `LinkRepeaterBlock`
- `hide` 物品模型改为直接引用对应 block model，仅调整 model json，不改贴图资源。

## 原子步骤清单

### 步骤 1：修正 hide 物品模型
- **操作对象**：`hide_core.json`、`hide_sync_trigger_source.json`
- **具体动作**：将物品模型父级从 `minecraft:item/generated` 改为对应 block model
- **预期结果**：`hide` 节点物品按块模型渲染
- **关键里程碑**：否

### 步骤 2：为块状 triggerSource 下沉面集输入能力
- **操作对象**：`LinkSignalEmitterBlock`、`LinkSyncEmitterBlock`
- **具体动作**：追加面集属性、默认全向与按启用面采样输入逻辑，清理同步发射器重复实现
- **预期结果**：块状 `triggerSource` 统一支持定向输入
- **关键里程碑**：是

### 步骤 3：为过滤器与区块激活器接入面集输入
- **操作对象**：`AbstractLinkFilterBlock`、`AbstractLinkFilterBlockEntity`、`LinkChunkActivatorBlock`、`LinkChunkActivatorBlockEntity`
- **具体动作**：增加面集属性并统一输入采样口径，编辑后立即刷新外显与真值
- **预期结果**：过滤器与区块激活器按面集输入工作
- **关键里程碑**：是

### 步骤 4：为转发器接入面集输出
- **操作对象**：`LinkRepeaterBlock`
- **具体动作**：增加面集属性、默认全向，并在红石输出方法中做面裁剪
- **预期结果**：转发器支持定向输出
- **关键里程碑**：是

### 步骤 5：扩展定向编辑器支持范围
- **操作对象**：`DirectionalFaceEditorItem`
- **具体动作**：支持新增块状节点，并区分输入型与输出型块的写入方向；补过滤器与区块激活器的立即刷新
- **预期结果**：一个工具统一编辑新增块状节点
- **关键里程碑**：是

### 步骤 6：补集成测试并回归验证
- **操作对象**：`HideNodeDirectionalIntegrationTest.java`、Gradle 测试任务
- **具体动作**：补充 `repeater`、块状 `triggerSource`、过滤器、区块激活器的定向测试，并运行编译与全量测试
- **预期结果**：本轮改动有自动化回归证据
- **关键里程碑**：是

## 预期结果

- `hide` 节点物品按块模型渲染。
- `toggle/pulse/sync/hide sync`、过滤器、区块激活器、转发器全部支持定向面编辑。
- 可见节点默认保持全向，`hide` 节点默认保持空面集。
- `triggerSource/core` 命名与方向语义保持不变，且本轮改动具备自动化测试覆盖。
