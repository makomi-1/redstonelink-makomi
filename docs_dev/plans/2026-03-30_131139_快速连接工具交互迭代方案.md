# 快速连接工具交互迭代方案

生成时间：2026-03-30 13:11:39
文件名：2026-03-30_131139_快速连接工具交互迭代方案.md

## 任务背景

在快速连接工具第一阶段实现基础上，继续调整交互语义与客户端反馈：
- 左键从“应用”改为“采集”
- 站立右键从“切模式”改为“应用”
- 模式切换改为客户端可配置按键，默认 `B`
- GUI 打开时禁止按键切模式
- 采集后根据命中对象自动切换序号缓存类型
- `core` 与 `triggerSource` 描边改为不同颜色
- `channel` 模式仅预留频道缓存/采集/应用接口，当前版本禁止切换进入，并明确提示未来扩展

## 方案详情

### 现状分析

- 当前 quick-link 客户端交互仍以“左键应用”为主，需要改成“左键采集 + 站立右键应用”。
- 现有客户端配置体系已支持可配置按键，可直接复用，不需要新开配置文件。
- 当前工具缓存只有基础读写，需要补“序号采集增量去重”和“频道缓存接口预留”的数据层入口。
- 当前描边只覆盖应用场景且固定红色，需要改为按命中对象类型着色。
- `channel` 模式当前没有真实业务承接，因此只能保留接口和提示，不能让玩家切换进入后误以为可用。

### 技术方案

- 扩展客户端配置，新增 quick-link 模式切换键，默认值为 `key.keyboard.b`。
- 模式切换由客户端按键驱动；若尝试从 `serial` 切到 `channel`，直接拦截并提示“频道模式将在未来扩展”。
- 站立右键应用改为客户端右键命中拦截后发送 C2S 应用请求，避免与按钮/拉杆等节点自身交互冲突。
- 左键采集新增独立 C2S 请求与服务端采集服务。
- 序号模式采集规则：
  - 同模式同类型：增量追加并去重
  - 其他情况：重建当前序号缓存
- 频道模式接口独立预留，但当前采集/应用只返回“未来扩展”提示。
- HUD 结果提示统一为泛化反馈 payload，供采集、应用和模式限制共用。

### 影响范围

- 客户端配置与键位注册
- quick-link 网络 payload 与服务端接包
- quick-link 数据模型、采集服务、应用服务
- quick-link 客户端交互回调、描边渲染、GUI 文案
- quick-link 相关单元测试

## 原子步骤清单

### 步骤 1：扩展客户端 quick-link 键位配置
- **操作对象**：客户端配置快照、解析器、模板、客户端初始化入口
- **具体动作**：新增 quick-link 模式切换键配置，默认 `B`，并在 GUI 打开时禁止触发
- **预期结果**：快速连接工具模式切换脱离右键交互
- **关键里程碑**：是

### 步骤 2：重构工具基础交互
- **操作对象**：`QuickLinkToolItem`
- **具体动作**：移除站立右键切模式，只保留潜行右键开 GUI；同步更新 tooltip
- **预期结果**：物品本体交互与目标语义一致
- **关键里程碑**：否

### 步骤 3：扩展 quick-link 数据模型
- **操作对象**：`QuickLinkToolData`
- **具体动作**：新增序号采集增量去重入口，并为频道缓存增加独立语义封装与预留方法
- **预期结果**：序号缓存与频道缓存边界清晰，后续可独立扩展
- **关键里程碑**：是

### 步骤 4：新增采集请求与服务端采集服务
- **操作对象**：quick-link 网络层、服务端处理层、采集服务
- **具体动作**：新增 collect 请求、泛化反馈回执与具体成功/失败提示
- **预期结果**：左键采集闭环完整
- **关键里程碑**：是

### 步骤 5：调整右键应用链路
- **操作对象**：客户端命中拦截、服务端应用处理
- **具体动作**：将应用入口迁移为站立右键命中方块，并继续复用既有方向校验与写控闭环
- **预期结果**：`triggerSource -> core` 单向写入约束保持不变
- **关键里程碑**：是

### 步骤 6：重做描边反馈
- **操作对象**：`QuickLinkOutlineRenderer`
- **具体动作**：按命中对象类型着色，`core` 亮蓝，`triggerSource` 亮橙
- **预期结果**：采集与应用都能获得直观目标语义反馈
- **关键里程碑**：否

### 步骤 7：补测试与回归
- **操作对象**：quick-link 相关测试
- **具体动作**：补数据层与 payload 契约测试，并执行全量 Gradle 回归
- **预期结果**：本轮迭代具备可追溯验证证据
- **关键里程碑**：是

## 预期结果

- 玩家手持快速连接工具时，左键用于采集、站立右键用于应用、潜行右键用于打开 GUI
- `serial` 模式完整可用，支持自动切换缓存类型、增量采集、去重与具体反馈
- `channel` 模式仅保留独立接口与未来扩展提示，当前版本不可切换进入
- 命中 `core` 显示亮蓝描边，命中 `triggerSource` 显示亮橙描边
