# 当前连接显示与图编辑节点池优化

生成时间：2026-04-25 17:48:25
文件名：2026-04-25_174825_当前连接显示与图编辑节点池优化.md

## 任务背景
本轮需要在不改动链路真值语义的前提下，统一优化“当前连接”相关展示，并补齐网页图编辑前端的节点池交互。用户明确要求：
- 所有“当前连接”显示支持 `#1:#100` 形式的结构化范围表达；
- 若区间中存在别名节点，则必须在别名节点处断开，不能跨别名压缩；
- 修复录制曲线查看页 tooltip 背景过窄导致字段溢出的问题；
- 在网页图编辑前端中，为“孤立节点池”增加 `triggerSource/core/repeater` 切换；
- 将“另一模式节点池”按当前模式改名为“频道节点池 / 序号节点池”。

## 方案详情

### 现状分析
- 现有 `SerialDisplayFormatUtil` 是通用纯序号结构化工具，直接修改会影响过滤器、区块激活器、配置表达式等非“当前连接”口径。
- 现有“当前连接”展示入口分散在物品 tooltip、pairing GUI、pairing tooltip、近外显 HUD，主要复用 `DisplayTextListFormatUtil` 直接拼接展示文本列表。
- 物品与快照层已经同时具备序号和展示文本，因此可以在展示层独立实现“纯序号连续压缩、别名节点断开”的摘要规则，无需改变图真值。
- 前端 `RecordingChart` 的 tooltip 宽度同时在 TS 与 CSS 中写死，且标签文本强制单行省略，是当前字段越界的主要原因。
- 网页图编辑前端的“孤立节点池”仅支持 `triggerSource/core` 两类，且“另一模式节点池”为固定文案，不够直观。

### 技术方案
1. 新增“当前连接摘要专用格式化工具”，输入对齐后的 `serial + displayText` 列表：
   - 纯 `#N` 节点允许压缩为 `#A:#B`；
   - 任意别名节点如 `门厅(#3)` 保持原样，并强制断开连续区间；
   - 保持现有 `(+n)` 截断提示与换行能力。
2. 将真正属于“当前连接”语义的展示入口统一切换到新工具：
   - 物品 tooltip；
   - pairing GUI 主行；
   - pairing tooltip；
   - 近外显 HUD 当前连接行。
3. 录制曲线 tooltip 放宽宽度约束，并取消导致字段外溢的单行强截断，改为更稳妥的可换行布局。
4. 网页图编辑前端在“孤立节点池”中增加池类型切换：
   - 保持单列列表区域；
   - 支持查看 `triggerSource/core/repeater` 三类孤立对象；
   - 不新增横向并列列数，避免面板过挤。
5. 将“另一模式节点池”改为按当前模式动态命名：
   - 序号模式下显示“频道节点池”；
   - 频道模式下显示“序号节点池”。

### 影响范围
- Java 展示格式化工具与其测试
- 物品 tooltip 与客户端 pairing / HUD 文本构建
- Web 前端录制曲线 tooltip 布局
- Web 图编辑前端节点池数据结构、视图切换与测试
