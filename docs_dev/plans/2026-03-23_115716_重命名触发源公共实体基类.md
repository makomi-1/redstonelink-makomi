## 任务背景
当前 `LinkButtonBlockEntity` 是历史语义遗留。它实际承载的是所有 `triggerSource` 实体的公共实现层，而不是“按钮专属行为”。

用户已确认本轮直接去掉该兼容壳，不保留过渡类，只做这层公共实体基类及其引用的重命名，不扩大到更广范围的历史命名清理。

## 方案详情

### 现状分析
- `LinkButtonBlockEntity` 仅负责固定 `TRIGGER_SOURCE -> CORE` 语义，以及维护运行态 `simulatedInputPower`。
- `TriggerSourceBlockEntity` 已是更高一层的语义抽象基类，负责序号、配对和派发链路。
- 当前 `LinkButtonBlockEntity` 被按钮、发射器、同步拉杆、sync replay 和输入器共同依赖。
- 世界兼容性依赖 block entity registry id，而不是 Java 类名；该类也无持久化字段名负担。

### 技术方案
- 将 `LinkButtonBlockEntity` 直接重命名为 `LinkTriggerSourceBlockEntity`。
- 更新所有继承、构造器泛型、导入、抽象返回类型和 `instanceof` 引用。
- 同步修正文档注释，将“复用 LinkButtonBlockEntity”收敛为“复用 triggerSource 公共实体层”。
- 不保留旧类作为兼容壳。
