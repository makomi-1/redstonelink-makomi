# graph中键拖拽整页滚动修复

生成时间：2026-04-18 00:05:24
文件名：2026-04-18_000524_graph中键拖拽整页滚动修复.md

## 任务背景

graph 视图当前已将中键拖拽配置为 ReactFlow 画布平移，但在 Windows 浏览器环境下，中键按下时仍会触发浏览器默认的整页自动滚动，导致不仅 graph 可视化窗口平移，整个页面也会一起滚动。本轮目标是在不改 `triggerSource/core` 真值、snapshot、draft 和服务端语义的前提下，把中键作用范围限制在 graph 画布内部。

## 方案详情

### 现状分析

- `ReactFlow` 已启用 `panOnDrag={[1]}`，中键本身已被用于画布平移
- 外层 `graph-canvas` 容器尚未拦截浏览器默认的中键行为
- 画布容器没有显式限制滚动链，外层页面仍可能承接滚动

### 技术方案

1. 在 `graph-canvas` 容器增加中键默认行为拦截，只对中键事件执行 `preventDefault()`
2. 保留事件传播，让 ReactFlow 仍能接收到中键拖拽并执行内部平移
3. 在 `.graph-canvas` 样式上增加 `overscroll-behavior: contain;`，把滚动影响限制在图窗口内部

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- `webapp/src/app.css`
- `docs_dev/reviews/` 审查文档

## 原子步骤清单

### 步骤 1：拦截中键默认滚动
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：为 `graph-canvas` 容器新增中键按下与中键点击默认行为拦截
- **预期结果**：浏览器不再启动整页自动滚动
- **关键里程碑**：是

### 步骤 2：限制滚动链
- **操作对象**：`webapp/src/app.css`
- **具体动作**：为 `.graph-canvas` 增加 `overscroll-behavior: contain;`
- **预期结果**：滚动影响不再向页面外层传递
- **关键里程碑**：是

### 步骤 3：回归验证
- **操作对象**：`webapp` 与 Gradle 构建测试链路
- **具体动作**：执行 `npm.cmd run typecheck`、`.\gradlew.bat buildWebapp --no-daemon`、`.\gradlew.bat test testIntegration testClient testSlow --no-daemon`
- **预期结果**：确认修复未引入新的前端或集成回归
- **关键里程碑**：是

## 预期结果

中键拖拽时只平移 graph 可视化窗口，不再带动整个页面滚动；左键框选、节点拖拽、缩放和右侧面板交互保持原样。
