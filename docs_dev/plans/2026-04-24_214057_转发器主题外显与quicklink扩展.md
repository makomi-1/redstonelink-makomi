# 转发器主题外显与quicklink扩展

生成时间：2026-04-24 21:40:57
文件名：2026-04-24_214057_转发器主题外显与quicklink扩展.md

## 任务背景
本轮需要继续完善转发器主题接入，具体包括三部分：一是把转发器远外显的序号显示文本改为亮绿色，并让其它 HUD 也像转发器一样拥有各自独立的亮色边框；二是从转发器打开的 `triggerSource/core` 配对 GUI 统一切到转发器主题且不显示图标；三是把快速连接工具扩展到可根据缓存类型写入转发器对应配置，而不是把转发器当普通 `core` 处理。

## 方案详情

### 现状分析
- 转发器近 HUD 已有绿色主题，但远外显仍走通用节点文本颜色；其它近 HUD 大多仍使用默认深色面板边框。
- `CorePairingScreen` / `TriggerSourcePairingScreen` 已携带 `displayContextToken=link_repeater`，并且当前上下文下已不显示图标，但背景与控件皮肤仍沿用普通 `core/triggerSource` 主题。
- `QuickLinkApplyService` 命中转发器时仍会落入普通 `PairableNodeBlockEntity` 分支，按直接配对边处理，尚未写入 `RepeaterConfigSnapshot.inputSerialExpression/outputSerialExpression`。

### 技术方案
- HUD 侧扩展现有颜色/面板预设，不新增渲染器结构：远外显通过公共颜色分发给转发器独立亮绿色；近 HUD 通过面板主题分发给 core / triggerSource / filter / chunk activator / repeater 各自亮色边框。
- GUI 侧继续复用现有 `displayContextToken=link_repeater`，把背景预设、输入框样式、按钮样式统一切换到转发器主题；图标保持为空，不额外新增 screen。
- quick-link 侧新增转发器专用应用分支：仅接受 `serial` 模式，`triggerSource` 缓存写入输入配置，`core` 缓存写入输出配置，并复用现有 replace / append / remove 三态合并逻辑，保持延迟配置不变。

### 影响范围
- 客户端 HUD 与远外显：`src/client/java/com/makomi/client/render/**`
- 配对 GUI 主题：`src/client/java/com/makomi/client/screen/**`
- 快速连接工具应用逻辑：`src/main/java/com/makomi/data/QuickLinkApplyService.java`
- 回归测试：`src/test/java/com/makomi/data/**`

## 原子步骤清单

### 步骤 1：补齐 HUD 与远外显主题色
- **操作对象**：`LinkSerialOverlayRenderCommon`、`LinkNodeFarOverlayRenderer`、`LinkSerialHudOverlayDrawSupport`、`LinkSerialHudOverlayRenderer`
- **具体动作**：为转发器远外显序号文本接入亮绿色；为 core / triggerSource / filter / chunk activator / repeater 的近 HUD 增加独立亮色边框预设并替换调用点
- **预期结果**：所有 HUD 都有各自亮色边框，转发器远外显颜色符合主题
- **关键里程碑**：是

### 步骤 2：切换转发器入口下的 pairing GUI 主题
- **操作对象**：`CorePairingScreen`、`TriggerSourcePairingScreen`
- **具体动作**：识别 `displayContextToken=link_repeater` 时切换到转发器背景与控件皮肤，并保持头部无图标
- **预期结果**：从转发器打开的 `triggerSource/core` GUI 统一使用转发器主题
- **关键里程碑**：是

### 步骤 3：扩展 quick-link 到转发器配置
- **操作对象**：`QuickLinkApplyService` 及相关转发器配置模型
- **具体动作**：新增转发器命中分支；serial 模式按缓存类型分别更新 `inputSerialExpression/outputSerialExpression`，并复用三态编辑语义
- **预期结果**：quick-link 可按缓存类型写入转发器对应配置
- **关键里程碑**：是

### 步骤 4：补测试与回归
- **操作对象**：`src/test/java/com/makomi/data/QuickLinkApplyServiceTest.java` 等
- **具体动作**：补充转发器 quick-link 配置应用测试，随后运行 `.\gradlew.bat test testIntegration testClient testSlow --no-daemon`
- **预期结果**：改动有自动化验证与可追溯结论
- **关键里程碑**：是

## 预期结果
- 转发器远外显序号显示文本为亮绿色
- 所有近 HUD 面板具备各自独立的亮色边框
- 从转发器入口打开的 `triggerSource/core` 配对 GUI 使用转发器主题且不显示图标
- 快速连接工具可按缓存类型应用到转发器输入/输出配置
