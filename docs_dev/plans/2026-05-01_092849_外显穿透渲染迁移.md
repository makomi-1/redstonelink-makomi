# 外显穿透渲染迁移

生成时间：2026-05-01 09:28:49
文件名：2026-05-01_092849_外显穿透渲染迁移.md

## 任务背景

当前 1.21.11/Fabric 迁移工作区中，quick-link 连线/描边、定向箭头和过滤器范围仍沿用默认世界线框或 debug filled box 渲染路径，会被方块遮挡。用户要求把本模组的连线、描边、定向显示统一改成穿透显示，同时保持现有业务语义不变。

## 方案详情

### 现状分析

- 智能眼镜第三形态连线已经通过自定义 `NO_DEPTH_TEST` 管线实现穿墙可见，但只覆盖单一入口。
- quick-link 命中描边与预览线框仍走 `RenderTypes.lines()` / `RenderTypes.linesTranslucent()`。
- 定向箭头仍通过 `VertexConsumer + linesTranslucent` 提交。
- 过滤器范围外显仍依赖 `submitCustomGeometry + debugFilledBox/linesTranslucent`，深度测试和内部状态提交通道都不利于统一穿透语义。

### 技术方案

- 新增公共穿透几何渲染支持，集中封装：
  - 无深度测试的世界线段管线
  - 无深度测试的半透明四边形管线
- quick-link 命中描边、预览线框、第三形态连线统一切到公共穿透线段管线。
- 定向箭头改为先收集世界空间线段，再统一走公共穿透线段管线。
- 过滤器范围拆层处理：
  - 文本仍保留原 `BlockEntityRenderer.submitText(...)` 路径
  - 范围面层与线框改到 `WorldRenderEvents.BEFORE_TRANSLUCENT` 统一提交，彻底摆脱默认深度测试

### 影响范围

- `src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java`
- `src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java`
- `src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java`
- `src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java`
- `src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java`
- `src/client/java/com/makomi/RedstoneLinkClient.java`

## 原子步骤清单

### 步骤 1：抽公共穿透几何支持
- **操作对象**：`SeeThroughWorldGeometryRenderSupport`
- **具体动作**：新增无深度测试的线段/四边形世界外显管线与统一上传、draw、缓冲轮转逻辑
- **预期结果**：所有需要穿透显示的外显共享同一套底层渲染语义
- **关键里程碑**：是

### 步骤 2：接管 quick-link 全部描边/连线
- **操作对象**：`QuickLinkWorldOverlayRenderer`
- **具体动作**：将命中描边、预览线框和第三形态连线全部改成穿透线段提交
- **预期结果**：quick-link 相关世界外显隔墙可见
- **关键里程碑**：是

### 步骤 3：接管定向箭头
- **操作对象**：`DirectionalFaceVectorRenderSupport`、`DirectionalFaceVectorWorldOverlayRenderer`
- **具体动作**：改为收集世界空间箭头线段并统一走穿透线段管线
- **预期结果**：定向显示隔墙可见
- **关键里程碑**：是

### 步骤 4：拆分过滤器范围几何与文本
- **操作对象**：`LinkFilterAreaRenderer`、`RedstoneLinkClient`
- **具体动作**：保留文本提交路径，将范围面层和线框改到世界事件中以穿透显示
- **预期结果**：过滤器范围完整穿透显示，文本功能保持不变
- **关键里程碑**：是

### 步骤 5：编译与启动冒烟验证
- **操作对象**：Gradle 客户端编译/运行链
- **具体动作**：执行 `compileClientJava` 和 `runClient`
- **预期结果**：迁移后客户端可编译、可启动，无新的渲染线程崩溃
- **关键里程碑**：是

## 预期结果

本模组的连线、描边、定向箭头与过滤器范围外显统一具备穿透显示语义；同时保持 `triggerSource/core` 业务方向语义、过滤器功能逻辑和文本 HUD 行为不变。
