# 配对界面多行输入与自动布局

生成时间：2026-03-28 22:44:50
文件名：2026-03-28_224450_配对界面多行输入与自动布局.md

## 任务背景
当前配对界面已经把输入框高度调大，但仍然使用单行 `EditBox`，导致文本不会按多行从上往下填充。与此同时，确认/清空按钮和状态提示文本的纵向位置仍依赖固定偏移，输入框高度变化后无法自动跟随。

## 方案详情

### 现状分析
- 客户端界面位于 `AbstractMultiPairingScreen`，当前输入控件为单行 `EditBox`。
- 输入提交链路会直接读取输入框文本并拼接 `link set` 命令。
- 状态提示和按钮布局使用固定 Y 偏移，缺少与输入框高度的联动。

### 技术方案
- 将单行 `EditBox` 替换为原生 `MultiLineEditBox`，获得真正的多行显示、换行和滚动能力。
- 新增发送前文本规范化，将换行折叠为现有批量序号输入可兼容的分隔形式，保持业务语义不变。
- 将按钮行、状态提示的位置改为基于输入框底边自动计算，避免后续高度调整引起布局错位。
- 调整回车行为：输入框聚焦时保留多行输入能力，提交动作改为 `Ctrl+Enter`；其他场景下保留回车提交。

### 影响范围
- `src/client/java/com/makomi/client/screen/AbstractMultiPairingScreen.java`
- `docs_dev/使用说明.md`

## 原子步骤清单

### 步骤 1：替换输入控件
- **操作对象**：`AbstractMultiPairingScreen`
- **具体动作**：将 `EditBox` 替换为 `MultiLineEditBox`，保留最大长度、初始值和悬停判定能力。
- **预期结果**：输入框支持真正多行显示与编辑。
- **关键里程碑**：是

### 步骤 2：收敛布局计算
- **操作对象**：`AbstractMultiPairingScreen`
- **具体动作**：将按钮行和状态提示的 Y 坐标改为按输入框底边自动推导。
- **预期结果**：输入框高度变化时，下方布局自动跟随。
- **关键里程碑**：是

### 步骤 3：保持命令输入兼容
- **操作对象**：`AbstractMultiPairingScreen`
- **具体动作**：在输入校验与命令发送前统一规范化多行文本，确保换行不会破坏现有命令语义。
- **预期结果**：仅增强显示层，不改服务端解析语义。
- **关键里程碑**：否

- **操作对象**：`AbstractMultiPairingScreen`
- **具体动作**：输入框聚焦时以 `Ctrl+Enter` 触发提交，普通回车保留为多行输入。
- **预期结果**：多行输入与快捷提交均可用。
- **关键里程碑**：否
