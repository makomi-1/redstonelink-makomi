# 过滤器与区块激活器物品Tooltip节点集别名显示

生成时间：2026-04-23 21:27:44
文件名：2026-04-23_212744_过滤器与区块激活器物品Tooltip节点集别名显示.md

## 任务背景

过滤器和区块激活器 HUD 近外显节点集别名显示已接入服务端同步，但对应物品 tooltip 仍只显示 `#序号`。物品 tooltip 在客户端本地生成，不能直接读取服务端别名库，因此需要像节点物品当前连接快照一样，把节点集展示文本缓存到物品自定义数据中。

## 方案详情

### 现状分析

过滤器物品 tooltip 通过 `LinkFilterItemData.buildTooltipTargetText(...)` 读取 `serialExpression` 并格式化序号；区块激活器物品 tooltip 通过 `ChunkActivatorItemData.buildTooltipSerialExpressionText(...)` 读取当前 activeType 配置并格式化序号。两条链路都没有物品侧 displayTexts 缓存，旧物品和未同步物品只能回退序号。

### 技术方案

为过滤器物品增加一组节点集 displayTexts 缓存；为区块激活器物品增加 triggerSource/core 两组 displayTexts 缓存。服务端保存手持编辑配置、方块掉落生成物品、节点别名变化刷新在线玩家物品时，同步这些 displayTexts。tooltip 构造优先使用 displayTexts，缺失或与序号数量不一致时回退 `#序号`。

### 影响范围

- 过滤器物品配置读写与 tooltip 文本构造。
- 区块激活器物品配置读写与 tooltip 文本构造。
- 手持编辑保存、方块掉落、别名变更后的玩家背包缓存刷新。
- 不改变过滤器规则、区块激活器强加载/常驻语义，不改变节点方向，不改贴图资源。

- **预期结果**：过滤器物品 tooltip 可显示 `别名(#序号)`

### 步骤 2：区块激活器物品 displayTexts 缓存
- **操作对象**：`ChunkActivatorItemData`
- **具体动作**：新增 triggerSource/core 两套展示文本读写、同步、tooltip 构造重载
- **预期结果**：区块激活器物品 tooltip 按 activeType 显示对应节点集别名
- **关键里程碑**：是

### 步骤 3：保存与掉落写入缓存
- **操作对象**：过滤器/区块激活器网络保存处理与方块掉落逻辑
- **具体动作**：服务端保存手持物品和掉落物时同步当前节点别名展示文本
- **预期结果**：新保存和新掉落的物品 tooltip 立即显示别名

- **具体动作**：别名变更后刷新在线玩家背包中引用该序号的过滤器/区块激活器物品 displayTexts
- **预期结果**：已有在线物品缓存能跟随别名变更更新
- **关键里程碑**：是

过滤器和区块激活器物品 tooltip 节点集显示 `别名(#序号)`；无别名、旧物品或缓存不匹配时仍稳定显示 `#序号`。

## 语义对齐说明

本次只补充 `triggerSource/core` 节点集展示文本缓存与 tooltip 消费，不改变来源到目标方向、不改变 `LinkNodeType.TRIGGER_SOURCE/CORE` 映射、不新增旧术语输出、不引入 `com.makomi.api.v1.*` 依赖。残余风险：离线玩家背包中的旧物品不会立即刷新，但下一次服务端保存、掉落或别名刷新触达在线玩家后会更新。
