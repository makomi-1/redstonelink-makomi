# 统一过滤器近外显颜色

生成时间：2026-04-12 19:38:01
文件名：2026-04-12_193801_统一过滤器近外显颜色.md

## 任务背景

当前过滤器近外显对 `send/receive` 使用了不同颜色，但本轮需要统一成同一个红色视觉，和现有红色过滤器风格保持一致。

## 方案详情

### 现状分析

- 过滤器近外显颜色由 `LinkSerialOverlayRenderCommon.resolveFilterTextColor(...)` 决定。
- 当前 `send filter` 使用暖粉色，`receive filter` 使用冷蓝色。
- 使用说明也按这套双色写死了描述。

### 技术方案

1. 在 `LinkSerialOverlayRenderCommon` 中把过滤器近外显颜色收敛为单一红色常量。
2. `resolveFilterTextColor(...)` 不再区分 `send/receive`，两者统一返回该红色。
3. 同步更新 `docs/使用说明.md` 的颜色说明。

### 影响范围

- `src/client/java/com/makomi/client/render/LinkSerialOverlayRenderCommon.java`
- `docs/使用说明.md`

### 语义对齐说明

- 本轮只调整客户端近外显配色，不改变 `triggerSource/core` 术语和方向语义。
- 不新增 API v1 依赖。
- 不涉及资源文件改写。
