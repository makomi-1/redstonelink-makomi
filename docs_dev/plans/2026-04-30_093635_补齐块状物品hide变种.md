# 补齐块状物品 hide 变种

生成时间：2026-04-30 09:36:35

## 任务背景

当前工作区已经具备 `hide core` 与 `hide sync triggerSource`，但剩余块状可放置物品仍没有对应 hide 版本。  
本轮目标是在不引入 `transparent core` 的前提下，把剩余块状物品的 hide 变种补齐，并继续对齐现有 hide 节点标准：默认不可见、需智能眼镜可见和交互、默认空面集、ghost 模型可视化、原节点+玻璃配方。

## 方案详情

### 现状分析

- 当前 hide 体系只覆盖两种节点，很多逻辑是按 `hide_core / hide_sync_trigger_source` 硬编码的。
- 过滤器、区块激活器、转发器与普通节点使用的方块实体渲染器和物品类不同，无法只复制两个 hide block 类就完成补齐。
- 本轮待补对象收敛为 6 类：
  - `hide_toggle_emitter`
  - `hide_pulse_emitter`
  - `hide_send_filter`
  - `hide_receive_filter`
  - `hide_chunk_activator`
  - `hide_repeater`

### 技术方案

- 先抽一层 hide 通用支撑，统一回答：
  - 哪些 block/item 属于 hide 节点
  - hide 节点在智能眼镜下应映射成哪种普通 ghost 方块状态
- 在渲染层补三类 hide ghost renderer：
  - 节点类：复用 `LinkNodeFarOverlayRenderer`
  - 过滤器类：复用 `LinkFilterAreaRenderer`
  - 区块激活器类：复用 `ChunkActivatorFarOverlayRenderer`
- 各 hide 方块继续按最小子类扩展：
  - 覆盖 `RenderShape.INVISIBLE`
  - 默认空面集
  - 覆盖交互 shape 为“戴眼镜才可命中”
  - 复用原有 block entity 运行时语义
- 统一补齐：
  - block/item/block entity 注册
  - 创造栏与 lang
  - item/block 模型、blockstate
  - 原节点 + 玻璃配方
  - 智能眼镜 tooltip
