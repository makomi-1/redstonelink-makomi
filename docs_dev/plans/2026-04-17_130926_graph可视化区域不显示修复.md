# graph可视化区域不显示修复

生成时间：2026-04-17 13:09:26
文件名：2026-04-17_130926_graph可视化区域不显示修复.md

## 任务背景

当前 `graph` 页面中，搜索、节点信息和其他外围 UI 都正常，但可视化网络画布部分没有显示出节点和连线。已有分析表明数据已经进入前端状态，问题更可能位于 `ReactFlow` 的渲染容器高度与首帧视口初始化，而不是 graph 数据导出或解析链路本身。

## 方案详情

### 现状分析

- `GraphViewer` 已经正常计算 `effectiveGraphBundle`、`matchedNodes` 和 `selectedNode`，说明 graph 数据已进入页面状态层。
- 当前 `.graph-canvas` 只有 `min-height`，没有明确高度，可能导致 `ReactFlow` 内部无法拿到稳定可用的父容器尺寸。
- 当前首帧没有在实例和节点都就绪后做一次稳定的自动 `fitView`，可能导致图虽然存在但没有进入可见视口。

### 技术方案

1. 调整 `graph` 画布容器高度策略：
   - 为 `.graph-canvas` 提供明确高度
   - 同时保留合理的最小高度与响应式表现
2. 在 `GraphViewer` 中补充图实例初始化后的自动 `fitView`：
   - 等 `reactFlowInstance`、节点与草稿加载状态稳定后执行
   - 使用一次延后调度，避免首帧容器尺寸未完成布局
3. 执行网页构建与全量回归验证，确认没有引入其他页面回归

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- `webapp/src/app.css`
- `docs_dev/reviews/**`

- **预期结果**：`ReactFlow` 能获取稳定的父容器高度并开始渲染
- **关键里程碑**：是

- **操作对象**：`webapp/src/components/GraphViewer.tsx`

- **预期结果**：首次进入页面时网络图自动进入可见区域
- **关键里程碑**：是

- **操作对象**：Gradle / webapp 构建、`docs_dev/reviews/**`
