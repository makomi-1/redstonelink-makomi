# 近外显跨区块身份显示

生成时间：2026-04-03 22:53:05
文件名：2026-04-03_225305_近外显跨区块身份显示.md

## 任务背景
用户要求实现 `docs_dev/更新计划草稿与索引.md` 中“近外显补充显示跨区块身份：普通/强加载/常驻”。
经确认，本次显示口径采用“纯持久化/配置视角”，不依赖具体实体在线状态或运行时票据是否已实际挂载。

## 方案详情

### 现状分析
当前近外显仅显示序号、激活状态、最终 IO 与当前连接；服务端 `CurrentLinksSnapshotPayload` 只携带当前连接序号列表，不包含跨区块身份字段。
跨区块身份真值已存在于服务端持久化与配置层：
1. `CrossChunkWhitelistSavedData` 维护 whitelist 与 `resident`。
2. `RedstoneLinkConfig.crossChunk()` 维护 `forceLoad.enabled`、`forceLoad.mode`、preset 与允许类型。
因此本次适合把身份判定收口到服务端查询层，再经 near overlay 协议下发到客户端显示。

### 技术方案
1. 在服务端新增“跨区块身份”读模型，按 `triggerSource -> source`、`core -> target` 方向判定当前节点属于 `normal/force_load/resident` 哪一类。
2. 扩展 `CurrentLinksSnapshotPayload` 与编解码逻辑，把当前连接与跨区块身份一起返回给客户端。
3. 客户端近外显缓存增加身份字段，并在 HUD 文案中新增“跨区块：普通/强加载/常驻”一行。
4. 补协议、身份判定与 HUD 文案三层单测，确保结构性风险可回归。

### 影响范围
- 服务端读模型与 near overlay 回包：`src/main/java/com/makomi/data`、`src/main/java/com/makomi/network`
- 客户端 near overlay 缓存与文案：`src/client/java/com/makomi/client/render`、`src/client/java/com/makomi/client/network`
- 本地化文案：`src/main/resources/assets/redstonelink/lang/*.json`
- 自动化测试：`src/test/java/com/makomi/data`、`src/test/java/com/makomi/network`

## 原子步骤清单

### 步骤 1：补服务端跨区块身份判定
- **操作对象**：`NodeSnapshotQueryService` 及相关 helper/DTO
- **具体动作**：新增基于 whitelist、resident、preset 与 force-load 配置的身份判定逻辑，方向固定映射 `triggerSource/source`、`core/target`
- **预期结果**：服务端可在不读取实体运行态的前提下得到节点跨区块身份
- **关键里程碑**：是

### 步骤 2：扩展 near overlay 当前连接协议
- **操作对象**：`PairingNetwork`、`PairingNetworkPayloadSupport`、`PairingNetworkServerHandlerSupport`
- **具体动作**：给 `CurrentLinksSnapshotPayload` 增加身份字段，并在 near overlay 当前连接请求处理时一并返回
- **预期结果**：客户端可收到“当前连接 + 跨区块身份”同一份快照
- **关键里程碑**：是

### 步骤 3：接入客户端缓存与 HUD 文案
- **操作对象**：`LinkSerialHudOverlaySnapshotSupport`、`LinkSerialHudOverlayRenderer`、`LinkSerialHudOverlayTextSupport`、语言文件
- **具体动作**：缓存身份字段，近外显新增跨区块身份一行与三态本地化文本
- **预期结果**：命中节点时可显示“普通/强加载/常驻”
- **关键里程碑**：是

### 步骤 4：补自动化测试并执行回归
- **操作对象**：协议/服务端判定/HUD 文案测试与 Gradle 测试任务
- **具体动作**：新增或更新单测，随后执行 `.\gradlew.bat test testIntegration testClient testSlow --no-daemon`
- **预期结果**：结构性风险被自动化锁定，回归结论可追溯
- **关键里程碑**：否

## 预期结果
近外显在保持现有隐私读取与方向语义不变的前提下，新增一条跨区块身份显示，准确反映节点在持久化/配置视角下属于普通、强加载还是常驻。
