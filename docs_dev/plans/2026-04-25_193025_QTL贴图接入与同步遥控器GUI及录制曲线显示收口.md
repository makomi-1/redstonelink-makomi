# QTL贴图接入与同步遥控器GUI及录制曲线显示收口

生成时间：2026-04-25 19:30:25
文件名：2026-04-25_193025_QTL贴图接入与同步遥控器GUI及录制曲线显示收口.md

## 任务背景

本轮在当前 `release/no-mixin` 分支上继续收口三个已经确认的方向：

1. 快速连接工具（QTL）第三形态 `visualize` 的贴图资源已准备完成，需要接入当前物品模型与文档展示。
2. 同步遥控器已经完成 `0~15` 强度支持，但 GUI 中间按钮仍保留“当前强度/Current Power”字段标签，相关文档也仍有旧的 `15/0` 切换表述。
3. 录制曲线页当前仍按“最多 5 个节点”限制选择，且曲线 tooltip 宽度偏窄；本轮需要把“同时显示最大”调整为真正的 `10` 条曲线，并修正 tooltip 显示宽度。

## 方案详情

### 现状分析

- `fast_link_tool_vs.png` 已经存在于 `src/main/resources/assets/redstonelink/textures/item/`，但当前 `quick_link_tool` 物品模型和图鉴轮播候选仍只覆盖 `_sd/_cp` 两种状态。
- `QuickLinkToolData` 当前只把 `channel` 模式映射到 `CustomModelData=1`，`visualize` 模式虽然已存在，但不会驱动物品贴图切换。
- 同步遥控器 GUI 的中间按钮仍使用 `screen.redstonelink.sync_linker.signal_strength.value` 翻译键，显示为“当前强度：%s / Current Power: %s”。
- 录制曲线网页前端的限制常量当前是 `MAX_SELECTED_RECORDING_NODES = 5`；这限制的是“节点数”而不是“曲线条数”，若直接改成 `10` 会在双指标同时显示时变成 `20` 条线。
- `RecordingChart` 中 tooltip 宽度常量与 CSS 都固定为 `360px`，长字段会超出背景宽度。
- `docs/item_guide.html`、`docs/usage_guide_cn.md`、`docs/usage_guide_en.md` 仍保留 QTL 只有 `serial/channel`、同步遥控器 `15/0` 两态切换等旧描述。

### 技术方案

1. 为 QTL 第三形态接入独立物品模型：
   - 在 `QuickLinkToolData` 中为 `visualize` 分配单独的 `CustomModelData=2`。
   - 新增 `quick_link_tool_visualize.json`，引用已存在的 `fast_link_tool_vs.png`。
   - 保持 `serial -> 默认`、`channel -> 1`、`visualize -> 2` 的简单镜像策略，避免引入额外状态耦合。

2. 将同步遥控器 GUI 当前强度按钮改为纯数字：
   - 保留三按钮布局和增减交互，只把中间禁用按钮文案改为 `0~15` 数字。
   - 同步清理对应中英文翻译键，保证文案与实现一致。

3. 按“最多 10 条曲线”而不是“最多 10 个节点”调整录制页限制：
   - 基于当前勾选指标数动态计算允许选择的最大节点数。
   - 单指标时最多允许 10 个节点，双指标同时启用时最多允许 5 个节点。
   - 同步更新页面计数、摘要、空态提示与禁用逻辑，确保前后口径一致。

4. 放宽曲线 tooltip 宽度：
   - 同时调整 `RecordingChart.tsx` 中的 `TOOLTIP_WIDTH` 与 `app.css` 中的 `.recording-chart-tooltip` 宽度。
   - 保持现有基础定位与边界钳制逻辑，仅扩大可承载内容的宽度。

5. 同步更新非 README 文档与图鉴：
   - `docs/item_guide.html`：补齐 QTL 第三形态展示轮播、QTL 三态使用说明、同步遥控器 `0~15` 语义与当前操作说明。
   - `docs/usage_guide_cn.md`、`docs/usage_guide_en.md`：改写 QTL 与同步遥控器章节，使之对齐当前真实实现。
   - 若文档中涉及“当前 power”字段名，则统一移除为纯数值描述。
