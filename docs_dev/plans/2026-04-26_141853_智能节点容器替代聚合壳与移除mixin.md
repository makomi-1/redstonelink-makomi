# 智能节点容器替代聚合壳与移除 mixin

生成时间：2026-04-26 14:18:53
文件名：2026-04-26_141853_智能节点容器替代聚合壳与移除mixin.md

## 任务背景

当前聚合壳体验依赖服务端与客户端 mixin 补丁完成第二层聚合归并、聚合数量角标与创造模式 tooltip 修复。需求要求去掉全部 mixin，并由一个新的智能节点容器承接手持收纳、箱子式 GUI、按类型放置与双层外显。

## 方案详情

### 现状分析

- 现有 mixin 配置入口位于 `fabric.mod.json`、`redstonelink.mixins.json`、`redstonelink.client.mixins.json`。
- 现有聚合逻辑主体位于 `PairableItemAggregateMenuNormalizationService`、`PairableItemAggregateClickSupport`、`LinkItemAggregateDecorationDisplaySupport`。
- 当前项目没有现成的“物品内库存容器”菜单与界面，也没有智能节点容器的物品类与数据结构。
- 现有资源中已经有智能节点容器侧面与底部贴图，以及可复用的 `dual_layer_cube` 双层模型基底。

### 技术方案

- 新增 `smart_node_container` 物品，作为真正的手持容器。
- 容器内部存完整 `ItemStack`，只允许 `core / triggerSource / repeater` 三类节点进入。
- 新增独立容器数据读写类，负责槽位内容、当前放置类型、自动排序开关和模型状态同步。
- 新增自定义 `AbstractContainerMenu` 与原版风格大箱子 Screen，完成 6 行容器区、玩家背包区和排序开关。
- 客户端复用现有 `B` 与鼠标中键分发入口：
  - 主手是智能节点容器时，`B` 打开容器；
  - 鼠标中键切换当前放置类型；
  - 主手右键按当前类型从容器中取一件节点并尝试放置。
- 智能节点容器 item 模型复用 `dual_layer_cube`，通过 `CUSTOM_MODEL_DATA` 在默认、core、triggerSource、repeater 四种外显间切换。
- 聚合壳相关 mixin 与仅为其服务的入口整体下线；保留仍能被其他逻辑单独复用的基础工具代码。

### 影响范围

- 物品注册与创造栏：`registry`
- 容器数据与排序：`data`
- 物品交互：`item`
- 菜单、界面与按键：`client`
- 网络收发：`network`
- mixin 配置与类删除：`resources`、`mixin`
- 语言与模型资源：`lang`、`models`
