# 物品栏tip连接去隐私过滤

生成时间：2026-03-29 21:19:46
文件名：2026-03-29_211946_物品栏tip连接去隐私过滤.md

## 任务背景
当前物品栏 tooltip 显示的连接列表来自物品 NBT 中的 `rl_links`。但该字段在“同步当前连接快照”时已经经过隐私读控裁剪，导致物品栏 tip 看到的是过滤后的结果。需求是取消这一层过滤，让物品栏 tip 显示完整连接，同时不影响命令、网络、近距 HUD 等其它隐私读控展示面。

## 方案详情

### 现状分析
- [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L314) 在同步单件物品快照时，调用 `NodeSnapshotQueryService.queryItemSnapshotLinks(...).visibleTargetSet()` 写入 `rl_links`。
- [NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L77) 当前将物品快照查询固定为 `hasViewPermission=false`，因此会经过隐私过滤。
- [PairableBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/PairableBlockItem.java#L125) 与 [LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L175) 只是直接读取 `LinkItemData.getLinkedSerials(stack)`，并未额外过滤。

### 技术方案
- 保留 `CurrentLinksPrivacyService` 对命令、网络、HUD 的现有过滤逻辑不动。
- 仅调整“写入物品 NBT 快照”的查询口径：
  - 在 [NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java) 中，让 `queryItemSnapshotLinks(...)` 返回未经过隐私过滤的完整目标集合。
  - 保持返回类型仍为 `NodeLinksSnapshot`，避免改动调用层结构。
- 由于 tooltip 仅读取 `rl_links`，无需改动物品 tooltip 实现。

### 影响范围
- `src/main/java/com/makomi/data/NodeSnapshotQueryService.java`
- 可能补充 `src/test/java/com/makomi/data/` 下相关测试
