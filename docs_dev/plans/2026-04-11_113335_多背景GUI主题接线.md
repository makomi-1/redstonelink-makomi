# 多背景GUI主题接线

生成时间：2026-04-11 11:33:35
文件名：2026-04-11_113335_多背景GUI主题接线.md

## 任务背景
当前 `core`、`triggerSource` 与过滤器 GUI 已各自具备独立背景贴图，但客户端背景支持代码仍指向旧的 `pairing_background.png`，过滤器编辑界面也尚未接入统一的 nine-slice 背景渲染。用户要求按 `core` 原先的设定整套调整，使三类界面都切换到各自的背景图，并保持与现有主题化结构一致；同时补充说明 `core` 原先背景图已改名，需要同步修正资源引用。

## 方案详情

### 现状分析
- `GuiBackgroundRenderSupport` 当前只持有旧的 `pairing_background.png` 单资源，`CORE_PAIRING` 与 `TRIGGER_SOURCE_PAIRING` 预设都共用它。
- `CorePairingScreen` 已接入背景预设、输入框皮肤、按钮皮肤以及“当前连接”边框色文字；`TriggerSourcePairingScreen` 仅接了背景预设，没有整套主题化样式。
- `LinkFilterEditorScreen` 当前使用默认 `Screen#renderBackground`，未接入自定义背景预设，也未复用 `StyledMultiLineEditBox` / `StyledButton`。
- 三张新背景图尺寸一致，均为 `180x200`，可复用 `core` 原有 nine-slice 参数 `4/4/4/4`；边框主色分别为 `core=#0D47A1`、`triggerSource=#9F5600`、`filter=#A00029`。

### 技术方案
- 在 `GuiBackgroundRenderSupport` 中拆出 `core`、`triggerSource`、`filter` 三个独立背景资源与预设，保留 `core` 原先的 nine-slice 尺寸和边框主色能力。
- `CorePairingScreen` 保持现有主题结构，只让其背景预设落到已改名的 `core_pairing_background.png`。
- `TriggerSourcePairingScreen` 补齐与 `core` 对齐的主题化样式：使用独立背景预设、独立输入框和按钮配色，并将“当前连接”文本颜色对齐到触发器背景边框色。
- `LinkFilterEditorScreen` 接入过滤器背景预设、过滤器主题按钮样式以及多行输入框皮肤，并通过内容区域包裹方式渲染背景；服务对象副标题颜色对齐过滤器背景边框色。
- 不修改贴图资源文件本身，只更新代码引用和界面渲染接线。

### 影响范围
- `src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java`
- `src/client/java/com/makomi/client/screen/CorePairingScreen.java`
- `src/client/java/com/makomi/client/screen/TriggerSourcePairingScreen.java`
- `src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java`

## 原子步骤清单

### 步骤 1：更新背景预设资源映射
- **操作对象**：`GuiBackgroundRenderSupport`
- **具体动作**：将旧单一背景资源拆成 `core/triggerSource/filter` 三个独立 `ResourceLocation`，并新增对应 `BackgroundPreset`
- **预期结果**：背景支持层可以按界面类型选中正确背景图
- **关键里程碑**：是

### 步骤 2：补齐 triggerSource 主题化样式
- **操作对象**：`TriggerSourcePairingScreen`
- **具体动作**：新增触发器输入框、按钮与“当前连接”文本主题色，使其与 `core` 当前做法保持同构
- **预期结果**：触发器配对界面拥有与自身背景图匹配的整套主题
- **关键里程碑**：是

### 步骤 3：接入过滤器编辑界面背景与基础主题
- **操作对象**：`LinkFilterEditorScreen`
- **具体动作**：接入过滤器背景预设、内容区域包裹渲染、主题按钮与多行输入框皮肤，并调整关键副标题颜色
- **预期结果**：过滤器编辑界面切到独立背景图并与现有 GUI 主题结构保持一致
- **关键里程碑**：是

### 步骤 4：成果验证
- **操作对象**：Gradle 测试任务与写后校验
- **具体动作**：执行 `.\gradlew.bat test testIntegration testClient testSlow --no-daemon`，并检查 diff、编码与空白错误
- **预期结果**：确认背景与主题改动未引入回归
- **关键里程碑**：是

## 预期结果
`core`、`triggerSource` 与过滤器编辑 GUI 都会切换到各自独立的背景贴图，并复用 `core` 原先的 nine-slice 背景机制与主题结构；其中 `core` 背景引用自动适配新文件名，`triggerSource` 与过滤器界面也获得与各自背景边框色一致的关键视觉强调，但不改变任何业务语义、协议或持久化数据。
