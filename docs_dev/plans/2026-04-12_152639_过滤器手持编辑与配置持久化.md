# 过滤器手持编辑与配置持久化

生成时间：2026-04-12 15:26:39
文件名：2026-04-12_152639_过滤器手持编辑与配置持久化.md

## 任务背景

当前过滤器仅支持作为已放置方块打开编辑 GUI，且配置真值只保存在方块实体里。  
本轮需要补齐与其它节点一致的手持编辑入口，并让过滤器配置在“手持物品 -> 放置方块 -> 掉落物品”之间保持闭环持久化，同时在 tooltip 中展示当前生效配置。

## 方案详情

### 现状分析

- `AbstractLinkFilterBlock` 已支持已放置过滤器按门禁打开 GUI。
- `LinkFilterBlockItem` 目前只有静态 tooltip，没有手持打开编辑器入口，也没有物品配置持久化。
- `LinkFilterNetwork` 当前只支持以“维度 + 方块坐标”为目标保存配置。

### 技术方案

- 新增过滤器物品配置读写工具，统一维护 `ItemStack` 上的过滤器配置快照。
- 扩展过滤器网络编辑上下文，让同一套过滤器 GUI 同时支持：
  - 已放置过滤器方块实体
  - 主手手持过滤器物品
- 过滤器物品补齐 `use/useOn`，复用“手持节点打开 GUI”的相同门禁。
- 方块放置时把物品配置回写到过滤器方块实体；方块掉落时把方块实体配置写回掉落物。
- tooltip 展示过滤器当前配置快照，至少包含节点集、节点集模式、阈值来源、固定阈值与信号模式。
