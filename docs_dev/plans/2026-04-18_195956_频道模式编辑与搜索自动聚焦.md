# 频道模式编辑与搜索自动聚焦

生成时间：2026-04-18 19:59:56
文件名：2026-04-18_195956_频道模式编辑与搜索自动聚焦.md

## 任务背景

当前 graph 可视化中，频道模式仍然只能只读浏览，无法像序号模式一样直接在网页里批量改频道；同时搜索会把非匹配节点整体压暗，但用户现在更希望搜索只负责定位结果，并自动把视图聚焦到首个命中节点。

本轮目标是在不改变 `triggerSource -> core` 真值方向语义的前提下，扩展频道模式的网页编辑与保存链路，并把搜索交互调整为“应用后自动聚焦，不再整体变暗”。

## 方案详情

### 现状分析

- 前端当前仅允许 `serial + topology` 进入编辑态，频道模式右侧没有批量编辑面板。
- 前端草稿与 `graph/save` 协议仅支持“改别名”和“覆盖 triggerSource 目标集合”，缺少节点频道覆盖操作。
- 服务端保存入口当前直接拒绝 `channel` 模式，但底层已经有现成的频道写入服务可复用。
- 搜索变暗逻辑位于画布样式层，而自动聚焦首个命中节点的基础能力已经存在。

### 技术方案

- 前端为频道模式新增独立的“节点频道覆盖”编辑态，不复用序号模式的 add/remove/replace 语义。
- 扩展草稿模型与保存协议，新增 `SetNodeChannel` 操作，并在前端先预演频道归属变化。
- 服务端 `graph/save` 增加频道操作解析、校验与落地，复用已有频道编辑服务；`channel=0` 作为清空频道配置处理。
- 搜索移除非匹配节点变暗逻辑，保留匹配集合并在应用搜索时自动聚焦第一个命中节点。
