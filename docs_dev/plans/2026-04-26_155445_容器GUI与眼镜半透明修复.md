# 容器GUI与眼镜半透明修复

生成时间：2026-04-26 15:54:45
文件名：2026-04-26_155445_容器GUI与眼镜半透明修复.md

## 任务背景

智能节点容器与智能眼镜上一轮接线后，用户在游戏内复测发现 3 个客户端表现问题：

1. 智能节点容器 GUI 右侧“当前放置类型”信息超出背景。
2. 容器内部与玩家背包槽位的物品悬停 tooltip 没有正常显示。
3. 智能眼镜穿戴后接近完全透明，不符合“半透明显示”的预期。

本轮按最小粒度修复这些现有缺陷，不扩展新设计，不改贴图像素文件。

## 方案详情

### 现状分析

- `SmartNodeContainerScreen` 当前右侧信息区宽度较窄，文字直接绘制，导致较长字段越界。
- 容器 screen 没有对 tooltip 进行显式接管，当前实测表现与预期不一致，需要补一个稳定的 screen 级兜底。
- `SmartGlassesArmorRenderer` 当前半透明实现会进一步压低一张本身透明区域很多的护甲贴图，可见度不足。

### 技术方案

1. 直接增大智能节点容器右侧背景宽度，同步调整按钮宽度和整体 `imageWidth`。
2. 在 `SmartNodeContainerScreen` 中显式覆盖 tooltip 渲染逻辑，按悬停槽位渲染容器、背包与热键栏物品 tooltip。
3. 调整 `SmartGlassesArmorRenderer` 的缓冲与 alpha 渲染方式，保留贴图原始透明通道，同时提高整体可见度，恢复真实半透明观感。

### 影响范围

- 客户端 GUI：智能节点容器界面布局与 tooltip 渲染
- 客户端渲染：智能眼镜护甲穿戴渲染
- 文档：本轮方案文档与后续审查文档

## 原子步骤清单

### 步骤 1：扩大容器右侧信息区
- **操作对象**：`src/client/java/com/makomi/client/screen/SmartNodeContainerScreen.java`
- **具体动作**：增大右侧背景与按钮宽度，确保当前放置类型与自动排序控件完全落在背景范围内。
- **预期结果**：右侧字段不再超出背景。
- **关键里程碑**：是

### 步骤 2：补齐槽位 tooltip
- **操作对象**：`src/client/java/com/makomi/client/screen/SmartNodeContainerScreen.java`
- **具体动作**：覆盖 screen 的 tooltip 渲染逻辑，按悬停槽位显示容器与玩家背包物品 tooltip。
- **预期结果**：容器区、背包区、热键栏都能正常悬停查看物品 tooltip。
- **关键里程碑**：是

- **操作对象**：`src/client/java/com/makomi/client/render/SmartGlassesArmorRenderer.java`
- **具体动作**：调整护甲渲染使用的 render layer / buffer 与 alpha 常量，恢复清晰可见的半透明效果。
- **预期结果**：智能眼镜穿戴时是半透明，而不是几乎不可见。
- **关键里程碑**：是
