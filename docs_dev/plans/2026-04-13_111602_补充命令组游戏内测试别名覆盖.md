# 补充命令组游戏内测试别名覆盖

生成时间：2026-04-13 11:16:02
文件名：2026-04-13_111602_补充命令组游戏内测试别名覆盖.md

## 任务背景
当前 `node alias` 已有 Java 命令契约测试，但命令组游戏内测试（bench functional）里还缺少别名相关覆盖。用户要求把别名命令补入现有命令组游戏内测试，并实际跑通完成收尾。

## 方案详情

### 现状分析
- 现有命令组 functional case 已分层为：
  - `C02`：基础查询/退役/审计路径
  - `C06`：命令边界与失败路径
  - `C08`：OTHER 组权限感知限流
- `node alias` 命令属于 `OTHER` 组，适合分别落到这三类现有 case 中，而不是额外新开一条独立 case。
- `server-basic-permission` suite 已接入 `C07/C08`，`functional-phase2` 与 `regression-core` 已接入 `C06`，因此优先复用现有入口，避免扩散接线范围。

### 技术方案
- 在 `C02` 中补充 alias 基础命令路径：`set`、`resolve`、`list`、`node get` 显示别名、`remove`、移除后的 `resolve` 失败。
- 在 `C06` 中补充 alias 边界路径：非法字符、纯数字、同名冲突、退役节点设置别名失败。
- 在 `C08` 中补充 alias 命令限流路径：复用 OTHER 组限流配置，对 `node alias list` 做连续调用并验证提权前后差异。
- 不新增新的 case id、matrix 或 suite 接线，仅扩充已存在 case 的 `phases`。

### 影响范围
- `tools/bench/cases/functional/c02/node_query_retire_audit_basic.json`
- `tools/bench/cases/functional/c06/command_boundary_matrix.json`
- `tools/bench/cases/functional/c08/server_permission_rate_limit_basic.json`
