# 快速连接工具中键清空方案

生成时间：2026-03-30 14:53:51
文件名：2026-03-30_145351_快速连接工具中键清空方案.md

## 任务背景

在现有快速连接工具交互基础上，新增“鼠标中键清空缓存”的快捷操作。
本次仅要求清空工具缓存本身，不改变现有左键采集、站立右键应用、潜行右键开 GUI、`B` 键切模式的既有行为。

## 方案详情

### 现状分析

- quick-link 快捷键目前集中在客户端 `END_CLIENT_TICK` 轮询中处理。
- quick-link 缓存写回已经有 `SaveQuickLinkPayload`，可直接复用。
- 工具缓存数据层目前缺少“保留模式/类型，仅清空缓存”的专用入口。

### 技术方案

- 在 `QuickLinkToolData` 中新增清空辅助方法，保留当前模式与序号缓存类型，仅清空序号缓存和频道缓存。
- 在客户端按键轮询中消费原版中键 `pick item`，仅当主手持快速连接工具且当前未打开 GUI 时触发。
- 触发后复用 `SaveQuickLinkPayload` 把清空后的快照发回服务端，并通过 action bar 给出“缓存已清空”提示。

### 影响范围

- quick-link 数据模型
- quick-link 客户端按键轮询
- 中英文本地化
- quick-link 相关测试

- **操作对象**：`QuickLinkToolData`
- **具体动作**：新增保留当前模式与序号缓存类型的清空方法
- **预期结果**：清空语义集中在数据层
- **关键里程碑**：是

### 步骤 2：接入中键清空
- **操作对象**：`RedstoneLinkClient`
- **具体动作**：消费原版 `pick item` 键，在限定条件下触发 quick-link 清空
- **预期结果**：鼠标中键可直接清空工具缓存
- **关键里程碑**：是

### 步骤 3：补提示与测试
- **操作对象**：语言文件、quick-link 测试

- 频道模式预留边界不受影响
