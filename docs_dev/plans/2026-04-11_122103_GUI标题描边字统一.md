# GUI标题描边字统一

生成时间：2026-04-11 12:21:03
文件名：2026-04-11_122103_GUI标题描边字统一.md

## 任务背景
当前多个客户端 GUI 顶部标题仍使用普通文本绘制，主标题与副标题的视觉强调不统一。需求是将所有 GUI 的标题字段统一改为描边字，并保持普通表单标签、列表表头、按钮文字和状态消息不受影响。

## 方案详情

### 现状分析
- 当前标题绘制入口集中在 `AbstractMultiPairingScreen`、`LinkFilterEditorScreen`、`QuickLinkToolScreen`、`StatePanelToolScreen`
- 这些界面都直接使用 `GuiGraphics.drawCenteredString(...)` 绘制标题
- Minecraft 1.21.1 的 `Font` 已提供 `drawInBatch8xOutline(...)`，可直接复用原生八向描边渲染能力

### 技术方案
- 新增统一的标题渲染支持类，封装居中描边文本绘制、默认标题样式与副标题样式
- 主标题统一使用白色正文 + 深色描边
- 副标题根据当前文本色生成更深的描边色，保持不同主题下的视觉一致性
- 各 GUI 仅改“顶部标题簇”，不改普通标签、列表表头、状态消息、按钮文字

### 影响范围
- `src/client/java/com/makomi/client/screen/AbstractMultiPairingScreen.java`
- `src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java`
- `src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java`
- `src/client/java/com/makomi/client/screen/StatePanelToolScreen.java`
- 新增标题渲染支持类
