# 网页主题预览切换

生成时间：2026-04-19 17:04:32
文件名：2026-04-19_170432_网页主题预览切换.md

## 任务背景

当前网页前端已经有统一视觉风格，但仍以单一深色玻璃面板风为主，颜色大多直接写死在 `webapp/src/app.css` 与少量组件内联样式中。  
本轮目标是先实现“可切换预览”的主题体系，让用户能直接在网页里预览多套现代极简 / 未来科幻方向的模板，再决定后续最终定稿方案。

## 方案详情

### 现状分析

- 页面主样式集中在 `webapp/src/app.css`，大量使用硬编码颜色、渐变和阴影。
- graph 画布节点、聚合块和边的配色还写在 `webapp/src/components/graphViewer/canvas.tsx` 中。
- recording 曲线的颜色与坐标轴网格色分别写在 `webapp/src/components/RecordingViewer.tsx` 与 `webapp/src/components/RecordingChart.tsx` 中。
- 目前没有主题切换状态，也没有可预览的模板入口。

### 技术方案

1. 新增统一主题定义文件，提供三套主题：
   - `future-command`：未来指挥台，深蓝 + 红 + 蓝
   - `lab-minimal`：实验室极简，白 + 蓝
   - `industrial-tech`：现代工业科技，浅灰/白 + 蓝 + 橙
2. 在 `App` 层维护当前主题状态，并传给首页、graph 页、recording 页。
3. 新增主题预览切换组件，三个页面都可直接切换。
4. 将核心页面样式、graph 配色、recording 图表配色提取为主题变量。
5. 补充前端测试，验证主题切换渲染不影响现有页面功能。

### 影响范围

- `webapp/src/App.tsx`
- `webapp/src/app/HomePage.tsx`
- `webapp/src/app/GraphPage.tsx`
- `webapp/src/app/RecordingPage.tsx`
- `webapp/src/app.css`
- `webapp/src/components/ThemeSwitcher.tsx`
- `webapp/src/app/theme.ts`
- `webapp/src/components/graphViewer/canvas.tsx`
- `webapp/src/components/RecordingViewer.tsx`
- `webapp/src/components/RecordingChart.tsx`
- 对应前端测试文件

## 原子步骤清单

### 步骤 1：建立主题定义与切换入口
- **操作对象**：`webapp/src/app/theme.ts`、`webapp/src/App.tsx`
- **具体动作**：新增主题 id、名称、说明，并在应用根层维护主题状态。
- **预期结果**：前端具备统一主题切换能力。
- **关键里程碑**：是

### 步骤 2：接入主题预览 UI
- **操作对象**：`webapp/src/components/ThemeSwitcher.tsx`、页面组件
- **具体动作**：为首页、graph 页、recording 页加入统一的主题预览切换组件。
- **预期结果**：用户可直接在现有页面里切换预览主题。
- **关键里程碑**：是

### 步骤 3：抽取主题变量并覆盖页面样式
- **操作对象**：`webapp/src/app.css`
- **具体动作**：将背景、面板、按钮、输入框、图例、graph 画布等核心视觉元素 token 化，并实现三套主题变量覆盖。
- **预期结果**：页面视觉可随主题整体切换。
- **关键里程碑**：是

### 步骤 4：让 graph 与 recording 的内联色彩跟随主题
- **操作对象**：`webapp/src/components/graphViewer/canvas.tsx`、`webapp/src/components/RecordingViewer.tsx`、`webapp/src/components/RecordingChart.tsx`
- **具体动作**：将 graph 节点/边颜色改为主题变量，将 recording 曲线与坐标轴颜色改为从主题变量解析。
- **预期结果**：图形内容与页面框架风格一致。
- **关键里程碑**：是

### 步骤 5：验证与审查记录
- **操作对象**：前端测试命令、`docs_dev/reviews/`
- **具体动作**：执行前端类型检查、相关测试，并在完成后生成审查文档。
- **预期结果**：确认主题切换不破坏既有功能。
- **关键里程碑**：是

## 预期结果

- 网页支持三套主题实时预览。
- 首页、graph 页、recording 页的整体视觉风格同步切换。
- graph 节点与边、recording 曲线与坐标轴颜色也会随主题变化。
