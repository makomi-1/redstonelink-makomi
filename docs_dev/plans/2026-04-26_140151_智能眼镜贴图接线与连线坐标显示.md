# 智能眼镜贴图接线与连线坐标显示

生成时间：2026-04-26 14:01:51
文件名：2026-04-26_140151_智能眼镜贴图接线与连线坐标显示.md

## 任务背景
当前智能眼镜已经有现成的物品贴图与穿戴展开贴图，但项目里仍在复用原版铁头盔图标与铁质头盔材质，导致新贴图没有真正生效。同时，第三形态连线悬停 HUD 只显示另一端对象文本，不显示坐标。

## 方案详情

### 现状分析
- 智能眼镜物品模型仍指向原版 `minecraft:item/iron_helmet`。
- 智能眼镜物品仍复用 `ArmorMaterials.IRON`，穿戴外显会继续吃原版 `iron_layer_1`。
- 第三形态命中目标虽然保留了另一端方块位置，但 HUD 文本链路没有把坐标透出。

### 技术方案
- 将智能眼镜物品模型改为引用现有 `redstonelink:item/smart_glasses` 贴图。
- 为智能眼镜构造只承担贴图解析职责的专用 `ArmorMaterial.Layer`，把穿戴外显定向到 `smart_glasses_layer_1.png`，不修改默认头盔模型。
- 将第三形态命中目标的 `blockPosLong` 透传到 HUD 文本构建函数，并在悬停面板中追加一行坐标文本。
- 补充对应单元测试，覆盖物品/穿戴链路相关逻辑出口与悬停坐标显示行为。

### 影响范围
- 智能眼镜物品定义与注册
- 智能眼镜物品模型资源
- 第三形态连线悬停 HUD
- 相关单元测试

## 原子步骤清单

### 步骤 1：接入现有物品贴图
- **操作对象**：`assets/redstonelink/models/item/smart_glasses.json`
- **具体动作**：将物品模型从原版铁头盔图标切换到模组已有 `smart_glasses.png`
- **预期结果**：物品栏图标显示智能眼镜贴图
- **关键里程碑**：是

### 步骤 2：接入独立穿戴贴图链路
- **操作对象**：`SmartGlassesItem`、`ModItems`
- **具体动作**：改用智能眼镜专用护甲材质层，定向到 `smart_glasses_layer_1.png`
- **预期结果**：穿戴时使用模组准备好的智能眼镜展开贴图
- **关键里程碑**：是

### 步骤 3：补齐连线悬停坐标显示
- **操作对象**：`QuickLinkOutlineRenderer`、`LinkSerialHudOverlayRenderer`、`LinkSerialHudOverlayTextSupport`
- **具体动作**：透传并渲染连线另一端的方块坐标
- **预期结果**：准星对准连线另一端时，HUD 同时显示对象文本与坐标
- **关键里程碑**：是

### 步骤 4：验证与留档
- **操作对象**：单元测试、全量 Gradle 回归、`docs_dev/reviews/`
- **具体动作**：补测试并执行全量回归，然后写审查文档
- **预期结果**：实现可追溯，行为有自动化验证支撑
- **关键里程碑**：是

## 预期结果
智能眼镜会正确显示你已准备好的物品贴图和穿戴展开贴图；第三形态连线悬停 HUD 在保留序号/别名显示的同时，会追加另一端方块坐标。
