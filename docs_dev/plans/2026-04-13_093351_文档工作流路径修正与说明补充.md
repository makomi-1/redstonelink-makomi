# 文档工作流路径修正与说明补充

生成时间：2026-04-13 09:33:51
文件名：2026-04-13_093351_文档工作流路径修正与说明补充.md

## 任务背景
用户要求修正文档工作流中已经删除或迁移的文档路径，具体包括 `AGENTS.md`、相关技能说明以及必要时的索引文件；同时对照最近两天的提交，检查当前生效的非 README 文档是否存在遗漏，并按最小范围直接补齐。

## 方案详情

### 现状分析
- 当前规则文件和技能说明中仍存在多处 `docs_dev/使用说明.md` 等旧路径引用，但实际说明文档已迁移到 `docs/` 目录。
- `docs_dev/索引.md` 中仍保留 `docs_/` 形式的旧索引项，已经与当前目录结构不一致。
- 最近两天提交中存在“节点别名”相关功能迭代，但公开文档是否已经同步，仍需基于当前 `docs/` 下文档内容做一次针对性核查。

### 技术方案
- 先修正规则入口文件中的失效路径与过期要求，确保后续文档流程指向当前真实位置。
- 再修正 `docs_dev/索引.md`，使其与当前文档结构一致，避免后续继续引用废弃路径。
- 最后基于最近两天提交和现行 `docs/` 文档内容，最小补齐确实缺失的“节点别名”使用说明；若英文文档同样缺失，则同步补充。

### 影响范围
- 协作规则：`AGENTS.md`
- 技能说明：`skills/docs-dev-docflow/SKILL.md`
- 开发索引：`docs_dev/索引.md`
- 用户文档：`docs/使用说明.md`，以及必要时的其他 `docs/` 文档

## 原子步骤清单

### 步骤 1：修正规则与技能中的失效路径
- **操作对象**：`AGENTS.md`、`skills/docs-dev-docflow/SKILL.md`
- **具体动作**：将文档工作流和 spark 分析相关的旧路径改为当前有效路径，去掉已经删除或迁移后不再成立的要求表述
- **预期结果**：规则入口和技能说明都指向当前真实文档位置
- **关键里程碑**：是

### 步骤 2：修正开发索引
- **操作对象**：`docs_dev/索引.md`
- **具体动作**：移除陈旧的 `docs_/` 伪路径，改为当前有效文档入口，并清理已废弃项
- **预期结果**：开发索引可以正确反映现行文档位置
- **关键里程碑**：否

### 步骤 3：核查并补齐公开文档
- **操作对象**：`docs/` 下最近两天涉及的非 README 文档
- **具体动作**：对照最近两天提交与现有文档内容，检查是否遗漏“节点别名”等最近新增行为的使用说明，只对确有缺口的文档做最小补充
- **预期结果**：当前对外文档与最近实际功能保持一致
- **关键里程碑**：是

### 步骤 4：校验与留痕
- **操作对象**：改动后的文档与审查记录
- **具体动作**：检查编码/BOM/异常字符与 diff 范围，补写本轮审查文档
- **预期结果**：本轮文档改动可追溯、可审查
- **关键里程碑**：是

## 预期结果
文档工作流重新指向当前有效文档路径，开发索引不再误导，最近新增的节点别名能力在现行说明文档中得到最小且准确的同步。
