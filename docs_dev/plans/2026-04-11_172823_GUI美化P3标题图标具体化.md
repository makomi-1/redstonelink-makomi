# GUI美化P3标题图标具体化

生成时间：2026-04-11 17:28:23
文件名：2026-04-11_172823_GUI美化P3标题图标具体化.md

## 任务背景

当前多个 GUI 已完成背景、描边标题和主题色抽象，但标题仍偏泛化，缺少“具体对象类型 + 中英文并排 + 图标锚点”这一层表达。  
本轮目标是在不改贴图资源的前提下，复用 `textures/gui` 下已有 icon，为核心、triggerSource、过滤器以及相关工具 GUI 提供更具体的标题头部渲染。

## 方案详情

### 现状分析

- `GuiTitleRenderSupport` 已提供描边标题渲染，但只支持纯文本居中绘制。
- `GuiBackgroundRenderSupport` 已提供背景预设与包围盒计算，但没有 icon 资源映射与标题头部布局。
- `AbstractMultiPairingScreen`、`LinkFilterEditorScreen`、`QuickLinkToolScreen`、`StatePanelToolScreen` 都有稳定的标题/副标题/内容包围盒入口，适合复用统一标题头部。
- `TriggerSourcePairingScreen` 与 `CorePairingScreen` 目前只能拿到 `LinkNodeType` 和序号，若要显示到 `pulse/sync/toggle` 或 `core block/dust core` 这种具体对象，必须从服务端打开界面的网络 payload 增补显示上下文。
- `textures/gui` 当前仅有 `core/filter/triggersource` 三类左右 icon，尺寸均为 `16x16`，足够支撑标题头部装饰。

### 技术方案

- 新增一套公共标题头部渲染支持，统一封装：
  - 双语主标题
  - 可选副标题
  - 16x16 icon
  - icon 放置在标题组件轴向最小包围框的左上角或右上角
  - 标题头部的包围盒计算，供背景包裹复用
- pairing 网络 payload 增加“GUI 显示上下文”字段，由具体打开入口（按钮、拉杆、发射器、遥控器、核心块、核心片等）传给客户端 screen，避免客户端猜测具体类型。
- 标题文本新增 GUI 专用国际化键，内容参考现有 `item./block.` 国际键命名，并直接提供中英文并排文案。
- `QuickLinkToolScreen` 与 `StatePanelToolScreen` 继续使用现有 screen 级上下文（模式、缓存类型、当前类型）具体化标题，不额外增加贴图。

## 原子步骤清单

### 步骤 1：新增公共标题头部渲染支持
- **操作对象**：`src/client/java/com/makomi/client/screen/`
- **具体动作**：抽象双语标题、icon 语义映射、左右上角锚点和标题头部包围盒计算。
- **预期结果**：各 GUI 可复用统一的“标题+图标”渲染入口。
- **关键里程碑**：是

### 步骤 2：为 pairing GUI 透传具体显示上下文
- **操作对象**：`PairingNetwork*`、相关 block/item 打开入口、pairing screen
- **具体动作**：为配对界面 payload 添加具体对象显示键，并在客户端据此渲染具体标题。
- **预期结果**：triggerSource/core 配对界面可显示具体对象类型，而不再只有泛化 `triggerSource/core` 标题。
- **关键里程碑**：是

### 步骤 3：接入 filter/quick link/state panel 标题头部
- **操作对象**：对应 screen 类
- **具体动作**：替换当前标题绘制，接入统一标题头部渲染和包围盒。
- **预期结果**：主要 GUI 标题表现一致，图标位置统一。
- **关键里程碑**：是

### 步骤 4：补国际化键与双语文案
- **操作对象**：`zh_cn.json`、`en_us.json`
- **具体动作**：新增 GUI 双语标题键，并调整相关副标题文案。
- **预期结果**：标题不写死代码，且稳定显示中英文。
- **关键里程碑**：否

### 步骤 5：回归验证与审查文档
- **操作对象**：Gradle 测试、`docs_dev/reviews/`
- **具体动作**：执行全标签测试并补审查文档。
- **预期结果**：本轮改动完成交付闭环。
- **关键里程碑**：是

## 预期结果

- GUI 标题不再只写抽象类型，而是明确到真实对象或真实模式。
- 现有 `core/filter/triggersource` icon 被统一锚定到标题组件包围盒左上角或右上角。
- 中英文标题通过国际化键输出，可在多个 screen 之间复用。

## 语义对齐说明

- 命名继续统一使用 `triggerSource/core` 作为系统语义基线，显示层只做对象具体化，不改变内部方向语义。
- 输入/输出结构保持 `triggerSource -> core` 一致，不引入反向写入。
- 文案新增不会把旧术语写回内部结构或网络协议字段；新增上下文字段仅服务 GUI 显示。
- 与 `LinkNodeType.TRIGGER_SOURCE/CORE` 映射保持一一对应。
- 兼容层仅新增“读上下文显示”，不引入 `com.makomi.api.v1.*`。残余风险：若未来继续扩展更多 GUI 专属 icon，需要再补贴图资源。
