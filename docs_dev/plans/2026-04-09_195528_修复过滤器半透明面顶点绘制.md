# 修复过滤器半透明面顶点绘制

生成时间：2026-04-09 19:55:28

## 任务背景
过滤器影响域当前已经具备不穿墙线框与半透明红色面层，用于增强范围辨识度。实测中面层显示成错误三角面，说明当前面层顶点组织方式不符合这条渲染管线的预期，需要在不改变既有线框、不引入穿墙效果的前提下修正盒体几何。

## 方案详情

### 现状分析
当前实现位于 `src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java`。面层绘制直接调用 `LevelRenderer.addChainedFilledBoxVertices(...)`，但该辅助方法的顶点组织与当前 `VertexFormat.Mode.QUADS` 面层渲染不匹配，导致过滤器影响域显示为错误三角面。线框绘制使用 `LevelRenderer.renderLineBox(...)`，行为正常，不需要调整。

### 技术方案
保留现有不穿墙红色线框、透明度常量、距离门控与渲染状态，仅替换半透明面层的顶点写入方式。具体做法是在渲染器内部新增手工顶点写入方法，按盒体的上、下、前、后、左、右六个面逐面写入四边形顶点，避免继续依赖语义不匹配的盒体辅助 API。
