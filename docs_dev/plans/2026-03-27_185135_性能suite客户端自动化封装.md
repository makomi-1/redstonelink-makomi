# 性能 suite 客户端自动化封装

生成时间：2026-03-27 18:51:35
文件名：2026-03-27_185135_性能suite客户端自动化封装.md

## 任务背景

当前 `performance-lite` 与 `performance-heavy` 已能通过 `run-bench-suite.ps1` 运行，但每次都要手写较长的客户端自动进服、自动传送、聚焦窗口、打开 `F3+2` tick 曲线等参数。

本轮目标是为性能 suite 提供可直接执行的命令文件，默认带上外部客户端自动化观察链路，同时保留按需覆盖 case 列表与构建同步的能力。

## 方案详情

### 现状分析

- 现有总入口：`tools/bench/run-bench-suite.ps1`
- 已支持的能力：
  - `-AutoStartBenchClient`
  - `-BenchClientFocusWindow`
  - `-BenchClientOpenTickCharts`
  - `-AutoTeleportPlayerToObservationPoint`
  - `-CaseIds`
  - `-BuildBeforeSyncLatestModJar`
  - `-SyncLatestModJar`
  - `-SyncLatestClientModJar`
- 已有包装脚本只覆盖 `first-mandatory`，性能 suite 还没有对应的一键入口。

### 技术方案

- 新增一个公共性能包装器脚本，集中处理：
  - lite/heavy suite 选择
  - Prism 启动命令构造
  - `AsPlayer` 与 `BenchClientPlayerName` 默认对齐
  - 自动传送、窗口聚焦、`F3+2` tick 曲线默认开启
  - `CaseIds`、构建同步等可选覆盖
- 再新增 4 个薄包装命令文件：
  - `run-performance-lite-suite.ps1`
  - `run-performance-lite-suite-build-sync.ps1`
  - `run-performance-heavy-suite.ps1`
  - `run-performance-heavy-suite-build-sync.ps1`
- 更新 `docs_dev/使用说明.md`，补充这 4 个脚本的默认行为与示例。

### 影响范围

- `tools/bench/` 下新增性能 suite 包装脚本
- `docs_dev/使用说明.md`
- `docs_dev/plans/`
