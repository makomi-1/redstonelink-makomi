# 跨模式草稿应用后的可见性聚合与聚焦修复

生成时间：2026-04-19 20:37:10
文件名：2026-04-19_203710_跨模式草稿应用后的可见性聚合与聚焦修复.md

## 任务背景

当前图可视化编辑器在“另一模式节点池”应用到草稿后，存在三类前端异常：

1. 序号模式下，新迁回的节点切到编辑模式后会消失；搜索能找到，但只显示命中的单个节点。
2. 频道模式下，新迁入的节点会破坏聚合恢复，尤其 `triggerSource` 侧无法重新聚合。
3. 应用草稿后的上下文自动聚焦不稳定，存在未聚焦或聚焦到错误对象的情况。

本轮只修前端显示与交互层，不新增后端 API，不改变草稿与保存语义。

## 方案详情

### 现状分析

- `GraphViewer` 当前把批量编辑选区直接作为“强制可见”和“自动展开”的依据，即使处于查看态也会持续生效。
- 跨模式应用草稿后，业务选区会写入 `selectedEditSourceSerials / selectedEditTargetSerials / selectedEditChannelNodeKeys`，但 ReactFlow 受控 `selected` 没同步更新。
- 切到编辑模式后，空的画布选区回流会把业务选区覆盖为空，导致刚迁入节点失去可见性与聚合展开资格。
- 聚焦逻辑没有统一复用“哪一类节点选得更多”的规则，跨模式应用后常使用不稳定的首节点作为焦点。

### 技术方案

- 在 `GraphViewer.tsx` 中拆分“存量编辑上下文”和“当前画布生效选区”：
  - 存量编辑上下文继续保留，供应用草稿后继续编辑。
  - 只有真正进入编辑态时，这些选区才参与 `forcedVisibleNodeKeys`、`aggregateAutoExpandNodeKeys` 和画布选中态。
- 在切入编辑态、跨模式应用草稿后，显式把业务选区同步回 ReactFlow 受控 `selected`，避免空选区回流把业务选区清空。
- 抽取统一的焦点选择规则，按“选中节点类别数量更多的一侧优先，当前已选节点次优先，最后再稳定兜底”决定重排后的聚焦目标。
- 在 `canvas.test.tsx` 和 `GraphViewer.test.tsx` 中补充针对“查看态聚合恢复”和“切入编辑态后节点不消失”的断言。

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- `webapp/src/components/GraphViewer.test.tsx`
- `webapp/src/components/graphViewer/canvas.test.tsx`
- 审查文档与验证产物

## 原子步骤清单

### 步骤 1：解耦编辑上下文与查看态显隐
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：新增“当前编辑态有效选区”派生集合，仅在编辑态参与强制可见、聚合自动展开和节点高亮。
- **预期结果**：查看态不再被残留编辑选区持续撑开，频道模式可重新聚合。
- **关键里程碑**：是

### 步骤 2：修复受控选区同步
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：在跨模式应用草稿和切入编辑态后，同步业务选区到 ReactFlow 受控选中态，并规避空回流覆盖。
- **预期结果**：序号模式下迁回节点切入编辑态不会消失，编辑态直接添加也可继续看到。
- **关键里程碑**：是

### 步骤 3：统一重排后的上下文聚焦
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：抽取统一焦点决策函数，跨模式应用和批量编辑都复用同一规则。
- **预期结果**：应用草稿后的自动聚焦更稳定，不再频繁回整图中心或焦错对象。
- **关键里程碑**：否

### 步骤 4：补充前端回归测试
- **操作对象**：`webapp/src/components/GraphViewer.test.tsx`、`webapp/src/components/graphViewer/canvas.test.tsx`
- **具体动作**：新增“编辑态不丢节点”和“频道查看态重新聚合”的测试。
- **预期结果**：本轮修复点可自动回归验证。
- **关键里程碑**：否

## 预期结果

- 序号模式下，跨模式应用后的节点在切换到编辑模式时仍保持可见，并可继续编辑。
- 频道模式下，新增成员在查看态可重新进入正确的聚合块显示，不再长期被强制展开。
- 自动聚焦复用稳定规则，减少应用草稿后的错误聚焦和失焦现象。
