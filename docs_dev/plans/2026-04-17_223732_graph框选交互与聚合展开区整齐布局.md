# graph框选交互与聚合展开区整齐布局

生成时间：2026-04-17 22:37:32

## 任务背景

当前 graph 编辑器只能逐个点击节点进行批量选择，缺少主流的框选交互；同时普通区域已经加入稳定微扰动来减少边重叠，但聚合块展开后的 core 节点也被一起打散，影响成组阅读。  
本轮目标是在不改变 `triggerSource/core` 真值语义的前提下，补齐左键框选，并让聚合块展开区恢复整齐排列。

## 方案详情

### 现状分析

- `GraphViewer` 当前通过 `selectedEditSourceSerials / selectedEditTargetSerials` 维护批量编辑选择，未接入 ReactFlow 的内建框选。
- 画布当前启用了 `panOnDrag`，这会和“空白处左键拖拽框选”冲突。
- 当前布局扰动统一施加在 `buildLaneLayout`，无法区分“普通区域可打散”和“聚合展开区要整齐”。

### 技术方案

- 使用 ReactFlow 内建框选能力：
  - 空白画布左键拖拽直接框选
  - 节点左键拖拽继续移动
  - `Ctrl/Shift` 作为追加多选键
  - 画布平移改为中键拖拽
- 在编辑模式下，将 ReactFlow 的选中节点集合映射回 `selectedEditSourceSerials / selectedEditTargetSerials`，保持与现有批量编辑面板兼容。
- 为 `buildLaneLayout` 增加扰动开关；普通区域继续保留轻微打散，聚合块展开后的 core 排布关闭扰动并保持整齐。

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- 如有必要，少量 `webapp/src/app.css`

## 原子步骤清单

### 步骤 1：接入框选交互
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：为 `ReactFlow` 开启左键框选、追加多选和中键平移配置
- **预期结果**：空白区域左键拖拽可以直接框选节点
- **关键里程碑**：是

### 步骤 2：同步批量编辑选择
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：将框选结果映射回来源/目标批量选择集合，并与现有点击选择逻辑保持一致
- **预期结果**：框选后的节点可直接参与 `add/remove/replace`
- **关键里程碑**：是

### 步骤 3：聚合展开区恢复整齐
- **操作对象**：`webapp/src/components/GraphViewer.tsx`
- **具体动作**：给 lane 布局增加扰动开关，对展开聚合块内部的 core 节点关闭微扰动
- **预期结果**：展开后的核心节点整齐排列，普通区域仍保持轻度去重叠
- **关键里程碑**：是

- **具体动作**：执行 `npm.cmd run typecheck`、`.\gradlew.bat buildWebapp --no-daemon`、`.\gradlew.bat test testIntegration testClient testSlow --no-daemon`

- **关键里程碑**：是
