# 新增无线化装饰发光原型

生成时间：2026-05-04 17:21:39
文件名：2026-05-04_172139_新增无线化装饰发光原型.md

## 任务背景

当前项目已经有 `无线化红石灯`、`无线化海晶灯` 等 `core` 原型，证明“保留原版外观与放置直觉，仅把亮灭控制改接到 `triggerSource -> core`”这条路线成立。  
本次继续补齐一批以装饰为主的发光原版件，降低玩家理解成本，并为后续更多原版或其它 Mod 灯具联动建立统一模式。

本轮目标：

- 无线化灯笼
- 无线化灵魂灯笼
- 无线化末地烛
- 无线化蛙明灯
- 无线化南瓜灯
- 无线化萤石
- 无线化普通火把
- 无线化灵魂火把

## 方案详情

### 现状分析

- 现有 `WirelessSeaLanternBlock` 已经提供了“普通装饰灯 `core`”的最小实现模板：自带 `LIT` 外显、只吃无线输入、不读原版邻居红石。
- 现有 `WirelessCoreBlockEntity` 已经把 `core` 的通用语义统一好了：方向固定为 `triggerSource -> core`，只负责把激活态映射到原版表现。
- 需要额外处理的主要差异不在节点语义，而在原版外观状态：
  - 灯笼类有悬挂状态
  - 火把类有地面 / 墙面双形态
  - 末地烛有层数与朝向
  - 蛙明灯、南瓜灯、萤石属于普通完整方块

### 技术方案

采用“同一语义、按外观族拆方块”的实现方式：

1. 普通装饰灯方块族  
   `蛙明灯 / 南瓜灯 / 萤石` 直接复用海晶灯式实现：
   - 方块侧维护 `LIT`
   - 方块实体继承 `WirelessCoreBlockEntity`
   - 只在无线输入变化时同步亮灭

2. 灯笼族  
   `灯笼 / 灵魂灯笼` 复用原版悬挂状态与模型，新增 `LIT` 外显，用无线输入控制亮灭。

3. 火把族  
   `普通火把 / 灵魂火把` 需要同时落地面火把与墙火把两种方块：
   - 统一作为 `core`
   - 共享同一种掉落物与节点语义
   - 只保留原版放置与模型切换，不保留原版邻居供电语义

4. 末地烛族  
   `末地烛` 保留层数、朝向和基本放置行为，仅把“是否发光”改由无线输入控制。

5. 资源与转化接线  
   - 模型、贴图、blockstate 优先复用原版资源路径
   - 接入 `ModBlocks / ModItems / ModBlockEntities`
   - 接入语言、loot、采掘标签、远外显 HUD、GUI 显示上下文
   - 接入 `wireless_conversion` 配方

## 预期结果

- 玩家可把这批装饰性发光原版件转成“无线化”版本。
- 它们统一作为 `core`，由已连接 `triggerSource` 控制亮灭。
- 原版外观和主要放置手感保留，原版邻居红石输入输出不再生效。
- 新增设计、文案和内部语义继续统一使用 `triggerSource/core`，兼容层仅保留“读旧写新”。
