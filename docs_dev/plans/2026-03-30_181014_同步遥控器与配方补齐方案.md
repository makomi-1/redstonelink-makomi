# 同步遥控器与配方补齐方案

生成时间：2026-03-30 18:10:14
文件名：2026-03-30_181014_同步遥控器与配方补齐方案.md

## 任务背景

本轮需要在现有两种遥控器基础上新增“同步遥控器”，其交互手势与已有遥控器一致，但行为语义类同步拉杆，采用 `15/0` 两态切换并随状态切换物品贴图。

同时补齐两个配方：
- 同步遥控器：沿用其它遥控器的两格横向配方风格，仅将按钮材料替换为连接同步拉杆。
- 快速连接工具：按既定图案新增 1:1 合成配方。

## 方案详情

### 现状分析

- 现有遥控器由 `LinkerItem` 承载，只支持 `TOGGLE/PULSE` 激活语义。
- 同步语义当前不属于 `ActivationMode`，而是由同步拉杆通过 `dispatchSyncSignal(...)` 走独立派发链。
- 仓库中已存在同步遥控器所需的两张贴图资源 `redstonelink_sync_linker_0.png` 与 `redstonelink_sync_linker_1.png`。
- 快速连接工具已完成注册与交互实现，但尚无合成配方。

### 技术方案

- 新增独立 `SyncLinkerItem`，不扩展 `ActivationMode`，避免污染现有切换/脉冲遥控器语义。
- 对 `LinkerItem` 做最小抽取，使同步遥控器可复用：
  - 潜行右键开配对界面
  - 站立右键执行主动作
  - 补序号、同步当前连接快照、基础 tooltip
- 在 `LinkItemData` 中新增同步遥控器 `0/15` 状态读写，并同步镜像到 `DataComponents.CUSTOM_MODEL_DATA`，供 item model override 切换贴图。
- 同步遥控器站立右键时：
  - 在 `0/15` 间切换
  - 回写 replay sync 快照
  - 调用 `dispatchSyncSignal(...)` 将当前强度同步到已连接 core
- 资源层仅新增模型、语言键与 recipe，不修改任何现有贴图内容。

## 原子步骤清单

### 步骤 1：抽取遥控器基础交互壳层
- **操作对象**：`LinkerItem`
- **具体动作**：将现有右键开配对、站立右键执行主动作、连接快照同步与基础 tooltip 整理为可复用受保护方法。
- **预期结果**：同步遥控器可在不复制整类的前提下复用基础交互。
- **关键里程碑**：是

### 步骤 2：扩展物品数据以保存同步遥控器状态
- **操作对象**：`LinkItemData`
- **具体动作**：新增同步遥控器 `0/15` 状态字段与 `CustomModelData` 镜像读写方法。
- **预期结果**：同步遥控器状态可持久化且贴图可切换。
- **关键里程碑**：是

### 步骤 3：新增同步遥控器物品类
- **操作对象**：`SyncLinkerItem`
- **具体动作**：实现站立右键 `15/0` 切换、回写 replay snapshot、同步派发到已连接 core。
- **预期结果**：同步遥控器具备类同步拉杆行为。
- **关键里程碑**：是

### 步骤 4：注册新物品并补齐资源
- **操作对象**：`ModItems`、`ModItemGroups`、语言文件、item model
- **具体动作**：注册 `redstonelink_sync_linker`，接入创造栏、中英文名称与状态贴图切换模型。
- **预期结果**：同步遥控器在游戏内可获取、可显示。
- **关键里程碑**：否

### 步骤 5：补齐两个 recipe
- **操作对象**：`src/main/resources/data/redstonelink/recipe`
- **具体动作**：新增同步遥控器配方与快速连接工具配方。
- **预期结果**：两者均可通过合成台 1:1 合成。
- **关键里程碑**：否

### 步骤 6：补最小测试与使用说明
- **操作对象**：`LinkItemDataTest`、`使用说明.md`
- **具体动作**：增加同步遥控器状态镜像测试，并同步使用说明中的获取与使用方式。
- **预期结果**：改动有最小回归证据，使用说明与实际一致。
- **关键里程碑**：否

## 预期结果

- 新增“连接同步遥控器”，交互与现有遥控器一致，但行为为同步拉杆式 `15/0` 状态对齐。
- 同步遥控器右键切换时会同步切换贴图，并将当前强度同步到已连接 core。
- 新增同步遥控器配方：`连接同步拉杆 + 拉杆 -> 连接同步遥控器`。
- 新增快速连接工具配方：按既定图案 1:1 合成。
