# 触发器和核心物品Tooltip补充频道信息

生成时间：2026-04-21 13:09:41
文件名：2026-04-21_130941_触发器和核心物品Tooltip补充频道信息.md

## 任务背景
当前 triggerSource 与 core 物品的 Tooltip 仅展示序号和连接快照，无法直接看到频道配置。项目已经落地频道模式，但物品快照尚未携带频道字段，导致玩家在物品栏、掉落物回收或频道编辑后无法稳定查看当前频道信息。本次仅补充 Tooltip 所需的频道快照与展示，不扩展到其他界面或协议。

## 方案详情

### 现状分析
- `PairableBlockItem` 的 Tooltip 入口当前只读取物品上的序号、别名和链接快照。
- `LinkItemData` 当前没有频道快照键，也没有统一同步频道值。
- 频道编辑完成后会刷新连接快照，但若频道变化不影响链接集合，物品 Tooltip 仍可能保留旧值。
- 方块掉落转回物品时会补序号、别名和链接，但不会补频道。

### 技术方案
- 在 `LinkItemData` 增加频道快照键、读写方法与统一同步逻辑。
- 将单件物品快照同步扩展为“别名 + 连接 + 频道”一起刷新，并在清空/聚合场景下同步清理频道字段。
- 在 `PairableBlockItem` 的单件 Tooltip 中追加频道行，使用新文案键展示当前频道；无频道时显示 `-`。
- 在 triggerSource/core 方块掉落与频道编辑后的物品同步链路中复用统一快照刷新，确保 Tooltip 展示始终与当前真值一致。

## 原子步骤清单

### 步骤 1：补充物品频道快照
- **操作对象**：`LinkItemData`
- **具体动作**：新增频道读写接口、频道快照同步与聚合清理逻辑，保持单件物品快照统一收口。
- **预期结果**：物品可持久携带频道值，且聚合态或无效态不会残留旧频道。
- **关键里程碑**：是

### 步骤 2：补充 Tooltip 展示
- **操作对象**：`PairableBlockItem`、语言文件
- **具体动作**：为单件 triggerSource/core Tooltip 追加频道信息，并补中英文文案。
- **预期结果**：玩家悬停物品时可直接看到频道信息。
- **关键里程碑**：是

### 步骤 3：补齐同步入口
- **操作对象**：频道编辑同步链路、方块掉落转物品路径
- **具体动作**：在频道编辑后刷新命中的物品频道快照，并在掉落物构造时补齐频道值。
- **预期结果**：频道修改、方块破坏回收、物品再查看时都能显示最新频道。
- **关键里程碑**：是

### 步骤 4：补充回归测试
- **操作对象**：`LinkItemDataTest`
- **具体动作**：增加频道字段读写、清理与快照行为测试。
- **预期结果**：核心数据链具备自动化回归覆盖。
- **关键里程碑**：否
