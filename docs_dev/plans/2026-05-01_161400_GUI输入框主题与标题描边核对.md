# GUI输入框主题与标题描边核对

生成时间：2026-05-01 16:14:00
文件名：2026-05-01_161400_GUI输入框主题与标题描边核对.md

## 任务背景
当前 1.21.11 工作区里的多行输入框主题色没有恢复到原 1.21.1 版本的设计效果，别名输入框里的预留字仍存在阴影；同时需要核对当前 GUI 标题描边是否仍是原版方法，以及当前是否带阴影。

## 方案详情

### 现状分析
- 当前 `StyledMultiLineEditBox` 已退化为简单 builder 工厂，主题色参数没有真正参与背景、边框与计数字体的绘制。
- 原 1.21.1 实现通过继承 `MultiLineEditBox` 覆写背景和装饰层，提供主题背景与无阴影计数。
- 当前 `StyledEditBox` 只自绘单行输入框外壳，但没有显式关闭 `EditBox` 文本/占位字阴影。
- 当前 `GuiTitleRenderSupport` 为手写四向描边，不是原版 `Font.drawInBatch8xOutline` 路径，且当前绘制不带阴影。

### 技术方案
- 在当前 1.21.11 接口下重建一层可主题化的多行输入框实现，恢复背景、边框、聚焦色和无阴影计数字体。
- 保留原版文本编辑、光标与滚动行为，只接管外观层。
- 在 `StyledEditBox` 内显式关闭文本阴影，使别名输入框占位提示也走无阴影路径。
- 标题描边本轮只做实现状态核对，不改当前绘制链。

### 影响范围
- `src/client/java/com/makomi/client/screen/StyledMultiLineEditBox.java`
- `src/client/java/com/makomi/client/screen/ShadowlessCounterMultiLineEditBox.java`
- `src/client/java/com/makomi/client/screen/StyledEditBox.java`
- `docs_dev/reviews/` 对应审查文档

## 原子步骤清单

### 步骤 1：重建多行输入框主题层
- **操作对象**：`StyledMultiLineEditBox`、`ShadowlessCounterMultiLineEditBox`
- **具体动作**：按 1.21.11 当前可用接口恢复主题背景、边框、聚焦态和无阴影计数渲染
- **预期结果**：多行输入框主题色与 1.21.1 设计对齐
- **关键里程碑**：是

### 步骤 2：修复别名输入框占位字阴影
- **操作对象**：`StyledEditBox`
- **具体动作**：显式关闭文本/占位字阴影，保持现有主题壳不变
- **预期结果**：别名输入框预留字无阴影
- **关键里程碑**：是

### 步骤 3：编译验证与审查文档
- **操作对象**：Gradle、`docs_dev/reviews/`
- **具体动作**：执行客户端编译验证，并补充本轮五段式审查文档
- **预期结果**：改动具备可编译验证与审查留痕
- **关键里程碑**：是
