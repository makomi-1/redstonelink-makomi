# P2独立曲线页与指定文件加载

生成时间：2026-04-16 19:02:18
文件名：2026-04-16_190218_P2独立曲线页与指定文件加载.md

## 任务背景

当前 `P2` 已完成状态面板录制子集选择和网页端基础曲线查看，但录制结果查看仍有三个明显问题：

- 游戏内导出后虽然能带 `kind=recording&name=...` 定位文件，但网页仍停在资产总览页，不是独立的曲线查看页。
- 曲线页面空间过小，和资产索引混在一页里，影响录制分析体验。
- 时间窗操作仍然依赖按钮，不符合录制曲线工具的常见操作方式。

本轮目标是在不引入复杂路由框架、不改 recording bundle 数据格式的前提下，补齐“独立曲线页 + 指定文件加载 + 鼠标/滚轮/快捷键交互”的查看闭环。

## 方案详情

### 现状分析

- 本地网页桥接服务已经支持带 `kind=recording&name=...` 参数打开网页，但入口仍默认解析到首页。
- 当前 `App.tsx` 同时承担资产总览与 recording viewer 渲染，页面结构耦合较重。
- 录制 viewer 已具备 recording 文件解析、节点切换、曲线显隐和窗口状态模型，但窗口操作仍通过按钮触发。
- `RecordingChart` 已基于 `uPlot` 渲染曲线，可继续复用其绘图层，不需要重做图表底座。

### 技术方案

#### 1. 独立 recording 页面

- 继续沿用当前单入口 SPA，不引入 `react-router`。
- 改为通过 query 参数区分页面：
  - `./` 或 `./?page=home`：资产入口页
  - `./?page=recording`：独立录制曲线页
  - `./?page=recording&kind=recording&name=...`：直接定位指定 recording 文件
- 首页保留资产总览；recording 页专注曲线查看。

#### 2. 曲线页内主动选择并加载指定文件

- recording 页启动后读取本地资产索引。
- 仅筛选 `recording` 分类资产作为可选文件列表。
- 曲线页顶部提供 recording 文件选择器，可主动切换到任意本地 recording 文件。
- 若 URL 已带 `name`，优先自动加载该文件；若未指定，则等待用户在曲线页中选择。
- 切换文件时同步更新地址栏参数，保证刷新页面后仍回到当前文件。

#### 3. 游戏内导出后的网页直达

- 调整 `LocalWebAppBridgeService.openAssetEntry(...)`。
- 当打开的是 recording 资产时，改为跳转 `page=recording&kind=recording&name=...`。
- 其他资产仍保持首页行为，避免把非 recording 资产错误送到曲线页。

#### 4. 窗口交互改为滚轮/拖拽/快捷键

- 移除 recording viewer 中按钮式窗口操作。
- 改为：
  - 鼠标滚轮：以当前鼠标 x 位置为中心缩放时间窗
  - 鼠标拖拽：水平平移时间窗
  - 双击：重置时间窗
  - 键盘 `←/→`：平移
  - 键盘 `+/-`：缩放
  - 键盘 `0`：重置
- 键盘事件仅在曲线主容器获得焦点后生效，避免干扰页面中其他控件。

### 技术取舍

- 不引入路由库，避免为离线嵌入网页增加额外框架负担。
- 指定文件加载入口放在曲线页自身，而不是继续依赖首页资产列表，减少页面跳转层级。
- 继续复用 `uPlot`，只改交互层和页面布局，不重做图表库。
- 时间窗仍由外层 viewer 持有真值，图表组件只负责事件采集和窗口变更回传，保持展示与状态分层。

### 影响范围

- 本地网页桥接跳转参数
- `webapp` 页面入口结构与 recording 专用页
- recording viewer 文件加载流程
- 图表组件鼠标/滚轮/键盘交互
- 样式布局与相关构建验证
