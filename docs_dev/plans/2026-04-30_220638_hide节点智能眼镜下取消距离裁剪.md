# hide节点智能眼镜下取消距离裁剪

生成时间：2026-04-30 22:06:38
文件名：2026-04-30_220638_hide节点智能眼镜下取消距离裁剪.md

## 任务背景

当前 `hide` 节点在佩戴智能眼镜后虽然可见，但仍会沿用可见节点的 block entity 渲染可视距离，导致远距离 ghost 模型被裁掉。需求是仅对 `hide` 节点取消这层距离裁剪，普通节点显示策略保持不变。

## 方案详情

### 现状分析

- `HideNodeGhostRenderer` 复用了 `LinkNodeFarOverlayRenderer.getViewDistance()`
- `HideFilterGhostRenderer` 复用了 `LinkFilterAreaRenderer.getViewDistance()`
- `HideChunkActivatorGhostRenderer` 复用了 `ChunkActivatorFarOverlayRenderer.getViewDistance()`

因此 `hide` 节点虽然是单独的 ghost 渲染器，但实际上仍被普通 far overlay 的 view distance 约束。

### 技术方案

只修改三个 `hide` ghost renderer 的 `getViewDistance()`，返回一个极大值，取消其 BER 距离裁剪。普通节点 renderer 不改，确保影响范围只落在 `hide` 节点。

### 影响范围

- `src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java`
- `src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java`
- `src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java`

## 原子步骤清单

### 步骤 1：取消普通 hide 节点距离裁剪
- **操作对象**：`HideNodeGhostRenderer`
- **具体动作**：`getViewDistance()` 改为返回极大值
- **预期结果**：hide core / hide triggerSource / hide repeater 不再因距离过远被 BER 裁掉
- **关键里程碑**：是

### 步骤 2：取消 hide 过滤器距离裁剪
- **操作对象**：`HideFilterGhostRenderer`
- **具体动作**：`getViewDistance()` 改为返回极大值
- **预期结果**：hide send/receive filter 不再因距离过远被 BER 裁掉
- **关键里程碑**：是

### 步骤 3：取消 hide 区块激活器距离裁剪
- **操作对象**：`HideChunkActivatorGhostRenderer`
- **具体动作**：`getViewDistance()` 改为返回极大值
- **预期结果**：hide chunk activator 不再因距离过远被 BER 裁掉
- **关键里程碑**：是

### 步骤 4：回归验证
- **操作对象**：Gradle 测试任务
- **具体动作**：执行 `.\gradlew.bat compileJava compileClientJava test testIntegration testClient testSlow --no-daemon`
- **预期结果**：客户端显示改动不引入回归
- **关键里程碑**：是

## 预期结果

佩戴智能眼镜时，所有 `hide` 块状节点的 ghost 显示不再因为距离过远被裁掉；未佩戴时仍保持不可见、不可正常交互；普通节点维持原有可视距离策略。
