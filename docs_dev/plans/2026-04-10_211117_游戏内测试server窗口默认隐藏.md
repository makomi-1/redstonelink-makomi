# 游戏内测试server窗口默认隐藏

生成时间：2026-04-10 21:11:17
文件名：2026-04-10_211117_游戏内测试server窗口默认隐藏.md

## 任务背景

当前仓库内大多数 dedicated bench / regression / performance 包装脚本已经默认使用 `ServerWindowMode=Hidden`，但核心 suite 入口与底层 dedicated server 启动兜底仍残留 `Normal` 默认值，导致“未显式传参时到底是否隐藏窗口”不完全一致。用户要求统一把所有游戏内测试的 server window 默认改为 `Hidden`。

## 方案详情

### 现状分析

- `tools/bench/run-bench-suite.ps1` 仍把 `ServerWindowMode` 默认值设为 `Normal`。
- `tools/bench/lib/BenchSuite.Server.ps1` 的 `Start-DedicatedServerProcess` 也仍保留 `WindowMode = "Normal"` 兜底值。
- 多数包装脚本与部分说明文档已经按 `Hidden` 使用，因此当前问题集中在入口默认值与文档描述不一致。

### 技术方案

- 把 `tools/bench/run-bench-suite.ps1` 的 `ServerWindowMode` 默认值改为 `Hidden`。
- 把 `tools/bench/lib/BenchSuite.Server.ps1` 的 `Start-DedicatedServerProcess` 兜底默认值改为 `Hidden`，保证未来脚本若漏传参数也保持一致。
- 同步 `docs_dev/使用说明.md` 中仍残留的旧说明，改成“原始 suite 入口也默认隐藏窗口”。

### 影响范围

- `tools/bench/run-bench-suite.ps1`
- `tools/bench/lib/BenchSuite.Server.ps1`
- `docs_dev/使用说明.md`

## 原子步骤清单

### 步骤 1：修改 suite 主入口默认值
- **操作对象**：`tools/bench/run-bench-suite.ps1`
- **具体动作**：将 `ServerWindowMode` 参数默认值从 `Normal` 调整为 `Hidden`
- **预期结果**：直接运行 suite 主入口时默认隐藏 dedicated server 窗口
- **关键里程碑**：是

### 步骤 2：修改底层 dedicated server 启动兜底
- **操作对象**：`tools/bench/lib/BenchSuite.Server.ps1`
- **具体动作**：将 `Start-DedicatedServerProcess` 的 `WindowMode` 默认值从 `Normal` 调整为 `Hidden`
- **预期结果**：即使漏传窗口参数，底层仍默认隐藏窗口
- **关键里程碑**：是

### 步骤 3：同步使用说明
- **操作对象**：`docs_dev/使用说明.md`
- **具体动作**：更新关于 `ServerWindowMode` 默认值的文档描述
- **预期结果**：文档与脚本真实行为一致
- **关键里程碑**：否

### 步骤 4：最小验证与审查
- **操作对象**：脚本搜索结果、审查文档
- **具体动作**：重新扫描 `ServerWindowMode` 默认值残留项，并补充审查文档
- **预期结果**：默认值统一且有可追溯记录
- **关键里程碑**：是

- 用户仍可通过显式传 `-ServerWindowMode Normal|Minimized|Hidden` 覆盖默认行为
- 文档与实际脚本行为保持一致
