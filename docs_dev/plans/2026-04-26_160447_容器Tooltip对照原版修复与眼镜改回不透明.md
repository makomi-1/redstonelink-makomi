# 容器Tooltip对照原版修复与眼镜改回不透明

生成时间：2026-04-26 16:04:47
文件名：2026-04-26_160447_容器Tooltip对照原版修复与眼镜改回不透明.md

## 任务背景

用户在上一轮修复后继续游戏内复测，发现两个残留问题：

1. 智能节点容器 GUI 内部与玩家背包物品仍然没有悬停 tooltip。
2. 智能眼镜半透明穿戴效果仍然失败，希望直接废弃半透明方案，改回不透明显示。

此外，用户询问智能眼镜当前是否像普通头盔一样具有耐久，本轮先给出现状结论，不改耐久逻辑。

## 方案详情

### 现状分析

- 原版 `AbstractContainerScreen` 的 tooltip 依赖 `render(...)` 中维护的 `hoveredSlot`，再在 `renderTooltip(...)` 里读取该状态绘制物品提示。
- 当前 `SmartNodeContainerScreen` 的 tooltip 兜底仍然依赖继承来的 `hoveredSlot`，如果该状态未稳定命中，则兜底逻辑也会同步失效。
- 当前智能眼镜半透明渲染已经被用户判定为失败方案，因此本轮不再继续调 alpha，直接恢复不透明护甲渲染。
- 智能眼镜当前注册时只使用 `new Item.Properties().stacksTo(1)`，未显式设置 `durability(...)`，因此没有普通头盔式耐久。

### 技术方案

1. 对照原版槽位命中方式，在 `SmartNodeContainerScreen` 中自行遍历菜单槽位并计算悬停槽位，不再依赖继承态 `hoveredSlot`。
2. 将槽位 tooltip 绘制放到 `render(...)` 末尾显式执行，确保 tooltip 最终绘制在界面最上层。
3. 将智能眼镜穿戴渲染改回 Fabric 提供的标准护甲绘制辅助 `ArmorRenderer.renderPart(...)`，恢复不透明显示。
4. 保持智能眼镜耐久现状不变，仅在结果中明确说明其当前无耐久。

### 影响范围

- 客户端 GUI：`SmartNodeContainerScreen`
- 客户端护甲渲染：`SmartGlassesArmorRenderer`
- 文档：本轮方案文档与后续审查文档
