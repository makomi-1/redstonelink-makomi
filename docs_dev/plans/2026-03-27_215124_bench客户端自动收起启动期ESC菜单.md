# bench 客户端自动收起启动期 ESC 菜单

生成时间：2026-03-27 21:51:24
文件名：2026-03-27_215124_bench客户端自动收起启动期ESC菜单.md

## 任务背景

当前 bench 外部客户端已经可以自动启动、自动进服、自动传送观察位、自动聚焦并打开 `F3+2` tick 曲线。  
但在实际运行中，客户端有时会在已经进入世界后停留在 `ESC` 暂停菜单，界面显示“回到游戏”，仍需要人工点击一次才能回到真实观察视角。

用户本轮要求是：让该类“启动阶段误弹出的 `ESC` 暂停菜单”也能自动收起，但不能影响后续玩家自己主动按 `ESC` 打开的菜单。

## 方案详情

### 现状分析

- `BenchClientAutomationController` 当前只会自动关闭标题页、多人页、连接页、加载页、断线页等“启动链路残留界面”
- 当前没有处理 `PauseScreen`
- 若直接把 `PauseScreen` 并入现有 `isTransientStartupScreen`，会导致玩家后续手动按 `ESC` 时也被自动关闭，不符合预期

### 技术方案

1. 新增“启动期暂停菜单自动清理截止时间”
   - 仅在“刚进入世界后的一小段窗口”内生效
   - 该窗口覆盖自动 TP、自动聚焦和 post-join 行为最容易扰动界面的阶段

2. 增加专门的 `dismissStartupPauseScreenIfNeeded`
   - 只识别 `PauseScreen`
   - 只在截止时间内执行 `client.setScreen(null)`
   - 截止时间后不再干预，保留玩家正常打开暂停菜单的能力

3. 保持现有 `dismissTransientStartupScreen` 不处理 `PauseScreen`
   - 避免把“短时启动修复”扩大成长期菜单劫持

4. 更新使用说明
   - 说明 bench 客户端会在启动/进服短窗口内自动清掉误弹出的 `ESC` 暂停菜单

### 影响范围

- `src/client/java/com/makomi/client/bench/BenchClientAutomationController.java`
- `docs_dev/使用说明.md`
