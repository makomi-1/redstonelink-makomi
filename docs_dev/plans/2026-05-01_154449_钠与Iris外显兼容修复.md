# 钠与Iris外显兼容修复

生成时间：2026-05-01 15:44:49
文件名：2026-05-01_154449_钠与Iris外显兼容修复.md

## 任务背景
- 当前 `1.21.11` 迁移工作区在 `Sodium` 或 `Sodium + Iris` 下，本模组的 quick-link 描边、连接可视化连线与定向箭头会整批不显示。
- 原 `1.21.1` 工作区已经在 `53d8754 / e2f2ef5 / dae3eb0` 这条提交链中解决了对应问题，但实现依赖旧版 world overlay 与即时直绘接口，不能机械搬运。

## 方案详情

### 现状分析
- 当前工作区已经保留 `IrisRenderCompatSupport.shouldUseCompatibilityBranch()`，并在 quick-link / 定向箭头入口走兼容分支。
- 但当前兼容分支把线段展开成四边形后，又交回了 `SeeThroughWorldGeometryRenderSupport` 的 world pipeline。
- 原 `1.21.1` 兼容链真正稳定的设计语义是“兼容分支绕开常规 world line target 与默认 world overlay 管线”。
- 同时，原兼容直绘显式关闭面剔除；当前 `1.21.11` 的兼容四边形管线没有显式关闭剔除，这会让单面四边形在 `Sodium/Iris` 下更容易整批消失。

### 技术方案
- 保留当前“兼容分支几何转四边形”的思路，因为这是适配 `1.21.11` 线段顶点格式和 `LineWidth` 约束的合理做法。
- 修正兼容分支的提交语义：
  1. 明确这条支撑不是仅 Iris，而是 `Sodium/Iris` 共用兼容几何出口
  2. 穿透四边形管线显式禁用剔除，避免单面带状四边形被 `Sodium/Iris` 剔除
  3. 继续挂在 `END_MAIN` 的后置阶段，保证不会被后续实体/透明层覆盖
- 兼容分支修复后，quick-link 当前命中描边、预览描边、第三形态连线，以及定向箭头，都继续复用这条统一出口。

### 影响范围
- `src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java`
- `src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java`
- 必要时调整：
  - `src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java`
  - `src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java`

## 原子步骤清单

### 步骤 1：修正兼容四边形管线状态
- **操作对象**：`SeeThroughWorldGeometryRenderSupport`
- **具体动作**：给兼容分支使用的穿透四边形管线显式关闭 cull，确保单面四边形在 `Sodium/Iris` 下可见
- **预期结果**：兼容分支的描边/连线/箭头不会因面剔除而整批消失
- **关键里程碑**：是

### 步骤 2：对齐兼容支撑职责
- **操作对象**：`IrisDirectLineRenderSupport`
- **具体动作**：保留其“线段转四边形”的职责，但文义上按 `Sodium/Iris` 共用兼容支撑来使用
- **预期结果**：兼容层语义和当前实际分支一致
- **关键里程碑**：否

### 步骤 3：冒烟验证兼容分支
- **操作对象**：Gradle / runClient
- **具体动作**：执行 `-PwithSodium=true -PwithIris=true --no-daemon runClient` 冒烟并检查最新日志
- **预期结果**：客户端启动链正常，兼容分支不再出现外显完全不显示的基础性断点
- **关键里程碑**：是

### 步骤 4：补审查文档并阶段提交
- **操作对象**：`docs_dev/reviews/`、Git
- **具体动作**：完成审查文档，确认编码与验证结果后提交
- **预期结果**：本阶段变更可追溯
- **关键里程碑**：是

## 预期结果
- `Sodium` 与 `Sodium + Iris` 下，本模组 quick-link 描边、连接可视化连线与定向箭头恢复显示
- vanilla 路径不受影响
