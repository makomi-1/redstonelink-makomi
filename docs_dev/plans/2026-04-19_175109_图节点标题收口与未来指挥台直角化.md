# 图节点标题收口与未来指挥台直角化

生成时间：2026-04-19 17:51:09
文件名：2026-04-19_175109_图节点标题收口与未来指挥台直角化.md

## 任务背景

当前图网络页面存在三个可见性与风格问题：

1. 图例已经说明了节点类型，但图中实际节点标题仍重复显示类型，导致序号和别名不够突出。
2. “未来指挥台”主题虽然已经完成冷色化，但仍沿用较多圆角设计，不够符合硬朗的指挥台/科幻界面风格。
3. 网页前端仍保留首页，而当前主要功能已经集中在 graph / recording 两个独立主页面，首页已不再需要。

需要在不改业务语义、不动后端接口的前提下，完成上述三项前端调整。

## 方案详情

### 现状分析

- 图中实际节点标题由 `webapp/src/components/graphViewer/canvas.tsx` 直接渲染 `graphNode.displayText`，而该字段被搜索结果、右侧详情和其它列表复用，不能直接整体重写。
- “未来指挥台”主题样式一部分在 `webapp/src/app.css`，另一部分在图节点的内联样式里；如果只改 CSS，会留下图节点圆角不一致的问题。
- 首页并非单独静态页面，而是 `App.tsx`、`app/location.ts`、`app/types.ts` 与 `HomePage.tsx` 的一整套路由与状态分支。

### 技术方案

- 为图画布新增“画布专用节点标题”格式，只用于实际节点标签，改为“序号（别名）”视图，不修改全局 `displayText`。
- 在 `app.css` 中补充统一半径变量，并让 `future-command` 主题覆盖成直角/硬边值；图节点内联样式也改为读取 CSS 变量。
- 删除首页路由与页面文件，让根路径默认进入 graph 页面，并移除原来的“返回首页”按钮。
- 同步更新相关测试，确保路由、主题切换与 graph 页面渲染行为仍可回归验证。

### 影响范围

- `webapp/src/components/graphViewer/canvas.tsx`
- `webapp/src/app.css`
- `webapp/src/App.tsx`
- `webapp/src/app/types.ts`
- `webapp/src/app/location.ts`
- `webapp/src/app/GraphPage.tsx`
- `webapp/src/app/RecordingPage.tsx`
- `webapp/src/app/HomePage.tsx`
- `webapp/src/App.test.tsx`
- `webapp/src/app/GraphPage.test.tsx`

## 原子步骤清单

### 步骤 1：收口图中实际节点标题
- **操作对象**：`webapp/src/components/graphViewer/canvas.tsx`
- **具体动作**：为实际节点新增画布专用标题格式，只显示序号及可选别名
- **预期结果**：图中节点标识不再重复类型信息，序号/别名更显眼
- **关键里程碑**：是

### 步骤 2：为未来指挥台主题引入直角半径体系
- **操作对象**：`webapp/src/app.css`、`webapp/src/components/graphViewer/canvas.tsx`
- **具体动作**：抽出常用圆角变量，并在 `future-command` 下覆写为直角/硬边值
- **预期结果**：未来指挥台页面卡片、控件和图节点风格统一变硬朗
- **关键里程碑**：是

### 步骤 3：删除首页与 home 路由分支
- **操作对象**：`webapp/src/App.tsx`、`webapp/src/app/types.ts`、`webapp/src/app/location.ts`、`webapp/src/app/HomePage.tsx`、页面组件
- **具体动作**：移除首页入口、默认根路由切到 graph 页面、删去“返回首页”按钮
- **预期结果**：网页只保留 graph / recording 两个主页面
- **关键里程碑**：是

### 步骤 4：同步更新测试并回归
- **操作对象**：前端测试与全量 Gradle 测试
- **具体动作**：更新受影响测试，执行 `webapp` 测试与全标签 Gradle 回归
- **预期结果**：确认本轮仅为前端展示与路由调整，无其它回归
- **关键里程碑**：是

## 预期结果

图中节点标题会更聚焦于序号与别名，未来指挥台主题整体改为更直角、更硬朗的界面风格，同时首页会被彻底移除，网页直接进入 graph 主页面。
