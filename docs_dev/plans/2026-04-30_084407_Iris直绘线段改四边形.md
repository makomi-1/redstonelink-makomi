# Iris直绘线段改四边形

生成时间：2026-04-30 08:44:07
文件名：2026-04-30_084407_Iris直绘线段改四边形.md

## 任务背景

上一轮已为 Iris 增加“直接穿透显示”兼容分支，但用户实测发现：随着视角移动，某些与视线近似平行的边会忽隐忽现。经分析，当前实现虽然绕开了自定义 line target 的深度问题，但仍在使用 vanilla `rendertype_lines` shader；该 shader 依赖屏幕空间投影差值扩线宽，在边接近平行视线时会退化，导致显示不稳定。

## 方案详情

### 现状分析

- 当前 Iris 兼容 helper 使用 `VertexFormat.Mode.LINES + GameRenderer.getRendertypeLinesShader()` 直接提交线段。
- `rendertype_lines` shader 的线宽来自屏幕空间偏移，而不是稳定几何宽度。
- 当线段方向接近平行视线时，投影后的屏幕差值趋近于零，`normalize(...)` 结果不稳定，最终表现为平行边闪烁、消失、重现。
- 非 Iris 路径当前表现稳定，不应一并改动。

### 技术方案

- 仅在 Iris 兼容分支内替换直绘 helper。
- 把每条线段在 CPU 侧展开成“面向相机的细长四边形”，再用 `VertexFormat.Mode.QUADS + GameRenderer.getPositionColorShader()` 绘制。
- 侧向量计算规则：
  - 基于线段方向与相机视线方向叉乘得到横向偏移；
  - 若叉乘结果过小，回退到相机 `up/left` 向量，避免退化。
- 保留现有穿透显示策略：
  - `disableDepthTest`
  - `depthMask(false)`
  - `enableBlend/defaultBlendFunc`
- 不改箭头、连线、命中描边的数据来源，只替换其 Iris 下的底层提交方式。

### 影响范围

- `src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java`
- 间接受影响：
  - `src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java`
  - `src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java`

## 原子步骤清单

### 步骤 1：替换 Iris 直绘 helper 的底层绘制模式
- **操作对象**：`IrisDirectLineRenderSupport`
- **具体动作**：把 `LINES` 改成 `QUADS`，并切换到 `PositionColor` shader
- **预期结果**：Iris 下不再依赖 `rendertype_lines` 的屏幕空间扩线
- **关键里程碑**：是

### 步骤 2：实现相机朝向四边形展开
- **操作对象**：`IrisDirectLineRenderSupport`
- **具体动作**：按线段方向、相机视线和兜底向量计算 quad 两侧偏移，并输出四个顶点
- **预期结果**：线段在平行视角下仍能稳定保持可见宽度
- **关键里程碑**：是

### 步骤 3：保留现有 Iris 上层调用
- **操作对象**：箭头与 quick-link 的 Iris 分支调用点
- **具体动作**：尽量不改上层数据结构，只兼容新的 helper 输入
- **预期结果**：箭头、连线、描边继续走同一条 Iris 穿透路径
- **关键里程碑**：否

### 步骤 4：验证与收尾
- **操作对象**：Gradle 构建与测试
- **具体动作**：执行 `.\gradlew.bat compileJava compileClientJava test testIntegration testClient testSlow --no-daemon`
- **预期结果**：改动可构建、可回归，且不影响非 Iris 逻辑
- **关键里程碑**：是

## 预期结果

- Iris 下的箭头、智能眼镜连线和命中描边仍保持穿透显示。
- 视角移动时，与视线近似平行的边不再频繁出现/消失。
- 非 Iris 路径保持现有显示与深度语义不变。
