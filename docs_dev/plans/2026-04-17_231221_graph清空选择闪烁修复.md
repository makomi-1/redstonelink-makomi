# graph清空选择闪烁修复

生成时间：2026-04-17 23:12:21
文件名：2026-04-17_231221_graph清空选择闪烁修复.md

## 任务背景

graph 视图已接入 ReactFlow 框选作为批量编辑选择入口，但当前点击“清空选择”后会出现持续闪烁。现象集中在前端视图层，目标是在不改 `triggerSource/core` 真值、snapshot、draft 和服务端语义的前提下，稳定清空批量选择。

## 方案详情

### 现状分析

- 现有“清空选择”只清空 `selectedEditSourceSerials` / `selectedEditTargetSerials`
- ReactFlow 内部选区与 `onSelectionChange` 仍可能把旧选中节点重新写回批量选择状态
- 批量选择节点又会进入 `forcedVisibleNodeKeys`，导致节点可见性和选中态反复切换，形成闪烁

### 技术方案

为清空选择增加一次完整的程序化清选流程：

1. 清空批量编辑的来源/目标数组
2. 同步清空 ReactFlow 当前节点的 `selected` 状态
3. 在这次程序化清选期间，临时忽略 ReactFlow 回流的节点选中变更与选区变更

这样可以把“清空选择”收敛为单次稳定状态切换，避免程序清空与内部选区回写互相打架。

### 影响范围

- `webapp/src/components/GraphViewer.tsx`
- `docs_dev/reviews/` 审查文档

- **预期结果**：旧选区不会在清空后重新写回，闪烁消失
