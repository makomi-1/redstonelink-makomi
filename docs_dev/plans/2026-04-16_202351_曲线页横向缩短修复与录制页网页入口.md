# 曲线页横向缩短修复与录制页网页入口

生成时间：2026-04-16 20:23:51
文件名：2026-04-16_202351_曲线页横向缩短修复与录制页网页入口.md

## 任务背景

上一轮已修复 recording 曲线页在“全部曲线关闭后再打开一条”时的时间窗恢复问题，但用户继续反馈当前异常仍然存在，并明确说明这次问题是“横向被挤短”，表现类似 recording 尚未拆成独立页面之前的宽度压缩效果。

同时，当前录制 GUI 只有“导出结束后自动打开网页”的开关，没有一个独立的主动入口让用户直接跳到 recording 曲线查看页。用户希望在录制 GUI 内直接增加一个按钮，随时打开曲线查看网页。

本轮目标是在不扩展 recording 数据结构和网络协议的前提下，修复曲线页横向缩短问题，并为录制 GUI 增加独立的网页入口。

## 方案详情

### 现状分析

- `RecordingChart` 当前在没有可见曲线时直接返回空提示，不再渲染图表宿主节点；这样会破坏 `ResizeObserver` 与宿主节点的生命周期连续性，导致再次恢复曲线时宽度状态容易退回最小值。
- 现有修复主要处理了 `xWindow` 时间窗的回灌，但横向宽度本质上由宿主节点宽度与 `chartWidth` 共同决定，因此仅恢复 `setScale('x', ...)` 不能覆盖当前问题。
- 录制 GUI 当前只通过 `autoOpenWeb` 控制“录制结束后是否自动跳转网页”，没有直接打开 recording 页的客户端入口。
- 本地网页桥接服务当前已有 `openHomePage()` 与 `openAssetEntry()`；为了让语义更清楚，适合补一个专用 `openRecordingPage()`。

### 技术方案

1. `RecordingChart` 改为始终保留图表宿主节点，不再在“无曲线可见”时整体切换成纯文本节点。
2. 无曲线或无样本时，仅销毁图表实例并在宿主节点上方显示覆盖提示，从而保持宽度观测链路稳定。
3. 保留现有 `xWindow` 回灌逻辑，同时让 `ResizeObserver` 与宿主节点生命周期保持一致，避免重新启用曲线后横向宽度退回最小值。
4. 在 `LocalWebAppBridgeService` 中新增 `openRecordingPage()`，并在 `StatePanelRecordingScreen` 中增加独立“打开曲线页”按钮。
5. 为新按钮补中英文语言键，并沿用现有网页打开成功/失败反馈消息。

### 技术取舍

- 不继续在时间窗状态上追加补丁，而是直接修宿主节点与宽度观测的生命周期问题，避免头痛医头。
- 不新增复杂导航协议或录制 GUI 到网页端的参数拼装，仅增加一个专用 recording 页面打开入口。
- 独立按钮沿用现有本地网页桥接逻辑和反馈消息，减少新增分支和维护成本。

## 预期结果

本轮完成后：

1. recording 曲线页在关闭全部曲线后重新启用任一曲线时，横向宽度保持稳定，不再退回小图宽度。
2. recording 曲线页在无曲线或无样本时仍保持完整图表占位，并显示清晰的提示信息。
