# 遥控器tooltip补充与网页转发器展开布局调整

生成时间：2026-04-25 16:20:08
文件名：2026-04-25_162008_遥控器tooltip补充与网页转发器展开布局调整.md

## 任务背景

当前需要完成两项局部改动：
1. 给遥控器 tooltip 补充跨区块边界说明，明确“遥控器只能作为强加载对象，不支持常驻”；
2. 调整网页前端图可视化中转发器的展开布局，使其展开后呈现“左 core 端 / 中间收起点 / 右 triggerSource 端”的结构。

这两项改动都属于现有功能收口，不涉及新增玩法、协议扩展或资源贴图修改。

## 方案详情

### 现状分析

- 遥控器 tooltip 当前统一由 `LinkerItem.appendHoverText(...)` 输出；同步遥控器仅覆写信号语义说明，因此跨区块说明适合继续挂在 `LinkerItem` 统一入口。
- 遥控器触发链路已经接入统一跨区块调度，能命中 force-load / queue，但 resident 票据依赖已放置节点位置，遥控器物品本身不具备常驻条件。
- 网页端转发器当前已支持组合显示与展开，但布局仍复用全局 `triggerSource / repeater / core` 三列分层，因此展开时成员的视觉位置与转发器内部双身份语义不一致。

### 技术方案

- 在 `LinkerItem` 中新增一条独立的遥控器跨区块 tooltip 说明，并补齐中英文 lang；普通遥控器与同步遥控器共享该说明。
- 在网页端 `graphViewer/canvas.tsx` 中为“展开态转发器相关节点”增加专用布局规则：
  - 左侧放置该转发器的 `core` 端真实成员；
  - 中间保留转发器组合节点作为收起点；
  - 右侧放置该转发器的 `triggerSource` 端真实成员。
- 保持转发器内部真实编辑语义不变，仍使用 `triggerSource/core` 真节点进行选择和草稿写入，不新增保存协议。
- 补充前端测试，验证转发器展开后结构与详情仍正确。

### 影响范围

- `src/main/java/com/makomi/item/LinkerItem.java`
- `src/main/resources/assets/redstonelink/lang/zh_cn.json`
- `src/main/resources/assets/redstonelink/lang/en_us.json`
- `webapp/src/components/graphViewer/canvas.tsx`
- `webapp/src/components/GraphViewer.test.tsx`
