# 录制与图编辑网页权限拆分

生成时间：2026-04-21 00:05:10
文件名：2026-04-21_000510_录制与图编辑网页权限拆分.md

## 任务背景

当前服务端没有为“录制网页功能”和“graph 可视化编辑网页功能”提供独立的默认权限配置。`graph` 保存链路复用了现有命令权限口径，`recording` 录制链路则缺乏独立权限门，导致这两条网页功能无法单独按服务器策略配置。需求是把两者都补成默认 `2` 的独立可配置项，并完成测试。

## 方案详情

### 现状分析

- 服务端配置快照中尚无独立的网页功能权限域。
- `graph` 导出物品、状态面板 graph 导出、bench graph export 与 graph preview/save 入口缺少统一的网页功能权限门。
- `recording` 会话启动链路没有独立权限门。
- 现有 `graph` 保存仍需要保留命令权限、写控、OCC 等原有限制，不能被新的网页功能门替代。

### 技术方案

- 新增 `RedstoneLinkWebConfig`，配置键为：
  - `server.web.recording.permissionLevel`
  - `server.web.graph.permissionLevel`
  两者默认值都为 `2`。
- 在 `RedstoneLinkConfig` / `RedstoneLinkServerConfigSnapshot` / `RedstoneLinkConfigParser` / `RedstoneLinkConfigTemplate` 中接入新配置域。
- 新增 `WebFeaturePermissionService` 统一收口网页功能权限判定。
- `recording` 链路：
  - 在 `StatePanelRecordingSessionService.start` 增加录制网页功能权限门。
- `graph` 链路：
  - 在 `GraphWriteService` 增加 graph 网页功能门，覆盖 alias/channel/topology 的网页保存入口。
  - 在 `GraphVisualEditorItem`、`StatePanelNetworkServerHandlerSupport.handleExportGraph`、`BenchGraphCommandRegistry.executeExport` 增加 graph 导出权限门。
- 测试：
  - 配置解析单测：新增网页权限默认值与边界夹紧测试。
  - 服务端单测：补 graph 网页权限拒绝保存的回归。
  - 游戏内自动化测试：新增 dedicated server functional case，覆盖低权限拒绝 graph export/preview/save，高权限恢复后允许保存并生效。

### 影响范围

- 配置层：`src/main/java/com/makomi/config/**`
- 权限判定与服务端功能链路：`src/main/java/com/makomi/data/**`、`src/main/java/com/makomi/item/**`、`src/main/java/com/makomi/network/**`、`src/main/java/com/makomi/command/bench/**`
- 文档：`docs/使用说明.md`、`docs/usage_guide_en.md`
- 测试：`src/test/java/**`、`tools/bench/**`

## 原子步骤清单

### 步骤 1：新增网页功能权限配置域
- **操作对象**：配置快照、解析器、模板、配置测试
- **具体动作**：增加 `recording` / `graph` 两个独立权限配置，默认都为 `2`
- **预期结果**：服务端支持独立配置录制与图编辑网页功能权限
- **关键里程碑**：是

### 步骤 2：接入 recording / graph 服务端权限门
- **操作对象**：录制服务、graph 保存服务、graph 导出入口、bench graph 命令
- **具体动作**：在现有功能链路前新增网页功能权限校验，保留原有命令权限、写控与 OCC
- **预期结果**：低权限玩家无法使用相应网页功能，高权限玩家功能不受影响
- **关键里程碑**：是

### 步骤 3：补文档与自动化回归
- **操作对象**：中英文使用说明、配置单测、graph 服务单测、bench functional case
- **具体动作**：说明新增配置项，并新增 dedicated server functional case 覆盖 graph 网页权限门
- **预期结果**：文档、单测和游戏内自动化测试都能证明改动生效
- **关键里程碑**：是

## 预期结果

最终服务端会提供两个默认值为 `2` 的独立配置项，分别控制录制网页功能和 graph 可视化编辑网页功能。录制启动、graph 导出、网页预检和网页保存都将受对应权限门控制，同时仍保留原有写控、隐私读控与 OCC 语义。新增的 dedicated server functional case 会覆盖 graph 网页权限门的低权限拒绝与高权限放行主链路。
