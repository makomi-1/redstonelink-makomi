# 配置层最终收口重构

生成时间：2026-03-24 23:32:28
文件名：2026-03-24_233228_配置层最终收口重构.md

## 任务背景

配置层已完成前两轮减重，但当前仍存在以下问题：

- 服务端配置门面 `RedstoneLinkConfig` 仍然保留大量平铺静态 getter。
- 跨区块配置解析仍然是一个偏重的大块。
- 客户端配置 `RedstoneLinkClientDisplayConfig` 仍是单体类，解析、模板、状态与访问混杂。
- 配置测试和部分数据测试仍依赖 façade 私有方法或私有字段反射，组织边界不清晰。

用户本轮要求是“配置层继续拆分，尽可能一步到位”，并明确“不需要兼容设计”。

## 方案详情

### 现状分析

当前服务端配置已经拥有：

- 独立 parser
- 独立 template
- 独立 interaction support
- 独立 runtime support

但仍未形成最终结构。最核心的问题不是“还差几个 helper”，而是：

1. 缺少统一的配置聚合根
2. 领域配置没有真正按域分组
3. 内部调用仍通过旧式静态平铺入口读取配置
4. 客户端配置结构没有与服务端对齐

### 技术方案

本轮直接收口为最终形态：

#### 服务端配置

1. 引入服务端配置聚合根 `RedstoneLinkServerConfigSnapshot`
2. 按域拆分为独立快照：
   - `RedstoneLinkGeneralConfig`
   - `RedstoneLinkCommandConfig`
   - `RedstoneLinkRateLimitConfig`
   - `RedstoneLinkPrivacyConfig`
   - `RedstoneLinkWriteControlConfig`
   - `RedstoneLinkInteractionConfig`
   - `RedstoneLinkRuntimeConfig`
   - `RedstoneLinkCrossChunkConfig`
   - `RedstoneLinkCrossChunkRetryConfig`
3. `RedstoneLinkConfig` 仅保留：
   - `load()`
   - 统一日志器
   - 配置文件路径与默认模板生成桥接
   - `general()/command()/rateLimit()/privacy()/writeControl()/interaction()/runtime()/crossChunk()`
   - 少量仍适合作为公共配置类型的 enum / preset
4. 删除旧式平铺静态 getter，不保留内部兼容层。

#### 解析层

1. 将主配置解析改为直接产出 `RedstoneLinkServerConfigSnapshot`
2. 将跨区块解析改为直接产出 `RedstoneLinkCrossChunkConfig`
3. 保留 parser support，但让 crosschunk 的 retry 成为独立快照

#### 客户端配置

1. 将客户端配置收口为：
   - `RedstoneLinkClientDisplaySnapshot`
   - `RedstoneLinkClientOverlayConfig`
   - `RedstoneLinkClientPairingConfig`
   - `RedstoneLinkClientDisplayParser`
   - `RedstoneLinkClientDisplayTemplate`
   - `RedstoneLinkClientKeyConfigSupport`
2. `RedstoneLinkClientDisplayConfig` 只保留薄门面和持久化入口
3. 删除客户端内部平铺状态字段直出模式

#### 测试

1. 配置测试改为直接测试 parser 产物，不再依赖 façade 私有 parse 方法
2. 数据测试提取测试辅助，统一处理配置快照注入，不再散落反射 façade 私有实现细节

### 技术取舍

- 不保留旧静态 getter 兼容层：
  这是本轮“最终收口”的核心前提，否则会继续拖出第三轮、第四轮。
- 保留服务端 façade 与客户端 façade 类名：
  启动入口与模块装配仍然清晰，不需要额外重命名震荡。
- enum 不强制全部外提：
  只要不妨碍配置结构收口，优先控制 churn，把重点放在快照家族和访问方式统一上。

### 影响范围

- `src/main/java/com/makomi/config/**`
- `src/client/java/com/makomi/client/config/**`
- 所有读取服务端配置的主代码调用点
- 所有读取客户端配置的客户端调用点
- `src/test/java/com/makomi/config/**`
- 依赖配置注入的数据测试
