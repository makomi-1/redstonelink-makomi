# 修复过滤器频道模式近外显标签

生成时间：2026-04-23 17:42:48
文件名：2026-04-23_174248_修复过滤器频道模式近外显标签.md

## 任务背景

过滤器使用频道模式时，近外显当前会显示为“节点集：频道值”。现状排查表明：

- 过滤器目标值解析已经能根据 `LinkFilterTargetMode.CHANNEL` 返回频道值。
- 近外显行标签仍固定使用 `hud.redstonelink.near_overlay.filter_node_set_line`。
- 因此错误发生在客户端近外显文本组装层，而不是过滤器配置、持久化或频道值读取层。

本轮只修复过滤器近外显标签选择，不扩散修改语言文件、过滤器编辑 GUI、网络 payload 或过滤器运行时语义。

## 方案详情

### 现状分析

- `LinkSerialHudOverlayTextSupport.buildNearOverlayLines(AbstractLinkFilterBlockEntity, Font)` 固定调用 `translate(KEY_NEAR_OVERLAY_FILTER_NODE_SET_LINE, resolveFilterTargetText(...))`。
- `resolveFilterTargetText(...)` 已经在频道模式返回 `resolveChannelValueText(snapshot.channel())`。
- 语言文件中已有通用频道行 `hud.redstonelink.near_overlay.channel_line`，可直接复用。

### 技术方案

在 `LinkSerialHudOverlayTextSupport` 中新增一个轻量选择 helper：

- `LinkFilterTargetMode.CHANNEL` 时返回 `KEY_NEAR_OVERLAY_CHANNEL_LINE`。
- 其他情况返回 `KEY_NEAR_OVERLAY_FILTER_NODE_SET_LINE`。

随后过滤器近外显目标行统一通过该 helper 决定翻译键。

### 影响范围

- `src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java`
- `src/test/java/com/makomi/client/render/LinkSerialHudOverlayTextSupportTest.java`
