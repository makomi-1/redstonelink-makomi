# 转发器配方补齐与网页展开间距调整

生成时间：2026-04-25 17:21:42
文件名：2026-04-25_172142_转发器配方补齐与网页展开间距调整.md

## 任务背景

本轮需要继续补齐转发器的交付完整度，目标包含三部分：

1. 为转发器新增正式合成配方，配方上排为“连接核心块 / 连接原件 / 同步触发器”，下两排留空。
2. 检查并补齐非 `README` 文档、图鉴、配方页中缺失的转发器相关说明与配方展示。
3. 网页前端图可视化中，转发器展开后虽然已经形成“左 `core` / 中 `repeater` / 右 `triggerSource`”结构，但内部间距仍偏大，需要进一步紧凑化。

## 方案详情

### 现状分析

- 运行时 `src/main/resources/data/redstonelink/recipe/` 目录当前还没有 `link_repeater.json`，且 `RecipeResourceLayoutTest` 的白名单未包含该配方。
- 文档侧 `docs/usage_guide_cn.md`、`docs/usage_guide_en.md`、`docs/item_guide.html`、`docs/recipe_sheet.html` 目前都没有完整覆盖转发器条目或转发器配方。
- 网页前端 `webapp/src/components/graphViewer/canvas.tsx` 已为展开态转发器引入专用 lane，但内部仍复用全局 `COMPONENT_LAYER_GAP_X`，导致展开后内部视觉距离偏松。

### 技术方案

1. 在运行时配方目录中新增 `link_repeater.json`：
   - 使用标准 shaped recipe；
   - 第一排分别放置 `redstonelink:link_redstone_core`、`redstonelink:redstone_link_component`、`redstonelink:link_sync_emitter`；
   - 结果为 `redstonelink:link_repeater`。
2. 更新配方契约测试：
   - 将 `link_repeater.json` 纳入 `RecipeResourceLayoutTest` 白名单；
   - 额外增加一个轻量契约测试，锁定转发器配方文件存在且关键输入/输出正确。
3. 补齐文档与图鉴：
   - 在中英文 `usage_guide` 中添加“转发器”条目和配方说明；
   - 在 `item_guide.html` 中加入转发器卡片、名称、用途与说明；
   - 在 `recipe_sheet.html` 中补静态配方卡片，并补齐名称、分类、贴图映射。
4. 调整网页展开态转发器内部间距：
   - 仅对展开态转发器内部 `repeaterCoreMember -> repeater -> repeaterTriggerSourceMember` 三列之间应用更小的专用横向间距；
   - 普通节点、聚合块、频道视图与整体组件块间距保持不变；
   - 增补前端测试，锁定“内部间距小于外侧普通 lane 间距”的结果。
