# QTL空覆盖与频道主题过滤器近外显

生成时间：2026-04-12 18:55:18
文件名：2026-04-12_185518_QTL空覆盖与频道主题过滤器近外显.md

## 任务背景

本轮需要在不改贴图资源本体的前提下，继续补齐快速连接工具与过滤器的可用性细节：

1. 快速连接工具在 `REPLACE` 模式下，空缓存也应允许应用，语义为“覆盖为空”，用于清空命中 `triggerSource/core` 的一跳关系或清空过滤器节点集。
2. 快速连接工具 `channel` 模式需要使用独立主题背景，并让物品贴图跟随模式切换；现有资源约定为频道 `_cp`、序号 `_sd`。
3. 过滤器需要补充近外显信息，颜色与展示逻辑参考现有过滤器贴图语义和节点近外显风格。

## 方案详情

### 现状分析

- `QuickLinkApplyService` 当前会在入口统一拦截空缓存，导致 `REPLACE` 无法执行“清空”语义。
- `QuickLinkToolScreen` 已具备 `serial/channel` 模式，但背景预设和控件色仍固定为 serial。
- 快速连接工具物品模型当前仅绑定 `_sd` 贴图，尚未镜像 `channel` 模式到 `CustomModelData`。
- 过滤器方块实体已有客户端可读快照，但近外显渲染器只处理 `PairableNodeBlockEntity`，因此不会显示过滤器信息。

### 技术方案

1. 仅放宽 `REPLACE` 的空缓存应用：
   - 命中 `triggerSource/core` 时，空缓存解析为“目标集合为空”。
   - 命中过滤器时，空缓存解析为“节点集为空字符串”。
   - `APPEND/REMOVE` 继续维持“空缓存不可应用”。
2. 为快速连接工具补齐模式镜像：
   - 在 `QuickLinkToolData` 写入路径同步 `CustomModelData`。
   - `serial` 使用默认 `_sd`，`channel` 使用 `_cp` override。
   - `QuickLinkToolScreen` 按当前模式切换背景预设，并同步切换输入框、按钮、标题副标题和状态色。
3. 扩展过滤器近外显：
   - 在 HUD 命中判定中支持 `AbstractLinkFilterBlockEntity`。
   - 读取过滤器快照后生成“服务对象 / 节点集 / 节点集模式 / 信号模式 / 阈值来源与邻居输入”等文案。
   - 颜色按过滤器类型区分：`send` 使用暖色，`receive` 使用冷色。
4. 同步补充测试、使用说明、保留问题和审查文档。

### 影响范围

- 服务端 quick-link 应用逻辑与测试
- 快速连接工具物品数据、物品模型 JSON、GUI 主题
- 过滤器近外显渲染与国际化文案
- 使用说明与保留问题文档

### 语义对齐说明

- 命名统一继续使用 `triggerSource/core`，不新增旧术语输出。
- 写入方向仍固定为 `triggerSource -> core`，本轮只调整“覆盖为空”的输入边界，不改变方向语义。
- GUI、提示、测试和文档均按 `triggerSource/core` 口径更新。
- 与 `LinkNodeType.TRIGGER_SOURCE/CORE` 的映射保持一一对应。
- 兼容层继续保持“读旧写新”，本轮无新增 API v1 依赖。
