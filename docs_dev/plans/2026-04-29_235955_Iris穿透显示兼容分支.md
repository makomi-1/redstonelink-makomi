# Iris穿透显示兼容分支

生成时间：2026-04-29 23:59:55
文件名：2026-04-29_235955_Iris穿透显示兼容分支.md

## 任务背景

上一轮已为 Iris 增加基础兼容分支，但用户进一步确认：Iris 下不仅要避免深度关系错误，还需要保留智能眼镜连线、定向箭头与 quick-link 命中描边的穿透显示效果。当前回退到 `RenderType.lines()` 后，虽然部分漂移问题缓解，但穿透显示丢失，需要继续补一条 Iris 专用的直接绘制分支。

## 方案详情

### 现状分析

- 现有 Iris 兼容分支主要通过 `RenderType.lines()` 回退，能降低部分自定义 line target 的异常，但无法保证穿透显示。
- `BLOCK_OUTLINE` 在 Iris 下不稳定，直接承担最终绘制会出现轻微漂移。
- `BEFORE_DEBUG_RENDER` 不能作为兼容主路径，Iris 侧存在已知旋转异常。
- 仍然最适合把兼容绘制放在 `LAST` 阶段，并在该阶段直接提交线段，显式控制深度、混合与 shader 状态。

### 技术方案

- 新增一个 Iris 直接线段绘制 helper，封装：
  - `Tesselator/BufferBuilder`
  - `BufferUploader.drawWithShader`
  - `RenderSystem.disableDepthTest / enableBlend / defaultBlendFunc / lineWidth`
  - `GameRenderer.getRendertypeLinesShader`
- 非 Iris 路径完全不变。
- Iris 路径下：
  - 定向箭头改为收集线段并交给 helper 直接绘制
  - quick-link preview 线框与第三形态连线改为收集线段并交给 helper 直接绘制
  - quick-link 命中描边仍在 `BLOCK_OUTLINE` 阶段拦截白框，但真正轮廓线在 `LAST` 阶段直接绘制

### 影响范围

- `src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java`
- `src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java`
- `src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java`
- 新增客户端 Iris 直接线段绘制 helper
