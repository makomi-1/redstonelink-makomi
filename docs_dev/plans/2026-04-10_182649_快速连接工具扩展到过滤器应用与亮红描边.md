# 快速连接工具扩展到过滤器应用与亮红描边

生成时间：2026-04-10 18:26:49
文件名：2026-04-10_182649_快速连接工具扩展到过滤器应用与亮红描边.md

## 任务背景

当前 quick-link 只识别 `PairableNodeBlockEntity`，因此：
- 过滤器不能被 quick-link 应用
- 过滤器也不会进入 quick-link 自定义描边
- 左键采集天然不会命中过滤器

本轮目标是在不改变“潜行右键打开 quick-link 编辑器”既有逻辑的前提下，补齐 quick-link 对过滤器的站立右键应用能力，并让过滤器命中时显示亮红色选择框。

## 方案详情

### 现状分析

- 客户端 `QuickLinkNetworkClientHandlerSupport` 只把 `PairableNodeBlockEntity` 当作 quick-link 目标。
- 服务端 `QuickLinkNetworkServerHandlerSupport` 的 apply 基线与正式 apply 也都只校验节点目标。
- `QuickLinkApplyService` 仅支持把缓存写入节点链接，不支持把缓存写入过滤器 `serialExpression`。
- `QuickLinkOutlineRenderer` 只会给节点绘制蓝/橙描边。

### 技术方案

- 客户端将“右键 apply 目标”扩展为“节点或过滤器”，其中：
  - 左键 collect 仍然只认节点
  - 站立右键 apply 可识别 `send/receive` 过滤器
  - 过滤器目标通过现有 payload 的 `typeToken + serial` 表达为 `send/receive + 0`
- 服务端对过滤器目标新增单独解析分支：
  - 基线请求直接返回零 revision，占位走完现有 apply 往返
  - 正式 apply 时跳过 OCC，直接执行过滤器配置写入
  - 写入时仅覆盖 `serialExpression`，保留过滤器其余配置
  - 权限口径对齐过滤器编辑：要求 `server.command.permissionLevel`
- 过滤器应用只允许类型匹配：
  - `send` 过滤器只接受 `triggerSource` 缓存
  - `receive` 过滤器只接受 `core` 缓存
- 客户端描边渲染扩展到过滤器目标，颜色使用亮红色；节点原有颜色保持不变。

## 原子步骤清单

### 步骤 1：扩展客户端 quick-link 目标识别
- **操作对象**：quick-link 客户端交互回调
- **具体动作**：左键仍只识别节点；站立右键新增过滤器识别，并为过滤器构造 `send/receive + 0` 的目标快照
- **预期结果**：客户端只在站立右键命中过滤器时进入 apply 链路
- **关键里程碑**：是

### 步骤 2：扩展服务端 apply 目标解析
- **操作对象**：quick-link 服务端网络处理
- **具体动作**：新增过滤器目标校验、零 revision baseline 回包，以及正式 apply 的过滤器分支
- **预期结果**：过滤器能复用现有 quick-link 网络往返完成应用
- **关键里程碑**：是

### 步骤 3：实现过滤器配置写入
- **操作对象**：`QuickLinkApplyService`
- **具体动作**：新增过滤器应用逻辑，校验缓存类型、权限、输入长度、非法项、数量上限与去重规则，只更新 `serialExpression`
- **预期结果**：send/receive 过滤器可接受对应类型缓存，collect 行为不受影响
- **关键里程碑**：是

### 步骤 4：扩展 quick-link 描边
- **操作对象**：`QuickLinkOutlineRenderer`
- **具体动作**：命中过滤器时绘制亮红色描边，节点维持原有颜色
- **预期结果**：玩家能明确区分过滤器目标
- **关键里程碑**：否

### 步骤 5：补测试与验证
- **操作对象**：纯逻辑/网络 payload 测试与 Gradle 回归
- **具体动作**：补 quick-link payload 与过滤器应用测试，然后执行全标签自动化测试
- **预期结果**：新增行为有回归保护，改动可通过自动化验证
- **关键里程碑**：是

## 预期结果

- 快速连接工具仍不可采集过滤器
- 快速连接工具可以站立右键把缓存应用到对应过滤器
- send 过滤器只接受 `triggerSource` 缓存，receive 过滤器只接受 `core` 缓存
- 手持 quick-link 命中过滤器时显示亮红色选择框
