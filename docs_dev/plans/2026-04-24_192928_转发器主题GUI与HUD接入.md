生成时间：2026-04-24 19:29:28

## 任务背景

当前工作区路径为 `D:\OpenProjects\RedstoneLink\rl-release-no-mixin`。

用户已准备好转发器主题背景图片，希望把转发器现有编辑界面接入专属主题 GUI，并补一个游戏内外显 HUD。额外约束是：HUD 需要使用亮绿色主题；本轮不改贴图资源本体，只接代码层渲染和文案。

## 方案详情

### 现状分析

- `RepeaterEditorScreen` 目前仍复用 `CHUNK_ACTIVATOR` 背景预设与紫色控件配色，没有使用 `textures/gui/repeater_background.png`
- 近距离 HUD 对转发器仍走普通 `PairableNodeBlockEntity` 分支，因此显示的是通用 `core` 节点外显，而不是转发器专用信息
- 资源目录里已存在 `src/main/resources/assets/redstonelink/textures/gui/repeater_background.png`
- 转发器客户端运行态已经有足够本地数据：`RepeaterConfigSnapshot`、输入/输出展示文本、输入即时功率、已派发输出功率，足以拼出专用 HUD，无需新增 API 或改贴图

### 技术方案

1. 在 `GuiBackgroundRenderSupport` 中新增 `REPEATER` 背景预设，直接绑定 `repeater_background.png`
2. 调整 `RepeaterEditorScreen`：
   - 改为使用 `REPEATER` 主题预设
   - 控件和标题副标题切换为绿色主题色
   - 保持现有布局、交互和 `triggerSource/core` 方向语义不变
3. 调整近距离 HUD：
   - 在 `LinkSerialHudOverlayRenderer` 中优先识别 `LinkRepeaterBlockEntity`
   - 新增转发器专用 HUD 文案构造，显示标题、延迟、输入侧、输出侧、最终 IO
   - 新增可选 HUD 面板样式，使转发器 HUD 使用亮绿色文字和绿色边框
4. 补充中英文文案键，保证 HUD 与 GUI 文案可本地化
