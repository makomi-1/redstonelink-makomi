# 录制曲线页新增阶跃式显示模式

生成时间：2026-04-16 21:48:34
文件名：2026-04-16_214834_录制曲线页新增阶跃式显示模式.md

## 任务背景

录制曲线页当前只支持普通折线显示。为便于观察“一个 tick 内保持当前采样值，直到下一个采样 tick 再跳变”的离散信号，需在现有网页端录制查看页中新增一套阶跃式曲线显示模式，并与现有折线模式共存切换。

本次实现只调整网页端图表渲染方式，不修改录制结果数据结构、采样逻辑、文件格式或后端数据流。

## 方案详情

### 现状分析

- `webapp/src/recordingTypes.ts` 当前仅定义横坐标模式与指标类型，没有图表渲染模式类型。
- `webapp/src/components/RecordingViewer.tsx` 负责录制查看页状态承载与工具栏切换，现阶段只维护横坐标模式、可见指标与时间窗。
- `webapp/src/components/RecordingChart.tsx` 基于 `uPlot` 绘制所有曲线，当前统一使用默认折线路径。
- 现有多节点同坐标系、时间窗保持、鼠标滚轮/拖拽/快捷键交互已经稳定，不应在本轮被破坏。

### 技术方案

- 在 `recordingTypes.ts` 中新增 `RecordingChartRenderMode = 'linear' | 'stepped'`，用于约束录制曲线渲染模式。
- 在 `RecordingViewer.tsx` 中增加全局图表模式状态，并在工具栏新增“折线 / 阶跃”切换入口。
- 在 `RecordingChart.tsx` 中为每条实际曲线 series 按模式决定是否注入 `uPlot.paths.stepped(...)`：
  - `linear`：保持默认折线渲染；
  - `stepped`：启用阶跃式路径构造。
- 保持现有输入/输出颜色、输出虚线样式、五节点同坐标系与当前时间窗恢复逻辑不变。

### 影响范围

- `webapp/src/recordingTypes.ts`
- `webapp/src/components/RecordingViewer.tsx`
- `webapp/src/components/RecordingChart.tsx`

### 语义对齐说明

- 本轮不涉及 `triggerSource/core` 方向写入或持久化字段修改。
- 输入输出结构不变，仅新增前端渲染模式枚举与界面切换状态。
- 无旧术语新增泄漏风险。
- 与 `LinkNodeType` 映射无新增影响。
- 兼容层无新增需求，保持“读旧写旧”现状即可。

## 预期结果

录制曲线页在保持现有交互与数据结构不变的前提下，新增一种阶跃式显示模式。用户可以在同一个图表里对当前所有已显示节点/指标统一切换为普通折线或阶跃曲线，以更直观地查看离散 tick 信号变化。
