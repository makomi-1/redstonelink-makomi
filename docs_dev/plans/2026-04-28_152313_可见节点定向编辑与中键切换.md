# 可见节点定向编辑与中键切换

生成时间：2026-04-28 15:23:13
文件名：2026-04-28_152313_可见节点定向编辑与中键切换.md

## 任务背景

现有定向面编辑能力仅支持 `hide core` 与 `hide sync triggerSource`。用户希望：

- 将定向编辑推广到可见的 `core` 与可见的同步 `triggerSource`
- 保持 `toggle/pulse triggerSource` 不参与本轮扩展
- 将定向编辑器模式切换从“右键空气”改为“鼠标中键”
- 明确定义默认面集：
  - 可见节点默认全向
  - `hide` 节点默认空
- 补两个游戏内自动化验证用例，覆盖可见节点的定向输入/输出
- 接入已补好的 `hide` 节点物品贴图，并且只改物品最外层渲染模型

## 方案详情

### 现状分析

- `DirectionalFaceEditorItem` 当前只支持 `HideCoreBlock` 与 `HideSyncTriggerSourceBlock`
- `HideCoreBlock` 自己负责输出面裁剪
- `HideSyncTriggerSourceBlock` 自己负责输入面采样
- 定向编辑器模式切换当前走 `DirectionalFaceEditorItem.use()`，即主手右键空气
- 客户端鼠标中键入口已经存在，当前优先处理：
  - 主手智能节点容器
  - 主手 quick-link
- `LinkSerialHudOverlayTextSupport` 已经能自动读取 `NodeFaceSetBlockStateSupport` 的面集文本，因此只要可见节点补上 `face_*` 属性，近外显无需另起一套逻辑
- `hide` 节点物品模型当前直接继承可见节点方块模型，尚未接到新的 item 贴图

### 技术方案

本轮采用“语义下沉 + 工具扩展”的方案：

1. 将 `core` 的面集输出裁剪能力下沉到 `LinkCoreBlock`
- 在 `LinkCoreBlock` 中统一引入 `face_*` 属性
- 默认状态使用“全向启用”
- `getSignal/getDirectSignal` 统一按面集裁剪
- `LinkTransparentCoreBlock` 会随之继承该能力
- `HideCoreBlock` 仅保留：
  - 默认空面集
  - 放置时按 `core` 语义写入相反存储面
  - 隐藏交互外形与隐藏渲染

2. 将同步 `triggerSource` 的面集输入裁剪能力下沉到 `LinkSyncEmitterBlock`
- 在 `LinkSyncEmitterBlock` 中统一引入 `face_*` 属性
- 默认状态使用“全向启用”
- `resolveInputSignalStrength` 只采样启用面，并对多面取 `max`
- `HideSyncTriggerSourceBlock` 仅保留：
  - 默认空面集
  - 隐藏交互外形与隐藏渲染

3. 扩展定向编辑器到可见节点
- `DirectionalFaceEditorItem` 的支持范围扩大到：
  - `LinkCoreBlock` 及其子类
  - `LinkSyncEmitterBlock` 及其子类
- `core` 系列继续保持“点击逻辑输出面，写入相反存储面”
- `sync triggerSource` 系列继续按点击面直接写入
- 编辑完成后，若命中对象是 `triggerSource`，继续立即执行输入重采样

4. 将定向编辑器模式切换改为鼠标中键
- 删除 `DirectionalFaceEditorItem.use()` 的切模式行为
- 在客户端中键边沿入口新增定向编辑器分支
- 按用户要求，中键只看主手：
  - 主手智能节点容器：切容器类型
  - 主手 quick-link：切 quick-link 应用编辑模式
  - 主手定向编辑器：切定向编辑模式
- 为定向编辑器新增极小 C2S payload，由服务端回写主手物品栈并回显消息

5. 接入 `hide` 节点物品贴图
- 仅调整 `models/item/hide_core.json`
- 仅调整 `models/item/hide_sync_trigger_source.json`
- 统一改为物品最外层 `item/generated + layer0`
- 不改方块模型，不改方块贴图

6. 补自动化验证
- 参考现有 `HideNodeDirectionalIntegrationTest`
- 新增两个 `integration` 用例：
  - 可见 `core` 的定向输出裁剪
  - 可见同步 `triggerSource` 的定向输入裁剪
- 最后执行全标签回归：
  - `.\gradlew.bat test testIntegration testClient testSlow --no-daemon`

### 影响范围

- 方块逻辑：
  - `LinkCoreBlock`
  - `LinkTransparentCoreBlock`
  - `HideCoreBlock`
  - `LinkSyncEmitterBlock`
  - `HideSyncTriggerSourceBlock`
- 工具与工具数据：
  - `DirectionalFaceEditorItem`
  - `HideDirectionalEditorToolData`
- 客户端输入：
  - `RedstoneLinkClient`
- 网络：
  - 新增定向编辑器模式切换 C2S 网络通道与处理器
- 资源：
  - `assets/redstonelink/lang/*.json`
  - `assets/redstonelink/models/item/hide_core.json`
  - `assets/redstonelink/models/item/hide_sync_trigger_source.json`
- 测试：
  - 新增可见节点定向 `integration` 用例
  - 必要时补工具模式数据测试

## 原子步骤清单

### 步骤 1：下沉 `core` 面集输出能力
- **操作对象**：`LinkCoreBlock`、`HideCoreBlock`
- **具体动作**：给 `LinkCoreBlock` 增加 `face_*` 属性、默认全向状态与输出面裁剪；让 `HideCoreBlock` 改为默认空面集并清理重复裁剪逻辑
- **预期结果**：可见核心块、透明核心块、隐藏核心块共用一套定向输出语义
- **关键里程碑**：是

### 步骤 2：下沉同步 `triggerSource` 面集输入能力
- **操作对象**：`LinkSyncEmitterBlock`、`HideSyncTriggerSourceBlock`
- **具体动作**：给 `LinkSyncEmitterBlock` 增加 `face_*` 属性、默认全向状态与输入面采样；让 `HideSyncTriggerSourceBlock` 改为默认空面集并复用基类逻辑
- **预期结果**：可见同步发射器与隐藏同步触发器共用一套定向输入语义
- **关键里程碑**：是

### 步骤 3：扩展定向编辑器支持范围
- **操作对象**：`DirectionalFaceEditorItem`
- **具体动作**：将支持对象扩到可见 `core / sync triggerSource`，保留 `core` 的反向存储面映射，并更新 tooltip 文案
- **预期结果**：可见节点也能被定向编辑器编辑
- **关键里程碑**：否

### 步骤 4：将模式切换改为中键
- **操作对象**：`RedstoneLinkClient`、新增定向编辑器网络通道与服务端处理
- **具体动作**：移除右键空气切模式；在中键入口按主手物品优先级处理容器、quick-link、定向编辑器；新增 C2S 保存模式
- **预期结果**：主手拿定向编辑器时可用鼠标中键切换模式
- **关键里程碑**：是

### 步骤 5：接入 `hide` 节点物品贴图
- **操作对象**：`models/item/hide_core.json`、`models/item/hide_sync_trigger_source.json`
- **具体动作**：将两者改为 `item/generated` 外层贴图模型，指向现有 `textures/item/*_hide.png`
- **预期结果**：`hide` 节点物品显示使用专属贴图，且只影响物品渲染
- **关键里程碑**：否

### 步骤 6：补测试并回归
- **操作对象**：`src/test/java/com/makomi/integration/`
- **具体动作**：新增两个可见节点定向输入/输出用例，随后跑全标签测试
- **预期结果**：本轮改动具备自动化回归证据
- **关键里程碑**：是

## 预期结果

- 可见 `core` 支持定向输出编辑
- 可见同步 `triggerSource` 支持定向输入编辑
- 可见节点默认全向，`hide` 节点默认空面集
- 定向编辑器模式切换改为鼠标中键，且只依据主手物品决定切换对象
- `hide` 节点物品模型接入专属贴图，只影响物品最外层渲染
- 新增两个可见节点定向回归测试并跑通全标签自动化测试
