# 智能眼镜半透明与连线显示条件调整及容器界面修正

生成时间：2026-04-26 15:26:43
文件名：2026-04-26_152643_智能眼镜半透明与连线显示条件调整及容器界面修正.md

## 任务背景
用户要求继续在现有“智能眼镜承接连线可视化”和“智能节点容器替代聚合壳”基础上做四类修正：
- 智能眼镜穿戴时改为半透明显示；
- 连线显示条件放宽为“穿戴眼镜即可显示”，但清空、添加、移除显示对象仍要求主手空；
- 智能节点容器的内层表现改为节点式内层，类型区分改由侧面贴图承担；
- 智能节点容器 `B` 键 GUI 将“自动排序 / 当前放置类型”移到右侧，并保证容器内物品悬停时能正常显示 tooltip。

## 方案详情

### 现状分析
- 当前连线显示与操作共用同一个判定：必须穿戴智能眼镜且主手空。
- 当前智能眼镜没有专用穿戴渲染入口，仍走普通护甲材质层渲染。
- 当前智能节点容器模型把类型贴图接在内层小立方体上，而不是接到容器侧面。
- 当前容器 GUI 直接把当前放置类型和自动排序放在顶部，和第一排槽位区域混在一起。

### 技术方案
1. 拆分智能眼镜连线“显示权限”和“操作权限”：
   - 显示：只要求穿戴智能眼镜；
   - 操作：要求穿戴智能眼镜且主手空。
2. 为智能眼镜新增客户端专用护甲渲染器：
   - 继续沿用默认头盔模型；
   - 使用半透明渲染层绘制，让穿戴效果变为半透明。
3. 调整智能节点容器模型接线：
   - 内层统一改为节点式内层纹理；
   - 类型变化改由 `smart_node_container_side_core / triggersource / repeater` 承担。
4. 调整智能节点容器 screen：
   - 扩出右侧控制区；
   - 将“当前放置类型 / 自动排序”移动到右侧；
   - 保持标准箱子式悬停 tooltip 行为。

### 影响范围
- 客户端判定与渲染：
  - `SmartGlassesAccessSupport`
  - `QuickLinkOutlineRenderer`
  - `QuickLinkNetworkClientHandlerSupport`
  - `RedstoneLinkClient`
  - 智能眼镜客户端渲染新增类
- 服务端 quick-link 可视化操作验权：
  - `QuickLinkNetworkServerHandlerSupport`
- 智能节点容器资源与界面：
  - `smart_node_container*.json`
  - `SmartNodeContainerScreen`

## 原子步骤清单

### 步骤 1：拆分连线显示与操作判定
- **操作对象**：`SmartGlassesAccessSupport`、quick-link 客户端/服务端入口
- **具体动作**：新增“仅显示可用”判定，并把渲染/HUD 与增删清空操作分流到不同条件
- **预期结果**：主手非空时仍可见连线，但不能清空和增删显示对象
- **关键里程碑**：是

### 步骤 2：实现智能眼镜半透明穿戴渲染
- **操作对象**：客户端渲染注册与智能眼镜专用 armor renderer
- **具体动作**：新增并注册半透明护甲渲染器，沿用默认头盔模型与现有贴图
- **预期结果**：智能眼镜穿戴时呈半透明显示
- **关键里程碑**：是

### 步骤 3：修正智能节点容器模型贴图链路
- **操作对象**：`smart_node_container.json`、`smart_node_container_core.json`、`smart_node_container_triggersource.json`、`smart_node_container_repeater.json`
- **具体动作**：把内层改为节点式内层纹理，把类型差异切到侧面贴图
- **预期结果**：容器内层像节点，侧面随类型切换
- **关键里程碑**：是

### 步骤 4：调整智能节点容器 GUI 右侧布局
- **操作对象**：`SmartNodeContainerScreen`
- **具体动作**：扩出右侧控制区并移动“当前放置类型 / 自动排序”，同时维持标准悬停 tooltip
- **预期结果**：界面更接近大箱子使用体验，信息区不压槽位
- **关键里程碑**：是

### 步骤 5：回归验证与审查文档
- **操作对象**：自动化测试与 `docs_dev/reviews/`
- **具体动作**：执行全标签测试，补写审查文档并做文本健康检查
- **预期结果**：改动可验证、可追溯
- **关键里程碑**：是

## 预期结果
- 穿戴智能眼镜后，主手非空也能看到连线显示；
- 只有主手空时才能清空和增删显示对象；
- 智能眼镜穿戴外显变为半透明；
- 智能节点容器外显改成“节点式内层 + 类型侧面”；
- 容器 GUI 右侧拥有独立信息区，槽位悬停 tooltip 恢复标准箱子体验。
