## 任务背景

当前工作区已经完成了多项与 `hide` 物品、转发器和智能节点容器相关的实现更新，包括：

- 补齐多种块状 `hide` 变种
- 转发器支持正整数延迟，`>2 tick` 标记为实验性
- 智能节点容器支持 `Ctrl + 滚轮` 一次性临时选取，并正确支持 `hide repeater`
- `hide_chunk_activator` 已补好专用 item 贴图

但现有非 `README.md` 文档、图鉴页和配方展示页仍停留在旧口径，需要同步到当前实现。

## 方案详情

### 现状分析

- `docs/usage_guide_cn.md` / `docs/usage_guide_en.md` 只覆盖了早期 `hide core / hide sync triggerSource` 和旧版转发器延迟说明。
- `docs/item_guide.html` 中：
  - 转发器仍写成只支持 `1 tick / 2 ticks`
  - 智能节点容器尚未写入 `Ctrl + 滚轮` 临时选取
  - `hide` 变种条目不完整
- `docs/recipe_sheet.html` 目前只完整覆盖了部分 `hide` 配方，新增的 `hide_toggle_emitter / hide_pulse_emitter / hide_send_filter / hide_receive_filter / hide_chunk_activator / hide_repeater` 需要同步补齐
- `src/main/resources/assets/redstonelink/models/item/hide_chunk_activator.json` 仍沿用可见方块模型，需要按其 `_hide` 贴图切换为单层外渲染

### 技术方案

1. 先接入 `hide_chunk_activator` 的单层物品模型，只改 model 引用，不改 PNG。
2. 更新中英文使用说明，补齐：
   - 块状 `hide` 变种覆盖范围
   - 转发器正整数延迟与实验性说明
   - 智能节点容器临时选取与 `hide repeater` 支持
3. 更新图鉴页 `docs/item_guide.html`，补条目、图标映射和说明文案。
4. 更新配方展示页 `docs/recipe_sheet.html`，补 6 张 `hide` 配方卡，以及名称/图标/分类映射。
