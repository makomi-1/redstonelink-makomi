# 10Hz输入器重压用例扩展

生成时间：2026-03-27 12:49:01
文件名：2026-03-27_124901_10Hz输入器重压用例扩展.md

## 任务背景
现有 bench 纯性能线已经切到输入器驱动，但 256 基线仍沿用旧波形口径，且缺少 `1 -> 1024` 与 `256 -> 1` 的重压用例。当前目标是统一纯性能输入器为 `0/15、2 tick、10Hz`，并补充单向广播与单点汇聚两类极端压力场景，同时保持物理世界端到端场景独立。

## 方案详情

### 现状分析
- `tools/bench/templates/performance/drive.json` 被 `matrix.json` 与 `matrix-baseline-256.json` 共同引用，是纯性能输入器波形的统一入口。
- `tools/bench/lib/Bench.PlaceAndLink.ps1` 当前建链默认把目标序号格式化为 `slash_list`，对 `1 -> 1024` 这类大广播场景不够友好。
- `Bench.PlaceAndLink.ps1` 已支持 `broadcast_all`、`fan_in_first`、`banded` 等映射，无需新增底层 mapping。
- bench 侧序号文本格式化已支持 `range`，服务端 `link set` 也支持 `1:1024` 这类结构化批量输入，因此只需让 bench case 能显式选择该格式。

### 技术方案
- 统一纯性能模板中的 `sync/pulse/toggle` 输入器波形为：
  - `periodTicks=2`
  - `highTicks=1`
  - `highPower=15`
  - `lowPower=0`
- 在建链规则中新增可选 `targetSerialFormat`，默认保持现状 `slash_list`，仅对 `1 -> 1024` case 指定为 `range`。
- 新增 6 个单类型重压 case：
  - `sync_1_to_1024_core_dense`
  - `toggle_1_to_1024_core_dense`
  - `pulse_1_to_1024_core_dense`
  - `sync_256_to_1_core_dense`
  - `toggle_256_to_1_core_dense`
  - `pulse_256_to_1_core_dense`
- 新增独立 `matrix-performance-heavy.json` 与 `suites/performance-heavy.json`，避免污染现有 baseline/light 的职责边界。

### 影响范围
- bench 纯性能模板与建链脚本
- 新增性能 case / matrix / suite
- 使用说明中的运行命令与场景说明

## 原子步骤清单

### 步骤 1：调整纯性能输入器模板
- **操作对象**：`tools/bench/templates/performance/drive.json`
- **具体动作**：统一 `sync_square_wave`、`activate_batch_pulse`、`activate_batch_toggle` 为 `periodTicks=2/highTicks=1/highPower=15/lowPower=0`
- **预期结果**：纯性能输入器线统一为 `10Hz`
- **关键里程碑**：是

### 步骤 2：补建链目标序号格式开关
- **操作对象**：`tools/bench/lib/Bench.PlaceAndLink.ps1`
- **具体动作**：为 link rule 读取可选 `targetSerialFormat`，并传给 `Format-SerialInputText`
- **预期结果**：`1 -> 1024` 可直接输出 `1:1024` 等结构化批量输入
- **关键里程碑**：是

### 步骤 3：新增 6 个重压性能 case
- **操作对象**：`tools/bench/cases/performance/p12~p17/*.json`
- **具体动作**：分别补齐 `1 -> 1024` 与 `256 -> 1` 的 `sync/toggle/pulse` case，统一采用输入器驱动
- **预期结果**：形成可单独执行的重压 case 集合
- **关键里程碑**：是

### 步骤 4：新增独立重压 matrix 与 suite
- **操作对象**：`tools/bench/matrix-performance-heavy.json`、`tools/bench/suites/performance-heavy.json`
- **具体动作**：组织上述 6 个 case 为独立重压入口
- **预期结果**：`baseline/light/heavy/physical-world` 分层清晰
- **关键里程碑**：是

### 步骤 5：更新使用说明并验证
- **操作对象**：`docs_dev/使用说明.md`
- **具体动作**：补充重压 suite/单 case 运行命令，并执行脚本解析与回归验证
- **预期结果**：实现与文档一致，可直接运行
- **关键里程碑**：是

## 预期结果
- 纯性能输入器场景统一使用 `0/15、2 tick、10Hz`
- 现有 256 基线自动切到新口径
- 新增 `1 -> 1024` 与 `256 -> 1` 两类极端单类型重压场景
- 提供独立重压 suite 命令，便于后续定向压测与扩展
