# 节点序号别名映射器第一版

生成时间：2026-04-12 20:33:03
文件名：2026-04-12_203303_node_alias_readonly_phase1.md

## 任务背景
现有 RedstoneLink 所有节点标识、读控/写控、链接拓扑与配对流程都以 `(LinkNodeType, serial)` 作为唯一真值。  
用户希望支持“节点序号别名”的第一版读取能力，并补齐“只知道别名时如何反查真实序号”的闭环，同时要求别名不改变现有 `triggerSource/core` 语义边界，也不替代基于序号的权限与拓扑判定。当前范围进一步收窄为：别名仅支持命令维护与读取展示，写路径仍只认序号。

## 方案详情

### 现状分析
- 当前命令、状态面板、配对、近外显与持久化模型都直接读写 `serial`，没有别名元数据层。
- 现有 `LinkSavedData` 负责节点真值、序号分配和 `triggerSource -> core` 链路，不适合再混入展示型别名状态。
- 现有读控 `CurrentLinksPrivacyService` 与写控 `LinkWriteControlService` 都按 `(type, serial)` 判定，说明别名应只作为入口查询与出口展示能力存在。
- 当前输出路径普遍只显示序号，哪怕未来支持别名维护，用户也无法稳定从读结果中反查真实序号。

### 技术方案
- 新增独立别名持久化层，维护 `(type, alias) -> serial` 与 `(type, serial) -> alias` 双向索引。
- 别名规则限制为“中文/字母/数字，且至少包含一个非数字字符”，避免与纯序号输入歧义。
- 第一版优先打通服务端命令与展示闭环：
  - 提供别名维护命令：`set/remove/resolve/list`
  - 提供别名反查：只需要输入别名即可返回对应序号
  - 提供关键节点序号展示：统一显示为 `别名(#序号)`，仅接入节点自身序号字段，不改当前连接列表
- 内部所有业务处理、读控/写控、拓扑更新、OCC 仍全部回落为 `(type, serial)` 真值，不改变方向语义。
- 本轮不接入任何写命令的别名输入，不改批量序号表达式解析。

## 原子步骤清单

### 步骤 1：新增别名持久化与基础服务
- **操作对象**：别名 `SavedData`、别名规则校验与展示 helper
- **具体动作**：新增别名双向索引、唯一性校验、按类型解析别名与按序号反查别名接口
- **预期结果**：服务端可稳定完成“别名 -> 序号”和“序号 -> 别名”查询
- **关键里程碑**：是

### 步骤 2：接入别名命令维护与反查
- **操作对象**：`node` 命令树
- **具体动作**：新增别名 `set/remove/resolve/list` 命令，并复用现有序号有效性校验
- **预期结果**：用户可通过命令维护别名，并在只知道别名时反查序号
- **关键里程碑**：是

### 步骤 3：接入节点序号字段展示
- **操作对象**：命令输出、远近外显、GUI、tooltip
- **具体动作**：只在“节点自身序号字段”上补别名展示，统一格式为 `别名(#序号)`；当前连接列表等序号集合展示保持原样
- **预期结果**：用户能在常用读取界面直接看到别名和真实序号对应关系
- **关键里程碑**：否

### 步骤 4：补测试与审查文档
- **操作对象**：命令测试、服务测试、审查文档

- **预期结果**：第一版实现具备回归保障与可追溯说明
- **关键里程碑**：是

## 预期结果
第一版交付后，节点别名将作为独立元数据层存在：用户可通过命令维护别名、通过别名反查真实序号，并在命令输出、远近外显、GUI 与 tooltip 的节点序号字段中看到 `别名(#序号)`。现有 `triggerSource/core` 方向语义、`LinkNodeType.TRIGGER_SOURCE/CORE` 映射、基于序号的读控/写控与持久化真值保持不变；所有写路径仍只接受序号。

## 语义对齐说明
- 命名是否仅使用 `triggerSource/core`：是
- 输入/输出结构是否保持方向一致：是
- 文案与注释是否无旧术语泄漏：是
- 与 `LinkNodeType` 映射是否一一对应：是，`triggerSource=TRIGGER_SOURCE`，`core=CORE`
- 兼容层是否仅“读旧写新”：是，本轮不改旧真值，仅新增别名附加层

## 残余风险
- 别名唯一性当前按“同类型内唯一”收敛，若后续要求跨类型全局唯一，需要再扩展规则。
- 所有写路径当前仍只接受序号；若未来要支持“写时别名”，需要单独设计输入歧义与批量语法规则。
- 当前连接列表、目标列表等序号集合展示本轮保持原样，避免把列表格式与别名展示一起耦合改动。
