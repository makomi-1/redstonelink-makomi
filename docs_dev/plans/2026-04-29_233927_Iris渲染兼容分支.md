# Iris渲染兼容分支

生成时间：2026-04-29 23:39:27
文件名：2026-04-29_233927_Iris渲染兼容分支.md

## 任务背景

当前版本在加载 Iris 后，方向箭头、quick-link 连线与命中描边存在两类渲染异常：

- 箭头、连线与节点贴图重叠时会被覆盖，深度关系表现错误。
- quick-link 命中描边会沿玩家视角方向出现轻微漂移，看起来像脱离原方块。

本轮需要调研 Iris 对 world render 管线的影响，并在加载 Iris 时切换到兼容渲染分支，同时保持非 Iris 环境的现有效果不变。

## 方案详情

### 现状分析

- 定向箭头当前在 `WorldRenderEvents.LAST` 阶段绘制，但使用自定义 line `RenderType`。
- quick-link 命中描边当前在 `WorldRenderEvents.BLOCK_OUTLINE` 阶段绘制，使用 `RenderType.lines()`。
- quick-link 预览线框在 `AFTER_TRANSLUCENT` 阶段绘制，第三形态连线在 `LAST` 阶段绘制，二者均使用自定义 line `RenderType`。
- Fabric 官方说明 `WorldRenderEvents` 在第三方渲染器下可能被合并、重排或直接失真；Iris 侧还存在 `BEFORE_DEBUG_RENDER` 旋转异常的已知问题。

### 技术方案

- 新增客户端侧 Iris 检测支撑，仅在加载 `iris` 时进入兼容分支。
- 非 Iris 环境继续沿用现有实现，不做行为变更。
- Iris 兼容分支中：
  - quick-link 命中描边不再依赖 `BLOCK_OUTLINE` 阶段实际绘制，只保留默认白框拦截。
  - 箭头、quick-link 预览线框、quick-link 第三形态连线、命中描边统一收口到 `LAST` 阶段。
  - Iris 下统一改用 `RenderType.lines()` 的直接后置绘制路径，避免当前自定义 line `RenderType` 与 `BLOCK_OUTLINE` 在 Iris 中出现目标缓冲和深度行为异常。

### 影响范围

- `src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java`
- `src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java`
- `src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java`
- 可能新增一个客户端渲染兼容支撑类

## 原子步骤清单

### 步骤 1：新增 Iris 检测与兼容支撑
- **操作对象**：客户端渲染支持类
- **具体动作**：增加 `FabricLoader.isModLoaded("iris")` 的统一判断入口，并抽出兼容绘制辅助方法
- **预期结果**：渲染代码可稳定切换 Iris / 非 Iris 分支
- **关键里程碑**：是

### 步骤 2：改造 quick-link 命中描边的 Iris 分支
- **操作对象**：`QuickLinkWorldOverlayRenderer`
- **具体动作**：Iris 下在 `BLOCK_OUTLINE` 仅拦截默认白框，实际命中描边改到 `LAST` 阶段统一绘制
- **预期结果**：Iris 下命中描边不再漂移
- **关键里程碑**：是

### 步骤 3：改造 quick-link 连线的 Iris 分支
- **操作对象**：`QuickLinkWorldOverlayRenderer`
- **具体动作**：Iris 下把预览线框与第三形态连线统一切换到 `RenderType.lines()` 的后置兼容路径
- **预期结果**：Iris 下连线不再被节点贴图覆盖
- **关键里程碑**：是

### 步骤 4：改造定向箭头的 Iris 分支
- **操作对象**：`DirectionalFaceVectorRenderSupport`、`DirectionalFaceVectorWorldOverlayRenderer`
- **具体动作**：Iris 下改用与 quick-link 一致的兼容线型路径，保留现有箭头几何、主题色和方向语义
- **预期结果**：Iris 下箭头不再被节点贴图覆盖
- **关键里程碑**：是

- **关键里程碑**：是

## 预期结果
