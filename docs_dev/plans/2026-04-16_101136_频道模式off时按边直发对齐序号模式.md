# 频道模式off时按边直发对齐序号模式

生成时间：2026-04-16 10:11:36
文件名：2026-04-16_101136_频道模式off时按边直发对齐序号模式.md

## 任务背景
- 当前频道模式的 loaded direct 派发只要来源处于频道模式，就会进入 `ChannelDispatchScheduler`。
- 用户要求在 `crosschunk.directBatching=off` 时，让频道模式与序号模式完全对齐：不走频道中间层，直接按边派发。
- 同时保持现有窗口语义不变：`dispatch.batchWindowTicks` 仍由 `CoreDispatchBatchScheduler` 处理，不把窗口搬到频道层。

## 方案详情

### 现状分析
- `LinkedTargetDispatchService` 通过 `shouldStageLoadedTargetsIntoChannelBucket` 决定频道模式 loaded direct 是否进入中间层。
- 该条件目前只判断来源是否为频道模式，没有排除 `directBatching=off`。
- 因此在 `off` 模式下，频道模式仍会先进频道中间层，再直接 `applyDispatchBatch(...)` 到目标，和序号模式不一致。

### 技术方案
- 最小化修改 `LinkedTargetDispatchService`：
  - 给 `shouldStageLoadedTargetsIntoChannelBucket` 增加 `directBatchingMode != OFF` 约束。
  - 这样 `off` 时 loaded direct 路径自动落回原有按边派发分支。
- 补一组稳定测试，覆盖“`off` 时不应启用频道中间层”的判定，避免后续回退。
- 不修改 `ChannelDispatchScheduler` 的窗口行为，不修改 `CoreDispatchBatchScheduler` 的延迟归属。
