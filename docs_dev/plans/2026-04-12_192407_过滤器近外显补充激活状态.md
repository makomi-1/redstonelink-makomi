# 过滤器近外显补充激活状态

生成时间：2026-04-12 19:24:07
文件名：2026-04-12_192407_过滤器近外显补充激活状态.md

## 任务背景

当前过滤器近外显已经能显示服务对象、节点集和阈值信息，但还缺少“当前是否被激活”的直观状态，和节点近外显相比少了一条关键运行态信息。

## 方案详情

### 现状分析

- 过滤器近外显文本由 `LinkSerialHudOverlayTextSupport.buildNearOverlayLines(AbstractLinkFilterBlockEntity, Font)` 组装。
- 过滤器方块现有 `POWERED` 方块状态已经承担“是否激活”的外显语义，不需要额外同步字段或网络包。

### 技术方案

1. 在过滤器近外显标题后追加一行“状态：ON/OFF”。
2. 状态来源直接读取过滤器方块状态中的 `powered` 布尔属性。
3. 继续复用现有 `hud.redstonelink.near_overlay.status_line/status_on/status_off` 文案，不新增翻译键。
4. 同步更新 `docs/使用说明.md` 中过滤器近外显说明，并按流程补审查文档。

### 影响范围

- `src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java`
- `docs/使用说明.md`

### 语义对齐说明

- 本轮不改 `triggerSource/core` 术语，不引入旧术语。
- 不改变任何链路方向与过滤逻辑，只补客户端近外显展示。
- 与现有 `LinkNodeType` 映射无新增影响。
- 无 API v1 依赖。

- **操作对象**：`LinkSerialHudOverlayTextSupport`

- **预期结果**：命中过滤器时可直接看到其当前是否激活
- **关键里程碑**：是

- **关键里程碑**：是
