# 箭头显示对齐与hide物品贴图修正

生成时间：2026-04-28 19:45:04
文件名：2026-04-28_194504_箭头显示对齐与hide物品贴图修正.md

## 任务背景

前一轮已经把定向面编辑推广到块状节点，但当前显示层还有两个偏差：

1. 新增到可见节点上的启用面箭头没有和 `hide` 节点复用同一套几何表现，实机观感偏短，容易看不见。
2. `hide core` 与 `hide sync triggerSource` 的物品虽然已经切到块显示，但 item model 仍直接引用可见方块模型，导致贴图没有使用新增的 `item/*_hide.png`。

本轮只修正显示层与模型引用，不改动 `triggerSource/core` 真值语义、方向约束与面集存储。

## 方案详情

### 现状分析

- `hide` 节点箭头逻辑当前独立实现于 `HideNodeGhostRenderer`，包含箭杆长度、箭头头部和粗线渲染状态。
- 可见 `core/triggerSource/repeater/filter/chunk activator` 当前没有统一复用这套箭头几何与主题色解析。
- `hide` 物品模型当前直接继承可见 block model，因此块显示成立，但纹理来源错误。

### 技术方案

1. 抽取共享的定向箭头渲染支持：
   - 统一沉淀箭头长度、箭头头部、线宽、无深度测试渲染类型。
   - 统一沉淀“是否佩戴智能眼镜 + 是否手持定向编辑器”的显示门槛。
   - 统一沉淀“方块状态 -> 实际显示方向”的映射规则，其中 `core/repeater` 继续按输出语义做反向显示，其余输入型节点按原面显示。

2. 将共享箭头接入现有 renderer：
   - `HideNodeGhostRenderer`
   - `LinkNodeFarOverlayRenderer`
   - `LinkFilterAreaRenderer`
   - `ChunkActivatorFarOverlayRenderer`
   这样可见节点与 `hide` 节点共用同一套几何，避免再次出现长度或透明度不一致。

3. 主题色按方块类别解析：
   - `core` 使用 `core` 主题色
   - `triggerSource` 使用 `triggerSource` 主题色
   - `repeater` 使用 `repeater` 主题色
   - `filter` 使用 `filter` 主题色
   - `chunk activator` 使用 `chunk activator` 主题色

4. `hide` 物品继续保持块显示，但改成专用 item model：
   - 保持双层方块结构
   - 外层显式改用 `item/link_redstone_core_hide` 与 `item/link_sync_emitter_hide`
   - 内层继续沿用 `block/component_core_block`
