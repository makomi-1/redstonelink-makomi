# 智能眼镜定向方向显示切换

生成时间：2026-04-30 22:40:48
文件名：2026-04-30_224048_智能眼镜定向方向显示切换.md

## 任务背景

当前定向方向箭头只有在佩戴智能眼镜且主手或副手持有定向面编辑工具时才会显示。现需要为智能眼镜新增一个默认 `Ctrl + K` 的显示开关，让玩家在不手持定向面编辑工具时，也能持续查看节点的定向方向箭头。同时，这个新开关不能替代现有工具显示逻辑，而应与其取并集。

此外，新增能力需要同步到智能眼镜物品 tooltip、图鉴页与非 `README.md` 文档，保证使用说明与当前实现一致。

## 方案详情

### 现状分析

- 当前定向方向箭头的显示条件分两层：
  - 佩戴智能眼镜
  - 主手或副手持有定向面编辑工具
- 当前客户端按键中，`K` 负责序号外显切换，`B` 负责 quick-link 模式切换。
- 当前智能眼镜 tooltip 仅说明外显和 visualize 功能，未覆盖定向方向箭头显示开关。
- 当前客户端显示配置没有“方向箭头显示开关”的持久化状态，也没有与该功能对应的独立按键配置。

### 技术方案

1. 在客户端显示配置中为智能眼镜新增“方向箭头显示开关”和对应基础按键配置：
   - 默认基础键位仍为 `K`
   - 默认开关状态为关闭
   - 实际使用时要求与 `Ctrl` 组合触发
2. 在客户端按键注册中新增一个同样默认绑定 `K` 的 keybinding：
   - 裸按 `K` 仍切换序号外显
   - `Ctrl + K` 切换智能眼镜方向箭头显示
   - 两者通过 `Ctrl` 判定分流，避免互相误触
3. 把定向方向箭头的显示判定改为并集：
   - 主手或副手持有定向面编辑工具
   - 或智能眼镜方向箭头显示开关已开启
4. 同步智能眼镜 tooltip、语言资源、图鉴和非 `README.md` 文档，使新快捷键与显示规则对外可见。
5. 补充客户端显示配置解析测试，并执行全量自动化回归。

### 影响范围

- 客户端显示配置与模板
- 客户端按键注册与 tick 分流逻辑
- 定向方向箭头显示判定
- 智能眼镜物品 tooltip 与语言资源
- 非 `README.md` 文档与图鉴

## 原子步骤清单

### 步骤 1：扩展客户端显示配置
- **操作对象**：`RedstoneLinkClientOverlayConfig`、`RedstoneLinkClientDisplaySnapshot`、`RedstoneLinkClientDisplayConfig`、`RedstoneLinkClientDisplayParser`、`RedstoneLinkClientDisplayTemplate`
- **具体动作**：新增智能眼镜方向箭头显示开关与基础按键配置，支持默认值、解析与持久化
- **预期结果**：客户端可持久保存“方向箭头是否持续显示”的本地偏好
- **关键里程碑**：是

### 步骤 2：接入 Ctrl + K 切换逻辑
- **操作对象**：`RedstoneLinkClient`
- **具体动作**：新增方向箭头显示切换 keybinding，并在客户端 tick 中按 `Ctrl` 状态与裸 `K` 分流
- **预期结果**：`Ctrl + K` 可单独切换方向箭头显示，而不影响原有序号外显切换
- **关键里程碑**：是

### 步骤 3：改为并集显示条件
- **操作对象**：`DirectionalFaceVectorRenderSupport`
- **具体动作**：把箭头显示条件从“持有定向面编辑工具”扩展为“持有定向面编辑工具或眼镜开关开启”
- **预期结果**：玩家可在佩戴智能眼镜时选择持续显示箭头
- **关键里程碑**：是

### 步骤 4：同步 tooltip 与文档
- **操作对象**：`SmartGlassesItem`、`zh_cn.json`、`en_us.json`、`docs/usage_guide_cn.md`、`docs/usage_guide_en.md`、`docs/item_guide.html`
- **具体动作**：补充 `Ctrl + K` 和并集显示规则的说明
- **预期结果**：物品提示、图鉴和非 README 文档与实现一致
- **关键里程碑**：否

### 步骤 5：补测试并执行回归
- **操作对象**：`RedstoneLinkClientDisplayParserTest`、Gradle 测试任务
- **具体动作**：补客户端显示配置解析测试并执行 `compileJava compileClientJava test testIntegration testClient testSlow --no-daemon`
- **预期结果**：配置与显示逻辑改动具备自动化守门
- **关键里程碑**：是

## 预期结果

完成后，玩家在佩戴智能眼镜时可以通过默认 `Ctrl + K` 持续显示节点定向方向箭头；如果同时持有定向面编辑工具，也仍会正常显示，二者取并集。智能眼镜 tooltip、图鉴页与非 `README.md` 文档会同步反映这一新行为。
