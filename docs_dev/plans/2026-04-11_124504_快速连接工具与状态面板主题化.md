# 快速连接工具与状态面板主题化

生成时间：2026-04-11 12:45:04
文件名：2026-04-11_124504_快速连接工具与状态面板主题化.md

## 任务背景
当前 `core / triggerSource / filter` 配对相关 GUI 已经接入独立背景图、描边标题与主题化控件，但快速连接工具与状态面板仍停留在原版控件和纯文本布局阶段。用户已经为它们补充了独立背景图，希望按 `core` 原先的整套设定接入统一主题，并明确：

- `sd` 表示序号直连，对应 `qlt_sd_background.png`
- `cp` 表示频道匹配，对应 `qlt_cp_background.png`
- 本轮先跳过频道匹配逻辑，只实现快速连接工具当前可用的序号直连主题
- 不改贴图资源，只在客户端 GUI 表现层接线

## 方案详情

### 现状分析
- `GuiBackgroundRenderSupport` 目前仅提供 `CORE_PAIRING`、`TRIGGER_SOURCE_PAIRING`、`FILTER_EDITOR` 三套预设，缺少快速连接工具和状态面板的主题入口。
- `QuickLinkToolScreen` 已有标题描边，但输入框仍使用旧的无阴影计数输入框，按钮仍是原版 `Button`，也没有独立背景区域。
- `StatePanelToolScreen` 已有标题描边，但输入框仍是原版 `EditBox`，按钮与列表文字也未按主题调整。
- 项目内已经有 `StyledButton`、`StyledEditBox`、`StyledMultiLineEditBox`、`GuiTitleRenderSupport` 等可复用样式基础，可直接复用避免重复实现。

### 技术方案
1. 在 `GuiBackgroundRenderSupport` 中新增快速连接工具与状态面板的背景资源常量和预设，统一暴露边框主色，供按钮、输入框和文本复用。
2. `QuickLinkToolScreen` 改为使用序号直连主题：
   - 绘制 `qlt_sd_background.png`
   - 输入框切换到 `StyledMultiLineEditBox`
   - 主操作按钮与缓存类型按钮切换到 `StyledButton`
   - 标题、副标题、标签和状态信息切换到对应主题色
3. `StatePanelToolScreen` 改为使用 `status_panel_background.png`：
   - 绘制独立背景区域
   - 输入框切换到 `StyledEditBox`
   - 全部按钮切换到 `StyledButton`
   - 表头、列表内容、状态提示统一为状态面板主题色

### 影响范围
- `src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java`
- `src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java`
- `src/client/java/com/makomi/client/screen/StatePanelToolScreen.java`
- `docs_dev/reviews/` 下新增本轮审查文档

### 技术取舍
- 复用现有样式组件而不是为两个界面各自重写控件，保持 DRY，后续也更容易继续扩展到 `qlt_cp`。
- 本轮不接入“根据模式动态切换两套快速连接主题”的复杂逻辑，避免在用户明确要求“频道先跳过”时引入额外状态分支。
- 不修改任何贴图资源，只消费现有 PNG 和其透明通道表现，符合资源改动管控要求。

### 预期与风险
- 预期结果：两个 GUI 都具备与 `core / triggerSource / filter` 一致的背景、标题、输入框、按钮与文本主题体验。
- 潜在风险：窗口缩放后背景包围盒与控件区域可能需要细调；通过复用既有布局结果和统一包围盒计算降低风险。
- 语义对齐说明：
  - 命名是否仅使用 `triggerSource/core`：是，本轮不新增业务语义字段。
  - 输入/输出结构是否保持方向一致：是，本轮不调整任何网络载荷或持久化结构。
  - 文案与注释是否无旧术语泄漏：是，仅调整界面主题表现。
  - 与 `LinkNodeType` 映射是否一一对应：保持现状，不改映射。
  - 兼容层是否仅“读旧写新”：本轮无兼容层改动。
  - 残余风险：无。
