# P3 serial模式只读可视化网络分析器

生成时间：2026-04-17 10:47:42
文件名：2026-04-17_104742_P3_serial模式只读可视化网络分析器.md

## 任务背景

现有整体方案文档已定义 `P3` 为“serial 模式只读可视化网络分析器”。当前仓库已经具备：

- 本地离线网页桥接服务
- 本地资产仓 `recordings/graphs/drafts/layouts`
- recording 导出分块链路
- recording 独立网页查看页

但还缺少拓扑图快照导出、graph 资产落盘、网页独立 graph 页面，以及游戏内可触发的导出入口。因此本轮实现以最小闭环为目标，把 `P3` 跑通，不提前进入 `P4` 的编辑保存。

## 方案详情

### 现状分析

- 服务端已有 `LinkSavedData`、`NodeSnapshotQueryService`、`NodeAliasServerSupport` 等读模型能力，可直接组装 serial 拓扑快照。
- 客户端已有 `LocalWebAppBridgeService`、`LocalWebAssetRepository`，并且 recording 已验证“服务端分块 -> 客户端写本地资产 -> 网页打开”的链路可复用。
- 网页端 `App.tsx` 目前只支持首页和 recording 页，graph 资产仍停留在首页原始文本预览。

### 技术方案

1. 新增服务端 graph DTO 与 JSON 支撑：
   - 定义 `GraphSnapshotBundle`
   - 定义 `GraphSnapshotJsonSupport`
   - 定义 `GraphSnapshotExportService`
2. 复用状态面板网络链路新增 graph 导出请求与分块回传：
   - C2S：请求导出当前玩家可读的 serial 图快照
   - S2C：返回压缩后的 graph snapshot 分块
3. 客户端接包后写入 `gameDir/redstonelink/web/graphs/*.json.gz`，并可直接打开 graph 页面。
4. 网页端新增独立 `graph` 页面：
   - 加载 graph 文件
   - 解析 `graphSnapshotBundle`
   - 使用 `React Flow` 做只读可视化
   - 提供搜索、自动布局、缩放/平移、节点详情侧栏

### 技术取舍

- 图布局先采用“按类型分列 + 按序号排序”的轻量布局，而不是一开始引入复杂自动布局算法。优点是实现成本低、可预测、稳定；代价是复杂图的美观度一般，但已满足 `P3` 的“简单好用”目标。
- 只导出“当前玩家可读节点和可读边”，不把被隐私裁剪的真值直接暴露给网页。这样可以延续现有读控语义。
- 图快照入口先挂到客户端命令，避免提前把过渡入口写死到状态面板 GUI；后续独立可视化编辑器物品只需要复用同一导出链路。

## 原子步骤清单

### 步骤 1：实现 graph snapshot DTO 与导出服务
- **操作对象**：`src/main/java/com/makomi/data/**`
- **具体动作**：新增 `GraphSnapshotBundle`、`GraphSnapshotJsonSupport`、`GraphSnapshotExportService`，按当前玩家读权限导出 `serial` 模式图快照
- **预期结果**：服务端可稳定生成压缩 graph snapshot 及文件名
- **关键里程碑**：是

### 步骤 2：打通 graph 分块网络链路
- **操作对象**：`src/main/java/com/makomi/network/**`
- **具体动作**：扩展状态面板网络 payload、编解码与服务端处理器，支持 graph 导出请求和分块下发
- **预期结果**：客户端可收到完整 graph 资产字节流
- **关键里程碑**：是

### 步骤 3：实现客户端 graph 资产落盘与命令入口
- **操作对象**：`src/client/java/com/makomi/client/network/**`、`src/client/java/com/makomi/client/web/**`、`src/client/java/com/makomi/RedstoneLinkClient.java`
- **具体动作**：分块重组后写入 `graphs/` 目录，并在客户端命令树增加 graph 导出入口
- **预期结果**：玩家可通过命令触发导出并直接打开 graph 页面
- **关键里程碑**：是

### 步骤 4：实现网页 graph 独立页面与只读图查看
- **操作对象**：`webapp/package.json`、`webapp/src/**`
- **具体动作**：新增 graph bundle 解析、独立 graph 页面、`React Flow` 只读图组件、搜索与详情侧栏
- **预期结果**：graph 资产不再只显示原始 JSON，而是可交互查看拓扑
- **关键里程碑**：是

### 步骤 5：回归验证与审查文档
- **操作对象**：构建/测试命令、`docs_dev/reviews/**`
- **具体动作**：执行全标签 Gradle 验证并补齐五段式审查文档
- **预期结果**：形成可追溯验证证据与审查记录
- **关键里程碑**：是

## 预期结果

完成后，客户端命令可以导出当前玩家可读的 serial 拓扑图快照，客户端会将结果写入本地 `graphs` 资产目录，并自动跳转到独立 graph 页面；网页端可对该图执行缩放、平移、搜索、重新布局和节点详情查看。当前阶段不包含编辑保存。
