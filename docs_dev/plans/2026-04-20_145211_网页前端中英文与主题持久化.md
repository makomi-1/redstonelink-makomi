# 网页前端中英文与主题持久化

生成时间：2026-04-20 14:52:11
文件名：2026-04-20_145211_网页前端中英文与主题持久化.md

## 任务背景

当前网页前端已支持主题切换，但主题选择不会持久化；同时界面文案主要为中文硬编码，缺少中英文切换能力。用户希望在不改后端接口与业务语义的前提下，为网页前端补充中英文切换，并让语言与主题选择在刷新后保持。

## 方案详情

### 现状分析

- `webapp/src/App.tsx` 已集中管理页面路由、bridge 状态、存储索引与 `currentThemeId`，适合作为语言与主题持久化的统一入口。
- `webapp/src/app/GraphPage.tsx` 与 `webapp/src/app/RecordingPage.tsx` 顶部均已挂载 `ThemeSwitcher`，适合在同一区域加入语言切换控件。
- 运行时用户可见文案分散在 `App.tsx`、页面组件与 `GraphViewer`/`RecordingViewer` 等组件中，目前没有统一字典或本地化层。
- 现有主题切换纯前端本地状态，不依赖后端接口，因此语言与主题持久化都可通过浏览器 `localStorage` 解决。

### 技术方案

- 新增轻量前端本地化模块，定义：
  - 语言类型与默认语言
  - 语言/主题持久化 key
  - 语言字典与取词函数
  - 主题与语言的本地读取兜底逻辑
- 在 `App.tsx` 顶层接入：
  - 初始读取持久化语言与主题
  - 语言切换与主题切换时同步写入 `localStorage`
  - 将语言能力下发给 graph/recording 页面与主要组件
- 新增 `LanguageSwitcher`，与 `ThemeSwitcher` 并排放到页面头部工具区。
- 逐步替换主要运行时文案为字典取值，优先覆盖主交互路径；后端原样返回的错误正文不做翻译，只翻译前端包装文案。
- 补充前端测试，覆盖：
  - 默认语言/主题回退
  - 切换后刷新仍保持
  - 页面主路径文案随语言切换更新

## 预期结果
