# gui中文文字描边修复

生成时间：2026-04-15 17:12:12
文件名：2026-04-15_171212_gui中文文字描边修复.md

## 任务背景

当前 GUI 标题描边由 `GuiTitleRenderSupport` 手写八向 `drawInBatch(...)` 叠加实现。项目已升级到 `1.21.1`，原版 `Font.drawInBatch8xOutline(...)` 已可用，因此本次需要把标题描边切回原版路径，修复中文标题描边显示问题，并减少手写渲染细节。

## 方案详情

### 现状分析

- 标题和副标题都经由 `GuiTitleRenderSupport.drawCenteredOutlinedText(...)` 渲染。
- 该方法当前通过双重循环手动绘制 8 次偏移描边，再绘制 1 次正文。
- 现有主标题固定描边色、副标题按文字色推导描边色的语义已经稳定，调用层不需要变化。

### 技术方案

- 保留 `GuiTitleRenderSupport` 作为唯一标题描边入口。
- 将内部实现从手写八向 `font.drawInBatch(...)` 切换为原版 `font.drawInBatch8xOutline(...)`。
- 保持现有居中定位、正文色和描边色推导逻辑不变，避免影响其他 GUI 布局和主题色。

### 影响范围

- `src/client/java/com/makomi/client/screen/GuiTitleRenderSupport.java`
- 依赖该 helper 的所有 GUI 头部标题渲染路径

## 原子步骤清单

### 步骤 1：替换标题描边实现
- **操作对象**：`GuiTitleRenderSupport`
- **具体动作**：移除手写八向偏移绘制，改为调用原版 `drawInBatch8xOutline(...)`
- **预期结果**：标题描边使用原版实现，中文描边路径一致
- **关键里程碑**：是

### 步骤 2：清理受影响导入与注释
- **操作对象**：`GuiTitleRenderSupport`
- **具体动作**：同步清理不再需要的导入和过时注释描述
- **预期结果**：代码保持简洁、注释与实现一致
- **关键里程碑**：否

### 步骤 3：执行回归验证
- **操作对象**：Gradle 测试任务
- **具体动作**：运行 `.\gradlew.bat test testIntegration testClient testSlow --no-daemon`

- **关键里程碑**：是

GUI 标题描边统一走原版八向描边实现，保持现有颜色语义与布局不变，减少手写描边逻辑带来的中文显示偏差。
