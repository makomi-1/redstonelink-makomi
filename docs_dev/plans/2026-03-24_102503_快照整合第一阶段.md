# 快照整合第一阶段

## 任务背景
当前代码中已经存在节点运行态快照链路，但命令读取与“当前连接”可见视图仍然分散在多个服务与输出点里。为了给后续状态面板工具物品、网络显示和测试读模型打基础，需要先完成第一阶段的“单节点读模型收口”，但不把事件回放、审计统计和诊断计数这类异质快照硬并在一起。

## 方案详情

### 现状分析
- `NodeRuntimeSnapshot` + `NodeRuntimeProbe` 已构成运行态读取链路
- `node get` / `link get` 仍在 `ModCommands` 内手动拼装身份、连接和运行态输出
- `CurrentLinksPrivacyService` 直接返回 `List<Long>` / `Set<Long>`，缺少稳定的内部 DTO
- `ReplaySyncSnapshot`、`AuditSnapshot`、`FanoutDiagnosticsSnapshot` 不属于单节点读模型，不纳入本阶段整合

### 技术方案
本阶段只整合“单节点、可读、可展示”的读模型：

1. 新增 `NodeIdentitySnapshot`
   - 统一承载节点身份字段：`type/serial/allocated/retired/online/dimension/pos`
2. 新增 `NodeLinksSnapshot`
   - 统一承载当前连接视图：`sourceIdentity/visibleTargets/masked`
3. 新增 `NodeSnapshotQueryService`
   - 统一装配 identity / runtime / links
   - 给命令读取复用
4. 重构 `NodeRuntimeSnapshot`
   - 依赖 `NodeIdentitySnapshot`
   - 保留现有便捷访问器，避免大面积调用点跟改
5. 收口 `node get` / `link get`
   - 改用统一读模型服务
   - 运行态输出改为读取统一 `NodeRuntimeSnapshot`

## 原子步骤清单

### 步骤 1：抽节点身份快照
- **操作对象**：`NodeRuntimeSnapshot`、`NodeRuntimeProbe`
- **具体动作**：
  - 新增 `NodeIdentitySnapshot`
  - `NodeRuntimeSnapshot` 改为持有 `identity`
  - 提供兼容访问器，减少外层调用点变化
- **预期结果**：身份信息从运行态快照中独立出来
- **关键里程碑**：是

### 步骤 2：抽当前连接视图快照
- **操作对象**：`CurrentLinksPrivacyService`
- **具体动作**：
  - 新增 `NodeLinksSnapshot`
  - 在现有 `resolveVisibleCurrentLinksSnapshot(...)` 基础上补充返回 DTO 的入口
  - 现有 `List/Set` 方法保留为包装层
- **预期结果**：当前连接可见视图具备统一内部 DTO
- **关键里程碑**：是

### 步骤 3：新增单节点查询门面
- **操作对象**：`NodeSnapshotQueryService`
- **具体动作**：
  - 统一组装 identity / runtime / links
  - 对命令层暴露稳定查询接口
- **预期结果**：命令读取不再自行拼装多份快照逻辑
- **关键里程碑**：是

### 步骤 4：收口 node get / link get
- **操作对象**：`ModCommands`
- **具体动作**：
  - `node get` 与 `link get` 改用 query service
  - 保持现有输出结构基本不变
  - 若存在可读 runtime，则统一从 `NodeRuntimeSnapshot` 输出
- **预期结果**：命令读取走统一读模型
- **关键里程碑**：是

### 步骤 5：补测试并回归
- **操作对象**：相关 `src/test/java/com/makomi/data/**`
- **具体动作**：
  - 补 identity / links / query service 的最小测试
  - 更新 `NodeStateTraceServiceTest` 等受构造器影响的测试
- **预期结果**：模型重构可回归验证
- **关键里程碑**：否

## 预期结果
- 建立“节点读模型家族”的最小骨架
- `node get` / `link get` 收口到统一查询服务
- 为后续网络包、物品 NBT 与状态面板复用留出稳定基础
- 不改变事件回放、审计统计与诊断计数的职责边界
