# 未来指挥台主题冷色重构

生成时间：2026-04-19 17:33:13
文件名：2026-04-19_173313_未来指挥台主题冷色重构.md

## 任务背景

当前网页前端已经支持主题切换，但“未来指挥台”主题仍沿用了此前默认的暖色暗底配色，导致主题名称、描述文案与实际视觉观感不一致。需要在不改动主题切换结构、不影响另外两套主题的前提下，将该主题调整为以冷白、深蓝为主，红色为高亮的未来指挥台风格。

## 方案详情

### 现状分析

- `future-command` 当前作为默认主题存在，但主要依赖 `webapp/src/app.css` 中 `.app-shell` 的基础变量。
- 基础变量仍以暖橙、暖白、琥珀色为主，和“未来指挥台”的冷色科幻定位不一致。
- 图网络与录制图表已经统一走 CSS 变量或通过主题变量解析颜色，因此只要修正主题 token，就可以同步带动多个页面的视觉更新。

### 技术方案

- 保留现有主题切换系统、主题名称和 ID 不变。
- 在 `webapp/src/app.css` 中为 `future-command` 建立显式主题变量覆写，替代当前暖色基底。
- 将未来指挥台配色调整为冷白、深蓝、冷蓝与红色高亮，压低橙色存在感。
- 同步更新 `webapp/src/app/theme.ts` 中该主题的说明文案与调色板标签，使文案与实际视觉一致。

### 影响范围

- `webapp/src/app.css`
- `webapp/src/app/theme.ts`
- 前端主题切换后的首页、图网络页、录制页视觉表现

- **操作对象**：`webapp/src/app.css`
- **具体动作**：为 `future-command` 补充独立主题 token，重设文本、面板、图网络、录制图表等颜色变量，并同步调整主题预览条色带
- **预期结果**：未来指挥台不再复用旧暖色默认样式，而是呈现统一的冷色科幻视觉
- **关键里程碑**：是

### 步骤 2：校正文案描述
- **操作对象**：`webapp/src/app/theme.ts`
- **具体动作**：更新“未来指挥台”的说明文案与调色板标签
- **预期结果**：切换器中的主题描述与实际视觉一致
- **关键里程碑**：否
