# 录制曲线tooltip增强

生成时间：2026-04-20 23:08:18
文件名：2026-04-20_230818_录制曲线tooltip增强.md

## 任务背景

当前网页录制曲线页面已经具备鼠标辅助线，但多条曲线重合时只能依赖颜色与线型区分，不方便直接读取当前位置的具体数值。需求是保留现有辅助线，仅补充一个随鼠标悬停显示的 tooltip，用于展示当前横坐标与各条可见曲线的值。

## 方案详情

### 现状分析

- 曲线渲染集中在 `webapp/src/components/RecordingChart.tsx`，当前使用 `uPlot` 渲染 canvas 曲线。
- 图表交互壳 `recording-chart-interaction-shell` 已经是相对定位容器，适合承载额外的绝对定位 tooltip。
- 组件已实现滚轮缩放、拖拽平移、双击重置和键盘控制，现阶段不应改动这些行为。
- 当前没有独立的 `RecordingChart` 单测文件，需要补一个最小测试覆盖 tooltip 显隐路径。

### 技术方案

- 在 `RecordingChart.tsx` 内新增 tooltip 状态，复用 `uPlot` 的 `hooks.setCursor` 读取当前 cursor 索引、横坐标值和各 series 值。
- 将 tooltip 数据在组件内折算为 React 可渲染结构，并在鼠标离开或命中无效索引时隐藏 tooltip。
- 在图表外层渲染绝对定位 tooltip，展示当前 tick 与可见曲线数值，并进行基础边界保护，避免贴边溢出。
- 在 `app.css` 中补充 tooltip 样式，确保与现有主题变量兼容。
- 为 `RecordingChart` 增加 Vitest 单测，验证空图不显示 tooltip，以及有 cursor 数据时能显示对应值。

### 影响范围

- `webapp/src/components/RecordingChart.tsx`
- `webapp/src/app.css`
- `webapp/src/components/RecordingChart.test.tsx`

- **操作对象**：`webapp/src/components/RecordingChart.tsx`

- **预期结果**：鼠标移动到曲线区域时可以看到清晰的数值提示
