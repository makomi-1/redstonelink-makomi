# graph工具区移到左侧并放宽页面

生成时间：2026-04-19 18:42:37
文件名：2026-04-19_184237_graph工具区移到左侧并放宽页面.md

## 任务背景

当前 graph 可视化编辑器已经完成主题与交互区优化，但“显示模式 / 编辑模式 / 搜索 / Save / 草稿提示”等编辑工具区仍位于画布上方。用户要求将这块工具区移动到左侧，右侧继续保留详情与编辑栏，并通过放宽整个页面而不是压缩画布的方式腾出空间。

## 方案详情

### 现状分析

- `webapp/src/components/GraphViewer.tsx` 当前把 `graph-toolbar-block` 放在 `graph-viewer` 顶层，再把画布卡片与详情卡片放入两栏 `graph-workspace`。
- `webapp/src/app.css` 当前 `graph-workspace` 仅有“画布 + 详情”两栏，且 graph 页面复用了 `recording-page-header` / `recording-page-main` 的 `1380px` 最大宽度。
- 如果直接把工具区塞到现有两栏里，会挤压中间画布宽度，不符合“画布大小不变、整页变宽”的约束。

### 技术方案

- 保持 `graph-toolbar-block` 内部逻辑不变，只调整 DOM 位置。
- 将 `GraphViewer` 的主布局改成三栏：
  - 左侧新增工具栏容器，承载原有 `graph-toolbar-block`
  - 中间保留 `graph-canvas-card`
  - 右侧继续保留 `graph-detail-card`
- 在 `app.css` 中为 graph 页面添加更宽的专用最大宽度，并把 `graph-workspace` 改成左中右三栏。
- 保留现有窄屏响应式回退，避免移动端或窄窗口布局断裂。
