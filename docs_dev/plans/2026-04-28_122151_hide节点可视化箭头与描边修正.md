# hide节点可视化箭头与描边修正

生成时间：2026-04-28 12:21:51
文件名：2026-04-28_122151_hide节点可视化箭头与描边修正.md

## 任务背景

当前第一轮 `hide` 节点实现已经具备智能眼镜下的幽灵模型显示，但仍有两个交互层问题需要回补：

- `hide` 节点额外绘制了方框描边，容易与现有其它描边体系冲突。
- 手持面编辑器时，玩家还无法直接看出 `hide` 节点当前到底启用了哪些面。

因此本轮只收敛客户端可视化表现，不改节点真值、容器逻辑或配对链路。

## 方案详情

### 现状分析

- `HideNodeGhostRenderer` 当前同时承担三件事：
  - 智能眼镜门槛判断
  - 半透明幽灵模型渲染
  - 额外方框描边渲染
- `DirectionalFaceEditorItem` 已经具备完整的 `hide` 节点面集编辑能力。
- `NodeFaceSetBlockStateSupport` 已经提供了启用面解析入口，可直接复用。

### 技术方案

- 保留 `hide` 节点幽灵模型渲染。
- 删除 `HideNodeGhostRenderer` 中的额外方框描边。
- 在 `HideNodeGhostRenderer` 内新增“手持面编辑器时的启用面箭头渲染”：
  - 仅对 `hide core / hide sync triggerSource` 生效
  - 仅在佩戴智能眼镜时生效
  - 仅在主手持有 `DirectionalFaceEditorItem` 时生效
  - 每个启用面绘制一根从方块中心指向该面的箭头
- 箭头颜色继续复用当前节点类型文本色，避免引入新的颜色语义。

### 影响范围

- `src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java`
- `docs_dev/reviews/` 本轮审查文档

## 原子步骤清单

### 步骤 1：移除额外描边
- **操作对象**：`HideNodeGhostRenderer`
- **具体动作**：删除隐藏节点额外方框描边调用与实现
- **预期结果**：`hide` 节点不再与现有描边体系叠加冲突
- **关键里程碑**：是

### 步骤 2：增加手持面编辑器判定
- **操作对象**：`HideNodeGhostRenderer`
- **具体动作**：在现有智能眼镜门槛上追加主手 `DirectionalFaceEditorItem` 判断
- **预期结果**：箭头只在编辑语境出现
- **关键里程碑**：是

### 步骤 3：实现启用面箭头渲染
- **操作对象**：`HideNodeGhostRenderer`
- **具体动作**：按启用面集合绘制箭杆和箭头头部线段
- **预期结果**：玩家能直观看到每个已启用面的向量方向
- **关键里程碑**：是

### 步骤 4：验证与审查
- **操作对象**：编译、自动化测试、审查文档
- **具体动作**：执行编译和全量测试，并写入本轮审查文档
- **预期结果**：改动可回归、可追溯
- **关键里程碑**：是

## 预期结果

- 戴智能眼镜时，`hide` 节点只显示半透明幽灵模型，不再额外显示方框描边。
- 主手手持面编辑器时，`hide` 节点会显示当前启用面的箭头。
- 本轮不改变任何 `triggerSource/core` 真值、配对方向或容器行为。
