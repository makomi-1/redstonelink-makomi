# 主题切换收紧与页面紧凑化

生成时间：2026-04-19 18:21:07
文件名：2026-04-19_182107_主题切换收紧与页面紧凑化.md

## 任务背景

当前网页前端已经具备三套可切换主题，但主题切换区仍然以“预览模板”的形式展示，附带大块说明文案和较高的垂直空间占用。同时 graph / recording 页面头部与主内容区的留白偏大，主要交互内容不够靠前，视觉重点被页面装饰与说明层分散。

需要在保留三套主题全部可用的前提下，去掉主题预览说明，收紧整体布局，让主要交互内容更突出。

## 方案详情

### 现状分析

- `ThemeSwitcher` 仍渲染主题标题、预览说明、色板说明等附加内容，组件本身占据较大空间。
- graph / recording 页面把主题切换单独放在一张卡片里，主功能区前面多了一层独立模块。
- `app.css` 中头部、卡片、空状态与主内容区的 `padding`、`gap`、`margin` 偏大，整体视觉更偏展示型而不是工具型。

### 技术方案

- 保留三套主题和切换能力，不修改主题 ID。
- 将 `ThemeSwitcher` 改成紧凑按钮组，只保留主题名称，不再渲染说明和色板文案。
- 把主题切换并入 graph / recording 页头部卡片，删除单独的主题预览卡片。
- 统一收紧页面间距、头部高度、卡片内边距和空状态容器，让主交互区域更靠前。

### 影响范围

- `webapp/src/components/ThemeSwitcher.tsx`
- `webapp/src/app/GraphPage.tsx`
- `webapp/src/app/RecordingPage.tsx`
- `webapp/src/app.css`
- 相关前端测试

## 原子步骤清单

### 步骤 1：收口主题切换器文案
- **操作对象**：`webapp/src/components/ThemeSwitcher.tsx`
- **具体动作**：去掉“主题预览”头部、说明文案和色板文案，只保留主题名称按钮
- **预期结果**：三套主题保留，但切换区明显更紧凑
- **关键里程碑**：是

### 步骤 2：把主题切换并入页面头部
- **操作对象**：`webapp/src/app/GraphPage.tsx`、`webapp/src/app/RecordingPage.tsx`
- **具体动作**：移除单独主题卡片，将切换器放入头部主卡片内
- **预期结果**：主页面更聚焦工具交互
- **关键里程碑**：是

### 步骤 3：统一收紧整体布局
- **操作对象**：`webapp/src/app.css`
- **具体动作**：压缩头部、卡片、工具条、主内容区和空状态的留白与间距
- **预期结果**：整体更紧凑，突出 graph / recording 主交互内容
- **关键里程碑**：是

### 步骤 4：回归验证
- **操作对象**：前端测试与全量 Gradle 测试
- **具体动作**：执行 `npm run typecheck`、`npm run test` 和全标签 Gradle 回归
- **预期结果**：确认本轮仅影响前端布局与样式，无功能回归
- **关键里程碑**：是

## 预期结果

网页前端会继续保留三套主题供用户自由切换，但主题区会从“预览展示”收敛为轻量工具栏；同时 graph / recording 页面头部和主内容区会更紧凑，主要交互内容更靠前、更突出。
