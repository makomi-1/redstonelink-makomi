# core与triggerSource发射器双层渲染

生成时间：2026-03-25 17:38:39
文件名：2026-03-25_173839_core与triggerSource发射器双层渲染.md

## 任务背景
用户希望将 `core` 方块与发射器类 `triggerSource` 方块的外观改成类似粘液块的内外双层结构。
已确认本轮不改贴图内容，只调整渲染资源组织方式。
内层统一复用 `block/component_core_block.png`，外层继续使用各自原有外层贴图。

## 方案详情

### 现状分析
- 当前 `core` 与三种发射器方块模型均为单层 `cube_all`。
- 客户端已将这些方块注册到 `translucent` 渲染层，可直接支持半透明外壳显示。
- 现有外层贴图本身已包含半透明像素，因此只要补足内层几何体即可形成双层观感。

### 技术方案
- 新增一个共享的双层方块模板模型，定义外层壳体与内层缩进立方体。
- 将 `core` 普通/亮态模型改为继承该模板，并分别绑定各自外层贴图。
- 将三种发射器普通/亮态模型改为继承同一模板，并分别绑定各自外层贴图。
- 内层纹理统一绑定 `redstonelink:block/component_core_block`。
- 不引入新的 BER、渲染器或贴图文件修改。

### 影响范围
- `src/main/resources/assets/redstonelink/models/block/**`
- 仅影响 `core` 与三种发射器的视觉模型表现。
- 不涉及命令、网络、持久化、节点语义与贴图资源内容。

- **预期结果**：`core` 普通态与亮态都呈现双层观感。
