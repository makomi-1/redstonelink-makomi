# 智能节点容器临时选取与 hide 转发器分类修复

生成时间：2026-04-30 21:11:12
文件名：2026-04-30_211112_智能节点容器临时选取与hide转发器分类修复.md

## 任务背景

当前智能节点容器存在两处交互缺口：

1. 容器只能按 `core/triggerSource/repeater` 三类的“首个槽位”放置，无法在同类节点之间做一次性临时指定。
2. `hide repeater` 在容器里被误识别成 `core`，导致放置类型判断错误。

用户要求新增 `Ctrl + 鼠标滚轮` 的临时选取能力：按当前放置类型在已排序好的同类节点中循环切换，成功作用一次后恢复原默认顺序；同时修复 `hide repeater` 的容器分类。

## 方案详情

### 现状分析

- `SmartNodeContainerData.classify(...)` 目前只把 `LINK_REPEATER` 单独识别为 `REPEATER`，`HIDE_REPEATER` 会退回 `PairableItem -> CORE` 分支。
- `SmartNodeContainerItem.useOn(...)` 目前总是调用 `findFirstSlotForType(...)` 选取当前类型的首个槽位，没有“一次性临时槽位”状态。
- 客户端已有全局滚轮 hook，仅用于 `SyncLinkerItem` 的 `Ctrl + 滚轮` 信号强度调节，可以复用为智能节点容器的快捷选取入口。
- 智能节点容器网络当前只有“打开容器”和“循环放置类型”两种 payload，缺少“选择临时槽位”的服务端同步通道。

### 技术方案

1. 在 `SmartNodeContainerData` 中补一个轻量持久化字段，记录“一次性临时选中的真实槽位”。
2. `SmartNodeContainerItem` 放置时优先使用临时槽位；成功放置后立即清空临时槽位，失败则保留。
3. 客户端在主手持智能节点容器且按住 `Ctrl` 时，通过滚轮在“当前放置类型”对应的候选槽位中循环选择，并通过新的网络 payload 通知服务端写入临时槽位。
4. `hide repeater` 在容器分类中显式归为 `REPEATER`，与可见 `repeater` 保持一致。

### 影响范围

- `src/main/java/com/makomi/data/SmartNodeContainerData.java`
- `src/main/java/com/makomi/item/SmartNodeContainerItem.java`
- `src/main/java/com/makomi/network/SmartNodeContainerNetwork*.java`
- `src/client/java/com/makomi/RedstoneLinkClient.java`
- 新增/调整相关测试类

## 原子步骤清单

### 步骤 1：修复 hide 转发器容器分类
- **操作对象**：`SmartNodeContainerData`
- **具体动作**：把 `HIDE_REPEATER` 与 `LINK_REPEATER` 一起归类为 `REPEATER`
- **预期结果**：hide 转发器在容器里不再被当作 `core`
- **关键里程碑**：否

### 步骤 2：补一次性临时槽位状态
- **操作对象**：`SmartNodeContainerData`
- **具体动作**：新增临时槽位字段、读写、清理与按类型候选槽位解析方法
- **预期结果**：容器可持久保存当前一次性的同类节点临时选取
- **关键里程碑**：是

### 步骤 3：放置链接入临时槽位
- **操作对象**：`SmartNodeContainerItem`
- **具体动作**：放置时优先消费临时槽位，成功后清空临时槽位并恢复默认顺序
- **预期结果**：实现“作用一次后回到原顺序”
- **关键里程碑**：是

### 步骤 4：接入 Ctrl + 滚轮快捷选取
- **操作对象**：`RedstoneLinkClient`、`SmartNodeContainerNetwork`、`SmartNodeContainerNetworkServerHandlerSupport`
- **具体动作**：在现有滚轮 hook 上增加智能节点容器分支，循环同类候选槽位并同步到服务端
- **预期结果**：玩家可用 `Ctrl + 滚轮` 暂时选中当前类型内的某个节点
- **关键里程碑**：是

### 步骤 5：补自动化回归并验证
- **操作对象**：测试类、Gradle 任务
- **具体动作**：补分类/候选槽位/临时槽位清理相关单测，并执行全量自动化测试
- **预期结果**：功能和兼容性都有自动化守门
- **关键里程碑**：是

## 预期结果

- 智能节点容器支持 `Ctrl + 鼠标滚轮` 在当前放置类型内做一次性临时选取。
- 临时选取成功作用一次后自动恢复原放置顺序。
- `hide repeater` 与可见 `repeater` 在容器内保持一致的 `REPEATER` 分类和放置行为。
