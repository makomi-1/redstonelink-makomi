# bench 重压用例扩容

生成时间：2026-03-27 15:31:21

## 任务背景

现有 `performance-heavy` 仅覆盖：
- `1 -> 1024`
- `256 -> 1`

该压力等级已经不足以覆盖后续并发链路、玩家观测与 spark 采样需求，需要按既定口径扩容到更高规模，同时保持纯输入器驱动与当前采样窗口不变。

## 方案详情

### 现状分析

- `tools/bench/matrix-performance-heavy.json` 当前只挂载 6 个 case。
- `tools/bench/suites/performance-heavy.json` 当前只编排 `1 -> 1024` 与 `256 -> 1` 两组单类型场景。
- 纯性能驱动模板已经统一为 `0/15、2 tick、10Hz`。
- matrix 默认采样窗口已经统一为 `1600 tick = 80 秒`，其中 `400 tick` 预热、`1200 tick` 计入结果。

### 技术方案

直接扩容现有 heavy case 集，并保持现有驱动/采样口径不变：

1. 将 `1 -> 1024` 三个单类型场景扩容为 `1 -> 2048`
2. 将 `256 -> 1` 三个单类型场景扩容为 `1024 -> 1`
3. 新增 `1024 -> 1024 sync`
4. 新增 `1024 -> 1024 mixed`

关键实现约束：

- `1 -> 2048` 的 `link set` 继续使用 `targetSerialFormat: range`
- 大 source group 的输入器驱动统一使用 `serialFormat: range`，避免 `input start` 命令串过长
- `1024 -> 1024 sync` 继续沿用 `banded16` 规则化多对多映射
- `1024 -> 1024 mixed` 采用 `512 sync + 256 pulse + 256 toggle = 1024` 的分组布局，并保持 banded 偏移映射
- 不改动 matrix 的 `performanceWindow`、驱动模板、spark 采集逻辑
