# 新增无线化粘性活塞原型

生成时间：2026-05-04 11:30:37
文件名：2026-05-04_113037_新增无线化粘性活塞原型.md

## 任务背景

当前项目已经实现了`无线化活塞`，它作为`core`只响应已连接`triggerSource`，并且已经补齐了无线活塞头、结构解析放宽、节点搬运恢复等关键能力。  
用户要求在此基础上追加一个`无线化粘性活塞`原型，保留原版粘性活塞的伸缩与回拉表现，同时继续沿用现有无线节点语义与搬运协议。

## 方案详情

### 现状分析

- `WirelessPistonBlock` 已经完成普通活塞的无线驱动与节点搬运协议，但当前实现把 `PistonType.DEFAULT`、普通头部和非粘性回缩逻辑写死了。
- `WirelessPistonHeadBlock` 已能识别 `PistonType.STICKY`，说明头部模型与生存判定基础已经具备。
- 注册、物品、创造栏、语言、loot、挖掘标签、转化配方目前都只有 `wireless_piston`。

### 技术方案

1. 把 `WirelessPistonBlock` 参数化为“普通/粘性”两型：
   - 新增一个 `sticky` 字段；
   - 统一决定自身 `PistonType`、回缩时是否尝试拉回前方方块、活塞头生成类型；
   - 保持既有无线驱动与节点搬运协议不变。
2. 把 `WirelessPistonBlockEntity` 改为能同时服务普通/粘性无线活塞，避免复制一套 block entity 逻辑。
3. 新增 `wireless_sticky_piston` 的 block/item/block entity 注册与 GUI 上下文 token。
4. 复用原版 `sticky_piston` 资源模型与贴图，只新增最小 blockstate/item model/lang/loot/recipe/tag 接线。

### 影响范围

- 无线活塞主实现：`WirelessPistonBlock`
- 无线活塞方块实体：`WirelessPistonBlockEntity`
- 无线活塞头：`WirelessPistonHeadBlock`
- 注册与展示：`ModBlocks`、`ModBlockEntities`、`ModItems`、`ModItemGroups`、`LinkGuiDisplayContext`
- 资源与数据：`assets/redstonelink/**`、`data/redstonelink/**`、`data/minecraft/tags/block/mineable/pickaxe.json`
