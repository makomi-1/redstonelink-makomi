# 频道聚合收起与搜索精确匹配

生成时间：2026-04-18 19:27:40
文件名：2026-04-18_192740_频道聚合收起与搜索精确匹配.md

## 任务背景

当前 graph 可视化里，频道模式的聚合块表现异常：聚合块会自动进入展开态，并且点击后无法稳定收起；同时搜索仍然使用模糊匹配，导致输入部分文本或序号时命中过多节点。  
本轮目标是在不修改 snapshot、draft、服务端真值的前提下，只修前端视图层和搜索匹配逻辑。

## 方案详情

### 现状分析

- 频道模式当前会在最终可见性收敛阶段复用“视觉展开态”逻辑，只要成员节点因边关系或强制显示进入画布，聚合块就会被回写为 `expanded=true`。
- 聚合块点击切换则依赖显式展开 key 集合，这和“视觉展开态”并不是同一口径，容易造成用户看到的是已展开，但内部切换目标却不是“收起当前态”。
- 搜索目前在前端使用 `includes` 做模糊匹配，导致结果范围过宽。

### 技术方案

- 频道模式的聚合显示收敛改为“显式展开优先”，不再把成员可见直接回写为聚合块已展开。
- 聚合点击切换时优先参考当前画布中的聚合节点状态，而不是只参考显式展开 key 集合，避免状态漂移时切换方向错误。
- 搜索匹配改为标准化后的精确等值匹配，保留现有类型筛选机制。
