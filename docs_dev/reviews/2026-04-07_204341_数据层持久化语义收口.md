## 2. 关键数据结构和算法性能分析
- `CoreLinkEditingService.buildChangedTargetsByTriggerSource(...)` 使用 `LinkedHashSet/LinkedHashMap` 保持输入顺序，并且只为“目标集合真的变化”的 triggerSource 生成计划，避免对未变化来源重复 prepare/apply。[CoreLinkEditingService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/CoreLinkEditingService.java#L82)
- `LinkSavedDataLinkIndexSupport.replaceTriggerSourceTargets(...)` 以差异集替换方式落库，只处理待新增/待移除集合，不扫描整图，复杂度主要取决于单个 triggerSource 的当前目标集与目标目标集大小。[LinkSavedDataLinkIndexSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedDataLinkIndexSupport.java#L73)
- `clearLinksForNode(...)` 会先汇总受影响 triggerSource，再统一推进一次 `graphRevision` 并分别 bump 来源 revision，避免在 core 侧批量清理时产生多次全图版本抖动。[LinkSavedDataLinkIndexSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedDataLinkIndexSupport.java#L210) [LinkSavedDataLinkIndexSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedDataLinkIndexSupport.java#L311)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 兼容性风险：本轮按“一步到位、不保留旧持久化兼容”执行，持久化键只写新名；任何仍依赖 `nextButtonSerial/allocatedButtonSerials/retiredButtonSerials` 的外部脚本都会直接失效，需要同步迁移读取方。[LinkSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedData.java#L31) [LinkSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedData.java#L41) [LinkSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedData.java#L43) [LinkSavedDataCodecSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedDataCodecSupport.java#L145)
- 权限与写控风险已被拦在共享闭环里：即使从 `core` 视角发起编辑，也仍逐条走 `LinkSetExecutionService.prepareConfirmedReplace(...)` 和 `feedbackFromWriteDecision(...)`，不会绕过 readonly/protected/limited 约束。[CoreLinkEditingService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/CoreLinkEditingService.java#L188) [LinkSetExecutionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkSetExecutionService.java#L46) [LinkSetExecutionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkSetExecutionService.java#L386)
- 扩展建议：后续若再增加 GUI、脚本或 bench 入口，应继续复用 `CoreLinkEditingService`，不要重新暴露 `CORE` 底层写接口，否则会再次破坏当前单向真值模型。[CoreLinkEditingService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/CoreLinkEditingService.java#L27) [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L395)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 风险等级：低。`LinkSavedData` 仍是服务端世界级 `SavedData`，本轮新增的 `CoreLinkEditingService` 只构造局部集合与预备操作，不引入新的跨线程缓存或后台共享状态。[LinkSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkSavedData.java#L25) [CoreLinkEditingService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/CoreLinkEditingService.java#L27)
