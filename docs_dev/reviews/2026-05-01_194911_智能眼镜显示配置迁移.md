# 智能眼镜显示配置迁移

## 1. 功能与语义、架构设计（关键方法和入口）

- 本次迁移把 1.21.11 的智能眼镜显示配置同步到 26.1，新增“持续显示定向方向箭头”的客户端配置、快捷键和提示文案，客户端入口集中在 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/RedstoneLinkClient.java#L180) 与 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/RedstoneLinkClient.java#L244)。
- 架构上继续沿用 26.1 现有客户端配置聚合链路：解析器负责“读配置”，快照负责“承载默认值”，配置门面负责“切换与持久化”，对应入口分别位于 [RedstoneLinkClientDisplayParser.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplayParser.java#L47)、[RedstoneLinkClientDisplaySnapshot.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplaySnapshot.java#L16) 与 [RedstoneLinkClientDisplayConfig.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplayConfig.java#L170)。
- 语义层没有引入旧术语，也没有放宽方向约束；新增能力只是在“已佩戴智能眼镜”前提下复用现有定向面箭头渲染链路，渲染门槛收敛在 [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L38)。

## 2. 关键数据结构和算法性能分析

- `RedstoneLinkClientOverlayConfig` 只新增一个按键字段和一个布尔开关，不改变原有配置结构的访问复杂度；快照写回仍是一次性构造不可变记录，关键写回点位于 [RedstoneLinkClientDisplayConfig.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplayConfig.java#L121) 与 [RedstoneLinkClientDisplayConfig.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplayConfig.java#L172)。
- 配置解析仍然是 `Properties` 的固定键读取与范围收敛，新增两个键不会引入额外扫描或动态反射成本，整体复杂度保持 O(1)，核心逻辑位于 [RedstoneLinkClientDisplayParser.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplayParser.java#L49)。
- 客户端 tick 中新增的快捷键消费只是在既有按键轮询内增加一个 `Ctrl+K` 分支，不引入新的全局缓存或渲染遍历；热点开销主要是一次布尔翻转与一次提示消息，入口位于 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/RedstoneLinkClient.java#L210)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 本次没有引入 `com.makomi.api.v1.*` 依赖，也没有修改 `triggerSource/core` 对应关系；新增逻辑只在客户端显示层生效，不会影响服务端配对、存档数据或方向合法性。
- 兼容性上，`K` 仍然保留给原有序号外显切换，新增能力通过 `Ctrl+K` 与其复用基础键位，避免直接改坏既有操作肌肉记忆；关键分流位于 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/RedstoneLinkClient.java#L212) 与 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/RedstoneLinkClient.java#L222)。
- 后续如果继续扩展智能眼镜的显示项，建议继续沿用“配置快照 + 模板注释 + 独立消息 key + 定向解析测试”这一套路径，避免把多个显示项硬编码进客户端入口，当前模板组织可参考 [RedstoneLinkClientDisplayTemplate.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/config/RedstoneLinkClientDisplayTemplate.java#L15)。
