## 2. 关键数据结构和算法性能分析

- `pickLocalizedText(...)` 采用常量时间分支，不做运行时词典深拷贝或模板解析；对页面渲染路径来说，新增成本基本等同于普通条件分支。[i18n.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/i18n.ts#L31)
- 主题与语言持久化都只在初始化读取一次、状态变化时回写一次 `localStorage`，写入频率与用户点击频率一致，不会进入高频热路径。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L114) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L121)
- `GraphViewer` 没有为语言切换重建新的数据模型；只是在既有节点/边重算流程中透传 `language`，并在保存预检 effect 中补充语言依赖，避免多余结构副本。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1031) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1111) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1409)
- `graphViewer/canvas.tsx` 只在聚合块与频道节点标签构建时新增语言参数，不改变布局算法、连通分量拆分和自动布局复杂度；布局复杂度保持原口径。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L77) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1717) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1773)
- `draft.ts` 与 `search.ts` 的改动仅是格式化函数增补语言参数，不影响草稿折算、搜索精确匹配和保存载荷生成的时间复杂度。[draft.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/draft.ts#L60) [draft.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/draft.ts#L310) [search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L21) [search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L49)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性：本地持久化 key 是新增的前端私有键，不影响后端协议和 graph/recording 文件格式；风险低。[i18n.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/i18n.ts#L4) [theme.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/theme.ts#L12)
- 风险：当前实现以“轻量二选一文本分发”为主，适合中英双语；如果后续扩到更多语言或复数/插值规则复杂化，建议再升级为集中词典或专业 i18n 框架。[i18n.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/i18n.ts#L31)
- 风险：`GraphViewer` 仍保留少量领域英文标签（如部分 metadata 字段名），这次优先覆盖主交互文案；若后续要求全量本地化，可继续沿当前 `language` 透传方式扩展。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2211)
- 验证覆盖：已补充 `App` 的语言/主题持久化测试，并让 graph/recording 页面测试和 graph helper 测试跟随新参数口径；前端类型检查与 Vitest 通过。[App.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.test.tsx#L54) [search.test.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.test.ts#L30) [canvas.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.test.tsx#L141) [GraphViewer.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.test.tsx#L161)
- 建议：如果后续希望主题名称、页面标题、错误文案完全去硬编码，可继续把目前分散在组件内的 `text(...)` 抽成更集中的词典层，减少后续维护成本。

## 5. 并发冲突审查

- 共享状态边界：语言与主题状态只在 `App.tsx` 顶层持有，子组件通过 props 只读消费，避免多个页面各自写 `localStorage` 导致覆盖竞态。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L36) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L114)
- 读改写覆盖：`GraphViewer` 的保存、预检和草稿消息仍沿用原有状态机；本轮只把消息文本语言化，没有改变请求顺序或共享草稿对象的写入路径，竞态风险未上升。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1409) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2161)
- 重入/线程边界：前端仍运行在浏览器主线程，`localStorage` 写入是同步操作，但只发生在用户切换语言/主题时，不位于高频拖拽或动画热路径，重入风险低。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L114) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L121)
- 特殊注意：`GraphViewer` 语言切换如果直接绑定到初始化 effect，会破坏当前选区；本轮通过只在重绘 effect 和预检 effect 上接入语言依赖，避免切语言时重置当前上下文。风险等级：低，当前实现可接受。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1111) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1400)
