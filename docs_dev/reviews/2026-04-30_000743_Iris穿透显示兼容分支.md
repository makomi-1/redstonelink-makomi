# Iris穿透显示兼容分支

## 1. 功能与语义、架构设计

- 本轮在已有 Iris 兼容检测基础上，新增了一个专门的“直接线段绘制”底座，用于 Iris 下需要穿透显示的外显路径；它显式控制 shader、混合、深度测试与线宽，不再依赖常规 `RenderType/MultiBufferSource` 路径。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L27)
- 定向箭头新增了 Iris 直接绘制入口 `renderEnabledFaceVectorsIrisDirect(...)`，只在兼容分支中使用，不改变既有方向映射、颜色语义和 `core/repeater` 反向显示规则。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L132) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L205)
- 定向箭头世界后置渲染器在 Iris 下切到直接绘制分支，非 Iris 继续沿用原有 `MultiBufferSource` 逻辑，实现了兼容行为隔离。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L84)
- quick-link 兼容分支进一步扩展：
  - `LAST` 阶段下，Iris 会重绘当前命中描边与 preview 线框。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L239)
  - 第三形态连线在 Iris 下也改为走直接绘制线段路径。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L848)

## 2. 关键数据结构和算法性能分析

- 新增的数据结构只有 `IrisDirectLineRenderSupport.ColoredLineSegment`，它是单条线段的轻量记录结构，包含两端坐标、法线和 RGBA，用于在 `LAST` 阶段批量提交 mesh。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L65)
- 箭头 Iris 分支现在按“单个节点 -> 若干线段 -> 一次直接 draw”处理，计算量与启用面数量线性相关；该路径只在佩戴智能眼镜且手持定向编辑器时生效，使用频率有限。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L142) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L301)
- quick-link preview / visualize 仍复用原有缓存与线段扫描逻辑，只是在 Iris 下增加了一次“转换为直接绘制线段”的线性映射，不会引入新的全图扫描成本。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L817) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L883)
- 命中描边的 Iris 分支通过 `VoxelShape.forAllEdges(...)` 提取边界边，复杂度与命中形状边数量线性相关，通常很小。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L914)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮只改客户端显示层，不涉及协议、存档或权限边界，安全风险低。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L14)
- 性能：Iris 直接绘制分支会比普通 buffer path 多一些 draw call，尤其是箭头当前按“单节点一次 draw”执行；但该路径只在 Iris + 智能眼镜 + 对应工具启用时生效，属于可接受的兼容成本。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L84)
- 兼容性：这条路径通过 `disableDepthTest` 恢复真正的穿透显示，能更接近非 Iris 体验；但不同 shader pack 对线宽和混合仍可能存在观感差异，建议后续至少做一次带实际 shader pack 的人工回归。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L31)
- 扩展性：直接线段绘制 helper 已经独立出来，后续若过滤器范围框、区块激活器范围框等也要 Iris 穿透显示，可继续复用这条底座，不需要重复写 RenderSystem 状态控制。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L20)

## 5. 并发冲突审查

- 共享状态：
  - 新增 helper 为无状态工具类，不维护任何静态缓存或共享可变对象。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L20)
  - quick-link 侧仍然复用既有的缓存状态，如 `cachedPreviewOutlineState`、`visualizedObjects`，本轮没有新增新的共享容器。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L112)
- 读改写覆盖：
  - 本轮没有新增缓存写入点，Iris 兼容分支只改变“如何消费这些线段数据”，不会扩大写后读覆盖面。
- 重入 / 线程边界：
  - 直接线段提交全部发生在客户端 world render 线程，仍处于既有 `LAST` 事件边界内，没有引入异步线程。
  - helper 通过 `try/finally` 恢复渲染状态，降低了状态泄漏到后续 hand / GUI 渲染的风险。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L38)
- 风险等级与建议：
  - 风险等级：低到中。
  - 建议：后续如果发现某些 shader pack 下线宽仍不稳定，可继续把 helper 的线宽、混合和 alpha 收口到客户端配置，而不要再分散到各 renderer 中。
