# graph移除summary并改为聚合块只展开节点

## 1. 功能与语义、架构设计

本轮前端视图层把原先“`triggerSource` 高扇出再做一层 `summary` 收起”的链路移除，改为只保留核心聚合块这一层折叠语义。`buildGraphCanvasView` 现在先识别共享来源集合的 `core` 分组，再统一把这些分组对应的真实 `triggerSource -> core` 边放入隐藏集合；画布只渲染外层 `triggerSource -> aggregate` 可见边，展开时只补出真实 `core` 节点，不恢复内部真实边。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L379)

聚合块标签也同步改成“展开只显示节点”的交互语义，避免继续暗示旧的摘要节点逻辑；点击行为改为只由聚合块自己负责展开/收起，并触发结构重排与视口归位。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L121) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1863) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1867)

## 2. 关键数据结构和算法性能分析

关键数据结构是 `sharedCoreGroupsBySignature`、`hiddenActualEdgeKeys` 和 `layoutEdges`。前两者分别负责“按来源集合聚类核心节点”和“永久隐藏被聚合承接的真实边”，`layoutEdges` 则把“渲染边”和“仅布局边”拆开，避免展开时为了排布稳定而把内部边也画出来。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L379)

布局侧的关键优化在 `buildComponentLayout` 与 `buildAutoLayoutPositions`：来源顺序会先落到聚合块，再通过内部布局边继续传给展开后的 `core`，这样聚合块和其内部节点仍能沿着来源顺序稳定排布，不会被拆成远处孤立块。整体仍以 `Map` / `Set` 的线性扫描为主，复杂度近似 `O(nodes + edges + grouped-edges)`，对当前前端视图裁剪链路是可接受的。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L751) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L827)

## 3. 数据流或调用链

搜索、草稿差异、编辑选择和手动拉回节点会先汇总成 `forcedVisibleNodeKeys`，再和当前有效图一起送入 `buildGraphCanvasView`，生成 `canvasNodes`、`canvasEdges`、`layoutEdges` 和 `hiddenActualEdgeKeys` 这组视图层中间结果。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1442) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1507) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1531)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全与兼容边界方面，本轮只动前端视图层，没有改 `snapshot`、`draft`、服务端写入和真实 `triggerSource -> core` 语义，因此不会影响已有持久化真值；`buildEdges` 还额外过滤了 `hiddenActualEdgeKeys`，避免被聚合隐藏的真实边又以 removed diff 的形式回流到画布。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L924)

仍需关注两个残余点。其一，当前聚合是按“来源集合完全相同”分组，若同一 `triggerSource` 指向的大量 `core` 只是部分来源不同，就会拆成多个聚合块，这属于设计上为了避免语义失真而接受的保真代价。其二，展开后的 `core` 依赖空间排布理解与聚合块的关系，用户看不到内部可见边，因此交互提示和小地图颜色仍然需要继续帮助用户识别“这是聚合展开态，不是新增真实边”。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L121) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2095) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2190)

## 5. 并发冲突审查

本文件的共享状态主要是 React 组件内的 `graphDraft`、聚合展开状态、节点位置和待聚焦节点。展开/收起链路由本地事件驱动，状态更新后通过 `useMemo` 重建 `graphCanvasView`，再由 `setNodes`/`setEdges` 刷新 React Flow；由于都在浏览器主线程中串行执行，典型并发风险较低，风险等级评估为“低”。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1531) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1662) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1867)

需要留意的线程边界主要在草稿读写与保存：`loadDraft`、`persistDraft`、`handleSave` 都是异步流程，如果后续再叠加更重的视图状态同步，仍要避免在旧快照返回后覆盖新状态。当前实现已经通过 `disposed` 标记和保存阶段状态做了基础防护，但这块若继续扩展，建议维持“异步 I/O 与画布派生状态分层”的做法，不要把布局结果直接写回持久层对象。 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1331) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1351) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1596) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1798) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1959)
