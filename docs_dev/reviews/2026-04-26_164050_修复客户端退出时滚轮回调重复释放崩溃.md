# 修复客户端退出时滚轮回调重复释放崩溃

## 1. 功能与语义、架构设计

本次修复没有改同步遥控器滚轮快捷调强度的功能语义，只调整客户端退出阶段的 native 资源回收策略。滚轮回调仍由 `ensureSyncLinkerScrollHookInstalled(...)` 在窗口可用时安装，并继续把未消费的滚轮事件转发给先前回调；退出时改为只清空 Java 侧引用，不再手动释放当前 GLFW 回调，避免与窗口关闭阶段的统一释放重复执行。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L337) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L446)

## 2. 关键数据结构和算法性能分析

这里的关键状态只有三个静态字段：当前挂钩窗口句柄、当前滚轮回调、以及被替换前的上一个滚轮回调引用。修复后没有增加任何新容器或新遍历，也没有改变事件分发复杂度；安装回调仍是常数级操作，退出时的清理也只是常数级赋空，不会引入额外性能负担。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L79) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L80) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L81)

## 3. 数据流或调用链

调用链仍然是“窗口可用时安装自定义滚轮回调 -> 滚轮事件先由同步遥控器逻辑尝试消费 -> 未消费则回落到前一个回调”。本次只改退出链：`CLIENT_STOPPING` 现在只做本地桥接服务停止和引用清理，不再对当前回调执行 `free()`，从而把实际 native 释放留给后续窗口关闭链统一处理。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L345) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L355) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L447)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全层面，本次修复降低的是 native 生命周期管理风险，避免重复释放导致的 JVM 访问冲突。性能层面无新增负担。兼容性层面，滚轮快捷调强度和原先回调透传逻辑保持不变，因此对同步遥控器已有交互没有行为回归。残余风险在于：当前仍保留 `previousSyncLinkerScrollCallback` 的委托链，如果未来继续叠加更多自定义窗口回调，最好再统一封装一个专门的 callback 生命周期管理器，避免多个功能点各自托管 native 回调。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L346) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L351) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L449)

## 5. 并发冲突审查
