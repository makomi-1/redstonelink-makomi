## 3. 数据流或调用链

- `x51/x53` 的调用链现在是：`remove target forceload -> wait target offline -> source high commit -> source unload -> activator 生效 -> force_load/replay 验证`，确保“那次 source 高态变化”发生时，目标尚未被重新拉起。[chunk_activator_trigger_source_force_load_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x51/chunk_activator_trigger_source_force_load_auto_replay.json#L77) [chunk_activator_core_force_load_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x53/chunk_activator_core_force_load_auto_replay.json#L77)
- `x52` 的调用链类似，但最后只检查来源区块被 `resident` 拉起并保持，不再把目标恢复高态作为断言目标，和当前 resident 语义一致。[chunk_activator_trigger_source_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x52/chunk_activator_trigger_source_resident_auto_replay.json#L77) [chunk_activator_trigger_source_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x52/chunk_activator_trigger_source_resident_auto_replay.json#L153)
- `x54` 则在目标先离线、来源后变化的前提下，先断言 resident 把目标区块拉起，再断言 core 后续重算高态；运行时 resident 票同步仍在 server tick 中先于 pending/force-load 处理执行。[chunk_activator_core_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x54/chunk_activator_core_resident_auto_replay.json#L77) [chunk_activator_core_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x54/chunk_activator_core_resident_auto_replay.json#L159) [CrossChunkDispatchService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/CrossChunkDispatchService.java#L503)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性风险低：本轮没有改变生产实现，只是把测试时序收紧到更符合设计的口径；若后续设计又要求“来源保持在线直到 core 重算”，则 `x54` 的来源卸载阶段需要再调整，但当前口径下用例已稳定通过。[chunk_activator_core_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x54/chunk_activator_core_resident_auto_replay.json#L111) [chunk_activator_core_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x54/chunk_activator_core_resident_auto_replay.json#L171)
- 扩展性建议：如果后续要覆盖“queue enabled”场景，应新增独立 case，而不是继续复用这 4 条；当前 suite 明确关闭 `crosschunk.queue.enabled`，就是为了隔离区块激活器与 resident/force_load 语义，不让排队链路混入判断口径。[regression-lifecycle.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/regression-lifecycle.json#L140) [regression-full.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/regression-full.json#L203)
- 风险建议：若将来再追加类似时序约束，优先通过 phase 排序来表达，不要把“时序口径”编码到实现逻辑里，避免把测试需求反向渗透成生产语义。[chunk_activator_trigger_source_force_load_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x51/chunk_activator_trigger_source_force_load_auto_replay.json#L83) [chunk_activator_trigger_source_resident_auto_replay.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x52/chunk_activator_trigger_source_resident_auto_replay.json#L83)
