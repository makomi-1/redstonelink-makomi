## 1. 功能与语义、架构设计

- 本次改动把网页语言/主题从浏览器 origin 绑定的 `localStorage` 迁到客户端本地偏好文件，通过 bridge 新增的 `/api/preferences` 统一读写，避免随机端口导致的跨重启丢失问题。核心入口在 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L46)、[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L179)、[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L265)。
- 偏好值抽成独立快照对象，默认值、归一化和局部覆盖集中在 [LocalWebPreferences.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferences.java#L12)、[LocalWebPreferences.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferences.java#L19)、[LocalWebPreferences.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferences.java#L30)、[LocalWebPreferences.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferences.java#L40)。
- 本地持久化不并入现有通用配置体系，而是独立存放在 `gameDir/redstonelink/web/preferences.json`；存储门面和原子写入逻辑在 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L20)、[LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L34)、[LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L42)、[LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L58)。
- 前端主入口改成“默认值启动 + 异步加载后覆盖 + 用户切换时回写接口”的模式，入口状态和事件收口在 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L43)、[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L61)、[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L213)、[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L245)、[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L254)。

## 2. 关键数据结构和算法性能分析

- 数据结构极小，仅包含 `language` 和 `themeId` 两个字符串，传输类型定义在 [types.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/types.ts#L49)，测试工厂在 [factories.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/test/factories.ts#L185)。
- Java 侧序列化/反序列化保持最小范围：返回体和落盘文档由 [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L96) 与 [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L113) 生成，请求合并解析走 [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L136)。时间复杂度和空间复杂度都近似 `O(1)`。
- 磁盘写入为单个小 JSON 文件的原子替换，关键路径在 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L58) 与 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L85)。相较 graph/recording 资产，这条链路的 I/O 成本可以忽略。
- 前端保存请求通过顺序队列串行化，避免连续切换主题/语言时发生乱序覆盖，关键逻辑在 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L245)。

## 3. 数据流或调用链

- 页面启动时，`App` 会并行加载 bridge 状态、storage index 和网页偏好；偏好读取从 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L113) 进入 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L213)，再调用 [preferencesApi.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/preferencesApi.ts#L6) 请求 `GET /api/preferences`。
- `GET /api/preferences` 由 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L265) 分发，读取 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L42) 的快照，并通过 [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L96) 回包。
- 用户切换语言或主题时，事件从 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L254) / [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L260) 进入 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L245)，再调用 [preferencesApi.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/preferencesApi.ts#L19) 发送 `POST /api/preferences`。
- `POST /api/preferences` 在 bridge 侧由 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L277) 调用 [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L136) 合并当前值与补丁，再通过 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L58) 原子落盘。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：接口仍只绑定 `127.0.0.1`，没有扩大暴露面，相关监听与路由注册见 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L169) 与 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L179)。
- 兼容性：Java 侧对 `language/themeId` 不做白名单硬编码，只做空值归一化；前端最终用 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L215) 的 `isAppLanguage/isWebThemeId` 做消费端校验。这让主题/语言扩展更灵活，但也意味着若前端删掉某个旧值，会静默回退默认主题或默认语言。该风险当前可接受。
- 性能：每次切换偏好都会发一次本地 POST 并写一次小文件，频率远低于 graph 编辑链路，成本可控；若后续把更多偏好也迁入此机制，再考虑批量提交或 debounce。
- 可扩展性：`LocalWebPreferences` 与 `/api/preferences` 目前只承载网页 UI 偏好，没有混入 graph/recording 业务字段，结构边界清晰，见 [LocalWebPreferences.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferences.java#L12) 与 [preferencesApi.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/preferencesApi.ts#L6)。
- 验证建议：这轮已经补了前端接口测试、App 入口测试和 Java 存储/解析测试，分别见 [preferencesApi.test.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/preferencesApi.test.ts#L7)、[App.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.test.tsx#L53)、[LocalWebJsonSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/web/LocalWebJsonSupportTest.java#L19)、[LocalWebPreferencesStoreTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/web/LocalWebPreferencesStoreTest.java#L25)。

## 5. 并发冲突审查

- 共享状态：后端共享状态主要是 `PREFERENCES_STORE` 单例和其内存缓存，入口在 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L46)。`LocalWebPreferencesStore` 的 `load/save` 都是 `synchronized`，见 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L42) 与 [LocalWebPreferencesStore.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebPreferencesStore.java#L58)，可避免并发请求下的读改写覆盖。
- 前端重入：连续切换语言/主题时，若直接并发 POST，存在旧请求晚到覆盖新值的风险。本次通过 [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L245) 的 promise 队列串行化保存，把该风险收敛为顺序提交。
- 线程边界：bridge 运行在 HTTP 线程池中，见 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L174)；本地磁盘读写没有跨线程共享可变集合，仅通过同步门面访问，线程边界清楚。
- 风险等级：低。当前剩余风险主要是“不同浏览器标签页同时打开网页并分别切换偏好”时，最终值按最后一次保存为准。这符合网页偏好场景的 last-write-wins 预期。
