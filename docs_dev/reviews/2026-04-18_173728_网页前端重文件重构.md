## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 本轮是结构重构，不是语义重写；风险主要在“导入重排后漏本地类型/漏依赖”。这类问题已被 `npm.cmd run typecheck`、`buildWebapp` 和全标签自动化测试兜住，当前没有发现功能回归证据。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L72) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L32)
- `GraphViewer.tsx` 虽已明显变薄，但仍保留较大的 JSX 区和大量 handler，后续若继续重构，优先建议再拆“工具栏/右侧详情面板/批量编辑面板”，否则组件仍会继续向 2k 行回涨。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1030)
- `canvas.tsx` 目前同时承担“布局算法”和“节点标签 JSX 组装”，语义上已经优于原状，但如果后续要引入更多显示模式，建议再拆一层 `viewFactory`，把布局和视觉标签生成彻底分离，减少模式切换时的耦合面。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L49) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L994)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- `GraphViewer` 在 graph 快照切换时先重置局部状态，再通过 `disposed` 守卫处理异步 `loadDraft` 返回，能够避免旧快照的草稿回写覆盖新页面状态；这属于典型的前端异步竞态防护，当前风险等级评估为低。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L292) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L293)
- 本地 draft 持久化使用 `setTimeout` 防抖并在 effect cleanup 中清理，能够避免连续编辑时多次并发写入；由于仍是覆盖式写入，若未来要支持多标签页协同，建议再补版本戳或冲突提示。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L571) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L572) [draft.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/draft.ts#L388)
- ReactFlow 框选相关共享状态通过 `selectionPreviewActiveRef`、`suspendCanvasSelectionSyncRef`、`aggregateOutlineSuspendDepthRef` 做了分层隔离，能避免“清空选择后旧选区回流”和“拖拽期间包围框抢恢复”这类重入问题；当前实现复杂但边界明确，风险等级评估为中低，后续可继续抽为专门 hook 降低维护成本。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L109) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L111) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L114) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L734)
