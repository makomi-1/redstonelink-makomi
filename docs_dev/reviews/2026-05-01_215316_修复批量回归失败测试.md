# 修复批量回归失败测试

## 1. 功能与语义、架构设计
- 本轮的主入口是测试支撑层 `TestMinecraftSupport.bootstrapMinecraft()`，它在原有 `Bootstrap.bootStrap()` 之后补入了 26.1 所需的默认组件绑定流程，统一修复 `ItemStack` 初始化失败问题，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L54) 与 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L312)。
- 对临时测试注册场景，`withWritableBlockRegistries(...)` 在开放写窗后执行 supplier，并在收尾阶段重新绑定物品默认组件，保证新注册 holder 后续可直接构造 `ItemStack`，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L93)。
- `LinkCommandSupportTest` 与 `SmartGlassesAccessSupportTest` 不再篡改 `ItemStack.item`，而是改为使用真实模组物品栈，测试语义仍然保持“真实 core / 智能眼镜物品行为”，见 [LinkCommandSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/command/link/LinkCommandSupportTest.java#L41) 与 [SmartGlassesAccessSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/data/SmartGlassesAccessSupportTest.java#L26)。
- 语义对齐说明：本轮只修测试支撑与构建工具链，没有改业务实现的 `triggerSource/core` 语义；相关测试中的节点类型断言仍保持 `triggerSource=TRIGGER_SOURCE`、`core=CORE` 的既有映射，无旧术语新增泄漏，残余风险为无。

## 2. 关键数据结构和算法性能分析
- 默认组件重绑定通过 `DataComponentInitializers.build(...)` 生成待应用列表，再线性调用 `apply()`，复杂度与已注册物品数量成正比，但仅发生在测试引导与临时注册收尾阶段，不在运行时代码路径上，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L326)。
- 反射字段兼容通过 `setFieldByCandidates(...)` 顺序尝试候选字段名，开销是极小的常数级反射开销，只用于测试夹具，不影响生产性能，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L223) 与 [GraphWriteServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/data/GraphWriteServiceTest.java#L396)。
- JaCoCo 版本升级只影响构建工具链兼容，不改变业务代码执行复杂度，见 [build.gradle](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/build.gradle#L241)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 兼容性收益是本轮核心：测试引导不再依赖缺 tag 的 lookup 构造方式，且服务端夹具不再绑死单一 Yarn 字段名，26.1 兼容性显著提升，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L357) 与 [CrossChunkDispatchServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/data/CrossChunkDispatchServiceTest.java#L1213)。
- 构建风险点在于 Java 工具链升级后覆盖率插件也必须同步升级，否则会出现“测试通过但构建失败”的非业务阻塞；本轮通过升级 `jacoco` 解决，见 [build.gradle](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/build.gradle#L238) 与 [build.gradle](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/build.gradle#L241)。
- 扩展性方面，后续若再出现注册表字段名漂移，优先在 `TestMinecraftSupport` 继续扩展候选字段解析，不要回到每个测试各自手写反射的模式，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L223)。

## 5. 并发冲突审查
- `lookupProvider` 与 `builtInItemComponentsBound` 属于测试支撑层共享状态，相关入口保持 `synchronized`，当前没有并发读改写竞争扩大，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L46)、[TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L54) 与 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L312)。
- `withWritableBlockRegistries(...)` 会短暂修改全局注册表冻结状态，因此仍然只适合测试启动或受控夹具阶段使用，不应在并行测试内随意扩散；当前调用点集中在少数 `@BeforeAll` 或局部夹具内，风险等级中，见 [TestMinecraftSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/testsupport/TestMinecraftSupport.java#L93) 与 [LinkCommandSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/command/link/LinkCommandSupportTest.java#L43)。
- 服务端夹具的候选字段写入只在单线程测试构造阶段执行，没有引入新的共享可变状态；风险等级低，建议后续继续保持集中封装，不要复制散落，见 [GraphWriteServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/data/GraphWriteServiceTest.java#L396) 与 [InternalDispatchDeltaEventsTest.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/test/java/com/makomi/data/InternalDispatchDeltaEventsTest.java#L468)。
