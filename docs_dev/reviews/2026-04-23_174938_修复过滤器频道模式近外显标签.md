# 修复过滤器频道模式近外显标签

## 1. 功能与语义、架构设计（关键方法和入口）

- 本轮修复点在客户端近外显文本组装层：过滤器目标行不再固定使用“节点集”翻译键，而是通过 `resolveFilterTargetLineTranslationKey(...)` 按 `targetMode` 选择“频道”或“节点集”。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L188)
- `resolveFilterTargetText(...)` 原本已经能在频道模式返回频道值，本轮没有改动目标值解析语义，只修正外层标签选择，避免出现“节点集：频道值”。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L305)
- 新增的 `resolveFilterTargetLineTranslationKey(...)` 保持 package-private，方便测试锁定文案键，同时不扩大对外 API。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L320)
- 语义边界：本轮不涉及 `triggerSource/core` 写入方向、不修改过滤器运行时规则、不修改频道派发或网络 payload，只改变过滤器近外显目标行标签。

## 2. 关键数据结构和算法性能分析

- 关键数据结构仍是 `LinkFilterConfigSnapshot`，其中 `targetMode` 决定当前过滤器目标是序号集合还是频道值；本轮新增逻辑只读取该字段。[LinkFilterConfigSnapshot.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterConfigSnapshot.java#L10)
- `LinkFilterConfigSnapshot` 已在构造阶段将频道模式与序号模式归一化：频道模式保留 `channel` 并清空 `serialExpression`，序号模式清空 `channel`；因此近外显只需要读取 `targetMode`，无需重复解析输入。[LinkFilterConfigSnapshot.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterConfigSnapshot.java#L32)
- 算法成本是一次空值归一化和一次 enum 比较，不引入循环、缓存或网络请求；近外显每帧调用的成本可以忽略。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L320)

## 3. 数据流或调用链

- 调用链为：`buildNearOverlayLines(AbstractLinkFilterBlockEntity, Font)` 读取过滤器 `snapshot()`，目标值走 `resolveFilterTargetText(...)`，目标行标签走 `resolveFilterTargetLineTranslationKey(...)`，最后一起传给 `translate(...)` 生成 HUD 文本。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L175)
- 频道模式路径：`targetMode == CHANNEL` 时，目标值为 `resolveChannelValueText(channel)`，目标行标签为 `hud.redstonelink.near_overlay.channel_line`。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L307) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L322)
- 序号模式路径：非频道模式继续解析 `serialExpression` 并使用 `hud.redstonelink.near_overlay.filter_node_set_line`，保留原“节点集”展示。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L310)
- 测试新增了频道模式和序号模式两条断言，直接锁定翻译键选择行为。[LinkSerialHudOverlayTextSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/render/LinkSerialHudOverlayTextSupportTest.java#L100)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮无新增输入、权限、网络或文件 IO，仅是客户端文案键选择，安全风险低。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L320)
- 性能：新增分支是 enum 比较，不影响渲染热路径性能；目标值原有序号解析/频道解析逻辑未扩展。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L305)
- 兼容性：语言文件已有通用频道行 `hud.redstonelink.near_overlay.channel_line`，无需新增翻译键；序号模式仍保留原 `filter_node_set_line`，不会改变旧显示。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L322)
- 扩展性：若后续过滤器新增目标模式，应集中扩展 `resolveFilterTargetLineTranslationKey(...)`，避免在 `buildNearOverlayLines(...)` 中堆叠标签判断。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L320)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 本轮没有修改任何共享服务端状态，也没有写入 `LinkFilterConfigSnapshot`；近外显只读 block entity 快照，风险等级低。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L175)
- 读改写覆盖风险：无写操作，不存在覆盖用户配置、频道值或节点集配置的问题。[LinkFilterConfigSnapshot.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterConfigSnapshot.java#L30)
- 重入/线程边界：逻辑仍运行在客户端 HUD 渲染文本组装流程内，没有引入异步任务、共享可变缓存或跨线程回调；建议后续继续保持过滤器近外显文本为纯读格式化逻辑。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L320)
