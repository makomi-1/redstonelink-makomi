## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性风险已知点是 bench 命令语法必须严格匹配命令树字面量层级，频道 case 不能把 `channel` 直接挂在 `serial` 后，否则 Brigadier 会在 dedicated 实跑时直接报参数错误。此次已把 4 个 case 修正为 `core -> triggerSource -> channel` 与 `triggerSource -> core -> channel` 的完整语法，后续新增频道 OCC case 应直接复用这一口径。[BenchOccCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchOccCommandRegistry.java#L69) [BenchOccCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchOccCommandRegistry.java#L96) [send_filter_runtime_channel_reconcile.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x39/send_filter_runtime_channel_reconcile.json#L82) [receive_filter_runtime_channel_reconcile.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x40/receive_filter_runtime_channel_reconcile.json#L82)
- 环境风险是 `run-bench-suite.ps1` 不会为外部 dedicated server 自动补默认启动命令，漏传 `-ServerStartCommand` 会导致 suite 在首个 case 前直接失败。该风险不影响业务语义，但会影响回归可执行性，建议后续继续按使用说明统一传 `-ServerStartCommand '.\start.bat'`。[filter-channel-regression.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/filter-channel-regression.json#L11)
- 扩展性上，本轮通过独立 suite 聚合频道过滤器关键回归，不挤占原有全量回归入口；若后续增加“频道白名单”“频道信号阈值”等用例，可以继续向同一 suite 追加，而不需要再修改生产命令结构。[filter-channel-regression.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/filter-channel-regression.json#L11) [functional-matrix.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/functional-matrix.json#L69)
