# 游戏内测试server窗口默认隐藏

## 1. 功能与语义、架构设计

- 本轮把 suite 主入口默认 `ServerWindowMode` 从 `Normal` 统一改为 `Hidden`，这样直接运行 `run-bench-suite.ps1` 时，不再与外围包装脚本产生默认值分歧。[run-bench-suite.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/run-bench-suite.ps1#L16)
- 同时把底层 dedicated server 启动兜底 `WindowMode` 也改为 `Hidden`，保证未来若有脚本漏传窗口参数，最终行为仍保持隐藏窗口。[BenchSuite.Server.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Server.ps1#L371)
- 使用说明已同步到新默认值，避免文档继续声称原始 suite 入口默认 `Normal`。[使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/使用说明.md#L610)

## 2. 关键数据结构和算法性能分析

- 本轮未引入新的数据结构，也未改动 bench 结果解析、server 生命周期轮询或 case 调度算法；仅修改参数默认值与说明文本，对运行时复杂度没有影响。[run-bench-suite.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/run-bench-suite.ps1#L12) [BenchSuite.Server.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Server.ps1#L367)
- `Start-Process` 的调用方式未变，仍由同一入口负责启动和跟踪真实 Java 子进程，因此不会新增额外进程扫描或优先级设置成本。[BenchSuite.Server.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Server.ps1#L378)

## 3. 数据流或调用链

- 调用链保持不变：包装脚本或用户直接调用 `run-bench-suite.ps1`，再由 `BenchSuite.EntryPoint` 把 `ServerWindowMode` 透传给 `Start-DedicatedServerProcess`；本轮只调整了这条链路上的默认值，不改变参数名与覆盖方式。[run-bench-suite.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/run-bench-suite.ps1#L16) [BenchSuite.EntryPoint.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.EntryPoint.ps1#L233) [BenchSuite.Server.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Server.ps1#L371)
- 文档层面对同一默认值进行了收口说明，使“脚本默认值”和“使用说明”一致。[使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/使用说明.md#L586) [使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/使用说明.md#L610)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 风险较低。主要兼容性变化在于：手工调试时如果依赖默认弹出 server 窗口观察控制台，现在需要显式传 `-ServerWindowMode Normal`；但脚本参数接口未变，覆盖路径仍保留。[run-bench-suite.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/run-bench-suite.ps1#L16)
- 由于底层兜底也改成 `Hidden`，后续新增包装脚本时即使漏传参数，也不会重新退回 `Normal` 默认，扩展性更一致。[BenchSuite.Server.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Server.ps1#L371)
- 本轮只做文本与默认值统一，没有改动 RCON、进程追踪、优先级、world 切换和结果写出逻辑，因此无新增安全或性能风险。[BenchSuite.Server.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Server.ps1#L378)
