## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全边界目前仍由服务端控制：开始录制时重新读取主手状态面板工具订阅，并再次做隐私读控校验，避免客户端伪造录制对象集。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L89) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L266)
- 性能边界主要依赖 `sampleEveryTicks`、`capacityPerNode` 和分块传输大小控制。当前实现已做参数 clamp 与固定 chunk 大小，但还没有细粒度限流；后续若录制对象和容量继续放大，需要补玩家级节流和总导出体积保护。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L358) [StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L339)
- 兼容性方面，本轮保持“读当前状态面板订阅、写新的 recording bundle”边界，没有动世界真值结构，也没有把旧术语重新写回存储层；网页端若未来扩展图表视图，建议继续复用当前 bundle 而不是直接读取运行时探针。[StatePanelRecordingBundle.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingBundle.java#L11) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L301)
- 当前验证已经覆盖 payload 稳定契约、JSON 导出和 recording 资产写入，但尚未引入游戏内自动化录制流程回归；后续若继续迭代 `P2+`，建议补 dedicated server 侧的端到端录制脚本验证。[StatePanelNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/StatePanelNetworkPayloadTest.java#L138) [StatePanelRecordingJsonSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/StatePanelRecordingJsonSupportTest.java#L15) [LocalWebAssetRepositoryTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/web/LocalWebAssetRepositoryTest.java#L90)

## 5. 并发冲突审查

- 服务端共享状态集中在 `ACTIVE_SESSIONS_BY_SERVER`，按 `MinecraftServer -> 玩家 UUID -> ActiveSession` 组织；当前所有读写都经由服务端主线程网络回调和生命周期回调执行，没有引入额外异步线程，风险等级为低。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L47) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L331)
- 客户端共享状态集中在 `PENDING_RECORDING_EXPORTS`，分块接收、重组和清理都绑定在 `context.client().execute(...)` 之后的客户端主线程执行，当前不存在多线程写同一导出缓存的问题，风险等级为低。[StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L23) [StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L83) [StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L141)
- 会话清理在玩家断线和服务器停止时都显式执行 `unmountAll`，避免 trace 挂载残留；当前没有发现重入导致的“重复卸载覆盖别的会话”风险，因为同一玩家同一时刻只允许一个活动会话。风险等级为低，后续若扩展为多标签录制，需要把会话键从玩家升级为更细粒度的 session id。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L56) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L290) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L304)
