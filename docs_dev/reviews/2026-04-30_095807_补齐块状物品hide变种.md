## 2. 关键数据结构和算法性能分析

- `HideNodeSupport` 采用的是常量时间的“已知物品/方块 + 显示状态映射”方案，没有引入扫描表或运行时查找树。对每次 tooltip、ghost 渲染和命中判断来说，额外成本就是常量级分支判断。[HideNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideNodeSupport.java#L36)
- 新增 hide 方块仍然复用 `NodeFaceSetBlockStateSupport` 的既有六面状态结构，没有额外持久化字段，也没有新增 SavedData，因此不会扩大序列化体积或引入新的全局索引维护成本。[HideToggleEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideToggleEmitterBlock.java#L25) [HideRepeaterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideRepeaterBlock.java#L27)
- 客户端渲染侧只是多了过滤器/区块激活器两类 ghost 包装器，仍然复用现有 `LinkFilterAreaRenderer`、`ChunkActivatorFarOverlayRenderer` 和 `LinkNodeFarOverlayRenderer`。这意味着渲染复杂度没有引入新的世界扫描，只是在原有渲染调用前追加一次半透明 ghost 模型绘制。[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L19) [HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L19) [HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L19)
- 资源与配方侧新增的是静态 JSON 文件，测试也继续用显式清单守门，没有引入运行时代码路径上的额外算法成本。[RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L26)

## 3. 数据流或调用链

- 物品放置链路：hide 物品通过现有 `BlockItem` / 具体物品类进入对应 hide 方块；方块在 `newBlockEntity/createEmitterBlockEntity` 中切换到 hide 实体类型；实体继续走原有可见节点的配置、序号和运行时逻辑。[ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L120) [HideToggleEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideToggleEmitterBlock.java#L29) [HideSendFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/HideSendFilterBlockEntity.java#L12)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮没有引入外部输入执行、权限放大或 API v1 依赖；所有变更仍在现有内部实现路径内完成，无新增高风险入口。[ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L120)
- 性能：hide 渲染仍然建立在“佩戴智能眼镜 + 原有远外显门槛”之上，未增加新的世界扫描。主要开销仍由既有 far overlay/area overlay 决定，hide ghost 只是常量级附加绘制。[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L29)
- 兼容性：新配方与资源文件已补齐，且 `RecipeResourceLayoutTest` 已更新为当前约定清单，避免后续再因资源目录契约误报回归。[RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L26)
- 扩展性：这轮已经把 hide 判定和 ghost 映射抽到 `HideNodeSupport`，后续若继续为按钮、拉杆或粉态节点补 hide 变种，优先继续沿这个入口扩展，而不要重新在 item/renderer 中写新分支。[HideNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideNodeSupport.java#L29)
- 建议：目前新增的 6 个 hide 物品模型都复用了可见方块模型，功能完整，但视觉上还没有独立 `_hide` 贴图。若后续确实要做差异化展示，应单独走贴图改动确认流程，不要在本轮直接覆盖资源。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 共享状态：本轮没有新增全局可变集合或新的 SavedData，主要是静态注册表常量、方块/实体子类与客户端 renderer 包装器，线程边界仍然沿用原有 Minecraft 主线程模型。[ModBlocks.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlocks.java#L92) [ModBlockEntities.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlockEntities.java#L70)
- 读改写覆盖：hide 方块实体复用可见实体逻辑，没有新开一套并发读写状态；通过“切换 BlockEntityType 而不改运行态算法”的方式，避免了双实现各自漂移。[LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L68) [HideRepeaterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/HideRepeaterBlockEntity.java#L12)
- 重入/线程边界：ghost renderer 只读方块状态和玩家智能眼镜上下文，不持有跨帧缓存，不参与网络和异步线程；风险等级为低。[HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L29) [HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L29)
- 综合风险等级：低。当前主要残余风险不是并发，而是“后续若继续补更多非立方/特殊载体 hide 变种，仍需保证继续复用 `HideNodeSupport` 与现有 renderer 包装模式”，避免重新回到多处硬编码分叉。
