## 3. 数据流或调用链

- 录制选集列表的数据流仍是“服务端订阅快照/打开状态面板时的订阅列表 -> `subscriptions` -> `refreshSubscriptionButtons()` -> 按钮文案与勾选态”；本轮只修了最后一段展示拼接，不影响开始录制时 `collectSelectedNodeKeysInOrder()` 的发送链路，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L88)、[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L503) 和 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L585)。
- 状态面板列表的数据流仍是“服务端快照条目 -> `buildStatusText()` 生成状态串 -> `renderList()` 按列裁剪绘制 -> `resolveColumnLayout()` 提供列坐标与宽度”；本轮把修复点放在布局和裁剪前的空间分配层，减少对业务文本的侵入，见 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L389)、[StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L439) 和 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L657)。
- 网页端曲线视窗的数据流是“`RecordingViewer` 持有 `recordingWindow` -> 传入 `RecordingChart` 的 `xWindow` -> 图表交互更新 `currentWindowRef` / 回调 `onWindowChange` -> `RecordingViewer` 重新下发窗口”；本轮新增的建图后 `setScale` 正好补齐了“图表被销毁后重建”的缺口，见 [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L34)、[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L183)、[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L65) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L174)。
- 曲线数据表的数据流保持只读：“recording bundle -> `RecordingSeriesPanel` -> 表格/折叠面板渲染”；默认折叠只改变可见层，不改变样本解析和曲线计算，见 [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L208) 和 [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L273)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮未新增网络接口、命令入口或持久化字段；改动集中在客户端 GUI 和本地网页渲染层，未引入 `com.makomi.api.v1.*` 依赖。录制选集仍走既有 payload 结构，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L394)。
- 性能：状态面板列宽调整是常量级计算，影响极小。曲线页建图后增加一次 `setScale`，只发生在图表重建时，不在每次滚轮事件里额外触发；高频交互仍由 `ref` 和 `uPlot` 承接，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L192) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L220)。
- 兼容性：状态面板加宽后仍通过屏幕宽度钳制解析布局，所以小屏不会直接越界，只是在极窄宽度下继续依赖裁剪机制，见 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L618)。网页端数据表改为 `details`，依赖浏览器原生支持；在当前离线桌面 WebView/现代浏览器环境中兼容性风险较低，见 [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L737)。
- 扩展性：当前数据表默认折叠只解决首屏拥挤问题，并未处理“大 recording 文件的长表格渲染”问题；如果后续引入更大样本规模，建议把表格进一步做成分页或虚拟列表。相关入口集中在 [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L273)。
- 语义对齐：本轮未更改 `triggerSource/core` 术语映射，也未新增旧术语出参；语义残余风险为无。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 录制 GUI 的共享状态主要是 `selectedSubscriptionKeys` 与 `subscriptionScrollOffset`，它们都被限制在客户端屏幕实例内，由单一 GUI 线程读写；本轮只改按钮展示文本，没有引入新的共享写入点，风险等级为低，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L68) 和 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L552)。
- 状态面板列表渲染链路是“快照替换后统一重绘”，本轮调整的是纯布局常量和列宽函数，不涉及服务端数据写回，因此不存在读改写覆盖风险；风险等级为低，见 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L389) 和 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L657)。
- 网页端图表交互存在“React 状态更新”与“uPlot 原生事件”交错执行的边界，本轮通过 `currentWindowRef` / `fullDomainRef` 维持单线程事件下的一致视图，再在建图后立即调用 `setScale` 避免重建瞬间丢失窗口；在浏览器单线程模型下风险等级为低到中，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L55)、[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L65) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L174)。
- 曲线数据表默认折叠没有新增共享状态，完全依赖浏览器原生 `details` 开闭状态，不参与 recording 数据回写，因此不存在跨线程或重入风险；风险等级为低，见 [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L273)。
