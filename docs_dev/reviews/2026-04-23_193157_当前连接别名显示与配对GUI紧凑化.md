## 2. 关键数据结构和算法性能分析

- `NodeAliasDisplayUtil.normalizeDisplayTexts` 以目标序号列表为基准做索引对齐，展示文本数量不一致时整体按序号兜底，避免局部错位导致“别名绑定到错误目标”。关键实现见 [NodeAliasDisplayUtil.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasDisplayUtil.java#L69)。
- `DisplayTextListFormatUtil` 抽出单行压缩和 Tooltip 换行逻辑，时间复杂度主要为 O(n) 加少量字符串宽度测量，适配 GUI 像素宽度和测试字符宽度两种口径。关键实现见 [DisplayTextListFormatUtil.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/util/DisplayTextListFormatUtil.java#L15)、[DisplayTextListFormatUtil.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/util/DisplayTextListFormatUtil.java#L42)、[DisplayTextListFormatUtil.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/util/DisplayTextListFormatUtil.java#L79)。
- 网络 payload 在 record 构造器中规范化目标展示文本，保证服务端读模型、客户端 GUI 与 HUD 缓存拿到的列表长度稳定。关键实现见 [PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L197)、[PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L383)、[PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L835)。
- 近外显缓存存储展示文本快照，避免每帧重新解析别名；缓存仍沿用原有 TTL 和条目上限。关键实现见 [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L84)、[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L445)。

- GUI 打开链路为服务端 `NodeSnapshotQueryService.queryLinks` 生成 `NodeLinksSnapshot`，`PairingNetworkPayloadSupport.buildGuiOpenPayload` 写入 payload，客户端 `PairingNetworkClientHandlerSupport` 将展示文本传入具体配对界面。关键调用见 [NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L57)、[PairingNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkPayloadSupport.java#L56)、[PairingNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkPayloadSupport.java#L70)、[PairingNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/PairingNetworkClientHandlerSupport.java#L32)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本次只扩展读模型和展示 payload，不新增写入方向，也未引入 `com.makomi.api.v1.*` 依赖；配对提交仍由原服务端校验路径处理。关键边界见 [CorePairingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/CorePairingScreen.java#L156)、[TriggerSourcePairingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/TriggerSourcePairingScreen.java#L180)。
- 性能风险：当前连接目标数量较多时展示文本解析会按目标逐个查询别名，属于 GUI 打开和 HUD 请求时触发，不在每帧直接访问服务端数据；客户端渲染只消费缓存快照。关键边界见 [NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L218)、[LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L84)。
- 兼容性风险：网络载荷新增展示文本字段，要求客户端与服务端模组版本一致；旧物品 NBT 已通过读取端兜底兼容。关键实现见 [PairingNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkPayloadSupport.java#L493)、[PairingNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkPayloadSupport.java#L501)、[LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L335)。
- 扩展性：展示文本格式化已独立为工具类，后续若要把过滤器、区块激活器等其他“节点集”展示切换为别名文本，可复用同一格式化入口。关键实现见 [DisplayTextListFormatUtil.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/util/DisplayTextListFormatUtil.java#L30)、[DisplayTextListFormatUtil.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/util/DisplayTextListFormatUtil.java#L79)。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 共享状态：服务端展示文本由 SavedData 和别名数据即时读取，没有新增长期共享可变状态；客户端 HUD 仍使用原缓存 Map，新增字段只作为不可变快照值写入缓存。关键实现见 [NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L218)、[LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L84)。
- 读改写覆盖：物品 NBT 的展示文本与连接序号由 `setLinkedSnapshot` 同批写入，清空序号时同步删除展示字段，降低旧字段残留风险。关键实现见 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L381)、[LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L391)。
- 重入与线程边界：网络接收仍按 Fabric 既有上下文执行，客户端 handler 只转发 payload 值给屏幕或 HUD 缓存，不做跨线程阻塞操作。关键入口见 [PairingNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/PairingNetworkClientHandlerSupport.java#L32)、[PairingNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/PairingNetworkClientHandlerSupport.java#L81)。
- 风险等级：低到中。主要风险是混用新旧网络包时的解码兼容性，以及别名修改后客户端缓存在 TTL 内短暂显示旧值；建议发布时保持 server/client 同步更新，必要时后续增加协议版本兼容分支。相关测试见 [PairingNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/PairingNetworkPayloadTest.java#L209)、[PairingNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/PairingNetworkPayloadTest.java#L407)、[AbstractMultiPairingScreenLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/screen/AbstractMultiPairingScreenLayoutTest.java#L36)。
