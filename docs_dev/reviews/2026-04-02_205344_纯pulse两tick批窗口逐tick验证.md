## 3. 数据流或调用链
- 入口调用链为：suite 选择单条 entry -> matrix 解析单个 case -> case phases 完成 mount、输入播放、trace 读取与断言。调试时可以直接从 suite 入口启动，不需要再从 mixed suite 中筛目标阶段。[functional-pulse-window2-debug.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/functional-pulse-window2-debug.json#L13) [functional-pulse-window2-matrix.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/functional-pulse-window2-matrix.json#L15) [pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L36)
- case 内部 phase 顺序为：先挂 source/target trace，再发起 pulse 输入播放，随后等待 `8` tick 收集窗口，最后分别验证 source 与 target 波形。这个顺序和原 mixed pulse 子阶段一致，因此复现口径保持一致。[pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L37) [pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L51) [pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L60) [pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L65) [pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L117)
- target 断言采用相对 source 的起始窗口对齐策略 `referencePhaseRef + referenceStartStrategy=min`，因此失败结果能直接说明“source 第二段 pulse 存在，但 target 对应窗口未生效”。[pulse_samechunk_direct_window2_tick_assert.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/pulse_samechunk_direct_window2_tick_assert.json#L125)
