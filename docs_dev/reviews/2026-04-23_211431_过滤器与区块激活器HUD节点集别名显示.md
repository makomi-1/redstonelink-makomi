# 过滤器与区块激活器HUD节点集别名显示审查

## 1. 功能与语义、架构设计（关键方法和入口）

本次将过滤器与区块激活器的节点集别名展示从“纯客户端序号兜底”改为“服务端同步展示文本、客户端 HUD 优先消费”。过滤器在 update tag 中写入 `nodeSetDisplayTexts`，区块激活器分别写入 `triggerSourceNodeSetDisplayTexts/coreNodeSetDisplayTexts`，HUD 渲染时优先使用这些 displayTexts；缺失时仍回退 `#序号`。关键入口：[AbstractLinkFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/AbstractLinkFilterBlockEntity.java#L279)、[LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L262)、[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L190)。

## 2. 关键数据结构和算法性能分析

新增 displayTexts 只作为方块实体客户端同步派生缓存，不写入持久化 saveAdditional 字段。展示文本解析按节点集序号线性遍历，过滤器节点集沿用原表达式规模，区块激活器仍受 `MAX_NODE_SET_SIZE` 约束；HUD 端继续使用 `DisplayTextListFormatUtil` 的宽度截断逻辑。关键引用：[AbstractLinkFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/AbstractLinkFilterBlockEntity.java#L333)、[LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L323)、[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L474)。

## 3. 数据流或调用链

服务端方块实体同步时根据 `serialExpression` 和节点类型解析 `NodeAliasServerSupport.resolveDisplayText(...)`，写入 update tag；客户端 `loadAdditional(...)` 读取 displayTexts；近外显 HUD 从方块实体读取 displayTexts 并构造节点集文本。别名变更后，`NodeAliasServerSupport.syncDisplaysAfterAliasChanged(...)` 额外刷新已加载且引用该序号的过滤器和区块激活器。关键引用：[AbstractLinkFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/AbstractLinkFilterBlockEntity.java#L234)、[LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L209)、[NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L92)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全与隐私：该显示面向本地近外显，显示的是过滤器/区块激活器配置节点集，与现有 `#序号` 可见范围一致，只把序号替换为别名展示文本。兼容性：旧存档或旧同步包没有 displayTexts 时，读取逻辑会通过 `NodeAliasDisplayUtil.normalizeDisplayTexts(...)` 回退 `#序号`。建议后续如需隐私裁剪过滤器/区块激活器节点集，应独立定义规则，不应复用节点当前连接隐私口径。关键引用：[AbstractLinkFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/AbstractLinkFilterBlockEntity.java#L377)、[LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L372)、[LinkSerialHudOverlayTextSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/render/LinkSerialHudOverlayTextSupportTest.java#L137)。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

风险等级：中低。新增同步缓存只在方块实体加载 update tag 或服务端生成 update tag 时读写，未改变持久化真值；别名变更刷新会扫描已放置条目并仅对已加载方块实体调用同步，不会主动加载离线区块。并发上仍由 Minecraft 主线程处理方块实体和 SavedData，未引入异步写。关键引用：[NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L100)、[NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L118)、[LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L274)。
