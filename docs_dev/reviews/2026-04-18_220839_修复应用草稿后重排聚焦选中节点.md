# 修复应用草稿后重排聚焦选中节点

## 1. 功能与语义、架构设计

- 当前选中节点仍由 `selectedNodeKey` 统一管理，结构重排相关状态与即时聚焦状态分离：即时聚焦继续使用 `pendingFocusNodeKey`，新增的重排后聚焦使用 `pendingPostLayoutFocusNodeKey`，定义位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L153) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L177)。
- 结构刷新入口 `requestStructureLayoutRefresh()` 现在支持 `focusNodeKey`，并在需要上下文聚焦时同步开启自动 `fitView` 抑制，入口在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L981)。
- “应用到草稿”成功后，会把当前 `selectedNodeKey` 作为重排后聚焦目标一起传给结构刷新入口，因此视角会跟到新布局位置，调用点位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1495) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1523)。

## 2. 关键数据结构和算法性能分析

- 本轮没有引入新的集合构建或布局算法，只新增一个字符串状态 `pendingPostLayoutFocusNodeKey`，内存和计算成本都很低，定义位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L177)。
- 重排后聚焦 effect 只在 `pendingStructureLayoutReset` 已经清空、且确实存在待聚焦节点时才执行一次 `setCenter`，避免像即时聚焦那样在旧坐标上抢跑，逻辑位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L860)。
- 结构重排本身仍复用原来的 `pendingStructureLayoutReset` 分支来决定是否丢弃旧坐标映射，未改变布局复杂度；相关位置在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L697)。

## 3. 数据流或调用链

- 批量编辑调用链：
  [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1495) 构造 `nextDraft`，再通过 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1236) 判断草稿是否真的变更；成功后调用 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1523) 请求结构重排并附带 `focusNodeKey`。
- 结构重排调用链：
  [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L981) 接收 `focusNodeKey` 后设置 `pendingPostLayoutFocusNodeKey` 与 `pendingStructureLayoutReset`，随后由 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L697) 进入“新结构重排”路径。
- 视口回归到选中节点的链路：
  新布局节点落位后，由 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L860) 执行一次延迟 `setCenter`，并在完成后释放自动归位抑制。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性：本轮只改前端视口状态机，不涉及 `snapshot`、`draft` 数据结构、服务端保存或 `triggerSource -> core` 真值链路，因此与现有语义兼容；结构刷新入口改动位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L981)。
- 性能：新增 effect 只在重排后且存在挂起聚焦目标时执行一次，属于低频 UI 调度；核心开销仍在既有布局重排流程，相关入口在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L697)。
- 可用性风险：如果当前选中节点在应用草稿后已不再进入当前画布，新的重排后聚焦 effect 会直接清空挂起状态而不强行跳别的目标，这样更稳，但用户可能仍需要手动点选新的上下文对象；对应容错逻辑在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L875)。
- 扩展性：`focusNodeKey` 已并入结构刷新入口，后续如果其它重排来源也需要“重排后回到上下文节点”，可以直接复用同一参数而无需再增加新的视口状态入口；接口定义在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L981)。

## 5. 并发冲突审查

- 共享状态主要是 `selectedNodeKey`、`pendingPostLayoutFocusNodeKey`、`pendingStructureLayoutReset`、`pendingStructureViewportFit` 这几类 React state，定义与写入位置在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L153)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L177)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L179)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L181)。
- 当前风险等级评估为低：所有更新都在 React 前端单线程事件和 effect 链中串行执行，没有新增跨线程共享状态。
- 需要关注的边界是“用户在应用草稿后立刻再次触发其它视口动作”：目前通过 `setPendingFocusNodeKey("")` 和自动归位抑制释放顺序，避免了即时聚焦与重排后聚焦互相覆盖；相关清理动作在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L989) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L886)。
