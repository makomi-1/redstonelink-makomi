# 快速连接工具与状态面板主题化

## 1. 功能与语义、架构设计
- 本轮把快速连接工具和状态面板接入了与 `core / triggerSource / filter` 相同的主题化入口：在 [GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L256) 新增 `QUICK_LINK_SERIAL / QUICK_LINK_CHANNEL / STATE_PANEL` 预设，并通过 [GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L279) 暴露边框主色，保持“背景资源 + 主题主色”统一抽象。
- 快速连接工具的主题接线集中在 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L79)、[QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L167)、[QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L288)，完成了背景绘制、主题输入框、主题按钮和文本配色的整套接线。
- 状态面板的主题接线集中在 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L113)、[StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L200)、[StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L460)，把输入框、操作按钮、删除按钮、背景与文本色统一到了状态面板主题。
- 语义对齐结论：本轮没有修改 `triggerSource/core` 的命名、方向、协议、持久化或 API 依赖，只改客户端 GUI 表现层，相关业务语义保持不变；快速连接保存逻辑仍位于 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L199)，状态面板订阅逻辑仍位于 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L272)。

## 2. 关键数据结构和算法性能分析
- 主题样式采用静态 `Style` 常量复用，快速连接工具在 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L23) 定义多行输入框和按钮样式，状态面板在 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L31) 与 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L40) 定义单行输入框和按钮样式，避免在每帧渲染里重复创建皮肤对象。
- 背景绘制仍沿用 nine-slice 常量复杂度路径，[GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L55) 到 [GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L84) 的调用链只处理固定九宫格切片，时间复杂度为 O(1)，不会随着文本长度或列表规模增加。
- 快速连接与状态面板的包围盒计算分别位于 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L295) 和 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L467)，只整合少量固定组件矩形，属于 O(1) 计算。
- 状态面板列表渲染继续限制在可见行窗口内，[StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L373) 只遍历 `VISIBLE_ROWS`，并通过 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L611) 的列宽收敛逻辑避免文本压住删除按钮，性能风险低。

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全性：本轮未新增命令、协议字段或服务端写入口，输入校验仍沿用既有 `SerialInputSyntaxSupport`，见 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L221) 与 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L272)，安全风险无新增。
- 性能：背景采用固定九宫格拉伸，列表仍只渲染可见窗口，热点主要还是字体绘制而非新增算法，参考 [GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L84) 与 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L373)，性能风险低。
- 兼容性：本轮没有触碰贴图资源文件本身，只消费已存在的 `png`；但快速连接工具当前仍固定接到序号直连主题，频道匹配主题预设只是占位，入口见 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L288) 与 [GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L261)，这属于已知范围内的保留项。
- 扩展性：新增主题预设后，后续其它 GUI 只需要复用 [GuiBackgroundRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiBackgroundRenderSupport.java#L256) 和对应 `Styled*` 样式常量即可接入；建议后续若要补 `qlt_cp`，优先在快速连接工具内部抽成“按模式取主题样式”的小钩子，而不是再复制一份 screen。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 共享状态：快速连接工具只维护本地 `statusMessage` 与 `currentSerialCacheType`，状态面板只维护 UI 控件状态、滚动偏移和快照列表，相关入口位于 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L64) 与 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L86)，没有新引入跨线程共享容器。
- 读改写覆盖：状态面板在 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L243) 对 `entries` 做整表替换，在 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L511) 只根据当前布局同步控件几何；本轮改动没有新增与服务端快照并发竞争的写路径。
- 重入/线程边界：新增的背景绘制与样式创建全部位于客户端渲染线程调用链，入口分别是 [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L167) 和 [StatePanelToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelToolScreen.java#L200)，没有异步任务、锁或回调重入问题。
- 风险等级：低。
- 建议：后续如果为快速连接工具补 `cp` 运行时切换主题，应继续把主题选择限制在 UI 层钩子内，避免把模式分支扩散到保存载荷或服务端协议路径。
