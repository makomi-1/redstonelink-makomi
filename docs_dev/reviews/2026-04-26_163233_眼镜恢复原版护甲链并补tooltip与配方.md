# 眼镜恢复原版护甲链并补tooltip与配方

## 1. 功能与语义、架构设计

- 智能眼镜客户端初始化已移除自定义护甲渲染注册，客户端入口现在不再接管眼镜穿戴渲染，智能眼镜因此重新回到原版护甲层渲染链。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L83)
- 智能眼镜物品本身仍然保留 `ArmorItem + 自定义 ArmorMaterial.Layer` 的结构，所以回到原版护甲链后依旧会使用模组自己的 `smart_glasses` 护甲层贴图，而不是退回铁头盔贴图。[SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L25)
- 转发器与智能节点容器 tooltip 的新增说明都挂在各自物品类的 `appendHoverText(...)` 里，属于纯展示层增强，不改变任何节点身份、容器同步或交互行为。[RepeaterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/RepeaterBlockItem.java#L75) [SmartNodeContainerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartNodeContainerItem.java#L114)
- 两个新配方以独立 shaped recipe 形式落到运行时 `recipe/` 目录，保持与当前项目既有配方布局一致。[smart_glasses.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/data/redstonelink/recipe/smart_glasses.json#L1) [smart_node_container.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/data/redstonelink/recipe/smart_node_container.json#L1)

## 2. 关键数据结构和算法性能分析

- 本轮没有引入新的复杂数据结构。tooltip 只是追加常量文案，属于 `O(1)` 附加开销，对物品提示性能无实质影响。[RepeaterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/RepeaterBlockItem.java#L109) [SmartNodeContainerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartNodeContainerItem.java#L145)
- 配方资源是静态 JSON，不引入运行时算法成本；新增的唯一测试层调整是把两个新配方文件名加入运行时配方清单契约集合，仍是常量集合比对。[RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L26)
- 恢复原版护甲链后，智能眼镜不再经过额外自定义渲染器分发，运行时路径与普通护甲层更接近，维护成本也更低。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L83) [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L45)

## 3. 数据流或调用链

- 智能眼镜现在的调用链是：物品注册为 `ArmorItem` -> `SmartGlassesItem` 提供 `ArmorMaterial.Layer` -> 客户端初始化时不再注册自定义 renderer -> 穿戴时直接落回原版护甲层渲染。[ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L164) [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L33) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L84)
- 转发器 tooltip 数据流保持原样：先读取序号和配置快照，再追加“dual identity”提示文案，最后交给父类继续绘制 tooltip。[RepeaterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/RepeaterBlockItem.java#L82)
- 智能节点容器 tooltip 数据流保持原样：先读取当前容器快照，再在交互提示后补上“连接信息不自动同步”的说明文案。[SmartNodeContainerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartNodeContainerItem.java#L121)
- 新配方数据流由资源加载器直接读取 `recipe/` 下 JSON；为了让测试与设计一致，运行时配方契约测试也同步更新了新文件名集合。[smart_glasses.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/data/redstonelink/recipe/smart_glasses.json#L1) [smart_node_container.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/data/redstonelink/recipe/smart_node_container.json#L1) [RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L54)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性：恢复原版护甲链的前提是 `SmartGlassesItem` 继续保持 `ArmorItem` 语义；如果以后改成普通 `Item` 或自定义头部附件系统，这条恢复路径将不再适用。[SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L25)
- 文案一致性：新增转发器提示已按项目语义基线使用 `core + triggerSource`，避免在新增 tooltip 中重新引入旧术语作为正式输出。[zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L78) [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L78)
- 配方扩展性：当前项目仍以 `recipe/` 作为运行时目录约定，新增配方时必须同步更新配方清单契约，否则会在全量测试阶段失败。[RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L24)
- 耐久边界：智能眼镜注册属性仍只有 `stacksTo(1)`，本轮未引入普通头盔式耐久；如果后续要改成有耐久，必须显式补 `durability(...)`，不能依赖 `ArmorItem` 自动推导。[ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L164)

## 5. 并发冲突审查

- 共享状态：本轮没有新增跨线程共享状态；护甲渲染回退只是减少客户端注册入口，tooltip 与 recipe 也都是静态资源或只读提示路径。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L83)
- 读改写覆盖：tooltip 变更只追加显示文案，不写回物品 NBT 或容器状态；配方与语言文件都是静态资源更新，没有读改写竞争窗口。[RepeaterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/RepeaterBlockItem.java#L75) [SmartNodeContainerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartNodeContainerItem.java#L114)
- 线程边界：配方加载与 tooltip 展示都在既有单线程资源/客户端 UI 生命周期中执行，没有新增异步任务或重入风险，风险等级为低。[smart_glasses.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/data/redstonelink/recipe/smart_glasses.json#L1) [RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L57)
