## 2. 关键数据结构和算法性能分析
- 打开配对界面的 payload 现在同时携带 `sourceAlias + sourceDisplayText`，编码仍是定长上限的 UTF 字段，单次打开/保存只增加常数级字节成本；相关实现位于 [PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L175)、[PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L236)、[PairingNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkPayloadSupport.java#L78)。
- alias 保存仍复用 `NodeAliasSavedData` 的按 `(type, serial)` 主键和按 alias 反查索引的双 HashMap 结构，`upsert/resolve` 复杂度保持 O(1) 平均；本轮没有改动真值主键或连接图结构，见 [NodeAliasSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasSavedData.java#L143)、[NodeAliasSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasSavedData.java#L205)。
- 服务端只有 `changed=true` 时才触发在线节点与玩家物品快照同步，避免 `unchanged` 场景做无效广播；同步入口见 [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L177)、[NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L39)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全性：GUI alias 保存权限故意沿用 `server.command.otherPermissionLevel`，没有放宽到“能打开 GUI 就能改 alias”；这样与命令维护口径一致，但也意味着低权限玩家即使能打开 pairing GUI，仍可能不能保存 alias。该边界由 [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L124) 和 [使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/使用说明.md#L172) 明确。
- 兼容性：连接真值主键与方向语义未变，alias 仍只是显示/反查附属数据；pairing 目标输入依旧只认序号表达式，不接受别名直接写入，避免把旧的“只读 alias”边界悄悄扩大。相关代码与说明见 [AbstractMultiPairingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/AbstractMultiPairingScreen.java#L900)、[使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/使用说明.md#L173)。
- 性能：本轮新增网络包与 GUI 控件都属常数级成本；全量回归首次执行时 `testSlow` 出现一次 `save cost 51ms > 50ms` 的 1ms 波动，复跑 `testSlow` 后通过，最终整套 `test testIntegration testClient testSlow` 复跑通过。该现象更像现有慢测阈值抖动，未见与 alias GUI 链路耦合的证据。风险等级：低。
- 扩展性：当前 GUI 只支持“修改 alias”，不支持在 GUI 中清空 alias，也不支持把 alias 当作配对写入表达式；如果后续扩展“GUI 清空”或“别名参与读写映射”，建议继续沿用现有 `SubmitPairingAliasPayload/PairingAliasStatePayload` 这条独立链路，不要混进 `Submit*PairingPayload` 的连接写入协议。参考入口见 [PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L364)、[PairingNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetwork.java#L421)。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 服务端线程边界：alias 保存包在注册层显式 `player.server.execute(...)` 后才进入 handler，因此 `NodeAliasSavedData` 的读改写仍发生在服务端主线程，没有新增跨线程写入。证据见 [PairingNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkRegistrationSupport.java#L63) 与 [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L120)。风险等级：低。
- 客户端线程边界：所有 S2C 反馈和 alias state 都先切回 `context.client().execute(...)`，再触摸 screen 状态；`statusMessage/sourceAlias` 的更新没有跨线程重入。证据见 [PairingNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/PairingNetworkClientHandlerSupport.java#L30)、[PairingNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/PairingNetworkClientHandlerSupport.java#L66)、[AbstractMultiPairingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/AbstractMultiPairingScreen.java#L900)。风险等级：低。
- 读改写覆盖：连接写入 OCC 与 alias 保存链路是分离的；alias 保存不会修改链接图 revision，也不会影响 `triggerSource -> core` 的 OCC 冲突模型，因此不存在“改 alias 覆盖连接图”的共享状态风险。证据见 [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L120) 与 [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L177)。风险等级：低。
