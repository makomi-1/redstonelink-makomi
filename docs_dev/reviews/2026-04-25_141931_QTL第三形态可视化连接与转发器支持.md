## 2. 关键数据结构和算法性能分析

- 第三形态显示对象在客户端使用 `LinkedHashMap<VisualizedObjectKey, VisualizedObjectState>` 持有，既完成去重，也保留加入顺序，便于颜色分配稳定且避免重复绘制同一对象。[QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L86) [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L211)
- 服务端快照查询同样使用 `LinkedHashMap` 去重目标对象；转发器会把两侧可见连接汇总后再折叠输出，复杂度主要与“当前对象可见连接数”线性相关，而不是与全图规模线性相关。[QuickLinkVisualizationSnapshotService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkVisualizationSnapshotService.java#L55) [QuickLinkVisualizationSnapshotService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkVisualizationSnapshotService.java#L91) [QuickLinkVisualizationSnapshotService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkVisualizationSnapshotService.java#L197)
- 第三形态渲染阶段只遍历已加入的显示对象及其目标列表，实际绘制复杂度约为 `O(显示对象数 + 连线数)`；没有引入后台轮询，也没有每帧重新向服务端取图，运行时成本可控。[QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L608)
- 原有缓存预览扫描仍保留短 TTL 节流与边界线段提取，避免逐帧全量扫描和内部接缝重复绘制；第三形态复用了同一条穿墙线渲染管线，但不走旧的区块扫描逻辑。[QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L267) [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L397) [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L511)
- 回归测试覆盖了模式循环、visualize 编解码以及显示对象去重/清空，能较好约束第三形态最核心的数据契约。[QuickLinkToolDataTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/QuickLinkToolDataTest.java#L67) [QuickLinkNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/QuickLinkNetworkPayloadTest.java#L108) [QuickLinkNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/QuickLinkNetworkPayloadTest.java#L132) [QuickLinkOutlineRendererTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/render/QuickLinkOutlineRendererTest.java#L47)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 设计上第三形态是“加入时/重新加入时刷新”的静态快照，不会在连接图变化后自动重抓；当前实现符合需求，但若后续要做动态图，需要增加 TTL 刷新或显式刷新指令，而不是让客户端自行猜图。[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L436) [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L211)
- 第三形态仅支持普通节点与转发器；过滤器、区块激活器在客户端目标解析阶段不会加入，在服务端也会被拒绝。这是当前范围内的有意收敛，但如果未来用户希望“全链路拓扑图”，这里需要继续扩展对象模型与 payload 协议。[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L333) [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L165)
- 渲染时按当前维度键过滤，只会绘制与玩家所在维度一致的对象；这避免了错误跨维度连线，但也意味着跨维度对象会暂时不可见，属于当前显示策略取舍。[QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L612) [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L623)
- 语义兼容性方面，本轮新增输出保持 `triggerSource/core`，转发器聚合对象仅使用现有上下文 token `link_repeater`，未引入 `button/source/target` 等旧术语，也未依赖 `com.makomi.api.v1.*`。风险结论：无新增语义漂移风险。[QuickLinkVisualizationSnapshotService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkVisualizationSnapshotService.java#L24) [QuickLinkNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetwork.java#L216)
