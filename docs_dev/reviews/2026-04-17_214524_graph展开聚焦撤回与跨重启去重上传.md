## 2. 关键数据结构和算法性能分析

- `GraphSnapshotJsonSupport.buildStructureChecksum` 使用排序后的节点/边及最小必要统计字段拼出规范化文本，再做 SHA-256 摘要。复杂度主要是 `O(N log N + E log E)`，适合当前导出体量，且只在导出时运行，不影响常驻 tick 路径。[GraphSnapshotJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotJsonSupport.java#L92) [GraphSnapshotJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotJsonSupport.java#L251)
- `GraphExportDedupeSavedData` 以 `UUID -> LinkedHashMap<checksum, fileName>` 维护最近 64 条下发记录，读写成本为均摊 `O(1)`，并通过截断最旧项控制持久化规模，避免台账无限膨胀。[GraphExportDedupeSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphExportDedupeSavedData.java#L22) [GraphExportDedupeSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphExportDedupeSavedData.java#L78) [GraphExportDedupeSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphExportDedupeSavedData.java#L94)
- 前端撤回实现只保留“一步前态”而非维护多级历史栈，空间成本固定；这符合本轮最小实现要求，也避免 alias 输入和批量编辑过程里频繁追加大对象数组。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1477) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1944)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮没有引入 `com.makomi.api.v1.*` 依赖；graph 读写真值仍走现有内部服务链，兼容边界保持“前端视图与导出层增强，不改 `triggerSource -> core` 真值约束”。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L59) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1953)
- 性能风险：结构校验码每次导出都会重算，如果后续 graph 规模继续增大，可以考虑把“规范化文本 + checksum”下沉为更细粒度缓存，但当前回归结果表明这一版仍在可接受范围内。[GraphSnapshotJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotJsonSupport.java#L92) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L31)
- 兼容性：旧 graph 本地样例和网页解析已同步删除运行态字段，并新增 `structureChecksum`；若后续还需要展示运行态，建议仅在 recording 或单独的 runtime 视图展示，不要重新混回 graph 结构快照。[graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L3) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L367)
- 扩展性：去重台账目前只保留最近 64 条记录，足够支撑当前单玩家导出复用；如果以后要做多频道或多视图 graph 缓存，可在同一 SavedData 上继续扩展命名空间，而不必重做协议。风险等级：中低。[GraphExportDedupeSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphExportDedupeSavedData.java#L22)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 服务端共享状态有两层：进程内 `EXPORT_CACHE` 和持久化 `GraphExportDedupeSavedData`。`EXPORT_CACHE` 仍使用 `ConcurrentHashMap`，适合处理多玩家并发导出；持久化台账只在服务端主线程导出路径上读写，没有新增异步写入线程。风险等级：低。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L23) [GraphExportDedupeSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphExportDedupeSavedData.java#L35)
- 客户端共享状态是 `PENDING_GRAPH_EXPORTS` 与 `PENDING_GRAPH_FORCE_TRANSFERS`。这两者都只在 `context.client().execute(...)` 进入主客户端线程后访问，因此没有跨线程并发读写；但如果未来 graph 导出接收改成异步文件流写，需要把这两个容器升级为并发容器或显式串行队列。风险等级：中低。[StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L24) [StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L196)
- 草稿撤回使用 React state 的单步前态覆盖，不会跨线程竞争；主要残余风险是“连续高频输入只保留最近一步”，这是本轮设计选择而非竞态问题。若未来要做多级撤回，应改成显式历史栈并补容量上限。风险等级：低。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1477) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1953)
