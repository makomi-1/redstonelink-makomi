- 客户端新增本地桥接服务，职责明确限定为“Jar 内静态网页分发 + `/api/ping` 验链”，没有提前承载录制、拓扑、保存 RPC 等后续业务，因此符合 `P0` 只搭底座的范围约束。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L22) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L129)

## 2. 关键数据结构和算法性能分析

- 核心运行态数据结构只有一个 `BridgeRuntime` 记录体，承载 `HttpServer`、线程池、根地址和启动时间，没有引入新的世界真值或 NBT 持久化结构，因此当前阶段复杂度低且边界明确。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L336)
- 静态资源解析采用“路径标准化 -> classpath 读取 -> MIME 判定”的直链，没有额外缓存层；对 `P0` 这种极小规模资源访问足够简单，但每次请求都会 `readAllBytes()`，后续若页面和资源增大，可再考虑内存缓存或 ETag。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L159) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L241)
- 前端首页的数据模型只有 `BridgePingPayload`，并通过一次 `fetch('./api/ping')` 加载，状态机仅含 `loading / ready / error` 三态，性能负担极低，适合作为后续录制页和图页的容器起点。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L3) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L24)

## 3. 数据流或调用链

- 构建链：`npmInstallWebapp -> buildWebapp -> processResources -> assets/redstonelink/webapp/**`，其中 `processResources` 直接复用前端生成目录，不需要手工复制静态资源。[build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L101) [build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L114) [build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L135)
- 运行链：玩家执行 `/rlclient web open` -> `executeOpenWebApp` -> `LocalWebAppBridgeService.openHomePage()` -> 如未启动则 `ensureStarted()/startRuntime()` 绑定 `127.0.0.1` 随机端口 -> 浏览器打开本地首页。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L348) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L47) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L105)
- 网页数据链：首页加载后请求 `./api/ping`，本地桥返回 `modId / bridgeVersion / mode / startedAtEpochMillis / baseUrl`，页面据此渲染当前桥接状态。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L27) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L132)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全：当前桥仅绑定 `127.0.0.1`，未暴露到局域网，且没有写接口，因此风险较低；后续进入 `P1/P2/P4` 时再补权限和限流即可，不应在当前阶段引入复杂授权层。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L102)
- 性能：Gradle 每次命中 `npmInstallWebapp` 都会执行 `npm ci`，在频繁开发期会增加构建时间；若后续前端变重，可以再评估增量安装策略，但目前优先保证可重复构建更合理。[build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L101)
- 兼容性：本地桥依赖 `net.minecraft.Util` 打开浏览器，已通过 `clientClasses` 编译校验；若未来要支持游戏内嵌浏览或更复杂协议，再抽象打开策略即可。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L348) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L66)
- 扩展性：当前首页只验证桥接和分期，不承载业务状态；这保证 `P1` 可以平滑补本地缓存、`P2/P3` 再分别补录制页和图页，而不用回退 `P0` 结构。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L61)
- 额外注意：`npm install` 与 Gradle 构建均提示存在 2 个 `moderate` 级漏洞，以及本地环境设置了 `NODE_TLS_REJECT_UNAUTHORIZED=0` 的警告；这不是本次功能回归阻断，但建议后续在依赖治理阶段统一收口。
