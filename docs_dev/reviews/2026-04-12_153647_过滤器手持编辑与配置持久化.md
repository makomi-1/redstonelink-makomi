# 过滤器手持编辑与配置持久化

## 1. 功能与语义、架构设计

- 本轮把过滤器编辑目标从“仅已放置方块实体”扩展为“双目标上下文”：已放置方块继续写回方块实体，手持过滤器则写回主手物品配置；对应的数据快照入口由 [LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L17) 与 [LinkFilterNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetwork.java#L20) 共同承接。
- 手持过滤器与其它手持节点统一使用“手持物品打开 GUI”门禁，入口落在 [LinkFilterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkFilterBlockItem.java#L54) 与 [LinkFilterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkFilterBlockItem.java#L64)，不会改变既有 `triggerSource -> core` 筛选语义。
- 放置与掉落配置闭环收口在 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L66) 和 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L78)：放置时把物品配置写入方块实体，掉落时把方块实体配置写回掉落物。
- 客户端继续复用同一套过滤器编辑界面，仅新增编辑目标上下文字段，不新起第二套 GUI；对应构造与提交入口位于 [LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L82) 与 [LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L270)。

## 2. 关键数据结构和算法性能分析

- 过滤器物品配置采用 `ItemStack CUSTOM_DATA` 小字段直写，字段规模固定，读写复杂度为 O(1)；实现位于 [LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L30) 与 [LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L46)。
- tooltip 的节点集展示会把保存的序号表达式重新解析为结构化 `N / A:B` 文本，并按长度上限截断；这一步的复杂度与序号数量线性相关，但只发生在 tooltip 构建时，不进入方块热路径，对应实现位于 [LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L60) 与 [LinkFilterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkFilterBlockItem.java#L80)。
- 网络 payload 仅增加目标类型、槽位号等常量规模字段，编解码仍是线性于配置快照文本长度的稳定成本；编码/解码入口位于 [LinkFilterNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkPayloadSupport.java#L32) 与 [LinkFilterNetworkPayloadSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkPayloadSupport.java#L52)。

## 3. 数据流或调用链

- 手持编辑链路：玩家右键手持过滤器 -> [LinkFilterBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkFilterBlockItem.java#L54) 打开服务端编辑器 -> [LinkFilterNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetwork.java#L54) 下发带 `HELD_MAIN_HAND` 上下文的打开包 -> [LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L82) 回填界面 -> [LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L270) 提交保存 -> [LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L33) 校验并写回主手物品。
- 已放置编辑链路保持原形，但现在与手持编辑共用同一网络上下文协议；打开与保存分别落在 [LinkFilterNetwork.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetwork.java#L29) 和 [LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L33)。
- 持久化闭环：手持配置先写入 [LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L46)，放置时由 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L66) 注入方块实体，掉落时由 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L78) 回写掉落物，形成闭环。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：已放置过滤器保存仍保留原有权限门禁；手持过滤器保存不再要求命令权限，因为它只修改玩家当前主手物品，不直接改世界态，相关分支位于 [LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L66)。
- 一致性：手持保存会校验当前选中热栏槽与主手物品类型，避免 GUI 打开后切物品时把配置错误写到别的对象上；目标解析逻辑位于 [LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L136)。
- 兼容性：payload 协议有字段扩展，但仍通过统一 codec 编解码；本轮已同步补齐协议单测，见 [LinkFilterNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/LinkFilterNetworkPayloadTest.java#L20)。
- 扩展性：当前编辑目标枚举已经抽象成独立类型 [LinkFilterEditorTargetKind.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterEditorTargetKind.java#L13)，后续若要支持副手或容器内过滤器编辑，可在不推翻现有 GUI 的前提下继续扩展。

## 5. 并发冲突审查

- 共享状态对象主要有两类：已放置过滤器方块实体配置与主手物品 `CUSTOM_DATA` 配置。两者的真实写入都统一落在服务端处理器 [LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L33)。
- 网络接包器会先切回服务端主线程再执行保存，避免异步网络线程直接读改写世界态或物品态；对应调度位于 [LinkFilterNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkRegistrationSupport.java#L40)。
- 客户端侧只负责开屏与显示反馈，不持有真实配置写权限；对应入口位于 [LinkFilterNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/LinkFilterNetworkClientHandlerSupport.java#L20)。
- 风险等级：低。当前不存在跨线程共享可变集合的直接并发写入；剩余风险主要是“同一玩家在 GUI 打开后切换主手物品”的时序问题，已通过主手槽位与物品种类校验降级为安全失败，而不是错误写入。
