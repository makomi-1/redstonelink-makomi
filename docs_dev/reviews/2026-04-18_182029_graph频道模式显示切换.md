## 2. 关键数据结构和算法性能分析

- 频道视图先筛选 `connectionMode === "channel" && channel > 0` 的真实节点，再按频道分桶，并在每个桶内分别排序 `triggerSource` 与 `core`；时间复杂度主要是排序带来的 `O(n log n)`，空间复杂度为 `O(n)`。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L879) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L907)
- 频道边数量从真实 serial 关系的“多来源直连多目标”压缩为“成员到频道块的星型边”，边数为 `triggerSourceCount + coreCount`，可显著低于高扇出时的真实边数，适合做频道层概览。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L945)
- 自动布局在检测到 `channelHub` 后进入三列 lane 布局：左侧 `triggerSource`、中间 `channelHub`、右侧 `core`，避免把频道视图误套用 serial 聚合布局逻辑。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1227) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1263)
- 频道模式的边渲染显式跳过 removed-edge diff 叠加，只画频道虚拟边，避免把 serial draft diff 错投到频道视图导致视觉噪声或语义错位。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1516) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1544)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 频道模式当前仍是只读显示层，`canEditCurrentView` 明确限制了编辑门禁；如果后续要做频道编辑，必须单独扩展 draft/save 协议，不能直接放宽这个条件，否则会把频道虚拟结构误写进 serial 真值语义。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L155) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L389) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L411) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1124)
- 频道模式只显示有效频道成员节点，未分配频道或非频道连接模式的节点不会出现在该视图中；这对“频道概览”是合理的，但如果用户期待“全图+频道层”混合展示，后续需要单独加混合模式，而不是修改当前筛选口径。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L166) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L879) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1447)
- `channelHub:*` 是纯前端虚拟 key，目前只在画布与详情面板中使用；如果以后加入深链接、右键菜单或编辑草稿，必须继续把它与真实 `nodeKey` 隔离，避免泄漏到服务端或持久化层。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L922) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1164)
- 详情面板实际节点分支已改成显式 `selectedCanvasNode.kind === "actual"`，规避了联合类型兜底分支下的空值误判；后续若继续扩展新的画布节点种类，应维持这种判别式分支写法，避免再次引入 TS 缩窄缺口。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2018)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 风险等级：低。前端状态都在 React 单线程事件循环内，没有跨线程共享对象，但存在 ReactFlow 选区回流与本地批量编辑状态互相覆盖的风险。
- `temporarilySuspendCanvasSelectionSync` 与 `handleCanvasNodesChange` 通过两帧延迟和过滤 `select` 变更，避免“程序化清空选区”被 ReactFlow 旧事件立刻写回；这是本轮模式切换与清空选择能稳定工作的关键防线。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L935) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L954)
- `handleSelectionPreviewStart/End` 把框选过程拆成预览态与最终提交态，只有结束时才把结果写回批量编辑集合，减少拖拽过程中的闪烁和高频状态覆盖。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1009) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1019)
- `handleDisplayModeChange`、`resetBatchSelectionState` 和 `canvasNodeKeySet` 校正 effect 共同处理模式切换时的脏选择、无效选中节点和页签漂移，避免从 serial 切到 channel 后残留旧的批量编辑态。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L534) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1099) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1107)
- ReactFlow 侧通过 `elementsSelectable={selectionEnabled}`、`selectionOnDrag={selectionEnabled}` 和 `onSelectionChange` 的早退判定，把频道只读模式与 serial 编辑模式彻底分离，降低模式切换后的重入风险。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1583) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1612)
