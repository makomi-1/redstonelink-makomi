## 2. 关键数据结构和算法性能分析

- 同输入核心聚合通过 `buildTargetSourcesByNodeKey(...)` 为每个 `core` 反查上游 `triggerSource` 集合，再用排序后的来源 `nodeKey` 串生成签名键；只有当“来源数 >= 2 且核心数 >= 2”时才落成聚合块，避免把普通小图也强行虚拟化 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L459) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L512) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L542)。
- 聚合块折叠时，会把对应的真实 `triggerSource -> core` 边加入 `hiddenActualEdgeKeys`，再为每个来源补一条 `triggerSource -> aggregate` 虚拟边；原本稠密矩阵型的 `S x C` 条边可降到 `S` 条边，核心收益点在边数压缩而不是节点数压缩 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L541) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L575) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L630)。
- 搜索性能上，本轮不是优化匹配算法本身，而是把高频输入事件从整条画布重算链路中隔离出来；`matchedNodes` 只依赖已应用态搜索条件，空搜索时直接返回空集，从根上修掉“空搜索把全部节点并入强制显示”的问题 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1616) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1628) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1682)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 语义边界保持不变：内部命名和文案继续使用 `triggerSource/core`，真实边保存语义没有改动，仍只处理 `triggerSource -> core`；本轮没有触碰 snapshot、draft 真值结构和服务端实现，也没有引入 `com.makomi.api.v1.*` 依赖 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L136) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L150) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2216)。
- 聚合块目前按“上游集合完全一致”分组，规则明确、可解释，但也意味着只要来源集合存在一个差异节点，就不会进入同一块；这是有意保持语义准确性的取舍，后续如果要支持“近似聚合”，建议新增独立策略开关，不要污染当前精确聚合语义 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L527) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L548)。
- 搜索工具栏样式只做了现有布局体系内的对齐补丁，按钮区左对齐后能容纳“应用搜索 / 清空搜索”新增操作，兼容风险低；残余风险主要是极大规模搜索结果仍会让结果 chip 区占据一定垂直空间 [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L716) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2205) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2275)。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
