# 曲线页横向缩短修复与录制页网页入口

## 1. 功能与语义、架构设计（关键方法和入口）

- recording 曲线页横向被挤短的问题，这次不是继续补 `xWindow`，而是直接修图表宿主节点的生命周期：`RecordingChart` 现在始终保留 `recording-chart-host`，无曲线时只显示覆盖提示，不再把整块图表 DOM 切换成纯文本节点，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L63) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L313)。
- 图表宿主节点常驻后，`ResizeObserver` 和图表宽度状态可以继续沿用同一块宿主区域，不会因为“全关再开”而退回到最小宽度；建图完成后仍会回灌当前横向时间窗，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L83) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L180)。
- 录制 GUI 新增了一个独立“打开曲线页”按钮，直接调用客户端本地网页桥接服务，不依赖录制导出完成后的自动跳转链路，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L35)、[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L160) 和 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L397)。
- 为了让这个入口语义明确，本地网页桥接服务增加了专用 `openRecordingPage()`，而不是用空文件名去伪装某个资产跳转，见 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L85)。
- 新按钮的中英文文案已补齐，见 [zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L457) 和 [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L457)。

## 2. 关键数据结构和算法性能分析

- `RecordingChart` 继续使用 `chartWidth`、`currentWindowRef`、`fullDomainRef` 和 `dragStateRef` 作为本地图表交互状态，这次新增的 `emptyStateMessage` 只是一个派生空状态，不引入新的 recording 数据副本或复杂状态机，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L55) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L63)。
- 图表在“无样本/无曲线”时会先销毁 `uPlot` 实例并清空宿主节点，然后直接返回，不再做额外的宽度或数据扫描；复杂度仍然与原先一致，且避免了反复创建/移除宿主节点带来的布局不稳定，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L96) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L105)。
- 录制 GUI 仍以 `PanelLayout` 作为布局解析结果，本轮只增加了 `splitFieldButtonWidth` 和 `splitFieldButtonX()`，让自动打开开关和“打开曲线页”按钮共用同一行，不引入新的控件容器或额外滚动区域，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L665) 和 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L702)。
- 本地网页桥接服务增加 `openRecordingPage()` 只是在已有 `resolveRuntime()` 和 `openUri()` 之上封装一个固定目标地址，时间复杂度和失败模式都与现有 `openHomePage()` 一致，见 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L73) 和 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L85)。

## 3. 数据流或调用链

- recording 图表宽度链路现在是“`recording-chart-host` 常驻渲染 -> `ResizeObserver` 持续监听宿主宽度 -> `chartWidth` 驱动 `uPlot` 建图 -> 空状态只覆盖显示而不切宿主节点”，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L83)、[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L120) 和 [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L713)。
- recording 图表交互链路保持不变：滚轮、拖拽、快捷键仍通过 `onWindowChange` / `onResetWindow` 回写给父组件，本轮只是让这条交互链路不再受宿主节点销毁影响，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L195) 和 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L265)。
- 录制 GUI 打开网页的链路是“按钮点击 -> `StatePanelRecordingScreen.openRecordingPage()` -> `LocalWebAppBridgeService.openRecordingPage()` -> 系统浏览器/本地 WebView 打开 recording 页 -> `applyFeedback()` 在 GUI 内显示成功或失败消息”，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L166)、[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L380)、[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L397) 和 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L85)。
- 录制结束后自动打开网页的旧链路仍然保留，本轮没有改变导出后 `openAssetEntry(RECORDING, fileName)` 的行为，因此“主动打开 recording 页”和“导出后直达具体文件”两条路径可并存，见 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L95)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮没有新增服务端网络协议、命令写入入口或持久化字段。网页打开按钮只是调用本地回环地址桥接服务，仍然限定在客户端本地环境；未引入 `com.makomi.api.v1.*`，残余安全风险低。
- 性能：`RecordingChart` 空状态下现在会保持宿主节点常驻，这会多保留一个空 `div` 和一条 `ResizeObserver` 监听，但代价极小，换来的是宽度状态稳定。交互热点仍由 `uPlot` 与 `ref` 承接，没有把滚轮/拖拽变成额外的 React 重排热点，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L198)。
- 兼容性：录制 GUI 新按钮复用现有网页打开反馈键与桥接启动逻辑，不改变旧的自动跳转行为；如果本地系统无法拉起 URI，仍会走已有失败反馈路径，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L399) 和 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L401)。
- 扩展性：当前“打开曲线页”只跳到 recording 独立页面，不携带具体文件名。后续如果要支持“从录制 GUI 直接跳到最近一次 recording 文件”，建议在会话快照或客户端导出缓存里增加最近导出文件名，但这超出本轮范围。
- 语义对齐：本轮不改变 `triggerSource/core` 输出语义、方向约束和持久化键名；残余语义风险为无。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- recording 图表的共享状态仍集中在单个 React 组件实例内部：`chartWidth`、`currentWindowRef`、`fullDomainRef` 和 `dragStateRef` 只在浏览器单线程事件循环内读写，没有新增跨线程共享；风险等级低，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L55)。
- 本轮对图表的核心修正是“宿主节点不再被 UI 分支移除”，这实际上降低了 `ResizeObserver` 与图表实例之间的生命周期竞态；之前的风险在于宿主节点被切掉后，宽度观测链路也一起断掉，现在这条边界更稳定，见 [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L105) 和 [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L725)。
- 录制 GUI 新增按钮只调用本地网页桥接服务并回写一条状态消息，不改服务端录制会话，也不与 `autoOpenWeb`、`selectedSubscriptionKeys` 产生读改写覆盖；风险等级低，见 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L75)、[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L397) 和 [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L460)。
- 本地网页桥接服务的 `runtime` 仍由既有同步块保护；新增 `openRecordingPage()` 只读当前 runtime 并打开 URI，不引入新的共享可变状态，风险等级低，见 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L38) 和 [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L85)。
