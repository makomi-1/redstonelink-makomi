# 块状节点定向编辑推广与hide物品块模型

## 1. 功能与语义、架构设计

本轮把定向面集能力从 `core/sync triggerSource` 推广到两条更通用的语义线：输入型块统一按启用面采样邻居红石，输出型块统一按启用面对外发信号。共享采样入口下沉到 [NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L128)，块状 `triggerSource` 基类接入于 [LinkSignalEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSignalEmitterBlock.java#L47) 与 [LinkSignalEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSignalEmitterBlock.java#L255)，过滤器与区块激活器分别接入于 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L43) 和 [LinkChunkActivatorBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkChunkActivatorBlock.java#L44)，转发器输出面裁剪落在 [LinkRepeaterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkRepeaterBlock.java#L124)。

编辑入口继续保持单工具模型，只扩大支持对象范围，并对 `core/repeater` 统一走“点击面反向写入存储面”的输出语义修正。相关入口在 [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L45)、支持范围判定在 [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L93)，输出型块的反向映射在 [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L128)。

`hide` 物品的表现层则从平面贴图切回块模型渲染，仅改 item model 父级，不触碰贴图资源本体，见 [hide_core.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/hide_core.json#L2) 与 [hide_sync_trigger_source.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/hide_sync_trigger_source.json#L2)。

## 2. 关键数据结构和算法性能分析

核心数据结构仍然是 6 个 `BlockState` 布尔面属性，读写入口集中在 [NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L20)。运行时采样算法是固定上界的 6 面扫描：若无面集属性则回退 `getBestNeighborSignal`，若有面集属性则遍历启用面并取 `max`，复杂度始终为 `O(6)`，见 [NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L128)。

输入型块的 block entity 侧也统一复用同一采样 helper，而不是各自维护一套邻居读取逻辑，从而避免过滤器/区块激活器的世界态与持久化态出现不同口径。对应实现见 [AbstractLinkFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/AbstractLinkFilterBlockEntity.java#L211) 与 [LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L168)。

输出型块这里没有引入额外索引或缓存；转发器仍沿用既有 `dispatchedOutputPower`，只是把 `getSignal/getDirectSignal` 前面加了一层面判断，因此输出裁剪仍是常数时间，见 [LinkRepeaterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkRepeaterBlock.java#L124) 与 [LinkRepeaterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkRepeaterBlock.java#L129)。

## 3. 数据流或调用链

面编辑的数据流是：玩家使用编辑器命中方块后，在 [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L45) 校验支持范围并改写 `BlockState`，随后按节点类型走立即刷新分支 [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L144)。块状 `triggerSource` 会重采样输入，过滤器和区块激活器会同时刷新 `POWERED` 外显与已放置真值，转发器/核心块则依赖 `Block.UPDATE_ALL` 触发输出侧邻居感知。

过滤器链路是：block 侧调用 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L143) 统一刷新，外显功率来自 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L167)，持久化过滤真值最终通过 block entity 的采样口径 [AbstractLinkFilterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/AbstractLinkFilterBlockEntity.java#L211) 进入服务层。

区块激活器链路与过滤器相同：block 侧入口在 [LinkChunkActivatorBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkChunkActivatorBlock.java#L151)，block entity 侧采样入口在 [LinkChunkActivatorBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkChunkActivatorBlockEntity.java#L168)。自动化回归则集中在 [HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L197)、[HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L221)、[HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L243) 与 [HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L265)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全风险低：本轮未新增网络入口、权限判断或跨端状态写入，编辑器仍只改本地方块状态并走既有运行态刷新。性能风险也较低，因为新增逻辑全部是定长 6 面采样，没有引入新的全图扫描，关键 helper 见 [NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L128)。

兼容性上，本轮通过“可见节点默认全向、`hide` 节点子类默认空面集”保持旧世界语义不变；旧可见节点加面集属性后会按默认全向加载，而隐藏节点仍由子类覆盖默认值。相关落点见 [LinkSignalEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSignalEmitterBlock.java#L47)、[AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L43)、[LinkChunkActivatorBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkChunkActivatorBlock.java#L44) 与 [LinkRepeaterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkRepeaterBlock.java#L48)。

扩展性上，这轮已经把块状 `triggerSource` 收口到 `LinkSignalEmitterBlock`，后续若要继续支持非块状载体（例如按钮/拉杆），建议不要硬塞进当前面集模型，而是单独定义它们的朝向/附着语义。否则会把“块状六面集”和“附着面/交互面”两种模型混在一起，增加后续维护成本。

## 5. 并发冲突审查

本轮共享状态主要是方块 `BlockState` 与 block entity 当前世界态；写入入口都发生在主线程方块交互或服务端邻居更新路径中，没有新增异步线程或并发集合。关键写入口在 [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L51)、[AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L143) 与 [LinkChunkActivatorBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkChunkActivatorBlock.java#L151)。

读改写覆盖风险为低。原因是面编辑先整体替换 `BlockState`，再立即按类型刷新运行态；不存在多个异步消费者同时写同一个面集字段的路径。重入风险也较低，因为过滤器和区块激活器刷新虽然会再次调用 `level.setBlock(...)` 同步 `POWERED`，但只在值变化时写回，见 [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L167) 与 [LinkChunkActivatorBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkChunkActivatorBlock.java#L172)。建议后续若继续把面集扩到更多方块，保持“共享 helper + 类型分派刷新”的结构，不要让每个 block entity 自己维护一套独立采样缓存。
