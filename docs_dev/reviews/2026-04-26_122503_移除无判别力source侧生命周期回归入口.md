- 本轮改动只涉及静态 JSON 配置和 Markdown 文档，不新增共享可变状态，也不改变 bench 运行时并发边界，因此线程安全风险为低。[repeater-lifecycle-regression.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/repeater-lifecycle-regression.json#L1) [functional-matrix.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/functional-matrix.json#L1)
