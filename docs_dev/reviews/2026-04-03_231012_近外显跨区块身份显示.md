## 2. 关键数据结构和算法性能分析

关键新增数据结构只有一个小枚举 `CrossChunkNodeIdentity` 和扩展后的 `CachedCurrentLinksSnapshot`；身份判定算法只读 `CrossChunkWhitelistSavedData` 与 `RedstoneLinkCrossChunkConfig`，不再触发实体/区块运行态探测，因此复杂度保持在常量级集合命中和配置判断，性能开销明显低于去读 `findRuntimeOnlineNode(...)` 这类路径。客户端缓存仍沿用原来的按 `(dimension + pos + type + serial)` 键控静态 map，只是缓存值从“目标列表”扩成“目标列表 + 身份”，不会改变请求频率与裁剪策略量级。[CrossChunkNodeIdentity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/CrossChunkNodeIdentity.java#L16) [NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L213) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L52) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L93) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L152) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L348)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

服务端新增的跨区块身份判定是纯读路径，只读取配置与 SavedData，不引入新的共享可变状态；`handleRequestCurrentLinks(...)` 仍沿用现有请求节流与回包入口，因此没有新的服务端读改写覆盖风险。客户端侧共享状态仍集中在 `LinkSerialHudOverlaySnapshotSupport` 的静态缓存 map，但网络接包已通过 `context.client().execute(...)` 切回客户端主线程后再写缓存，HUD 渲染读取也发生在同一线程，当前线程边界保持清晰，风险等级评估为低。建议后续若 near overlay 想接入异步预取或后台缓存刷新，必须先把这两张静态 map 明确封装到主线程调度约束内，避免引入跨线程读写竞态。[PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L273) [PairingNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/PairingNetworkServerHandlerSupport.java#L417) [PairingNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/PairingNetworkClientHandlerSupport.java#L53) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L52) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L79) [LinkSerialHudOverlaySnapshotSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlaySnapshotSupport.java#L152)
