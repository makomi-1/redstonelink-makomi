# 修复sync跨tick覆盖语义

## 1. 功能与语义、架构设计（关键方法和入口）

- 本轮把 `sync` 类内语义从“跨所有 tick 全局 max”收口为“同 tick 内按强度 `max`，跨 tick 只保留最新一帧”，入口仍保持 `triggerSource -> core` 现有写入链路不变，继续由 `syncBySource(...)` 进入统一派发支持层。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L271) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L340)
- `sync` 真值重算改为只读取最新 `TimeKey` 帧；若持久帧与 runtime simulated 帧时间相同，则只在同一帧内合并来源强度，避免旧 tick 的高强度继续污染当前输出。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L399) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L573)
- later `sync` 写入时现在会显式清理更早 tick 的 `sync` 桶，因此最新帧删除后不会回露旧 tick；同时 runtime simulated 路径只清自己的旧帧，不直接抹掉真实持久帧，保持输入播放的内存覆盖层边界。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L223) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L235) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L184)

## 2. 关键数据结构和算法性能分析

- 关键数据结构仍是 `NavigableMap<TimeKey, Map<SourceKey, SyncConcurrentEntry>>`，没有新增新的持久化容器或额外索引；本轮只改变“从哪个帧重建真值”，没有扩大常驻状态面。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L40)
- 重算复杂度从“遍历所有 `sync` bucket 合并”收敛为“最多读取持久/运行态两侧的最新帧，再在帧内做一次来源级 `max` 合并”，热点复杂度更低，且与“later 覆盖 earlier”语义一致。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L399) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L573) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L633)
- 持久化快照也改为只导出最新持久 `sync` 帧，避免旧 tick 再次通过 `SyncSourceStrengths/SyncMaxSources` 回灌到读档结果里；存档格式本身未变，兼容成本低。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L450) [ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L803)

## 3. 数据流或调用链

- 真实 `sync` 写入链路现在是：`syncBySource(...) -> applySyncDeltaMutation(...) -> clearSyncTruthBefore(...) + upsertSyncConcurrentSource(...) -> recomputeSyncTruthFromConcurrentBuckets() -> recomputeAuthorityFromConcurrentBuckets(...) -> applyDerivedStateFromTruth()`，later 帧会在 mutation 阶段先淘汰 earlier 帧。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L271) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L340) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L223)
- runtime simulated `sync` 保持独立链路：`applyRuntimeSimulatedSyncSource(...) -> applyRuntimeSimulatedSyncDelta(...) -> clearRuntimeSimulatedSyncTruthBefore(...)`，只约束内存模拟帧自身的跨 tick 语义，不直接改写持久 `sync` 桶。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L361) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L184) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L235)
- 验证链路新增了三类关键断言：later 低强度覆盖 earlier 高强度、最新帧删除不回露旧帧、save/load 只保留最新帧；同时保留了同 tick 批提交仍按 `max` 聚合的旧断言，保证“跨 tick 收紧、同 tick 不变”。[ActivatableTargetBlockEntityInternalTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/block/entity/ActivatableTargetBlockEntityInternalTest.java#L308) [ActivatableTargetBlockEntityInternalTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/block/entity/ActivatableTargetBlockEntityInternalTest.java#L325) [ActivatableTargetBlockEntityInternalTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/block/entity/ActivatableTargetBlockEntityInternalTest.java#L634) [ActivatableTargetBlockEntityInternalTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/block/entity/ActivatableTargetBlockEntityInternalTest.java#L677)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性方面，本轮没有新增 NBT 键，也没有调整 `triggerSource/core` 映射；旧存档仍通过既有 `SyncConcurrentEntries` / `SyncSourceStrengths` 读取，只是重算输出时改成“最新帧优先”。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L727) [ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L450)
- 主要语义风险已从“更晚 tick 的低强度无法覆盖 earlier 高强度”转成“旧文档继续写成全局 max”；本轮已同步收口代码注释与机制/使用说明，降低实现与说明分叉风险。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L258) [mechanism_design_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/mechanism_design_cn.md#L71) [usage_guide_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_cn.md#L257)
- 残余风险：runtime simulated `sync` 仍是“内存覆盖层”，不会像真实 later `sync` 一样抹掉持久帧；这条边界是有意保留的，但若后续要把输入播放也定义成真实业务信号，就需要单独评估是否收口到同一淘汰语义。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L235) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L184)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 共享状态仍集中在单个 `core` 方块实体内部：`syncConcurrentBuckets`、`runtimeSimulatedSyncConcurrentBuckets`、`syncSignalStrengthBySource/max/maxSources` 都由 `ActivatableTargetConcurrentBucketComponent` 串行维护，没有新增跨实体共享容器。[ActivatableTargetConcurrentBucketComponent.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetConcurrentBucketComponent.java#L24)
- 读改写覆盖风险主要在“later 帧清旧 + 批末统一重算”的顺序控制；当前实现仍由 `applySyncDeltaMutation(...)` / `finalizeStructuredBatchMutation(...)` 在同一服务端主线程内执行，避免同批次多次交错写回造成中间态回露。风险等级：低。[ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L340) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L462)
- 线程边界未变化：本轮没有引入异步任务、后台线程或新锁；残余注意点仍是未来若新增旁路写入口，必须继续统一走目标级 dispatch/batch 提交流程，否则 later/earlier `sync` 的淘汰顺序又可能重新分叉。风险等级：低。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L649) [ActivatableTargetDispatchSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetDispatchSupport.java#L462)
