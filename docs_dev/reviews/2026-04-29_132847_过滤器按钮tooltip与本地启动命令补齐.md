## 2. 关键数据结构和算法性能分析

- 过滤器 tooltip 改动只是基于现有 `signalModeButtons` 数组做 `isHoveredOrFocused()` 判断，再按命中的按钮渲染一个固定 2 行 tooltip；这是典型 `O(1)` UI 判定，不会引入额外状态同步或遍历开销。[LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L646)
- `build.gradle` 的本地运行时依赖开关也只是配置期布尔分流，只有对应属性为 `true` 时才增加 `modRuntimeOnly` 依赖，对默认测试链和常规构建没有额外运行时成本。[build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L14) [build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L95)
- 版本号与命令文档变更属于静态配置/静态文档更新，不引入新的数据结构风险；主要价值是减少人工启动时的口径漂移。[gradle.properties](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/gradle.properties#L17) [docs_dev/references/开发命令.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/references/开发命令.md#L30)

## 3. 数据流或调用链

- 过滤器界面的调用链现在是：`render(...)` -> `renderSignalModeTooltip(...)` -> 按按钮 hover 状态选择对应的翻译键 -> `GuiGraphics.renderTooltip(...)` 输出说明文本。[LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L246) [LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L646)
- 运行时 mod 开关链路是：Gradle 读取 `-PwithJei/-PwithSodium/-PwithIris` 属性 -> `withRuntimeMod` 归一化布尔值 -> `dependencies` 中按需追加 `modRuntimeOnly` -> `runClient` 时进入本地模组类路径。[build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L14) [build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L95)
- 命令文档链路是：开发者查阅 `docs_dev/references/开发命令.md` -> 直接复制 `runClient` 命令 -> 由新增的 Gradle 属性开关决定本地附带的测试模组栈。[docs_dev/references/开发命令.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/references/开发命令.md#L27) [build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L17)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全风险低：本轮不涉及网络协议、权限校验、持久化格式或 `triggerSource -> core` 真值链，仅改 GUI tooltip、lang、Gradle 运行时依赖开关和文档。[LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L646) [build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L95)
- 兼容性风险主要在 `Sodium / Iris / JEI` 的版本口径上：当前工作区是 `1.21.1`，而新增的 `Sodium / Iris` 版本沿用了 `1.21.11` 分支已有值；这次构建链不默认解析这些依赖，所以不会影响普通测试，但后续若实际用这些命令跑 `runClient`，仍建议做一次本地实机启动确认。[gradle.properties](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/gradle.properties#L31) [docs_dev/references/开发命令.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/references/开发命令.md#L30)
- 扩展性良好：后续如果还要补别的本地可选模组，继续沿用 `withRuntimeMod(property)` 这条模式即可，不需要再复制一套解析逻辑。[build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L14)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- GUI tooltip 改动只在客户端主线程的单帧渲染阶段读取按钮 hover 状态，不引入共享可变状态，也没有跨线程访问；并发风险低。[LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L646)
- Gradle 依赖开关属于构建期配置读，不参与游戏运行时共享状态；唯一需要注意的是多人协作下若有人同时维护 `build.gradle` 或 `gradle.properties`，要避免覆盖彼此的依赖/版本字段。当前改动范围集中，风险等级低。[build.gradle](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/build.gradle#L14) [gradle.properties](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/gradle.properties#L17)
- 语言文件是扁平键值映射，本轮新增键与替换键都局限在过滤器 signal mode 这一组，不会与其它系统产生运行时并发读写冲突。建议后续继续按功能域成组维护 lang 键，减少多人并发改同一片段时的冲突概率。[zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L202) [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L202)
