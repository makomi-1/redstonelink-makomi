# 跨模式混合保存失败修复

- 本次修复把网页混合保存请求的核心编排收口到 `GraphWriteService`：先准备频道批量计划，再收集“同请求迁回 serial 的 core”，随后校验显式 replace，最后再裁剪频道派生 replace 与显式 replace 的冲突来源。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L295) [GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L315) [GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L338)
- 提交阶段改为“先应用频道配置及其剩余派生 replace，再应用显式 replace”，让最终真值以显式 `triggerSource -> core` 编辑为准，避免同批请求后写覆盖前写。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L90) [GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L125)

## 2. 关键数据结构和算法性能分析

- “同请求迁回 serial 的 core” 通过 `LinkedHashSet<Long>` 收集，时间复杂度为 `O(C)`，其中 `C` 为本批频道覆盖节点数；只在准备阶段执行一次，不会进入热路径。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L614)
- 频道派生 replace 的裁剪按来源序号做集合过滤，复杂度约为 `O(R + P)`，其中 `R` 为显式 replace 数，`P` 为频道派生 replace 数；实现只保留最终需要执行的计划，并同步重算命令成本，避免后续预检/保存口径偏大。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L637)
- 目标 core 的频道校验仍沿用 `LinkSetExecutionService` 的线性扫描，只是新增了一个允许集合判断，额外开销是一次 `Set.contains`，对原有 `O(T)` 校验复杂度基本无影响。[LinkSetExecutionService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkSetExecutionService.java#L210)
- graph 计费仍按“显式 replace 数 + 频道派生来源数 + 频道节点变更数”折算，但现在基于裁剪后的频道计划计算，避免重复计费。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L829)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全与权限：图编辑权限、别名权限与 OCC 冲突门禁仍保持在计划准备前，不因混合请求编排调整而绕过现有限制。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L261) [GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L276)
- 兼容性：命令层默认调用全部传 `Set.of()`，因此普通命令、core 编辑服务与频道编辑服务的既有行为保持不变；新增白名单只在网页混合保存路径下生效。[LinkSetExecutionService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkSetExecutionService.java#L110) [LinkChannelEditingService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkChannelEditingService.java#L112) [CoreLinkEditingService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/CoreLinkEditingService.java#L201)
- 残余风险：当前策略明确选择“显式 replace 优先于频道派生 replace”；若未来要支持“同一 `triggerSource` 在同批请求里既切到频道又保留显式边”的新语义，需要再单独定义冲突策略，而不是复用本次的显式优先规则。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L637)
- 建议：如果后续网页端继续扩展更多混合操作类型，优先复用现在这套“先生成子计划，再在 `GraphWriteService` 顶层裁剪冲突”的模式，避免把网页专属语义散落到命令层公共校验里。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L584) [GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L637)

## 5. 并发冲突审查

- 共享状态：新增逻辑只使用局部 `Set`、`List` 和裁剪后的不可变计划对象，没有引入新的静态可变状态；实际共享写入仍集中在 `LinkSavedData` 与频道配置存储上。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L57) [LinkChannelEditingService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkChannelEditingService.java#L181) [LinkSetExecutionService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkSetExecutionService.java#L404)

- 线程边界：`GraphWriteService` 仍假设运行在服务端主线程/命令线程上下文，本次未新增异步任务、缓存或延迟执行结构。若未来将 graph 保存挪到异步线程，需要重新评估 `LinkSavedData` 与 `NodeAliasSavedData` 的线程安全。风险等级：低。[GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L57) [GraphWriteService.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L688)
