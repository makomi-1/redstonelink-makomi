## 2. 关键数据结构和算法性能分析

- 核心数据结构仍是“主表 + 反向索引 + 引用计数”，但从单类型扩为双类型：`entriesByKey` 保存每个激活器完整真值，`triggerSource/core` 各自维护 serial 反向索引与 force-load/resident 引用计数，避免查询期遍历全表。[PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L58) [PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L64)
- `upsert` 仍是按“旧条目反索引/反贡献移除 -> 新条目重建”执行，复杂度与节点集大小线性相关；节点集上限固定为 32，因此单次更新成本被硬上限约束，不会随世界规模线性放大。[PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L41) [PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L101) [PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L279) [PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L297)
- `sameContribution` 只比较“当前生效类型 + 当前生效配置模式 + 当前生效节点集 + 激活态”，因此切换未生效侧配置不会误触发 resident/force-load 重算；`sameSerialIndex` 则仍比较两侧节点集，保证索引表与持久化真值一致。[PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L479) [PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L472)

- 交互风险：作用类型切换确认只覆盖 GUI 操作路径；管理员命令或 `data merge block` 仍可直接改 `activeType`，这符合“配置真值可被外部写入”的现状，但如果后续要把“确认”升级为强业务约束，需要在服务端再增加切换审计或显式确认协议。[ChunkActivatorEditorScreen.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/ChunkActivatorEditorScreen.java#L264) [ChunkActivatorNetworkServerHandlerSupport.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/ChunkActivatorNetworkServerHandlerSupport.java#L34)
- 扩展性：当前双配置是显式 `triggerSource/core` 双槽实现，满足本轮需求且结构清晰；如果未来区块激活器要继续扩展到更多节点类别，建议再抽象成按标准 type token 的映射结构，避免继续横向复制字段与索引桶。[ChunkActivatorConfigStateSnapshot.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/ChunkActivatorConfigStateSnapshot.java#L11) [PlacedChunkActivatorSavedData.java](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedChunkActivatorSavedData.java#L58)
