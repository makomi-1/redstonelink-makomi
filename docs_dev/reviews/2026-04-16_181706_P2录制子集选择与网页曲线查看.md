## 2. 关键数据结构和算法性能分析

- 服务端 `StartRequest`、`SessionSnapshot` 与 `ActiveSession` 都显式携带 `selectedNodeKeys`，把“录制参数”“会话快照”“运行态会话”统一到同一套语义上，减少跨层重新推导的分叉。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L415) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L458) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L531)
- 录制子集过滤采用“遍历真实订阅列表 + `LinkedHashSet` 成员判断”的线性策略，时间复杂度约为 `O(n)`，并保持订阅顺序稳定，足以覆盖当前状态面板订阅规模。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L310) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L333)
- 录制 GUI 的本地勾选集合使用 `LinkedHashSet<String>`，滚动显示则固定为 5 行窗口，通过偏移量换页，避免在 Minecraft GUI 里引入更重的列表控件。[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L67) [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L502) [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L659)
- 网页端保持 bundle 原始 `tick` 不变，只在显示层做 `relative/raw` 派生；平移和缩放只修改当前视窗区间，不复制样本数据，空间成本主要仍由原始样本数组决定。[recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L80) [recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L140) [recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L156)

## 3. 数据流或调用链

- 游戏内开始录制时，`StatePanelRecordingScreen.startRecording()` 会把标题、采样参数、自动打开网页开关和当前勾选的 `selectedNodeKeys` 一起发给服务端；服务端 handler 再转成 `StartRequest` 交给会话服务。[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L382) [StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L199)
- 服务端开始录制后，会生成带 `selectedNodeKeys` 的 `SessionSnapshot`，再经 `sendRecordingSession()` 回传客户端 GUI，使界面在重新打开或刷新时能显示真实选中子集与挂载状态。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L137) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L531) [StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L335) [StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L342)
- 网页端从 `App` 读取本地资产内容后，通过 `parseRecordingBundle()` 解析 recording bundle，并把结果交给 `RecordingViewer` 维护节点切换、曲线显隐、横坐标模式和视窗状态。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L227) [recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L51) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L29)
- `RecordingViewer` 负责把当前节点样本、视窗和坐标模式送入 `RecordingChart`，图表组件只做绘制，不反向改写 bundle 真值，从而把展示态和录制结果真值隔离开。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L228) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L37)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全边界当前依赖“服务端只信真实订阅列表，再按子集过滤”的策略，已经避免客户端伪造录制外部节点，但节流与权限门闩仍未补齐，后续应在开始录制、导出和网页打开入口继续加限制。[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L79) [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L310)
- 前端图表已改为 `uPlot 1.6.32`，当前交互采用按钮式平移/缩放，复杂度低，但大量样本时仍可能出现页面渲染压力；若后续录制窗口继续扩大，可再补可视窗抽样或分段聚合。[package.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/package.json#L15) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L37)
- 兼容性方面，录制 bundle 本身没有改格式，新增字段只落在网络协议和会话快照层，因此旧 bundle 仍可被网页端解析；测试也已补齐协议 round-trip 覆盖。[recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L51) [StatePanelNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/StatePanelNetworkPayloadTest.java#L138) [StatePanelNetworkPayloadTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/network/StatePanelNetworkPayloadTest.java#L162)
