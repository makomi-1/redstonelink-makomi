# 外显穿透渲染迁移

## 1. 功能与语义、架构设计

- 本轮将连线、描边、定向箭头和过滤器范围的“穿透显示”统一收敛到新的公共渲染支持层，避免不同入口各自维护深度测试策略。[SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L38)
- quick-link 命中描边、预览线框、第三形态连线全部改走公共穿透线段提交，原有业务判断和颜色分配逻辑未变。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L79) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L140) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L755)
- 定向箭头改成先收集世界空间线段，再由世界后置渲染器统一提交；`core/repeater` 的面向修正语义保持原样。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L62) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L135) [DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L18)
- 过滤器范围被拆成“两层渲染”：文本仍走 `BlockEntityRenderer.submitText(...)`，范围几何改为世界事件穿透显示，避免方块实体几何提交通道把深度测试重新带回去。[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L99) [LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L151) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/RedstoneLinkClient.java#L612)

## 2. 关键数据结构和算法性能分析

- 公共穿透渲染支持使用 `MappableRingBuffer` 复用顶点上传缓冲，避免每帧重新创建 GPU buffer；线段与四边形分别维护独立 ring buffer，降低互相扩容影响。[SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L58) [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L255)
- quick-link 预览与第三形态仍复用原有缓存/可见对象收集逻辑，本轮没有引入新的图遍历复杂度，只是把提交目标从 `VertexConsumer` 改为线段列表。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L140) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L755)
- 定向箭头的复杂度仍是“每个可见节点 * 启用面数量”，本轮只把箭头片段写入列表，没有增加额外空间级别以外的复杂逻辑。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L101) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L230)
- 过滤器范围世界扫描按玩家渲染距离遍历可见 chunk 并筛选过滤器方块实体，复杂度与原远外显模式同量级；范围盒子固定为 12 条边和 12 个双面四边形，不会随半径增大线性膨胀。[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L162) [LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L229) [LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L253)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全风险低：本轮只涉及客户端显示层，没有新增网络包、命令或服务端持久化改动；`triggerSource/core` 业务方向语义未受影响。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L755) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L135)
- 性能风险中等：穿透显示意味着即使被遮挡也会绘制，复杂场景下会比原深度裁掉后的提交更显眼；当前仍通过玩家视距和已有显示开关限制范围，建议后续若观察到 GPU 压力再按显示对象数做上限控制。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L43) [LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L162)
- 兼容性风险中等：本轮自定义管线直接使用 1.21.11 的 `RenderPipeline` / `RenderPipelines` API，若未来 Mojang 再调整世界外显提交接口，需要优先检查公共支持层，而不是逐个渲染器排查。[SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L38) [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L231)
- 扩展性较好：后续若 `hide` 节点幽灵模型也需要穿透，可继续在公共支持层新增“无深度测试模型/贴图面层”分支，而不是再次分散到单个渲染器实现。[SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L108)

## 5. 并发冲突审查

- 共享状态主要集中在公共渲染支持的静态 ring buffer 与 quick-link 本地缓存；它们都仅在客户端渲染/主线程事件链内使用，没有新增跨线程写入路径，当前风险等级为低。[SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L58) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L62)
- `SeeThroughWorldGeometryRenderSupport.close()` 会在客户端停止时释放缓冲；如果未来引入异步渲染或后台资源刷新，需要重新确认关闭时机和提交线程边界，避免 draw 中途关闭 buffer。[SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L144) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/RedstoneLinkClient.java#L497)
- 过滤器范围改成世界事件扫描后，和方块实体文本提交之间不存在共享可变容器，避免了原本“同一渲染器同时管几何和文本”导致的重入混写风险，当前风险等级为低。[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L99) [LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L151)
