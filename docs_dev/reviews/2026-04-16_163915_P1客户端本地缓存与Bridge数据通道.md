## 2. 关键数据结构和算法性能分析

- 资产仓核心结构是 `StorageIndex / StorageCategorySummary / StorageEntrySummary / StorageEntryContent` 四层只读 DTO，足以支撑 `P1` 的目录概览和内容预览，不提前绑定后续 `P2/P3` 的真实业务写模型。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L393) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L405) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L421) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L433)
- `recordings/graphs` 采用 `.json.gz`，`drafts/layouts` 采用 `.json`，仓内同时提供压缩和非压缩读写路径，提前对齐整体方案对大体积导出资产的文件形态要求。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L201) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L222) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L232)
- 目录索引算法目前是按类目做一次 `Files.list` 全量扫描并排序，再转换成摘要 DTO，复杂度低且对 `P1` 的示例/小规模资产完全足够；若后续资产量增大，再考虑分页或缓存索引即可。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L69) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L129)
- JSON 返回体当前由最小手写序列化层统一生成，避免为 `P1` 再引入额外 JSON 依赖；代价是字段演进时要同步维护转义和结构拼接代码。[LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L14) [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L47) [LocalWebJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebJsonSupport.java#L143)

## 3. 数据流或调用链

- 启动链：Bridge 启动时先初始化本地资产仓，再注册 `/api/ping`、`/api/storage/index`、`/api/storage/entry`，因此网页一打开就能读到稳定目录结构和示例资产。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L112)
- 索引链：网页调用 `/api/storage/index` -> Bridge 调 `ASSET_REPOSITORY.index()` -> 仓服务扫描 `recordings/graphs/drafts/layouts` -> JSON 返回目录摘要。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L160) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L69)
- 预览链：网页点选某个条目 -> 调 `/api/storage/entry?kind=...&name=...` -> Bridge 校验查询参数 -> 仓服务按资产类型读取 `.json` 或解压 `.json.gz` -> JSON 返回文本内容 -> 页面右侧 `<pre>` 预览。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L177) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L91) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L106) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L315)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全：文件读取路径已通过 `kind + fileName` 双重约束和目录归属校验阻断目录穿越，当前只读接口没有写回世界的风险。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L91) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L115)
- 性能：当前每次请求都会重新扫描目录或读取整文件文本，`P1` 阶段是合理取舍；后续若录制和图快照体积上升，再考虑索引缓存、分页预览或预览长度限制。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L69) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L103)
- 兼容性：默认根目录解析依赖 `FabricLoader.getGameDir()`，同时保留测试环境回退路径，能兼顾运行态与单测环境。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L210)
- 扩展性：示例资产仅是 `P1` 验链占位数据，后续必须由 `P2/P3` 的真实录制 bundle 和图快照导出逻辑接管，不能把当前示例字段直接固化为最终契约。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L165) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L261)

## 5. 并发冲突审查

- Bridge 仍沿用单例 `runtime + synchronized` 的启动/停止门闩，避免重复启动或退出期二次关闭冲突，当前并发边界保持稳定。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L54) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L83)
- 本地资产写入只发生在仓初始化阶段，且统一走原子替换写入，能降低网页同时读取时读到半写文件的概率。[LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L58) [LocalWebAssetRepository.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAssetRepository.java#L244)
- 当前所有接口均为只读，不触发 `triggerSource/core` 真值读改写冲突，也不与服务端 OCC 体系产生重叠；并发风险等级评估为“低”。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L157) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L130)
