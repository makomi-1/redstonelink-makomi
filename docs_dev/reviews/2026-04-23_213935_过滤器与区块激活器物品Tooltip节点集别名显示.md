## 2. 关键数据结构和算法性能分析
- 新缓存结构是物品 NBT 中的字符串列表，过滤器一套、区块激活器按 `triggerSource/core` 分两套；读写都是按解析后的有序序号列表线性归一化，复杂度为 O(n)。[LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L122) [LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L231) [ChunkActivatorItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/ChunkActivatorItemData.java#L133) [ChunkActivatorItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/ChunkActivatorItemData.java#L253)
- 别名刷新前先判断物品类型与序号集合是否命中，避免对背包中全部过滤器/激活器做无差别重建；真正命中后才执行一次列表同步。[NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L186) [NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L208)
- tooltip 渲染完全消费本地缓存，不做服务端查询，因此客户端悬浮展示没有新增网络或世界查询开销。[LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L157) [ChunkActivatorItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/ChunkActivatorItemData.java#L171)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 风险等级：低。缓存字段都是新增的可选 NBT 键，旧物品没有这些键时仍会回退到 `#序号` 或 `-`，不会破坏现有读档兼容性。[LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L107) [ChunkActivatorItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/ChunkActivatorItemData.java#L120)
- 主要一致性风险在于未来若新增旁路配置入口，却没有在写完配置后补调 `syncNodeSetDisplayTexts`，那客户端 tooltip 会退回纯序号显示；当前 GUI 保存和掉落入口都已覆盖，但后续新增入口时要沿用同一约束。[LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L128) [ChunkActivatorNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/ChunkActivatorNetworkServerHandlerSupport.java#L79) [AbstractLinkFilterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/AbstractLinkFilterBlock.java#L88) [LinkChunkActivatorBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkChunkActivatorBlock.java#L96)
- 数量错位时统一回退 `#序号` 是有意的兼容保护，牺牲的是局部别名显示，换来不出现错位 alias；如果以后要支持部分命中展示，需要同时引入更强的序号-文本绑定结构，而不是仅靠索引对齐。[LinkFilterItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterItemData.java#L253) [ChunkActivatorItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/ChunkActivatorItemData.java#L275)

## 5. 并发冲突审查
- 本轮写入点全部位于服务端主线程的 GUI 保存、方块掉落和别名刷新流程，没有引入异步任务、共享可变静态状态或跨线程回调；并发风险低。[LinkFilterNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/LinkFilterNetworkServerHandlerSupport.java#L38) [ChunkActivatorNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/ChunkActivatorNetworkServerHandlerSupport.java#L36) [NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L44)
- 背包刷新采用“同步前后值比较 + `broadcastChanges`”策略，只在缓存确实变化时广播，避免无效容器同步放大。[NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L84) [NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L200) [NodeAliasServerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeAliasServerSupport.java#L217)
- 若未来把别名刷新改成异步批处理，需保持 `ItemStack` NBT 更新仍回到主线程执行；当前实现没有该问题，残余风险无。
