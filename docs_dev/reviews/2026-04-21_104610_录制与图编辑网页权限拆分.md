## 1. 功能与语义、架构设计（关键方法和入口）

本轮把网页相关能力从原先的通用命令权限口径中拆成两个独立配置域：`recording` 与 `graph`。配置模型新增 `RedstoneLinkWebConfig`，并接入主配置快照、解析器与模板，默认值均为 `2`，从而允许服务端独立控制“状态面板录制网页功能”和“graph 可视化编辑网页功能”。关键入口见 [RedstoneLinkWebConfig.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkWebConfig.java#L3)、[RedstoneLinkServerConfigSnapshot.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkServerConfigSnapshot.java#L10)、[RedstoneLinkConfig.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfig.java#L229)、[RedstoneLinkConfigParser.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfigParser.java#L67)、[RedstoneLinkConfigTemplate.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfigTemplate.java#L66)。

权限判定统一收口到 `WebFeaturePermissionService`，避免 recording / graph 两条服务端链路各自散落复制判断。recording 侧在录制会话启动前置校验，graph 侧在网页导出、graph 导出网络入口、bench graph 导出以及 `GraphWriteService.preparePlan` 前置校验。对应入口见 [WebFeaturePermissionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/WebFeaturePermissionService.java#L10)、[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L77)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L222)、[GraphVisualEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/GraphVisualEditorItem.java#L75)、[StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L297)、[BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L89)。

为 dedicated server 自动化补测，本轮新增 `bench recording` 命令树，并挂到 bench 根命令下。该入口只负责 bench 场景准备状态面板订阅、启动录制和停止导出，不对正常业务链路扩散额外设计。关键入口见 [BenchCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchCommandRegistry.java#L20)、[BenchRecordingCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchRecordingCommandRegistry.java#L37)。

语义对齐说明：
- 新增配置、文案与 bench 摘要全部继续使用 `triggerSource/core`，未引入旧术语输出。
- 方向约束未改变，graph 写入仍只允许 `triggerSource -> core`，权限拆分不改变拓扑语义。
- 兼容层仍保持“读旧写新”边界，本轮无 API `com.makomi.api.v1.*` 依赖引入。

## 2. 关键数据结构和算法性能分析

本轮新增的数据结构很轻：`RedstoneLinkWebConfig` 仅包含两个 `int` 权限等级字段，配置快照只多一层只读 record 引用，对启动与读取开销几乎可以忽略。见 [RedstoneLinkWebConfig.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkWebConfig.java#L10)、[RedstoneLinkServerConfigSnapshot.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkServerConfigSnapshot.java#L10)。

`GraphWriteService` 把 graph 网页功能权限提前折算进 `ResolvedRequestContext`，这样 preview/save 后续不会重复查询权限，也不会把权限判断分散到 alias/channel/topology 各个分支里。对应实现见 [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L222)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L236)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L1203)。

`bench recording` 里新增的 `collectSelectedNodeKeys` 只对当前状态面板订阅做一次线性扫描，复杂度 `O(n)`，其中 `n` 受 `server.statePanel.maxSubscriptions` 上限约束，当前默认 `50`，因此对 dedicated server 回归成本稳定。对应实现见 [BenchRecordingCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchRecordingCommandRegistry.java#L188)、[RedstoneLinkConfigTemplate.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfigTemplate.java#L48)。

游戏内自动化方面，本轮新增 `g02/g03` 两个 functional case，并挂接到 `server-basic-permission` suite。它们都只覆盖最小权限差异路径，不引入大规模放置或高频 trace，因此对 suite 执行时长影响较小。对应定义见 [graph_web_permission_gate_basic.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/g02/graph_web_permission_gate_basic.json#L2)、[recording_web_permission_gate_basic.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/g03/recording_web_permission_gate_basic.json#L2)、[server-basic-permission.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/server-basic-permission.json#L47)。

## 3. 数据流或调用链

配置链路为：`redstonelink-server.properties -> RedstoneLinkConfigParser.parseWeb -> RedstoneLinkServerConfigSnapshot.web -> RedstoneLinkConfig.web()`。调用点统一读取该快照，不再各自硬编码默认值。关键链路见 [RedstoneLinkConfigParser.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfigParser.java#L18)、[RedstoneLinkConfigParser.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfigParser.java#L69)、[RedstoneLinkConfig.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfig.java#L229)。

recording 链路为：`bench recording start / 网络录制启动 -> StatePanelRecordingSessionService.start -> WebFeaturePermissionService.canUseRecordingFeature -> 会话建立或拒绝`。bench 侧先通过 `prepare` 把订阅写进状态面板，再由 `start` 把订阅折成 `selectedNodeKeys`，避免被服务端按“未选节点”拒绝。关键链路见 [BenchRecordingCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchRecordingCommandRegistry.java#L112)、[BenchRecordingCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchRecordingCommandRegistry.java#L188)、[StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L77)。

graph 链路为：`GraphVisualEditorItem / export_graph 网络入口 / bench graph export / GraphWriteService.preview(save) -> WebFeaturePermissionService.canUseGraphFeature -> preparePlan -> 原有写控 / OCC / alias 权限继续生效`。这保证 graph 网页功能门只是前置功能门，不替代现有写权限与并发保护。关键链路见 [GraphVisualEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/GraphVisualEditorItem.java#L75)、[StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L297)、[BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L89)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L236)。

自动化验证链路为：`functional-matrix -> g02/g03 case -> server-basic-permission suite -> dedicated server + 外部 bench client -> result json / suite summary`。其中 `g02` 断言 graph 权限门，`g03` 断言 recording 权限门。关键定义见 [graph_web_permission_gate_basic.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/g02/graph_web_permission_gate_basic.json#L79)、[graph_web_permission_gate_basic.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/g02/graph_web_permission_gate_basic.json#L140)、[recording_web_permission_gate_basic.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/g03/recording_web_permission_gate_basic.json#L47)、[recording_web_permission_gate_basic.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/g03/recording_web_permission_gate_basic.json#L76)、[server-basic-permission.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/suites/server-basic-permission.json#L58)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全性方面，本轮没有放宽现有拓扑写入边界。graph 网页链路虽然新增了独立功能权限，但保存阶段仍保留原有 `server.command.permissionLevel`、别名权限、写控、限流与 OCC，因此不会因为网页功能门放开而绕过真实写入门。对应见 [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L263)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L270)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L275)。

兼容性方面，两项配置都提供默认值 `2`，老配置文件即使没有新增键，也会回退到稳定默认值；对应的解析边界与非法值回退已有单测覆盖。对应见 [RedstoneLinkConfigParser.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfigParser.java#L69)、[RedstoneLinkConfigWebPermissionParseTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/config/RedstoneLinkConfigWebPermissionParseTest.java#L15)。

扩展性方面，`WebFeaturePermissionService` 已把“网页功能门”抽象成独立服务；后续若继续拆 `curve viewer`、更多 graph 页面或其它 web feature，可沿同一模式新增配置与入口，不必再次把权限判断分散回业务实现。对应见 [WebFeaturePermissionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/WebFeaturePermissionService.java#L10)。

残余风险：
- recording 当前是在“开始录制”时校验网页功能权限；如果会话已经建立、之后玩家权限变化，停止导出不会再次重查权限。这与“先过功能入口门，再允许完成本次会话”的当前设计一致，但若未来要改成严格连续授权，需要在 stop/export 侧再补一层权限校验。对应入口见 [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L77)。
- 本轮 dedicated server suite 实跑显示 bench client 命令桥最终仍走 `server_network` 模式，但不影响本轮权限专项验证结论；若后续要强制覆盖 `client_direct_command`，建议单独修 bench 参数透传问题，不与业务权限语义混改。对应结果见本轮 suite summary（运行产物，不纳入仓库）。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

配置读取侧继续依赖 `RedstoneLinkConfig.snapshot` 的 `volatile` 快照切换，本轮只是为快照增加 `web` 域，没有引入新的可变共享集合，因此配置热加载的可见性模型不变，风险低。对应见 [RedstoneLinkConfig.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkConfig.java#L29)、[RedstoneLinkServerConfigSnapshot.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/config/RedstoneLinkServerConfigSnapshot.java#L10)。

graph 写入链路的并发保护仍然落在原有 graph revision / source revision 校验上，本轮只是在 `ResolvedRequestContext` 中附带 `hasGraphFeaturePermission`，没有改变写入时序，也没有新增绕过 OCC 的旁路。对应见 [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L222)、[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L1203)、[GraphWriteServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/GraphWriteServiceTest.java#L158)。

recording 会话状态仍按 `server -> playerId -> ActiveSession` 存在服务端主线程维护的映射中，本轮 bench 入口只是在玩家主手物品上写入状态面板订阅，并同步折算 `selectedNodeKeys`，没有引入额外后台线程或异步写回，因此重入风险低。对应见 [StatePanelRecordingSessionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/StatePanelRecordingSessionService.java#L48)、[BenchRecordingCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchRecordingCommandRegistry.java#L72)、[BenchRecordingCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchRecordingCommandRegistry.java#L188)。

综合风险等级：低。建议保持现有“网页功能门前置、真实写控/OCC 后置”的分层；若后续继续扩展网页能力，优先继续复用 `WebFeaturePermissionService`，不要回到各入口散落硬编码。
