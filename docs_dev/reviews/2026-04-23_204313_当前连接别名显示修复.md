# 当前连接别名显示修复审查

## 1. 功能与语义、架构设计（关键方法和入口）

本次修复点集中在 `NodeSnapshotQueryService.withRevisions(...)`：该方法原职责是为已构建的当前连接视图补充 revision 基线，不应改变可见目标和展示文本语义。现已在重建 `NodeLinksSnapshot` 时保留 `visibleTargetDisplayTexts()`，保证 pairing GUI 打开包与近外显 HUD 回包沿用上游已解析的 `别名(#序号)` 展示文本。关键入口：[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L178)、[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L187)。

## 2. 关键数据结构和算法性能分析

`NodeLinksSnapshot` 仍是当前连接可见视图的唯一 DTO，展示文本列表与目标序号列表保持一一对齐；本次只是把既有列表传入构造器，不新增遍历、不新增查询、不改变排序/去重规则。构造器内部仍由 `NodeAliasDisplayUtil.normalizeDisplayTexts(...)` 做对齐兜底，因此展示文本数量不匹配时仍会退回 `#序号`，性能复杂度保持与目标数线性相关。关键引用：[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L189)、[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L190)。

## 3. 数据流或调用链

数据流为：`queryLinks(...)` 生成隐私过滤后的 `NodeLinksSnapshot`，`withRevisions(...)` 补充 revision 后返回给网络层；随后 pairing GUI 打开包和 HUD 当前连接回包读取 `visibleTargetDisplayTexts()`。新增测试通过反射直测 `withRevisions(...)`，复现“已有别名展示文本补 revision 后被覆盖”的失败点。关键引用：[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L57)、[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L74)、[NodeSnapshotQueryServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/NodeSnapshotQueryServiceTest.java#L87)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全与隐私：本次不改变 `CurrentLinksPrivacyService` 的可见性裁剪，只保留裁剪后快照已有的展示文本，不扩大可见范围。兼容性：网络 payload 字段未变，旧无别名场景仍由构造器兜底为 `#序号`。扩展性：后续若要处理“GUI 已打开后目标别名外部变化”的即时刷新，应另行设计刷新事件或重新请求机制，不应混入本次补 revision 修复。关键引用：[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L184)、[NodeSnapshotQueryServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/NodeSnapshotQueryServiceTest.java#L117)。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

风险等级：低。`withRevisions(...)` 不写共享状态，只基于传入快照与 `LinkSavedData` revision 读值构造新 DTO；本次修改消除了读模型重建时的字段覆盖问题，不引入新的线程边界或重入路径。测试 helper 仅在单元测试中反射调用私有方法，不影响生产运行。关键引用：[NodeSnapshotQueryService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeSnapshotQueryService.java#L178)、[NodeSnapshotQueryServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/NodeSnapshotQueryServiceTest.java#L360)。
