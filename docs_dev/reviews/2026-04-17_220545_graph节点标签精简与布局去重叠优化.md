- 普通 `triggerSource/core` 节点的图内标签已收敛为单行主标题，`buildNodeLabel` 不再渲染副字段；样式层通过紧凑标签类控制单行留白，避免影响聚合块标签说明。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L129) [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L1114)
- 自动布局仍沿用“连通分量分块 -> 组件内部 lane 布局 -> 全局流式铺排”的原有架构，但在中间引入了确定性偏移函数，保证同结构可复现，同时减少过度整齐带来的边重叠。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L771) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L832) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L963)

## 2. 关键数据结构和算法性能分析

- `hashLayoutKey` + `resolveLaneJitter` 通过字符串哈希生成稳定偏移，复杂度为 `O(len(nodeKey))`，对当前节点规模开销极低，适合作为每次布局的常规计算。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L771) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L780)
- `normalizeLayoutPositions` 会对 lane 内所有节点做一次最小包围盒归一化，复杂度为 `O(n)`，保证引入负向/正向偏移后，组件宽高仍可被正确计算，不会因为局部偏移导致包围盒裁切错误。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L792)
- `buildAutoLayoutPositions` 在组件级再次叠加稳定偏移，使不同块不会形成完全齐平的列边界；这比引入随机扰动更利于调试和用户复盘，也不会带来额外状态存储成本。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L824) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L963)

## 3. 数据流或调用链

- 图视图渲染链路仍然是：`buildAutoLayoutPositions` 先生成 `positionByNodeKey`，随后 `buildGraphFlowNodes` 把位置和标签一起装配成 ReactFlow 节点；因此标签精简和布局偏移都集中在前端视图层闭环内，不影响 draft/save 语义。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L963) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1036) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1690)
- lane 布局内部的数据流是：`buildLaneLayout` 对节点按列/行编号，调用 `resolveLaneJitter` 施加稳定偏移，再经过 `normalizeLayoutPositions` 输出标准化布局结果，最后在 `buildComponentLayout` 中合并为 triggerSource/core 双层布局。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L780) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L792) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L832)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全与语义：本轮没有改动任何 `triggerSource -> core` 真值写入链路，也没有新增服务端接口或 API 依赖，风险集中在前端可视化观感层，语义风险低。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L129) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L963)
- 性能：布局扰动是纯前端同步计算，节点数继续增大时仍可能受 ReactFlow 本身渲染成本主导；目前新增逻辑为线性或近线性处理，未引入高阶复杂度。建议后续若图规模再上升，再评估边虚拟化或按层折叠策略。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L792) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L963)
- 兼容性：聚合块标签未被一并压缩，保留了“分组数量/展开态”说明，这样不会损伤当前聚合交互可读性；如果以后想进一步极简，需要先补别处的聚合态提示。风险等级：中低。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L138)
