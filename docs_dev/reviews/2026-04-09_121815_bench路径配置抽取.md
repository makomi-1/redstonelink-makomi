## 2. 关键数据结构和算法性能分析

- 路径配置文件仍是扁平键值结构，读取后缓存为单个脚本级对象，入口在 `[Bench.PathConfig.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/Bench.PathConfig.ps1#L32)`；读取成本固定为一次 JSON 反序列化，不会按 case 重复读取。
- helper 的路径推导是常数级字符串归一化与 `GetFullPath` 调用，server-relative 世界路径解析分别落在 `[Bench.PathConfig.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/Bench.PathConfig.ps1#L67)` 与 [Bench.PathConfig.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/Bench.PathConfig.ps1#L77)，不会给 suite 主循环增加可观测额外成本。
- suite 解析阶段新增了两层参数 map 合并：bench 路径参数与 suite/case 参数分离，再按用途组合；核心步骤在 `[BenchSuite.Config.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Config.ps1#L249)`、[BenchSuite.Config.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Config.ps1#L283)、[BenchSuite.Config.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Config.ps1#L286)，复杂度仍为按 entry 线性扩展。
- 由于 bench 路径参数不再写回 `entry.parameters`，case 展开阶段避免了把无关路径键传入 `Get-CaseConfig`，既保持了原有 case 参数模型，也避免了额外的对象扩展与失败回写。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性方面，当前 bench 运行现在强依赖 `[bench.path-config.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/bench.path-config.json#L1)` 存在且字段完整；缺文件或缺键会在 `[Bench.PathConfig.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/Bench.PathConfig.ps1#L32)` 与 [Bench.PathConfig.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/Bench.PathConfig.ps1#L45) 提前失败，这是可接受的早失败策略。
- 设计上已把 bench 路径参数与 case 参数隔离，关键修复位于 `[BenchSuite.Config.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Config.ps1#L283)` 与 [BenchSuite.Config.ps1](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/lib/BenchSuite.Config.ps1#L286)；这避免了无关路径键进入 case 展开链路，减少了后续再踩 `Get-CaseConfig` 隐式假设的风险。
- 残余兼容性风险是当前 `Get-BenchPathParameters` 会统一产出 Prism 路径键，即便 regression suite 不使用这些值；如果未来有人裁掉配置文件中的 Prism 字段，纯回归也会在 helper 层失败。若后续要进一步收敛依赖，可把 Prism 相关键改成按需懒解析。
- 性能方面，本轮只引入少量启动期参数合并和一次性配置读取，对 35 case dedicated regression 总耗时无显著放大；验证结果依旧保持 35/35 通过。
