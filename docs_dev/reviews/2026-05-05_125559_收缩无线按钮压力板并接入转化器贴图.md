## 2. 关键数据结构和算法性能分析
- 这轮没有引入新算法，重点是收缩静态注册集合，减少无效注册、资源扫描和创造栏展示条目数量。按钮/压力板白名单从多木种收缩到橡木、磨制黑石和测重压力板，属于常量表减法，不增加运行时复杂度。[ModBlockEntities.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlockEntities.java#L188)
- GUI 上下文归一化 `switch` 分支减少，客户端 cutout 注册项减少，属于常量查表缩减，不影响热路径复杂度，只降低维护噪音。[LinkGuiDisplayContext.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkGuiDisplayContext.java#L153) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L135)
- 配方与资源布局测试白名单同步删减，避免测试继续强制要求已经不再保留的配方文件。[RecipeResourceLayoutTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/RecipeResourceLayoutTest.java#L21)

## 3. 数据流或调用链
- 无线化按钮/压力板的数据流保持不变：物品注册进入创造栏，放置后通过 `WIRELESS_VARIANT_SYNC_TRIGGER_SOURCE` 方块实体进入同步 `triggerSource` 语义；这轮只是把允许进入这条链的木种缩减为橡木。[ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L282) [ModBlockEntities.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlockEntities.java#L188)
- GUI 和远外显上下文链仍然走“注册名 -> `LinkGuiDisplayContext` 归一化 -> `GuiHeaderContextSupport` 分类判断”，这轮同步删除了不再保留的木种 token，避免客户端拿到悬空上下文。[LinkGuiDisplayContext.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkGuiDisplayContext.java#L39) [GuiHeaderContextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiHeaderContextSupport.java#L183)
- 转化器显示链改为“blockstate 根据 facing/lit 选择模组模型 -> 模型引用 block 贴图 -> item model 直接继承 block model”，因此物品栏与世界内方块会统一显示新贴图。[wireless_converter.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/blockstates/wireless_converter.json#L1) [wireless_converter.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/wireless_converter.json#L1)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全风险低：本轮未触碰存档序列化字段，也未改节点持久化结构；主要是注册面、资源面和显示面收缩。[ModBlocks.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlocks.java#L216)
- 兼容性风险在于：如果玩家已有被移除木种的旧存档方块或物品，后续会因为注册名不再存在而无法解析；本轮没有做旧注册兼容壳。这是设计收缩的显式代价，需要用户自行确认是否接受。[ModBlocks.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlocks.java#L216)
- 贴图接线风险主要在资源引用路径，如果 block/item 贴图路径再次挪动，`wireless_converter` 的 blockstate 和 model 会同时失效；建议后续保持 `converter_*` 贴图仅保留在 `textures/block/`，不要再混放到 `textures/item/`。[wireless_converter.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/block/wireless_converter.json#L1)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 本轮改动集中在静态注册、资源文件和客户端初始化表，没有新增共享可变状态，也没有引入新的线程边界。注册集合在模组启动阶段一次性构建，风险等级低。[ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L282) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L135)
