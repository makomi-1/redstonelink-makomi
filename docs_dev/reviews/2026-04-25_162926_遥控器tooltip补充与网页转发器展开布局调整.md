## 1. 功能与语义、架构设计（关键方法和入口）

- 遥控器 tooltip 继续收口到统一入口 `LinkerItem.appendHoverText(...)`，在原有“信号语义”之后追加一条跨区块能力边界说明，因此普通遥控器与同步遥控器都会继承同一提示，不需要在 `SyncLinkerItem` 单独复制逻辑。[LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L176) [LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L197)
- 遥控器跨区块说明被抽成静态 helper `crossChunkCapabilityTooltip()`，实例方法仅转发到该 helper，既降低 tooltip 入口重复，也为契约测试提供了稳定目标。[LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L269) [LinkerItemTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/item/LinkerItemTest.java#L20)
- 中英文文案新增同一翻译键 `tooltip.redstonelink.linker.crosschunk.force_load_only`，明确表达“遥控器只能作为强加载对象，不支持常驻”，只补充现有语义边界，不改变任何运行时判定。[zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L79) [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L79)
- 网页前端没有改 graph 存储协议，而是在 `graphViewer/canvas.tsx` 的布局阶段增加“展开态转发器成员 lane”概念：`core` 端成员放到转发器左侧，`triggerSource` 端成员放到转发器右侧，中间仍保留组合节点作为收起点。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L448) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L542) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1843)

## 2. 关键数据结构和算法性能分析

- 前端布局新增的核心结构是 `expandedRepeaterMemberLaneByNodeKey`，它只在单次 `buildComponentLayout(...)` 过程中按展开态转发器成员生成，查表复杂度为 `O(1)`，构建复杂度为 `O(组件节点数)`，不会扩大长期状态面。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1847)
- 组件布局阶段把节点拆成 `triggerSource / repeaterCoreMember / repeater / repeaterTriggerSourceMember / core` 五类 lane 后，仍然沿用现有 `buildLaneLayout(...)` 做列内排布，因此整体复杂度仍主要由“节点过滤 + 排序 + lane 归位”组成，没有引入新的图搜索或递归布局器。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1888) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L2025)
- 为了避免转发器右侧 `triggerSource` 成员与其下游 `core` 的排序完全失锚，本轮把 `repeaterTriggerSourceMemberNodes` 也纳入 `sourceOrderByNodeKey`，这样后续 `core` 排序仍能复用现有的“来源顺序传播”策略，而不是另起一套排序规则。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1976)
- 验证层新增了两种轻量回归：Java 侧校验 tooltip 文案键，前端侧校验展开态转发器的左右中相对位置，覆盖了本轮最核心的契约点。[LinkerItemTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/item/LinkerItemTest.java#L20) [canvas.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.test.tsx#L160)

## 3. 数据流或调用链

- 遥控器 tooltip 调用链：物品悬停进入 `LinkerItem.appendHoverText(...)` → 读取连接与语义说明 → 调用 `buildCrossChunkCapabilityTooltip()` → 转发到 `crossChunkCapabilityTooltip()` → 命中中英文 lang 键输出最终文案。[LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L176) [LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L269) [zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L79)
- 前端展开链路：`buildGraphCanvasView(...)` 先保留展开态转发器与其真实成员可见性，再在 `buildComponentLayout(...)` 中把展开态成员映射为专用 lane，最后由 `buildAutoLayoutPositions(...)` 根据 lane 顺序生成实际 x/y 坐标。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1176) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1843) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L2104)
- 回归验证链路：`canvas.test.tsx` 直接构造 `triggerSource -> repeater -> core` 拓扑，展开转发器后读取 `buildAutoLayoutPositions(...)` 结果，并断言 `core member < repeater < triggerSource member` 以及外侧上下游节点继续分布在两端。[canvas.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.test.tsx#L160)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 语义兼容性：本轮没有改变任何实际跨区块判定逻辑，只是在 tooltip 里把既有边界显式化；运行时“强加载可用、resident 不支持”的真实行为保持不变，风险低。[LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L269)
- 协议兼容性：网页端只改布局层，不改 graph bundle、草稿操作或保存协议，因此不会影响现有导出/保存链路。风险低。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L542) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1843)
- 性能风险：布局阶段新增了几次 lane 过滤和一个小型 `Map`，相对原有组件级排序和 lane 归位成本很小；在当前图规模下可忽略。风险低。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1888) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L2025)
- 残余风险：当一个连通分量中存在多个展开态转发器时，当前实现是“同类成员共用 lane、靠序号排序自然对齐”，不是为每个转发器单独做局部子布局。现阶段足够满足“左右中”语义，但如果后续要求更强的局部编排感，可再考虑转发器级嵌套布局。风险等级：低到中。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L2025) [canvas.test.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.test.tsx#L160)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- Java 侧 tooltip 改动完全是纯函数/纯展示层收口，没有新增共享可变状态，也不进入服务端主线程业务路径。并发风险低。[LinkerItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/LinkerItem.java#L269)
- 前端布局改动只发生在 `buildComponentLayout(...)` 的派生计算过程中，输入来自当前 render 的 `componentNodes/componentEdges`，内部 `Map` 均为局部变量，没有跨 render 共享写状态。并发风险低。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1847)
- 本轮没有增加新的异步请求、网络回调、定时器或 React 持久状态来源；`GraphViewer` 仍按原有 render -> derive -> layout 流程消费画布数据，未见新的重入覆盖风险。建议后续若继续扩展局部布局规则，保持这种“纯派生布局、不写全局缓存”的实现方式。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L2104)
