# Iris直绘线段改四边形

## 1. 功能与语义、架构设计（关键方法和入口）

- 本轮把 Iris 兼容分支的底层直绘从 `LINES + rendertype_lines` 改成了 `QUADS + position_color`，入口仍然保持在统一的 `drawSegments(...)`，因此上层箭头、命中描边和智能眼镜连线的调用方式没有改变，只替换了提交后的几何表达方式。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L35)
- 新的核心展开逻辑在 `appendSegmentQuad(...)`：先把局部坐标应用当前 `pose`，再按线段方向与相机视线构造朝向相机的细长四边形，避免继续依赖 vanilla 线宽 shader 的屏幕空间扩线。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L70)
- 定向箭头的 Iris 路径仍从 `renderEnabledFaceVectorsIrisDirect(...)` 收集线段后统一交给该 helper，因此 `hide` 节点和可见节点继续共享同一条兼容渲染语义。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L132)
- quick-link 的 Iris 路径保持原有分层：当前命中描边、preview 线框、第三形态连线都仍在各自入口收集线段，只是最终全部汇入新的四边形直绘 helper。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L776) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L817) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L865)

## 2. 关键数据结构和算法性能分析

- `ColoredLineSegment` 现在只保留两端点与颜色，不再缓存 `normal`，因为四边形展开完全由 helper 内部按相机关系动态计算，减少了无效字段耦合。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L178)
- 侧向量算法分三步：
  - 先由 `pose` 变换得到相机相对坐标；
  - 用线段方向与视线方向叉乘得到面向相机的横向偏移；
  - 若近平行退化，再用“与线段最不平行的世界轴”兜底，避免边忽隐忽现。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L76) [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L107) [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L143)
- 复杂度保持线性：每条线段仍然只处理一次，时间复杂度 `O(n)`；但顶点数从每段 2 个提升为 4 个，Iris 分支的 fill-rate 和顶点提交开销会略增，不过范围只限于开启 Iris 且命中相关外显时。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L47) [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L127)
- 宽度按距离做上限约束放大，目标是避免远处完全细到不可见，同时限制过近时过粗遮挡；这是经验型参数，不影响算法稳定性，但仍属于后续可调项。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L159)

## 3. 数据流或调用链

- 定向箭头调用链：
  - world overlay 最终阶段扫描可见 block entity；
  - Iris 下走 `renderEnabledFaceVectorsIrisDirect(...)`；
  - 收集面向量线段后交给 `drawSegments(...)`；
  - `drawSegments(...)` 再把每段展开成四边形提交给 GPU。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L31) [DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L78) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L132) [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L35)
- quick-link preview / visualize 调用链：
  - `onLast(...)` 在 Iris 下分别进入当前命中轮廓与 preview 兼容路径；
  - 连线/轮廓先被转成 `ColoredLineSegment` 集合；
  - 最终统一由 `drawSegments(...)` 做直接绘制。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L227) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L776) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L817) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L883)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮仅改客户端渲染路径，不涉及序列化、网络协议、权限判定或 `triggerSource -> core` 真值写入，安全风险低。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L35)
- 性能：Iris 分支的每条线段顶点数翻倍，且增加了每段一次 `pose` 变换和若干向量运算；当前因为只在命中/智能眼镜/定向编辑等显示上下文触发，可接受，但若后续把更多大范围线框都接到此路径，建议补一层帧级批处理或距离裁剪。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L47) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L817)
- 兼容性：本轮明确只在 Iris 兼容分支内生效，非 Iris 路径没有被修改，因此普通客户端渲染语义保持稳定；但不同 shader pack 对 `PositionColor` 四边形的混合与观感仍可能有差异，建议继续做实机观察。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L143) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L865)
- 扩展性：`resolveFallbackAxis(...)` 和 `resolveHalfWidth(...)` 已经把“近平行兜底”和“宽度策略”封装成独立点，后续若要按 shader pack、FOV 或观察距离继续微调，只需要调整 helper 内部策略，不会再影响上层箭头/连线收集逻辑。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L143) [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L159)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 共享状态：本轮没有新增全局缓存、静态可变集合或跨线程共享数据；修改集中在 `IrisDirectLineRenderSupport` 的纯渲染 helper 内，输入是当前帧构造好的线段列表，输出是即时 GPU 提交。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L35)
- 线程边界：调用仍发生在客户端 render thread 的 world overlay 渲染阶段，没有把这段逻辑移出渲染线程，也没有引入异步准备或后台上传。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L31) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L227)
- 读改写覆盖：helper 只读传入线段，不反写上层缓存；因此不存在与 quick-link 可视化缓存、面集状态或节点数据的读改写冲突。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L883)
- RenderSystem 状态风险：本轮显式改动了 blend/depth/cull 状态，但都在 `try/finally` 中恢复，避免把状态泄漏到后续手部、HUD 或其它世界后置渲染路径；风险等级为低。[IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L40) [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L55)
