## 2. 关键数据结构和算法性能分析

- 服务端导出核心数据结构是 `nodes + edges + stats`，节点视图包含运行态、电平、连接模式、频道和 revision 字段，足够支撑只读分析和后续 OCC 基线扩展；序列化复杂度为 `O(V + E)`，未引入额外 JSON 依赖。[GraphSnapshotBundle.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotBundle.java#L11) [GraphSnapshotJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotJsonSupport.java#L25)
- `GraphSnapshotExportService` 按 `triggerSource` 遍历并查询当前可见边，再补齐可读 `core` 节点，整体仍是线性遍历思路；当前实现适合 `P3` 的手动导出链路，但当图规模继续增长时，导出耗时会主要受 `NodeSnapshotQueryService` 的单节点查询成本影响。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L37) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L151)
- 前端布局算法采用“按类型分列、按序号顺序下排”的两栏自动布局，复杂度为 `O(V)`；搜索是对节点字段的线性匹配，边高亮按 `matchedNodeKeys` 再做一次 `O(E)` 映射，满足当前“简单好用”的目标。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L94) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L138) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L210)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全方面：当前导出链路已经按玩家读权限裁剪可见节点和边，未直接暴露服务端真值，这一点是正确的；但额外的命令频率限制、操作者权限策略和超大图导出保护仍未补齐，后续应在命令入口或服务端处理器增加节流与权限门槛。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L37) [StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L292)
- 兼容性方面：当前 graph bundle 尚未显式携带独立 `formatVersion` 字段，前后端靠字段容错解析维持兼容；若后续进入 `P4/P5` 并增加编辑草稿、频道模式或更多状态字段，建议尽早补一个稳定版本号，降低旧资产兼容风险。[GraphSnapshotBundle.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotBundle.java#L11) [GraphSnapshotJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotJsonSupport.java#L25) [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L85)
- 扩展性方面：当前 `ReactFlow` 图页只做只读分析，没有本地 draft/dirty/save 状态机；这让 `P3` 边界明确，但也意味着后续进入编辑保存时需要再补一层本地草稿与显式保存流程，而不是直接在当前 viewer 上堆写逻辑。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L576) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L138)
- 性能方面：前端当前是整图一次性解析、整图一次性渲染，适合现阶段离线小中图分析；若后续图规模明显扩大，建议追加节点筛选分页、详情面板延迟统计以及更轻量的搜索结果列表裁剪。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L138) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L286)

## 5. 并发冲突审查

- 共享状态：服务端 graph 导出本身是只读行为，不修改 `LinkSavedData`，主线程处理后直接分块发包，因此不存在写写冲突；当前风险等级为低。[StatePanelNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkRegistrationSupport.java#L143) [StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L292)
- 客户端读改写覆盖：图快照分块重组使用 `PENDING_GRAPH_EXPORTS` 按文件名缓存并在齐包后落盘，若未来出现同名并发导出，后到请求会覆盖前一份临时缓存；当前由于文件名带 tick/revision/snapshot 后缀，实际碰撞概率较低，风险等级为低到中。[StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L24) [StatePanelNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/StatePanelNetworkClientHandlerSupport.java#L125)
- 线程边界：本地网页桥运行时通过 `volatile runtime + synchronized` 控制启动/停止，graph 页面跳转只是读取当前桥实例并打开 URI，没有额外共享写路径，风险等级为低。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L43) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L98) [LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L108)
- 前端重入：`GraphViewer` 在图快照切换时才重置布局，搜索和选中仅更新样式，不会把用户刚拖动的节点位置立即重置；当前没有自动保存或回传，因此不存在前端写回重入，风险等级为低。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L172) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L178)
