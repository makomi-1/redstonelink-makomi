# P2独立曲线页与指定文件加载

## 1. 功能与语义、架构设计（关键方法和入口）

- 本地网页桥接对 recording 资产的打开入口已改为直达 `page=recording&kind=recording&name=...`，而非继续落到首页，保证游戏内导出后直接进入独立曲线页。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L83)
- 网页入口 `App` 改成 query 参数驱动的双页面结构：`home` 负责资产入口，`recording` 负责独立录制曲线查看；地址构造与页面状态同步统一收敛到 `parseAppLocation()`、`buildAppHref()` 和 `syncAppLocation()`。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L85) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L104) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L332)
- recording 页内部新增“加载指定文件”入口，不再依赖首页资产列表充当间接选择器；文件索引继续来自本地 bridge 的 `/api/storage/index`，而实际 recording 文件内容通过 `/api/storage/entry` 按需读取。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L269) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L317) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L415)
- recording viewer 继续负责节点切换、曲线显隐和横坐标模式切换，而图表窗口交互正式下沉到 `RecordingChart`，形成“页级文件加载 -> viewer 状态 -> chart 交互”的清晰分层。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L27) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L42)

## 2. 关键数据结构和算法性能分析

- `AppLocation` 把 `page/kind/fileName` 收敛成单一 URL 状态模型，避免首页和 recording 页分别维护不一致的地址解析逻辑，降低页面切换时的状态分裂风险。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L47) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L85)
- recording 视窗算法仍然保留“真值窗口 + 完整域”的双结构，所有平移缩放都先在纯函数层完成，再回传给组件状态，因此鼠标拖拽、滚轮缩放和键盘快捷键可以共用同一套边界裁剪逻辑。[recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L85) [recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L145) [recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L182) [recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L209)
- `RecordingChart` 不再在每次窗口变化时重建整张图，而是把图表实例生命周期和 `xWindow` 缩放同步拆开，平移/缩放阶段只调用 `setScale('x', ...)`，降低交互过程中的重绘开销。[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L78) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L179)
- recording 页样式调整后，图表主容器尺寸从原先紧凑嵌入式布局扩大为专页主工作区，并给焦点态与文件选择栏留出固定位置，用户可见可操作面积明显提升。[App.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.css#L540) [App.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.css#L565) [App.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.css#L713)

## 3. 数据流或调用链

- 游戏内录制导出完成后，客户端 bridge 会把 recording 文件名拼进 `page=recording` 地址并打开本地网页，从而让本轮新增的 recording 专页成为默认入口。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L83)
- 网页启动后，`App` 先读取 query 参数，再读取资产索引；当页面为 recording 且 `name` 已给出时，会自动命中对应 recording 资产并加载内容，否则停留在“请选择 recording 文件”的空状态。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L145) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L201) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L228)
- `RecordingViewer` 根据当前 recording 文件选择节点、推导完整时间域和当前时间窗，再把 `samples/xWindow/fullDomain` 交给 `RecordingChart`，其中 `setRecordingWindow` 作为唯一窗口写入口继续由 viewer 持有。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L34) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L54) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L176)
- `RecordingChart` 通过滚轮、拖拽、双击和键盘事件采集用户意图，把窗口变换统一落到 `onWindowChange/onResetWindow` 回调，避免图表组件直接改写 bundle 或 URL 状态。[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L187) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L257)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全边界方面，本轮没有扩大 bridge 的读写能力，只是改变了前端页面和 URL 入口，因此没有新增本地文件写回风险；recording 文件仍然只能通过既有 bridge API 按 `kind/name` 读取。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L269) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L317)
- 性能方面，独立 recording 页把首页资产索引和曲线查看拆开后，用户实际操作时不再需要同时渲染左侧大索引和右侧图表；再配合 `setScale` 式窗口更新，交互过程的抖动风险低于上一版按钮式整页嵌入布局。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L371) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L179)
- 兼容性方面，本轮没有改 recording bundle 格式，也没有改录制协议，只是换了打开方式和前端交互，因此旧 recording 文件仍可被当前 viewer 直接加载。[recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L55)
- 扩展性方面，当前 URL 模型已经预留 `page`，后续若要继续拆分 graph/editor 页面，可以复用同一套路由化 query 结构，而不必引入额外路由框架。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 客户端 bridge 跳转改动只发生在 `openAssetEntry()` 的 URI 构造阶段，不引入新的共享可变状态，风险等级低。[LocalWebAppBridgeService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/web/LocalWebAppBridgeService.java#L83)
- 前端页状态主要集中在 `App` 的 `appLocation`、首页预览状态和 recording 文件状态三组 React state，中间没有跨线程共享，竞争风险低；唯一需要注意的是地址栏变化与异步读取之间的同步，本轮通过 `appLocation + useEffect` 单向收敛处理。[App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L145) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L205) [App.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L228)
- 图表交互中的拖拽状态被限制在 `RecordingChart` 内部的 `dragStateRef/currentWindowRef/fullDomainRef`，只在浏览器主线程事件循环中读写，没有和其他组件形成共享写覆盖，风险等级低；后续如果要做多图联动，建议把当前窗口提升到更高层并显式序列化更新顺序。[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L56) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L187)
