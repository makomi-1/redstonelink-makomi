# 26.1 渲染基础设施迁移

## 1. 功能与语义、架构设计（关键方法和入口）

- 本次迁移把 quick-link 世界描边、preview、第三形态连线，以及定向面箭头统一收敛为“先收集世界空间几何，再走穿墙渲染管线”的架构，核心入口分别落在 [DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L25) 与 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L205)。
- 定向面箭头不再直接写 `bufferSource`，而是由 [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L62) 统一输出世界空间线段，保持 `triggerSource/core` 对应节点主题色与 `core/repeater` 方向反转语义不变。
- quick-link 普通分支继续走 level 渲染事件，但命中描边、preview 和第三形态连线都改为复用 [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L69)；Iris/Sodium 兼容分支则由 [IrisRenderCompatSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/IrisRenderCompatSupport.java#L19) 决策，再委托 [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L29) 把线段展开为面向相机的四边形。

## 2. 关键数据结构和算法性能分析

- 统一的 `ColoredLineSegment` / `ColoredQuad` 数据结构集中定义在 [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L333)，把颜色、法线和世界空间端点从业务渲染器抽离出来，降低了渲染入口之间的重复逻辑。
- 定向面箭头的几何展开仍保持线性复杂度，`collectEnabledFaceVectors` 仅按启用面数量生成箭头主干与四个箭头头部短线，关键实现位于 [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L101) 与 [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L144)。
- Iris/Sodium 兼容分支的成本主要来自“线段转四边形”，每条线段额外做一次视线叉积和厚度计算，复杂度仍为 O(n)，实现位于 [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L55)。

## 3. 数据流或调用链

- 定向面箭头链路为：`END_MAIN` 事件触发 [DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L29) → 逐区块筛选目标方块实体 → [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L62) 生成世界空间线段 → 普通分支走 [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L69) / 兼容分支走 [IrisDirectLineRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/IrisDirectLineRenderSupport.java#L29)。
- quick-link 命中描边链路为：`BEFORE_BLOCK_OUTLINE` 进入 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L81) → 解析节点颜色与命中体积 → [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L803) 拆解边界线段 → 普通分支立刻穿墙提交，兼容分支延后到 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L742) 重绘。
- quick-link preview 与第三形态链路为：`BEFORE_TRANSLUCENT_TERRAIN` 进入 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L125) 处理普通分支 preview → `END_MAIN` 进入 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L145) 处理兼容分支 preview/命中描边及全部第三形态连线 → 第三形态实际提交位于 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L847)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性方面，本次显式保留 26.1 的 `net.fabricmc.fabric.api.client.rendering.v1.level.*` 事件与上下文接口，没有把 1.21.11 的 `world` 事件直接搬入，关键适配点在 [DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L25) 与 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L205)。
- 渲染性能方面，当前实现仍按视距扫描区块方块实体与缓存对象，普通分支主要增量成本是一次 world-space 线段收集；若后续 visualized 对象数量明显上升，可优先考虑在 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L847) 前增加更细粒度的视锥或距离裁剪。
- 扩展性方面，quick-link 旧的专用穿墙线管线已经被公共几何支撑替代，关闭路径也统一收敛到 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L349)；后续过滤器范围、更多世界外显若也要“穿墙可见”，应优先复用 [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L69) 而不是再建独立管线。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 当前新增的共享状态主要是穿透渲染公共类里的 GPU/CPU ring buffer，集中生命周期管理位于 [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L141)；调用侧只在客户端渲染线程事件中访问，线程边界与原有渲染入口一致，风险等级为低。
- quick-link 既有的 preview/visualized 缓存仍保持原有单线程客户端访问模型，新增改动没有扩大共享可变状态面，关闭路径统一收敛到 [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L330)。
- 建议后续若要把同一公共渲染支撑扩展到异步数据准备场景，必须保持“异步线程仅准备不可变几何数据、渲染线程独占 GPU 提交”的边界，避免直接跨线程读写 [SeeThroughWorldGeometryRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-26.1/src/client/java/com/makomi/client/render/SeeThroughWorldGeometryRenderSupport.java#L60) 的缓冲引用。
