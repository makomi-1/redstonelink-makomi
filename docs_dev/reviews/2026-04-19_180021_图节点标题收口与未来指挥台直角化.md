# 图节点标题收口与未来指挥台直角化

## 1. 功能与语义、架构设计

本轮改动聚焦三个前端目标：删除首页、让根路由直接落到 graph 页面；收口图中实际节点标题，只强调序号与别名；让“未来指挥台”主题先落一版直角硬边风格。整体实现仍保持原来的页面分层，`App` 只负责路由与数据装配，`canvas` 只负责图节点展示，主题风格继续通过 CSS token 与页面属性组合生效。

- 根路由与页面分发现在只保留 graph / recording 两个分支，入口见 [App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L237) 与 [App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L260)
- 路由语义从类型层移除了 `home`，见 [types.ts](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/types.ts#L49)
- 根地址默认解析为 graph，见 [location.ts](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/location.ts#L7)
- 图中实际节点标题已独立改为画布专用格式，不再复用全局 `displayText`，见 [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L61)

## 2. 关键数据结构和算法性能分析

这次没有新增复杂算法，关键变化是“展示口径拆分”与“主题半径 token 化”。节点标题层面只增加了一个轻量字符串格式函数，不影响布局算法和边构建流程；主题层面主要是静态 CSS 变量与选择器覆写，运行时成本仍然接近原实现。

- 画布节点标题由独立函数生成，避免修改全局 `displayText` 造成连锁影响，见 [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L61)
- 图节点、聚合块、频道节点的圆角已改为读取主题变量，见 [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L232)、[canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L266)、[canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L298)
- 默认半径与未来指挥台半径覆写都在 CSS token 中声明，见 [app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L120) 与 [app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L227)
- 未来指挥台的直角控件覆写集中在一处，不引入新的运行时分支，见 [app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L232)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全层面本轮未涉及后端接口、权限或持久化协议，风险低。性能层面主要是样式与标签改动，没有引入新的重排热点。兼容性方面，删除首页后，用户默认进入 graph 页面，这与旧的入口行为不同，但测试已经覆盖默认 graph 路由和 recording 直接进入。扩展性方面，当前“未来指挥台”的直角化是通过主题块单独覆写实现的，后续若要把这种硬边风格扩展到其它主题，建议继续沿用 token / 主题块方式，不要再回退到散落的硬编码半径。

- 默认 graph 路由与主题状态同步测试见 [App.test.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.test.tsx#L44)
- graph 页面基础交互测试已同步去掉首页依赖，见 [GraphPage.test.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/GraphPage.test.tsx#L19)
- 未来指挥台直角化的样式入口集中在 [app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L232)

## 5. 并发冲突审查

本轮没有新增共享可变状态，也没有引入异步并发写冲突。主要的“并发”风险仍来自前端状态切换时的语义漂移：例如将画布标签和全局 `displayText` 混用会导致多个视图口径串扰。这次通过把画布专用标题单独拆出来，降低了展示层互相覆盖的风险。整体并发风险等级为低。

- 画布专用标题拆分点在 [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L61)
- 路由状态仍集中在 `App` 内部，未扩散到新的共享存储，见 [App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L24)
- graph / recording 页面头部去掉首页跳转后，状态切换路径更简单，见 [GraphPage.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/GraphPage.tsx#L54) 与 [RecordingPage.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/RecordingPage.tsx#L50)
