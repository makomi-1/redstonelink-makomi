# 成就系统判定优化

## 1. 功能与语义、架构设计（关键方法和入口）

- 本轮把“创造模式不参与成就系统”前移到条件型成就入口：`awardComeFindMeInTheEndIfMatched(...)` 与 `awardConstellationIfThresholdReached(...)` 在进入业务匹配前先做 `isEligibleGameMode(player)` 短路，避免创造模式继续执行“跨维激活匹配”和“跨阈值判断”，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L48)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L78)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L98)。
- 同时新增统一的“已达成短路”收口：`awardIfEligible(...)` 现在先通过 `resolveAwardableAdvancement(...)` 解析成就定义、检查模式是否合法、并通过 `isAdvancementAlreadyAwarded(...)` 拦掉已完成成就，再进入最终 `award(...)`，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L150)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L160)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L170)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L183)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L193)。
- 单测补齐了两类关键语义：`isEligibleGameMode(GameType)` 保证只有生存类模式允许进入成就处理，`shouldProcessAward(GameType, boolean)` 保证已达成成就不会继续进入统一发奖流程，见 [RedstoneLinkAdvancementServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/advancement/RedstoneLinkAdvancementServiceTest.java#L66)、[RedstoneLinkAdvancementServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/advancement/RedstoneLinkAdvancementServiceTest.java#L77)。
- 语义对齐说明：本轮只收紧成就判定路径，不修改成就定义、业务事件语义或 `triggerSource/core` 方向语义；修复层次是“成就服务与测试”，不是玩法语义变更。残余风险：无。

## 2. 关键数据结构和算法性能分析

- 条件型成就在创造模式下现在是 `O(1)` 提前返回，不再进入 `shouldAwardComeFindMeInTheEnd(...)` 或 `reachesConstellationThreshold(...)`；这直接减少了无效事件上的业务判定开销，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L53)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L83)。
- 已达成短路复用了原有 `AdvancementHolder` 与玩家进度对象，没有引入新的缓存、Map 或额外持久化结构；新增 helper 只是把“模式判断 / 成就解析 / 已达成判断”拆成单职责函数，复杂度仍为常数级，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L140)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L150)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L170)。
- 这次没有把“已达成短路”继续前移到所有条件型业务匹配前，原因是 `isAdvancementAlreadyAwarded(...)` 需要借助玩家进度对象判断；当前实现刻意把它保留在统一发奖口，避免把额外状态读取副作用过早扩散到所有事件路径。这个取舍让性能提升集中在创造模式和重复发奖尝试两处高价值节点，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L160)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L193)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性：本轮没有修改 `data/redstonelink/advancement/*.json` 成就定义，也没有改默认 criterion 名称 `unlock`，因此玩家现有存档与进度文件的兼容性不受影响，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L21)。
- 性能收益：创造模式下条件型成就不再进入业务匹配；已解锁成就在统一发奖口会被拦下，避免重复调用 `award(...)`。这两处都属于高频事件的低成本剪枝，收益明确且实现面集中，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L53)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L170)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L193)。
- 风险与建议：已达成短路没有继续前移到所有条件型业务匹配之前，这是有意为之。原因是当前玩家进度查询 API 需要依赖进度对象判断，过早前移会把额外状态读取扩散到所有条件事件。后续如果项目引入无副作用的“是否已完成”查询接口，可以再把这层短路前移到更早。风险等级：低，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L160)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L170)。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 共享状态：本轮没有新增 mod 内部共享状态，只是复用原生 `PlayerAdvancements` 与现有成就定义；新增 helper 也都只是只读决策或最终一次 `award(...)` 调用，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L150)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L183)。风险等级：低。
- 读改写覆盖：统一发奖口现在先做“模式合法 + 未完成”判定，再决定是否调用 `award(...)`，可避免多个业务入口在已完成成就上重复尝试写入同一 criterion；这降低了重复写路径但不改变最终结果一致性，见 [RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L133)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L170)、[RedstoneLinkAdvancementService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/advancement/RedstoneLinkAdvancementService.java#L193)。风险等级：低。
- 重入与线程边界：现有成就触发仍全部发生在服务端主线程业务事件里，本轮没有新增异步任务、延迟任务或跨线程缓存；命令、方块实体、物品和网络处理器仍沿用原有线程边界。建议继续保持成就发放只在服务端线程触发。残余风险：无，见 [ActivateCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/activate/ActivateCommandRegistry.java#L196)、[TriggerSourceBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/TriggerSourceBlockEntity.java#L112)、[StatePanelNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/StatePanelNetworkServerHandlerSupport.java#L158)、[LinkSetExecutionService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkSetExecutionService.java#L375)。
