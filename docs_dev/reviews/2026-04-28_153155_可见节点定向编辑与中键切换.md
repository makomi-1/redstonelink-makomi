# 可见节点定向编辑与中键切换

## 1. 功能与语义、架构设计

- 本轮把 `core` 的定向输出能力下沉到基类 `LinkCoreBlock`，默认全向启用面集；隐藏核心仅保留“默认空面集 + 隐藏交互外形”，不再重复维护输出裁剪逻辑。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L51) [LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L134) [HideCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideCoreBlock.java#L29)
- 同步 `triggerSource` 的定向输入能力同样下沉到 `LinkSyncEmitterBlock`，默认全向采样；隐藏同步节点只保留“默认空面集 + 隐藏外形”。这样可见/隐藏节点共享同一套输入语义，而 `toggle/pulse triggerSource` 不会被带入本轮范围。[LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L22) [LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L90) [HideSyncTriggerSourceBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java#L24)
- 定向编辑器现在支持所有 `LinkCoreBlock` 与 `LinkSyncEmitterBlock` 子类，并继续对 `core` 使用“点击逻辑输出面，写入相反存储面”的映射，保持显示方向、编辑方向和运行时输出方向一致。[DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L42) [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L90) [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L121)

## 2. 关键数据结构和算法性能分析

- 关键数据结构仍然是 `NodeFaceSetBlockStateSupport` 提供的 6 个 `face_*` 布尔属性。本轮没有新增持久化表或运行时缓存，只是把这些属性扩展到可见 `core / sync triggerSource`，因此额外成本仅是更大的 `BlockState` 组合空间。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L160) [LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L84)
- `core` 输出裁剪是 `O(1)`：读取单个方向布尔并决定返回真实功率或 `0`，不会引入额外邻居扫描。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L134)
- 同步 `triggerSource` 输入裁剪是 `O(k)`，其中 `k <= 6`。实现上只遍历当前启用面，按邻位输入取 `max`，上限固定，因此不会引入可感知的复杂度抖动。[LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L90)
- 中键切换模式的数据流是单个空载荷包，服务端只对主手栈做一次 `cycleMode` 和一次菜单同步，开销常数级。[DirectionalFaceEditorNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkRegistrationSupport.java#L19) [DirectionalFaceEditorNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkServerHandlerSupport.java#L19)

## 3. 数据流或调用链

- 可见/隐藏 `core` 的信号链现在统一是：`BlockState.face_* -> LinkCoreBlock.getSignal/getDirectSignal -> LinkCoreBlockEntity.resolveOutputPower`。隐藏核心只改默认面集和命中形状，不再改信号链本身。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L134) [HideCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideCoreBlock.java#L49)
- 可见/隐藏同步 `triggerSource` 的输入链统一是：`BlockState.face_* -> LinkSyncEmitterBlock.resolveInputSignalStrength -> updatePoweredState/forwardLinkedSignal`。这样编辑工具改的是统一面集真值，而不是两套平行逻辑。[LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L90)
- 中键切换链路现在是：`RedstoneLinkClient` 捕获主手中键边沿 -> 若主手为定向编辑器则发 C2S -> 服务端接包校验主手 -> 回写 `HideDirectionalEditorToolData` 并提示玩家。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L209) [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L302) [DirectionalFaceEditorNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkRegistrationSupport.java#L24) [DirectionalFaceEditorNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkServerHandlerSupport.java#L19)
- 自动化验证链路覆盖了两类默认行为和两类定向行为：`hide` 节点默认空面集后启用单面，可见节点默认全向后改成单面；这样既验证新默认值，也验证面集裁剪本身。[HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L89) [HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L117) [HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L144) [HideNodeDirectionalIntegrationTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/integration/HideNodeDirectionalIntegrationTest.java#L167)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性风险低：新网络通道只接受空载荷，且服务端再次校验“主手必须是定向编辑器”，因此客户端不能借这个入口越权修改其它物品状态。[DirectionalFaceEditorNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkRegistrationSupport.java#L24) [DirectionalFaceEditorNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkServerHandlerSupport.java#L25)
- 兼容性风险可控：可见 `core / sync triggerSource` 以前没有面集属性，本轮新增后按“默认全向”加载，能保持历史行为；`hide` 节点默认值改为空，但老世界中已有 `face_*` 值的方块不会被强制重置。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L51) [LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L22)
- 性能风险低：输入采样最多遍历 6 个方向，输出裁剪为单次布尔判定，本轮不会引入新的 SavedData、全局扫描或定时任务。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L134) [LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L90)
- 扩展性建议：如果后续还要把面编辑推广到 `LinkRedstoneDustCoreBlock` 或其它节点，最好继续沿用“在具体语义基类下沉面集逻辑”的方式，而不是再把逻辑写回某个特例子类，避免重新分叉运行时语义。[LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L160) [LinkSyncEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncEmitterBlock.java#L84)
- 资源风险提示：`hide` 节点物品模型已经接入专属贴图，但贴图文件本身当前仍处于未跟踪状态；若后续提交要包含这次物品外观变化，需要把这两个 PNG 一并纳入版本控制。[hide_core.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/hide_core.json#L1) [hide_sync_trigger_source.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/hide_sync_trigger_source.json#L1)

## 5. 并发冲突审查

- 共享状态 1：主手物品 `CUSTOM_DATA`。中键切换现在由客户端发送一次请求、服务端单点回写主手栈，并通过 `containerMenu.broadcastChanges()` 同步，因此不存在客户端和服务端同时写不同模式的竞态；风险等级低。[DirectionalFaceEditorNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkServerHandlerSupport.java#L25)
- 共享状态 2：客户端中键分流。当前入口按“主手容器 -> 主手 quick-link -> 主手定向编辑器”顺序短路，避免一次中键同时触发多个系统；风险等级低。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L302)
- 读改写覆盖：面编辑对 `BlockState` 的写入仍然是整块替换，但只在明确命中 `LinkCoreBlock / LinkSyncEmitterBlock` 且状态带 `face_*` 时触发，不会误改其它节点；风险等级低。[DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L42)
- 重入/线程边界：网络接包通过 `player.server.execute(...)` 切回服务端主线程处理，不存在异步线程直接改物品栈或世界方块的重入风险；风险等级低。[DirectionalFaceEditorNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/DirectionalFaceEditorNetworkRegistrationSupport.java#L24)
