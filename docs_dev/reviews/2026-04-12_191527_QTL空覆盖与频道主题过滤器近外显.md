- QTL 模式视觉被拆成“持久化镜像 + GUI 主题”两层：物品侧由 `QuickLinkToolData.write` 和 `QuickLinkToolItem.inventoryTick` 维护 `CustomModelData`，界面侧由 `QuickLinkToolScreen` 的 `Theme` 记录和 `GuiHeaderContextSupport` 的副标题配色切换 serial/channel 主题。[QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L50) [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L155) [QuickLinkToolItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/QuickLinkToolItem.java#L64) [QuickLinkToolScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/QuickLinkToolScreen.java#L73) [GuiHeaderContextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/GuiHeaderContextSupport.java#L51)
- 过滤器近外显采用“HUD 命中分流 + 本地快照组装”的结构，不新增网络协议，直接复用过滤器方块实体已有同步快照和邻居输入采样能力。[LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L97) [LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L173) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L159)

## 2. 关键数据结构和算法性能分析

- 空缓存覆盖没有引入新的全图扫描，仍复用现有 `Set` / `LinkedHashSet` 构造下一跳集合；复杂度保持在“当前一跳规模 + 缓存规模”量级。[QuickLinkApplyService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkApplyService.java#L449) [QuickLinkApplyService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkApplyService.java#L473) [QuickLinkApplyService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkApplyService.java#L496)
- 过滤器近外显不走额外 C2S/S2C 请求，文本构建仅对命中对象执行一次本地格式化；节点集显示仍复用现有截断逻辑，避免长表达式直接撑爆 HUD 宽度。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L159) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L312)
- QTL 物品贴图镜像是 O(1) 的组件写入；`inventoryTick` 只做模式判定和单个 `CustomModelData` 组件增删，开销与同步遥控器现有方案一致。[QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L155) [QuickLinkToolItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/QuickLinkToolItem.java#L64)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全：本轮没有新增 API v1 依赖，也没有放宽 quick-link 的目标合法性校验；空缓存仅在服务端确认 `REPLACE` 时生效，仍走原有节点/过滤器目标校验链路。[QuickLinkApplyService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkApplyService.java#L43) [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L98)
- 性能：过滤器近外显已经避免新增网络轮询，但英文长文案仍可能在极窄分辨率下偏宽；若后续继续增加字段，建议补自适应截断或双列排版，而不是继续横向堆叠。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L159) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L364)
- 兼容性：旧物品即使缺少镜像组件，也会在 `inventoryTick` 被自动修正；因此这轮没有引入额外迁移步骤。残余边界是 `channel` 仍只提供缓存与主题，不开放 collect/apply，后续功能扩展时需继续复用当前镜像约定。[QuickLinkToolItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/QuickLinkToolItem.java#L64) [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L155)
- 扩展性：过滤器近外显的文本解析已经拆成节点集模式、信号模式、阈值来源三个 helper，后续若新增过滤器字段，可以局部扩展文本生成而不需要改动渲染入口。[LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L340) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L352) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L364)

## 5. 并发冲突审查

- 共享状态：QTL 物品缓存仍是主手 `ItemStack` 上的单份 `CUSTOM_DATA/CUSTOM_MODEL_DATA`，客户端本地按键和服务端保存包都只围绕同一快照更新，没有新引入的跨物品共享容器。风险等级：低。[QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L50) [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L155)
- 读改写覆盖：客户端 `inventoryTick` 只负责镜像贴图，不会改写业务缓存字段；真正的业务状态仍由 `SaveQuickLinkPayload` 和服务端写回统一落盘，因此不会把渲染镜像反向覆盖业务数据。风险等级：低。[QuickLinkToolItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/QuickLinkToolItem.java#L64) [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L36)
- 线程边界：近外显渲染和文本组装都发生在客户端渲染线程，服务端应用逻辑仍在主线程网络处理上下文执行；本轮没有新增异步任务、缓存线程或并行集合。风险等级：低。[LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L82) [QuickLinkApplyService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkApplyService.java#L31)
