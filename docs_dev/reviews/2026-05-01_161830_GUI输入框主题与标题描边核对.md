# GUI输入框主题与标题描边核对

## 1. 功能与语义、架构设计
- 多行输入框的恢复方案没有改动各个 screen 的调用面，而是在工厂层把实例切回真正可主题化的兼容类，避免每个界面各自补渲染逻辑。[ShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/ShadowlessCounterMultiLineEditBox.java#L22) [StyledMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/StyledMultiLineEditBox.java#L22)
- 兼容层被收敛到 Minecraft 同包下的两个薄子类：基础类只处理无阴影计数，主题类只补背景与边框，职责边界和原 1.21.1 设计保持一致。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L16) [RedstoneLinkStyledMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkStyledMultiLineEditBox.java#L14)
- 别名单行输入框采用最小修复，只在现有主题壳上显式关闭文本阴影，不改变原有布局和交互路径。[StyledEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/StyledEditBox.java#L26)

## 2. 关键数据结构和算法性能分析
- 多行输入框新增的数据结构只有几组常量主题色与一个 `characterLimit` 缓存，绘制时仍是 O(1) 的矩形填充和单次计数文本绘制，不会引入新的复杂度热点。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L17) [RedstoneLinkStyledMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkStyledMultiLineEditBox.java#L15)
- 透明度处理沿用控件自身 `alpha` 混合到 ARGB 的方式，避免额外分配对象或引入多余渲染状态切换。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L74) [StyledEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/StyledEditBox.java#L100)
- 装饰层选择保留 `super.renderDecorations(...)` 的新版滚动条实现，只追加无阴影计数字体，避免重写新版内部滚动算法带来的维护成本和潜在回归。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L45)

## 3. 数据流或调用链
- Screen 仍通过 `createSerialInputBox(...)` 创建多行输入框，调用先进入 `StyledMultiLineEditBox.create(...)` 或 `ShadowlessCounterMultiLineEditBox.create(...)`，再落到同包兼容子类实例。[AbstractMultiPairingScreen.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/AbstractMultiPairingScreen.java#L754) [ChunkActivatorEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/ChunkActivatorEditorScreen.java#L277) [LinkFilterEditorScreen.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/LinkFilterEditorScreen.java#L598)
- 多行输入框的实际渲染链现在是：原版文本编辑与滚动装饰由 `MultiLineEditBox` 负责，`RedstoneLinkShadowlessCounterMultiLineEditBox` 在装饰阶段补无阴影计数，`RedstoneLinkStyledMultiLineEditBox` 在背景阶段补主题壳。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L45) [RedstoneLinkStyledMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkStyledMultiLineEditBox.java#L43)
- 别名输入框的占位字仍由原版 `EditBox` 渲染，但因为构造时显式关闭了 `textShadow`，因此提示字与正文统一走无阴影路径。[StyledEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/StyledEditBox.java#L40)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 兼容层放在 `net.minecraft.client.gui.components` 同包，目的是拿到 `MultiLineEditBox` 当前版本的扩展入口；这在客户端兼容层里可行，但应保持实现极薄，避免未来 Mojang 改内部类时放大维护面。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L8)
- 当前方案没有重写新版滚动条，只保留无阴影计数和主题背景，因此与 1.21.11 内部滚动实现的兼容性更稳；代价是滚动条细节继续以新版原版为准，而不是完全冻结在 1.21.1 外观上。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L45)
- 标题描边本轮未改，当前仍是手写四向描边且无阴影；如果后续要继续追原版 `drawInBatch8xOutline`，需要单独验证 1.21.11 GUI 提交流程，不应和本轮输入框修复混做。[GuiTitleRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/GuiTitleRenderSupport.java#L39)

## 5. 并发冲突审查
- 本轮改动全部落在客户端 GUI 线程使用的控件和工厂类，没有新增共享可变全局状态；`characterLimit` 与主题色字段都绑定在控件实例上，不跨 screen 共享。[RedstoneLinkShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkShadowlessCounterMultiLineEditBox.java#L20) [RedstoneLinkStyledMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/net/minecraft/client/gui/components/RedstoneLinkStyledMultiLineEditBox.java#L15)
- 工厂层只是同步创建新控件实例，不持有缓存，不存在读改写覆盖风险；screen 重新 `init()/resize()` 时也会按现有流程重建组件。[ShadowlessCounterMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/ShadowlessCounterMultiLineEditBox.java#L22) [StyledMultiLineEditBox.java](/d:/OpenProjects/RedstoneLink/rl-fabric-1.21.11/src/client/java/com/makomi/client/screen/StyledMultiLineEditBox.java#L22)
- 风险等级为低。主要剩余风险不是并发，而是 GUI 视觉验收：需要进游戏确认多行输入框主题与别名占位字无阴影是否完全符合原设计。
