## 1. 功能与语义、架构设计（关键方法和入口）

- 频道模式的聚合显示收敛新增了可配置口径，`resolveCanvasAggregateVisibility` 现在允许按模式决定是否把“成员可见”提升为“聚合已展开”，为频道模式关闭了这条自动提升链路。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L497)
- 频道模式里的 `core` 与 `triggerSource` 聚合都改成只看显式展开 key 集合，不再因为成员节点被强制显示而自动变成展开态，因此聚合块可以恢复为稳定的收起状态。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1041) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1090)
- 聚合块点击交互从“纯 toggle”改成“根据当前画布聚合节点状态设置为展开或收起”，修掉了视觉态和显式状态漂移时点击方向错误的问题。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1193) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1212)
- 搜索匹配从 `includes` 模糊匹配改成标准化后的精确等值匹配，类型筛选逻辑保持不变，只收紧命中条件。[search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L4) [search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L26)

## 2. 关键数据结构和算法性能分析

- 聚合可见性仍然基于 `Set<string>` 收集画布边与强制显示节点，复杂度维持在线性级；本轮新增的只是一个布尔开关，没有引入额外的高复杂度结构。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L497)
- 频道聚合展开态从“显式展开 + 成员强制显示”收缩到“仅显式展开”，减少了因为搜索、选中、草稿差异带来的连锁成员展开，渲染节点数在频道模式下会更稳定。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1045) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1094)
- 搜索逻辑把每个候选字段做 `trim + lowercase` 后直接做相等比较，避免了模糊搜索导致的广泛命中和额外画布重算，但命中范围会更严格。[search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L4) [search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L31)

## 3. 数据流或调用链

- `GraphViewer` 先根据已应用的搜索词和类型筛选得到 `matchedNodes`，再把命中集合并入 `forcedVisibleNodeKeys`，最后交给 `buildGraphCanvasView` 构造画布视图。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L187) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L255)
- 频道模式的数据流仍是“channel hub 基础边 -> 两类聚合边 -> 最终可见节点收敛”，但本轮在最终收敛入口显式关闭了“成员可见即展开”的提升逻辑。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1119) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1146)
- 用户点击聚合块后，`handleCanvasNodeClick` 先读取当前 `graphCanvasView.aggregateNodes` 中对应聚合块的实际展开态，再写回显式展开集合并触发布局刷新，确保交互与当前画布状态一致。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1212)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 语义边界未变，本轮只改前端视图层和搜索逻辑，真实保存语义仍然只处理 `triggerSource -> core`，未触及 snapshot、draft、服务端真值，也未引入 `com.makomi.api.v1.*`。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1041) [search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L26)
- 兼容性风险在于：频道模式关闭自动视觉展开后，如果成员节点因选中或搜索被强制显示，聚合块本体可能保持收起文案。这是为修复“自动展开且无法收起”优先做出的交互取舍，后续如需更强一致性，可以再引入单独的“临时揭示但不算展开”表现层。[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L497) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L1153)
- 回归验证方面，`buildWebapp` 与前端类型检查通过，但全量测试被 `LinkSavedDataPerformanceSlowTest` 的性能基线断言拦住，失败点是慢测性能阈值，不是本轮前端逻辑断言失败；仍需单独跟踪该慢测基线波动。[LinkSavedDataPerformanceSlowTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkSavedDataPerformanceSlowTest.java#L72)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 本轮改动仍然局限于 React 前端本地状态与纯函数视图构建，没有新增跨模块共享可变状态；`expandedAggregateNodeKeys` 仍通过 React `useState` 单线程更新，风险低。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L124) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1193)
- 聚合点击交互现在从读当前画布状态再写显式集合，属于单次事件内的读改写闭环，没有引入异步竞争；剩余风险主要是 React 重渲染过程中用户快速连点带来的普通状态覆盖，这和现有交互模型一致。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1212)
- 搜索匹配逻辑是纯函数，无共享状态，无并发冲突风险；频道聚合可见性收敛也只操作当前计算周期内的局部 `Set` 和数组，线程边界清晰。[search.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/search.ts#L26) [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L497)
