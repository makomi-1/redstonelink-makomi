# 智能眼镜贴图接线与连线坐标显示

## 1. 功能与语义、架构设计
- 智能眼镜不再复用原版铁头盔物品图标，物品模型已切到模组现有贴图资源 [smart_glasses.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/smart_glasses.json#L1)。这保证背包图标和你准备的 `smart_glasses.png` 真正接通。
- 穿戴外显没有改模型，而是给智能眼镜挂了一个只负责贴图解析的专用护甲材质层；实现集中在 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L25) 和注册入口 [ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L163)。这样仍走原版头盔渲染模型，但材质贴图改为模组自己的 `smart_glasses_layer_1`。
- 第三形态连线悬停目标现在会额外携带另一端方块坐标；目标构造与记录定义位于 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L370) 和 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L1225)，HUD 调用位于 [LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L295)。

## 2. 关键数据结构和算法性能分析
- 智能眼镜专用护甲材质通过 `Holder.direct(new ArmorMaterial(...))` 直接内嵌在物品类中，防御映射统一置零，避免为只读贴图链路额外引入注册表或数据包复杂度；关键代码见 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L33) 与 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L70)。
- 连线悬停算法本身未变化，仍然复用现有的射线与线段最近点求解；本次只是在命中候选里多透传一个 `blockPosLong` 字段，不额外增加新的空间扫描或几何计算，见 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L356)。
- HUD 坐标格式化只在命中目标后做一次 `BlockPos.of(...)` 和字符串拼接，复杂度为 O(1)，实现位于 [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L547)。

## 3. 数据流或调用链
- 物品贴图链路：物品注册 [ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L163) 创建 `SmartGlassesItem`，物品模型 [smart_glasses.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/smart_glasses.json#L1) 解析到 `redstonelink:item/smart_glasses`，最终显示背包图标。
- 穿戴贴图链路：`SmartGlassesItem` 在 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L33) 构造专用 `ArmorMaterial.Layer`，让客户端头盔渲染链路解析到 `smart_glasses_layer_1`；由于物品类型仍是 `HELMET`，只会消费 `layer_1` 中的头部 UV 区域。
- 连线坐标链路：命中解析在 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L370) 把目标 `blockPosLong` 填入 `HoveredVisualizedTarget`，HUD 渲染入口 [LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L302) 把它交给 [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L547) 生成坐标行。

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全/兼容性：本次没有放宽任何交互权限判断，只改了智能眼镜的资源绑定与 HUD 表达层；连线可视化是否可用仍由既有智能眼镜判定控制，相关上下文仍在 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L202)。
- 性能：悬停 HUD 只多传一个 `long` 并多做一次 `BlockPos.of(...)`，相比既有射线命中算法几乎没有额外成本；主要热点仍然在原有最近点求解逻辑 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L356)。
- 扩展性：当前实现坚持“只改贴图、不改模型”，因此视觉轮廓仍受默认头盔模型约束；如果后续要做真正的眼镜立体轮廓，应在此基础上再引入自定义头部渲染模型，而不是继续堆贴图技巧。
- 自动化验证已覆盖坐标链路与悬停对象链路，见 [LinkSerialHudOverlayTextSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/render/LinkSerialHudOverlayTextSupportTest.java#L152) 和 [QuickLinkOutlineRendererTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/client/render/QuickLinkOutlineRendererTest.java#L89)。

## 5. 并发冲突审查
- 共享状态方面，本次没有新增新的全局可变容器；智能眼镜材质是不可变静态常量 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L33)，连线悬停仍复用既有 `visualizedObjects` 读路径 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L356)。
- 读改写覆盖方面，HUD 新增的坐标显示只消费 `HoveredVisualizedTarget` 只读快照，不会反写任何可视化集合；调用点位于 [LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L295)。
- 线程边界方面，本次改动仍运行在客户端渲染/输入主线程和测试线程内，没有引入新的异步任务、锁或网络写入路径；风险等级低。
- 建议：如果后续还要在悬停 HUD 里追加维度名或更多节点信息，应继续沿用 `HoveredVisualizedTarget` 只读快照扩展字段，避免让 HUD 反向读取世界状态导致渲染线程耦合上升；当前快照定义见 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L1225)。
