# 移除频道前端归一化并保留多数类型聚焦

## 1. 功能与语义、架构设计

- `GraphViewer` 继续保留“批量应用草稿后按当前选区里 `triggerSource/core` 哪类更多来决定聚焦目标”的链路，核心入口是 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L316)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1017) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1531)。
- 结构重排后的聚焦仍通过 `pendingPostLayoutFocusNodeKey` 延后到新坐标落位后执行，避免聚焦到旧布局位置；状态和落位逻辑位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L177) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L902)。
- 频道视图、搜索集和频道详情绑定恢复为显式 `connectionMode/channel` 判定，不再把 `channel > 0` 自动归一化为频道成员；对应位置在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L225)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L466) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1885)。
- 解析层同样恢复为直接保留回包中的 `connectionMode` 文本，不再做前端归一化；实现见 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L222) 和 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L268)。

## 2. 关键数据结构和算法性能分析

- `batchEditFocusNodeKey` 只是对当前选区做一次线性计数和优先级选择，没有引入新的布局算法或额外大集合，复杂度与选区大小线性相关；实现位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L316)。
- 重排后聚焦的新增成本是一次 `requestAnimationFrame + setCenter`，只在批量应用且存在聚焦目标时触发一次，不会进入持续热路径；逻辑在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L902)。
- 序号/频道画布分桶恢复为直接依据节点字段过滤，避免前端额外做模式推断；入口位于 [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L591)、[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L597)、[canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L943) 和 [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L949)。
- 解析层恢复原始 `connectionMode` 读取后，不再额外做 `channel > 0` 归类判断，因此本轮总体性能影响为低；相关口径在 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L241) 和 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L307)。

## 3. 数据流或调用链

- 批量编辑调用链为：选区节点集合生成后先在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L316) 计算 `batchEditFocusNodeKey`，随后在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1531) 应用草稿，并通过 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1017) 把 `focusNodeKey` 传入结构重排入口。
- 视口链路为：结构重排设置 `pendingPostLayoutFocusNodeKey` 后，等待新布局节点写回，再由 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L902) 统一执行 `setCenter`。
- 频道视图链路为：快照解析先在 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L268) 保留原始 `connectionMode`，`GraphViewer` 再在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L225) 构造搜索集，画布入口在 [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L943) 依据显式 `connectionMode/channel` 进入频道分组。
- 频道详情绑定链路为：当前选中节点满足显式频道条件后，才在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L466) 回查对应 `channelHub`，不会再因前端兜底而把非显式频道节点带入频道详情。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 语义一致性：本轮仍只使用 `triggerSource/core`，真实写入方向仍是 `triggerSource -> core`，未改 snapshot、draft 或服务端真值结构；相关编辑入口仍在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1531)。
- 兼容性风险：移除前端归一化后，如果后端真实回包存在 `channel > 0` 但 `connectionMode` 不是 `channel` 的数据，这些节点将不会进入频道视图；也就是说，本轮选择的是“显式口径优先”，而不是前端容错兜底。对应解析口径在 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L241) 和 [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L307)。
- 可维护性：把频道成员判定收回到显式字段后，搜索、详情、画布分桶三处口径重新一致，减少了前端“推断模式”和“真实回包模式”分离的维护成本；对应位置在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L225)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L466) 和 [canvas.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L949)。
- 测试结果：`npm.cmd run typecheck`、`.\gradlew.bat buildWebapp --no-daemon`、`.\gradlew.bat test testIntegration testClient testSlow --no-daemon` 本轮均通过，当前没有残留自动化失败项。

## 5. 并发冲突审查

- 共享状态主要是 `selectedNodeKey`、`pendingPostLayoutFocusNodeKey`、`pendingStructureLayoutReset` 和批量选区集合；对应定义和使用位于 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L177)、[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L316) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1017)。
- 当前风险等级评估为低：所有状态更新都在 React 单线程事件与 effect 链中串行执行，本轮没有新增跨线程共享数据或异步并发写入路径。
- 需要关注的边界是“批量应用后立即切换视图或再次编辑”。当前实现把聚焦目标先折叠成单个 `focusNodeKey`，再在重排后统一处理，可避免多个上下文焦点互相覆盖；关键位置在 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L316) 和 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L902)。
