## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全与一致性：预检不锁定额度，它只是“当前窗口快照”，因此多玩家并发下仍可能出现“预检通过但保存时被别人抢占窗口”的瞬时竞争；当前实现用正式保存复用相同的 hard block / wait tick 文案收口，保证失败原因可理解，但不保证预约式成功。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L778) [CommandRateLimitService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/CommandRateLimitService.java#L102)
- 性能：dirty 草稿每次稳定 220ms 后都会多一次本地 bridge 往返，别名连续输入场景请求会变多；当前通过延迟与旧响应丢弃降低噪声，若后续实测仍有压力，再考虑只对 batch/channel 编辑立即预检、别名改动采用更长去抖。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1080)
- 兼容与扩展：前端协议是向后兼容增量扩展，新增字段都挂在 `preview` 下，不影响现有 `applied/conflict/rejected` 解析；后续如果还要扩成更复杂的保存诊断，可在不打破当前桥接结构的前提下继续扩展 `PreviewState`。[GraphWriteJsonSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteJsonSupport.java#L97) [graphTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/graphTypes.ts#L108)
- 残余建议：本轮没有新增针对 `GraphWriteService` 成本摘要的专门单测，目前依赖现有全量 Gradle 回归兜底；后续若继续演进 graph 计费规则，建议补一组专测锁死 write unit 与 hard block 文案口径。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L662)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 共享状态：`CommandRateLimitService` 的全局 / tier / actor / actorGroup 计数器是服务端共享可变状态；本轮只给 graph 保存新增了独立分组，没有改变其窗口并发模型。风险等级：中。建议：若后续需要“预检后保留额度”，必须单独设计 reservation，而不是继续叠加在当前窗口计数上。[CommandRateLimitService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/CommandRateLimitService.java#L30) [CommandRateLimitService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/CommandRateLimitService.java#L102)
- 读改写覆盖：`GraphWriteService` 仍先走 graph revision / source revision / core revision 的 OCC 校验，再允许正式保存，因此预检链路没有削弱已有冲突检测。风险等级：低。建议：继续保持“preview 只读、submit 才落真值”的边界，不要让预检修改任何 revision 或 savedData。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L181) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L550)
- 前端重入：预检请求和 Save 失败后的刷新都可能异步返回，当前通过 `previewRequestSequenceRef` 丢弃过期回包，避免旧草稿状态覆盖新草稿。风险等级：低。建议：后续如再引入更多草稿侧异步任务，继续沿用同类 request sequence 或 abort controller 机制。[GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L210) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1080)
