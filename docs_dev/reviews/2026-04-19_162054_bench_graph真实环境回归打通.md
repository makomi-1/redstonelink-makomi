## 1. 功能与语义、架构设计

- `bench graph export/preview/save` 现在不再把 dedicated bench 的控制台 / RCON 命令源直接判成 `no_player`，而是统一走命令源兼容路径，保持 `triggerSource -> core` 方向语义不变。[BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L86) [BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L120)
- 图导出服务新增 `ViewerContext`，把“可见性、viewerId、dedupe actor”从玩家实体抽象成统一上下文，既兼容原玩家网页导出，也兼容 benchmark mode 下的系统命令源。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L33) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L311)
- graph 保存服务新增 `CommandSourceStack` 入口，权限、限流、OCC、频道/拓扑覆盖写入仍沿用原有内部实现，只把“谁来执行”从玩家扩展成“玩家或命令源”。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L45) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L193)

## 2. 关键数据结构和算法性能分析

- 导出去重仍是 `ConcurrentHashMap + SavedData` 的 O(1) 读写路径，只是把 key 从“真实玩家 UUID”扩成“玩家 UUID 或系统源合成 UUID”，没有引入额外图遍历复杂度。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L25) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L49) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L324)
- `preparePlan` 仍按请求操作数线性拆分与校验；`ReplaceTriggerSourceTargets` 与频道批量覆盖的主要成本仍集中在目标集合校验和受影响 serial 汇总，没有新增高阶复杂度。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L235) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L417) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L500)
- 限流预检与正式扣费继续复用统一窗口模型，只是把输入改成 `CommandSourceStack`，因此 dedicated bench 与玩家网页编辑共享同一套计费/等待判定，复杂度和行为都保持稳定。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L590) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L783)

## 3. 数据流或调用链

- 导出链路现在是：`bench graph export` -> `BenchGraphCommandRegistry.executeExport` -> `GraphSnapshotExportService.exportVisibleSerialGraph(source, ...)` -> `NodeSnapshotQueryService.queryLinks(level, ..., hasViewPermission)` -> dedupe/cache summary 输出。[BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L86) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L49) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L108)
- 写入链路现在是：`bench graph preview/save` -> 组装最小 graph draft 请求 -> `GraphWriteService.preview/submit(source, ...)` -> `preparePlan` -> `LinkSetExecutionService` / `LinkChannelEditingService` -> machine-readable summary 回包。[BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L131) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L57) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L461) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L551)
- OCC 与最小补丁回包口径未变；source-only 路径只是把 `level/permission/rateLimitSource` 从命令源解析出来，避免 dedicated bench 与网页编辑在判定上漂移。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L202) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L687)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性风险低：非玩家路径仍依赖命令源权限检查，且 bench 命令树本身受 `benchmarkModeEnabled + otherPermission` 双重门控；只要后续不把这套 source-aware 入口暴露到普通命令树，权限边界就是稳定的。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L222) [BenchGraphCommandRegistry.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/bench/BenchGraphCommandRegistry.java#L120)
- 兼容性风险中低：系统源 dedupe 目前按 `source.getTextName()` 合成 UUID，足够覆盖 dedicated bench / RCON 回归，但如果未来要支持多控制台主体并发导出，建议再把维度或远端标识纳入 principal 计算。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L332)
- 扩展性风险低：`GraphWriteService` 新增的是重载入口和上下文 record，没有改动 `triggerSource/core` 真值结构，也没有引入 `com.makomi.api.v1.*` 依赖；后续若要把其它 bench 子命令迁移到 source-aware，可复用同一模式。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L1098)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- `GraphSnapshotExportService` 新增的共享状态仍只有 `EXPORT_CACHE`，使用 `ConcurrentHashMap` 承载；写持久化台账仍通过 `SavedData` 在服务端主线程收口，没有新增跨线程写 world data 的路径，风险低。[GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L25) [GraphSnapshotExportService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphSnapshotExportService.java#L67)
- graph 保存的并发保护仍然主要依赖 `graphRevision/sourceRevision/coreRevision` 的 OCC 检查；source-only 路径没有绕开这层，因此不会放大读改写覆盖风险，风险低。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L272) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L437) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L526)
- 限流共享状态继续复用现有 `CommandRateLimitService`；切到 `CommandSourceStack` 后，system actor 会按命令源身份单独分桶，不会和玩家 actor 错桶，但若未来把多个批处理入口都复用同一系统名，仍可能出现同桶竞争，需要通过更细的 principal 细分，风险中低。[GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L590) [GraphWriteService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/GraphWriteService.java#L904)
