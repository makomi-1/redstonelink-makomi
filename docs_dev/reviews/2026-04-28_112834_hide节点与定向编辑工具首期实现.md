# hide节点与定向编辑工具首期实现

## 1. 功能与语义、架构设计

本轮把隐藏节点实现为两种真实方块载体：`hide core` 与 `hide sync triggerSource`。两者分别复用现有 `core` / `triggerSource` 生命周期，只在方块层增加“默认不可见 + 面集限制”语义，避免新建第二套链路模型。[HideCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideCoreBlock.java#L23) [HideSyncTriggerSourceBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java#L22) [HideCoreBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/HideCoreBlockEntity.java#L12) [HideSyncTriggerSourceBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/HideSyncTriggerSourceBlockEntity.java#L12)

面集配置被统一抽到 `NodeFaceSetBlockStateSupport`，由 `BlockState` 上的 6 个布尔属性承载，隐藏节点和后续可见节点都能走同一组读写入口。这样语义上仍保持 `triggerSource -> core`，只是把“输入/输出朝向”从单朝向扩展为可编辑的面集。[NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L17) [HideCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideCoreBlock.java#L47) [HideSyncTriggerSourceBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java#L39)

交互入口则收敛到定向面编辑工具：空挥右键循环 `toggle/single/all/clear` 模式，命中隐藏节点时按点击面修改面集，并在 `triggerSource` 上立即刷新输入采样，避免等待后续邻居更新。[DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L36) [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L55) [HideDirectionalEditorToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideDirectionalEditorToolData.java#L14)

## 2. 关键数据结构和算法性能分析

关键数据结构有两类。一类是节点面集属性，使用 `BlockState` 的 6 个 `BooleanProperty` 表示，读写复杂度是 `O(6)`，不会引入额外持久化对象，也不需要额外网络同步协议；另一类是编辑工具模式，使用 `ItemStack` 的 `CUSTOM_DATA` 保存一个短 token，切换与读取开销都很小。[NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L18) [NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L106) [HideDirectionalEditorToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideDirectionalEditorToolData.java#L23) [HideDirectionalEditorToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideDirectionalEditorToolData.java#L45)

运行态算法也保持局部常量复杂度。`hide core` 仅在 `getSignal/getDirectSignal` 时判断当前面是否启用；`hide sync triggerSource` 只遍历已启用面求 `max` 输入强度，不做范围扫描或额外世界索引，因此单节点采样成本稳定可控。[HideCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideCoreBlock.java#L53) [HideCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideCoreBlock.java#L58) [HideSyncTriggerSourceBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java#L51)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

安全层面，本轮没有引入命令执行、文件 IO 或外部协议变更，主要风险是隐藏节点默认不可见后带来的误操作成本。当前通过智能眼镜幽灵层、轮廓框、HUD 面集行和工具即时提示来降低误配风险，但仍建议后续补“命中高亮”或“回收确认”类可见反馈。[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L48) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L559) [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L75)

性能层面，当前实现是单节点局部判定，没有使用全局扫描；主要新增成本在客户端幽灵渲染和 HUD 文本刷新。由于幽灵渲染只在佩戴智能眼镜时开启，且 HUD 缓存已经把面集签名并入缓存键，这部分成本在当前设计下可接受。[HideSyncTriggerSourceBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java#L51) [HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L38) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L87)

兼容性与扩展性方面，本轮严格保持内部语义为 `triggerSource/core`，没有引入 `com.makomi.api.v1.*` 依赖，也没有修改旧节点存储结构；面集工具和面集属性抽象已为后续推广到可见 `core` / `sync triggerSource` 预留统一入口。残余风险是未来如果要把面集推广到更多节点，需要继续确认每种节点的输入/输出语义是否仍然适合 `max` 采样与多面并行输出。[HideSyncTriggerSourceBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/HideSyncTriggerSourceBlock.java#L51) [NodeFaceSetBlockStateSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/NodeFaceSetBlockStateSupport.java#L31) [LinkSyncEmitterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/LinkSyncEmitterBlockEntity.java#L26)

## 5. 并发冲突审查

风险等级评估为“低”。隐藏节点放置、面集编辑、节点刷新都发生在主游戏线程，`DirectionalFaceEditorItem` 对 `BlockState` 的写入和对 `triggerSource` 的刷新是同一条服务端交互链，未引入后台线程共享写入点。[DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L55) [DirectionalFaceEditorItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/DirectionalFaceEditorItem.java#L137)

共享状态主要有两类：工具 `ItemStack` 上的模式数据，以及客户端近外显静态缓存。前者仅跟随手持物品实例流转，没有跨玩家共享；后者是客户端单例缓存，当前默认运行在渲染线程/客户端主线程语境下安全，但如果未来引入异步 HUD 快照刷新，需要把 `cachedNearOverlayLines` 访问继续限制在主线程或改成线程安全封装。[HideDirectionalEditorToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideDirectionalEditorToolData.java#L23) [HideDirectionalEditorToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/HideDirectionalEditorToolData.java#L34) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L87) [LinkSerialHudOverlayTextSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayTextSupport.java#L195)
