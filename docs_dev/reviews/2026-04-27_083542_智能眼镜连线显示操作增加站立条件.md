# 智能眼镜连线显示操作增加站立条件

## 1. 功能与语义、架构设计（关键方法和入口）
- 本轮把智能眼镜 quick-link visualize 的“广义操作门槛”和“显示对象修改门槛”显式拆开：`canOperateQuickLinkVisualization(...)` 继续承担“戴眼镜 + 主手空”的 broad gate，用于 visualize 模式成立与 `Shift+B` 清空；新增 `canModifyQuickLinkVisualizationObjects(...)` 额外要求非潜行，只服务于添加/移除显示对象。[SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L66) [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L78)
- 客户端入口将左键添加、右键移除从原本的 broad visualize gate 收紧到新的站立 gate，并通过 `canModifyVisualizedObjects(...)` 统一复用，避免交互散落在多个回调里各自判断。[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L199) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L398) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L427)
- 服务端 `handleRequestQuickLinkVisualizeSnapshot(...)` 同步切到同一站立 gate，保证客户端不能通过直接发包绕过该门槛；显示增量刷新仍只要求可显示，不被站立条件误伤。[QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L149) [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L194)

## 2. 关键数据结构和算法性能分析
- 本轮未新增持久化结构、集合或图算法；新增逻辑只是对现有 `Player` 状态做常数时间判定：头部装备、主手是否为空、是否潜行，复杂度为 O(1)。[SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L23) [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L41) [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L85)
- 客户端 `shouldSendVisualizeAddRequest/RemoveRequest` 只是把既有目标解析前置多加一层 gate，不会增加额外扫描或网络轮询成本；增量刷新轮询逻辑保持不变。[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L199) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L206) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L510)
- 回归测试使用 `Unsafe` + 反射构造最小替身，避免拉起完整物品注册链，测试成本低且不会引入额外运行态依赖；该替身只覆盖本次门槛需要的字段访问。[SmartGlassesAccessSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/SmartGlassesAccessSupportTest.java#L81) [SmartGlassesAccessSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/SmartGlassesAccessSupportTest.java#L92) [SmartGlassesAccessSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/SmartGlassesAccessSupportTest.java#L119)

## 3. 数据流或调用链
- 添加显示对象链路现在是：客户端左键回调命中方块 -> `shouldSendVisualizeAddRequest(...)` 先过站立 gate -> `resolveVisualizeTarget(...)` 解析节点/转发器 -> 发送 `RequestQuickLinkVisualizeSnapshotPayload` -> 服务端 `handleRequestQuickLinkVisualizeSnapshot(...)` 再做站立 gate 验证 -> 查询快照并回包。[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L88) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L199) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L342) [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L149)
- 移除显示对象链路现在是：客户端右键回调命中方块 -> `shouldSendVisualizeRemoveRequest(...)` 先过站立 gate -> `handleVisualizeRemove(...)` 本地移除显示对象并反馈；该链路没有服务端参与，所以站立 gate 必须在客户端收口。[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L115) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L206) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L475)
- 清空显示对象链路保持原语义：按键处理仍先看 broad visualize gate，潜行时进入 `clearVisualizedObjects()`，因此“站立限制”只影响 add/remove，不影响 `Shift+B` 清空。[RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L273) [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L164) [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L74)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全性：服务端已对“添加显示对象”同步收口，避免客户端绕过站立条件直接发包；移除与清空是纯客户端本地状态修改，不涉及服务端写入风险。[QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L149)
- 兼容性：tooltip 已同步声明“站立添加/移除，Shift+B 清空”，避免用户把“潜行无效”误判为功能损坏。中英文文案已对齐。[zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L96) [zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L100) [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L96) [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L100)
- 扩展性：智能眼镜识别改为按 `SmartGlassesItem` 类型判断，而不是注册表单例相等，降低了测试和潜在扩展物品对注册生命周期的耦合；在当前代码库中该类型只有一处实现，风险可控。[SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L102)
- 建议：若后续继续细分 visualize 交互，例如增加“站立添加、潜行批量框选、空中只读观察”等模式，应继续沿用“broad gate + 场景细 gate”的分层，而不要重新收拢成单一布尔判定。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 共享状态方面，本轮没有新增服务端全局共享集合或 SavedData 写入；服务端只是在既有网络入口前增加一个只读 gate，因此不会引入新的读改写覆盖点，风险等级低。[QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L149)
