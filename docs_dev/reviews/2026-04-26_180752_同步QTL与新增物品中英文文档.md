## 2. 关键数据结构和算法性能分析

- 本轮无运行时算法变更，所有变更均为静态文档和静态页面映射补录，不引入额外的游戏内时间复杂度或内存占用风险。[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L558) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L556)
- `docs/item_guide.html` 主要新增的是展示映射表：物品贴图覆盖、双层内层贴图覆盖、侧面轮播贴图引用，以及新增物品条目数据。这些都是前端静态对象扩展，开销与既有物品条目呈线性增长，规模很小。[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L558) [item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L590) [item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L631) [item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L941)
- `docs/recipe_sheet.html` 主要新增配方卡片与名称/分类映射，同样只影响静态页面渲染的数据表，不影响游戏运行时配方管理器或 JEI 行为。[recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L239) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L748) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L1749)

## 3. 数据流或调用链

- 文档同步链路一：使用说明以“智能眼镜 -> QLT -> 智能节点容器 -> 过滤器”的顺序补齐用户操作流，确保玩家先理解观察门槛，再理解工具和容器语义。[usage_guide_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_cn.md#L18) [usage_guide_en.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_en.md#L18)
- 文档同步链路二：机制设计将使用说明中的操作结果进一步上收为机制语义，用于解释“显示不等于操作”“增量同步不等于每帧网络请求”“容器是物品内库存而非聚合壳”的原因。[mechanism_design_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/mechanism_design_cn.md#L308) [mechanism_design_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/mechanism_design_cn.md#L317)
- 文档同步链路三：图鉴页通过新增条目和展示映射把智能眼镜、智能节点容器接入现有浏览入口；配方页通过新增卡片和分类函数把两件物品纳入 `tools` 分类展示。[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L941) [item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L979) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L223) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L1749)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮不涉及脚本执行入口、权限判定或运行时数据写入，安全风险低。[usage_guide_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_cn.md#L20) [mechanism_design_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/mechanism_design_cn.md#L308)
- 性能：静态页面新增的数据量很小，对本地文档浏览性能影响可忽略；未引入新的外部资源请求或动态图形计算路径。[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L631) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L723)
- 兼容性：当前文档术语已统一写为 `triggerSource/core`，避免继续传播旧术语；但若后续游戏内 tooltip 再次变更，文档需要继续手动同步，否则会出现“文档正确、游戏内提示滞后”的偏差。[usage_guide_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_cn.md#L89) [item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L974)
- 扩展性：图鉴和配方页本次采用继续扩展静态映射表的方式，适合当前规模；如果未来物品数量显著增加，建议再考虑抽出共享数据源，避免同一物品定义在多处重复维护。[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L558) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L735)

- 风险等级：低。本轮仅修改静态文档与静态 HTML 数据表，不涉及共享运行时状态、读改写竞争、线程边界或重入行为。[usage_guide_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_cn.md#L20) [mechanism_design_en.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/mechanism_design_en.md#L300)
- 共享状态：无新增共享内存或跨线程读写对象；页面映射表只是构建期/浏览期静态数据声明。[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L558) [recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L556)
