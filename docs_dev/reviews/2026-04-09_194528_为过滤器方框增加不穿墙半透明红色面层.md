# 为过滤器方框增加不穿墙半透明红色面层

## 1. 功能与语义、架构设计
本轮基于用户手动回退后的当前提交态，只增强过滤器影响域的非穿墙可视化表现，没有恢复或引入任何 see-through 逻辑。实现仍收敛在 `LinkFilterAreaRenderer`：保留原有 `RenderType.lines()` 线框作为不穿墙轮廓，再新增一层默认深度测试的半透明红色面层，用于提升范围辨识度并保留地面与遮挡提供的空间参考。代码参考：[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L21)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L91)

## 2. 关键数据结构和算法性能分析
新增的主要数据结构是静态 `FILTER_FILL_RENDER_TYPE` 和透明度常量 `FILL_ALPHA`。它们在类加载时初始化一次，后续渲染复用，不会引入逐帧构建渲染状态对象的额外成本。几何数据仍沿用固定 `AABB FILTER_BOX`，运行期成本保持为常数级：一次距离平方判断、一次面层顶点写入和一次线框顶点写入。代码参考：[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L25)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L43)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L95)

## 3. 数据流或调用链
渲染调用链为：`render(...)` 先检查远外显开关、玩家存在性与最大显示距离，满足条件后进入 `renderFilterBox(...)`。在 `renderFilterBox(...)` 中，先通过 `buffer.getBuffer(FILTER_FILL_RENDER_TYPE)` 获取半透明填充缓冲，并用 `LevelRenderer.addChainedFilledBoxVertices(...)` 写入整个范围盒体的面层顶点；随后再通过 `RenderType.lines()` 绘制原有线框轮廓。由于 fill `RenderType` 使用 `LEQUAL_DEPTH_TEST`，面层会受到场景遮挡，不会穿墙。代码参考：[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L56)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L79)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L95)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L109)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
安全风险低，本轮未触及网络、持久化、命令、配方或服务端逻辑。兼容性风险主要集中在客户端渲染 API：当前实现依赖 `RenderType.create(...)`、`POSITION_COLOR_SHADER`、`TRANSLUCENT_TRANSPARENCY`、`LEQUAL_DEPTH_TEST` 与 `LevelRenderer.addChainedFilledBoxVertices(...)` 的 1.21.1 签名，后续若升级 Minecraft 或 mappings，需要优先回归这一段。扩展性方面，`FILL_ALPHA` 已经抽成单独常量，后续若用户觉得面层太淡或太浓，只需局部调整该值即可。代码参考：[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L26)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L35)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L37)

## 5. 并发冲突审查
本轮没有新增跨线程共享可变状态。`FILTER_FILL_RENDER_TYPE`、`FILTER_BOX` 与 `FILL_ALPHA` 都是只读静态常量；渲染过程通过当前帧的 `MultiBufferSource` 写入顶点，不使用跨帧缓存，也没有异步状态更新。整体线程边界与现有 BER 渲染模型保持一致，在当前客户端渲染线程上下文下风险等级为低。代码参考：[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L21)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L26)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L91)
