## 3. 数据流或调用链

- 正常运行期查询链路仍是 `PlacedLinkFilterSavedData.collectFilters(...) -> LinkFilterRuleEvaluator.allows(...)`；因此本轮把 zero 门控放在 evaluator 就能统一覆盖 send/receive 两侧，不需要拆改持久化层或派发层接口。[PlacedLinkFilterSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedLinkFilterSavedData.java#L172) [LinkDispatchFilterService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkDispatchFilterService.java#L360) [LinkFilterRuleEvaluator.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterRuleEvaluator.java#L26)
- 过滤器变更后的 `sync` 失效/补发仍沿用 `allowsByKindWithChangedEntry(...)` 的 before/after 回算，再由 `reconcileSyncDeltaAfterFilterChange(...)` 发布路径差分事件；本轮没有改动这条协调链，只是让 zero 邻居在回算时自然体现为“关闭过滤器”。[LinkDispatchFilterService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkDispatchFilterService.java#L378) [LinkDispatchFilterService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkDispatchFilterService.java#L412)
- functional 失败回溯显示：`data merge` 改配置本身不会立即触发过滤真值重采样，仍要依赖后续邻居变化路径刷新；因此 `x24/x26` 最终只断言 zero 总开关，不把“配置写入即刷新”误写成设计语义。[send_filter_runtime_sync_reconcile.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x24/send_filter_runtime_sync_reconcile.json#L149) [receive_filter_runtime_sync_reconcile.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/receive_filter_runtime_sync_reconcile.json#L149)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 兼容性风险：zero 邻居现在会关闭所有过滤规则，包括固定阈值过滤器；这与旧语义不兼容，但本轮通过 Java 测试与 dedicated case 已显式固化新契约，残余风险主要在外部手工玩法习惯迁移，而不是实现不一致。[LinkFilterRuleEvaluatorTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkFilterRuleEvaluatorTest.java#L79) [LinkDispatchFilterServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkDispatchFilterServiceTest.java#L272)
- 测试口径风险：过滤器配置经 `data merge` 修改后仍需刷新触发，这类场景若直接写“配置后立刻生效”断言，容易把 bench 观测口径错误提升成设计语义；建议后续 functional case 继续把“配置写入”和“刷新触发”拆成两个 phase。[send_filter_runtime_sync_reconcile.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x24/send_filter_runtime_sync_reconcile.json#L149) [receive_filter_runtime_sync_reconcile.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/tools/bench/cases/functional/x26/receive_filter_runtime_sync_reconcile.json#L149)
- 性能残余风险：全标签自动化中的慢测 `LinkSavedDataPerformanceSlowTest` 仍未全绿，本次实测先后出现 `load 45ms > 40ms` 与 `save > 50ms` 的基线越界；这看起来更像环境/性能基线问题，和本轮过滤器改动模块无直接耦合，但它仍阻断了“全标签完全通过”的结论，建议单独复核慢测阈值或运行环境波动。[LinkSavedDataPerformanceSlowTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkSavedDataPerformanceSlowTest.java#L21) [LinkSavedDataPerformanceSlowTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkSavedDataPerformanceSlowTest.java#L72)

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 风险等级：低。
- `LinkFilterRuleEvaluator` 仍是纯函数式只读求值器，本轮新增的 `isEnabled(...)` 不引入共享可变状态，也不改变线程边界。[LinkFilterRuleEvaluator.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterRuleEvaluator.java#L26) [LinkFilterRuleEvaluator.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkFilterRuleEvaluator.java#L59)
- 共享状态仍集中在 `PlacedLinkFilterSavedData` 的 `entriesByKey` 与 `chunkIndex`，本轮没有新增并发容器，也没有把写路径扩散到新的线程环境；写入仍通过 `upsertInternal(...)` 单点完成，读路径继续基于快照列表消费。[PlacedLinkFilterSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedLinkFilterSavedData.java#L54) [PlacedLinkFilterSavedData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/PlacedLinkFilterSavedData.java#L127)
- `LinkDispatchFilterService` 的 before/after 差分发布仍假定在服务端主线程顺序执行；本轮 zero 门控没有改变重入面，也没有增加跨线程回调。若后续要把过滤重采样异步化，需要重新审查 `SavedData` 读改写与 `publishSyncPathTransition(...)` 的线程约束。[LinkDispatchFilterService.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkDispatchFilterService.java#L412)
