# hide节点智能眼镜下取消距离裁剪

生成时间：2026-04-30 22:08:21

## 1. 功能与语义、架构设计（关键方法和入口）

本轮只改客户端 `hide` 节点 ghost 渲染器的可视距离，不改任何业务真值链。三个入口现在都在 `getViewDistance()` 上直接返回极大值：

- 普通 `hide` 节点 ghost：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L46)
- `hide` 过滤器 ghost：[HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L46)
- `hide` 区块激活器 ghost：[HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L46)

原有 ghost 渲染逻辑、智能眼镜门槛和普通 far overlay 复用关系都保持不变：

- `HideNodeGhostRenderer.render(...)` 仍然先在佩戴智能眼镜时绘制半透明 ghost，再复用原有 far overlay：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L26)
- `HideFilterGhostRenderer.render(...)` 与 `HideChunkActivatorGhostRenderer.render(...)` 同样保持原样：[HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L26)、[HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L26)

## 2. 关键数据结构和算法性能分析

本轮没有新增数据结构，也没有改任何算法。只是把三个 renderer 的 `getViewDistance()` 从“复用普通 far overlay 距离”改成“恒定极大值”：

- `HideNodeGhostRenderer` 原先等价于复用普通节点可视距离，现在恒定 `Integer.MAX_VALUE`：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L46)
- `HideFilterGhostRenderer` 与 `HideChunkActivatorGhostRenderer` 同理：[HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L46)、[HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L46)

算法复杂度不变。唯一实质性变化是：客户端在更远距离上也会继续尝试渲染这些 ghost。

## 3. 数据流或调用链

数据流仍然保持原结构：

1. 玩家是否佩戴智能眼镜，仍由 `SmartGlassesAccessSupport.canRenderSerialOverlay(...)` 决定：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L33)、[HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L33)、[HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L33)
2. 允许显示时，`HideNodeSupport.resolveGhostDisplayState(...)` 继续把当前 `hide` 方块映射到对应可见普通方块状态：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L34)
3. `HideGhostRenderSupport.renderGhostModel(...)` 继续实际画半透明普通模型：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L36)
4. 之后仍然复用现有 far overlay renderer，只是 BER 不再因为距离把整个 hide ghost 渲染器剔除：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L40)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：纯客户端显示改动，无网络、权限、存档或 API 面风险。
- 性能：
  - 风险点存在。因为 view distance 不再裁剪，远距离大量 `hide` 节点在视野内时，客户端渲染压力会比之前更高。
  - 但本轮需求就是明确取消这层裁剪，因此这是预期代价。
- 兼容性：
  - 普通节点 renderer 未改，非 `hide` 节点行为不受影响。
  - 智能眼镜门槛未改，未佩戴时仍不可见、不可正常交互。
- 扩展性建议：
  - 如果后面还要给其它 hide 载体补独立 ghost renderer，应同步遵守同一策略，避免部分 hide 节点有距离裁剪、部分没有，造成体验不一致。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

本轮没有修改共享状态、服务端数据、异步任务或网络消息；所有改动都位于客户端单线程渲染路径中：

- `HideNodeGhostRenderer` 仅在渲染线程内读取玩家和方块状态：[HideNodeGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideNodeGhostRenderer.java#L31)
- `HideFilterGhostRenderer` 与 `HideChunkActivatorGhostRenderer` 同理：[HideFilterGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideFilterGhostRenderer.java#L31)、[HideChunkActivatorGhostRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/HideChunkActivatorGhostRenderer.java#L31)

风险等级：低。
