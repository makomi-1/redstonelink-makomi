# 智能眼镜承接连线可视化与外显

## 1. 功能与语义、架构设计
- 本次实现新增了智能眼镜物品，并明确把“连线显示”和“远近外显”的生效门槛从手持 QLT 切到穿戴入口；共享门槛收口在 [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L16)，物品注册入口在 [ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L164)，物品自身 tooltip 在 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L18)。
- 客户端输入入口保持原按键语义，但 `Shift+B` 先检查“戴眼镜 + 主手空”后再清空连线显示，否则回退到 QLT 缓存清空；对应逻辑在 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L247)。
- 连线显示的左键添加、右键移除、hover 判定与最终连线渲染都已从“主手 QLT + visualize 第三模式”切到智能眼镜条件；关键入口在 [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L339)、[QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L380)、[QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L202)、[QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L304)。
- 远外显、近外显和过滤器/区块激活器 far overlay 现在统一要求已穿戴智能眼镜；关键门槛分别位于 [LinkNodeFarOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkNodeFarOverlayRenderer.java#L57)、[LinkFilterAreaRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkFilterAreaRenderer.java#L73)、[ChunkActivatorFarOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/ChunkActivatorFarOverlayRenderer.java#L40)、[LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L101)。
- QLT 自身的模式契约被收回为 serial/channel 两态，历史 `visualize` token 仅做兼容读取，不再驱动第三贴图和第三入口；实现集中在 [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L66)、[QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L180)、[QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L280)、[QuickLinkToolItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/QuickLinkToolItem.java#L32)。

## 2. 关键数据结构和算法性能分析
- 智能眼镜门槛判断只读取头部装备槽和主手物品，时间复杂度为 O(1)，不会引入额外扫描；相关实现见 [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L23)。
- 连线显示的核心数据结构仍然复用 `QuickLinkOutlineRenderer` 内部的 `LinkedHashMap`/`LinkedHashSet` 缓存，不新增更高复杂度结构；本次只替换入口判定，不改变可视化对象集合的去重与渲染算法，见 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L112)。
- QLT 模式镜像仍保留 `CustomModelData` 常量切换，但现在只保留 channel 的单一自定义模型，减少了一次第三形态分支判断；对应实现见 [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L180)。
- 新增智能眼镜物品复用原版头盔渲染链路，并把默认属性清空，避免为了显示功能再维护独立头戴渲染模型；关键实现见 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L24)。

## 3. 数据流或调用链
- 连线显示添加链路：客户端攻击方块事件进入 [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L80)，经 `isVisualizeMode` 与智能眼镜门槛判定后发送 visualize 请求，再由服务端 [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L147) 返回可视化快照，最后写入 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L259)。
- 连线显示清空链路：`Shift+B` 触发 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L198)，在 [RedstoneLinkClient.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/RedstoneLinkClient.java#L247) 优先命中智能眼镜条件后，进入 [QuickLinkNetworkClientHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/network/QuickLinkNetworkClientHandlerSupport.java#L156) 清空本地显示对象集合。
- 外显链路：`K` 键仍只切换本地 overlay 配置；真正决定是否可见的门槛在各渲染入口分别检查 [SmartGlassesAccessSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/SmartGlassesAccessSupport.java#L61)，然后由 [LinkNodeFarOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkNodeFarOverlayRenderer.java#L57) 与 [LinkSerialHudOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/LinkSerialHudOverlayRenderer.java#L101) 落地显示。
- QLT 主链路仍保留：serial/channel 缓存读写继续走 [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L38) 和 [QuickLinkToolItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/QuickLinkToolItem.java#L70)，没有把 apply/collect 误迁到智能眼镜入口。

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全/权限：服务端只对 visualize 请求改成智能眼镜门槛，serial/channel/apply 仍保持原 QLT 验权，避免无意放宽现有 quick-link 修改能力；对应边界见 [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L43) 与 [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L147)。
- 兼容性：历史 `visualize` mode token 已在 [QuickLinkToolData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/QuickLinkToolData.java#L280) 回退为 `serial`，旧物品不会因为遗留 NBT 直接坏掉；同时测试已更新为两态模型，见 [QuickLinkToolDataTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/QuickLinkToolDataTest.java#L70)。
- 性能：外显门槛只增加一次头部槽/主手 O(1) 判定，对逐帧渲染压力可忽略；可视化对象遍历和线段命中算法未变，热点仍然集中在原有 `QuickLinkOutlineRenderer` 逻辑。
- 扩展性：当前智能眼镜使用原版头盔渲染外观并清空属性，后续若要替换为真正“眼镜”模型，可在 [SmartGlassesItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/SmartGlassesItem.java#L18) 和资源链路上继续迭代，而无需再改客户端/服务端门槛判定。
- 残余风险：资源层目前复用铁头盔外观占位，视觉上仍是头盔而非轻量眼镜；这是明确的可接受占位风险，不影响交互语义。

## 5. 并发冲突审查
- 共享状态：客户端连线显示对象集合仍集中在 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L112)，本次未新增新的共享容器，只改变进入/读取该容器的资格判定。
- 读改写覆盖：`Shift+B` 清空与服务端 visualize 快照写回都仍通过客户端主线程事件链路触发；本次没有引入跨线程直接修改 `visualizedObjects` 的新入口，风险低。
- 重入/线程边界：Fabric 客户端输入回调、HUD/world render 回调、S2C 接包回调都在客户端线程上串行执行；服务端 visualize 请求处理仍通过网络注册入口投递到服务端线程，见 [QuickLinkNetworkRegistrationSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkRegistrationSupport.java#L102) 与 [QuickLinkNetworkServerHandlerSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/network/QuickLinkNetworkServerHandlerSupport.java#L147)。
- 风险等级：低。当前改动以门槛替换为主，没有新增异步任务、锁或跨线程缓存。
- 建议：后续如果继续把“第三形态”命名整体替换为“智能眼镜连线显示”，应同步清理 [QuickLinkOutlineRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkOutlineRenderer.java#L198) 等注释中的历史术语，降低后续维护歧义。
