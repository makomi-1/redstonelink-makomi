## 2. 关键数据结构和算法性能分析
- `RecordingViewer` 使用 `selectedRecordingNodeKeys` 作为多选主状态，并通过 `useMemo` 派生 `selectedRecordingNodes`、`selectedRecordingSeries` 和 `chartNodeSeriesGroups`，避免时间窗变化时重复重建图表数据。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L38) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L65) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L90)
- 联合横坐标范围由 `resolveCombinedRecordingDomain()` 统一扫描所有已选节点样本得到，复杂度 O(totalSamples)。相较于每次切换节点单独求域，这更符合“多节点同坐标系”的真实语义。[recordingTypes.ts](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/recordingTypes.ts#L107)
- `RecordingChart` 先构造排序后的联合 `xValues`，再为每个节点的每条指标线补齐对齐数组，形成 `uPlot.AlignedData`。整体复杂度约为 O(U + N)，其中 U 是联合横坐标数，N 是总样本数，当前离线录制场景下足够轻量。[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L123) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L143)
- 节点色板、按钮禁用态和图例线型都放在前端轻量状态层与 CSS 层实现，没有引入额外状态管理或复杂绘图库扩展，符合 KISS/YAGNI。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L17) [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L498) [app.css](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L547)

## 3. 数据流或调用链
- 录制文件加载后，`App` 仍把 `recordingBundle` 传给 `RecordingViewer`；`RecordingViewer` 从 `recordingBundle.nodes` 与 `recordingBundle.series` 组合出多选节点和图表输入，再下发给 `RecordingChart`。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L47) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L72) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L268)
- 时间窗数据流保持单向：`RecordingViewer` 持有 `recordingWindow`，`RecordingChart` 通过滚轮、拖拽、双击和键盘回调 `onWindowChange/onResetWindow` 更新父层状态，父层再把窗口回灌给图表组件。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L44) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L237)
- 样本明细链路没有改变数据源，只是从“当前单节点表”改成“已选节点分组折叠表”，仍直接读取 recording bundle 中的 `series.samples`。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L377)
- GUI 背景调用链则进一步收敛：录制屏直接进入 `GuiBackgroundRenderSupport.renderWrappedRegion(...STATE_PANEL...)`，与状态面板一致，不再加额外透明背景层。[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L257)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 当前最多 5 节点、最多 2 指标，理论上是 10 条线。这个上限在可读性和性能上是合理的，但如果后续再增加指标种类，建议把图例筛选或节点分组进一步前置，否则图面会很快过载。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L17) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L127)
- 联合横坐标当前按精确 tick 合并；如果后续录制文件出现不同采样步长、插值或非整数时间戳，现有“按 x 值精确映射”策略需要升级成更显式的重采样策略。[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L130) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L147)
- 录制 GUI 背景只改渲染方式，没有改任何贴图资源，因此不存在资源兼容性和回退风险；残余风险为无。[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L257)
- 本轮前端和全量 Gradle 回归均已通过，说明现有实现与离线打包链路兼容。若后续新增更多图例或筛选器，建议继续先跑 `npm run build` 再跑整库 Gradle 回归。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 前端共享状态主要是 `selectedRecordingNodeKeys`、`visibleRecordingMetrics` 与 `recordingWindow`。这些状态都集中在 `RecordingViewer`，图表组件只通过回调修改窗口，当前不存在跨组件双写同一源状态的问题，风险等级低。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L38) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L119)
- `RecordingChart` 每次只维护一个 `uPlot` 实例，并在重建时先销毁旧实例、清空拖拽状态，再注册新交互处理器，避免重复绑定造成事件重入。[RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L114) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L224)
- 使用 `useMemo` 固定多节点图表输入后，时间窗拖拽不会因为父组件重渲染而反复重建图表，这消除了一个前端层面的隐性“状态更新触发对象重建”冲突点。[RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L65) [RecordingViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L90) [RecordingChart.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L71)
- 客户端 GUI 背景调整仅影响渲染入口，没有读改写共享业务状态，也没有线程边界变化，风险等级低。[StatePanelRecordingScreen.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/screen/StatePanelRecordingScreen.java#L257)
