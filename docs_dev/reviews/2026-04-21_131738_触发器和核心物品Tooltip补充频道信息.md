# 触发器和核心物品Tooltip补充频道信息

## 1. 功能与语义、架构设计（关键方法和入口）
- 本次以物品快照为主路径扩展频道字段，在 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L351)、[LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L364)、[LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L382) 新增“读频道/写频道/统一快照同步”收口，保持 Tooltip 仍然只读取物品自身数据，不引入额外客户端查服端逻辑。
- Tooltip 展示入口保持在 [PairableBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/PairableBlockItem.java#L117)，并在 [PairableBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/PairableBlockItem.java#L150) 追加频道文案；该入口只对 `triggerSource/core` 单件物品显示频道，未扩散到聚合态或其他工具物品。
- 语义上继续使用 `triggerSource/core`，语言资源新增键分别落在 [zh_cn.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/zh_cn.json#L42) 与 [en_us.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/lang/en_us.json#L42)，未引入旧术语输出。

## 2. 关键数据结构和算法性能分析
- 频道快照仅在物品 `CustomData` 上新增一个 `long` 字段，定义位于 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L41)，读写复杂度均为 O(1)，不会改变现有 Tooltip 热路径复杂度。
- 聚合序号组改写时在 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L568) 同步清理频道字段，避免旧频道附着到新顶部序号；该清理属于常数级 tag remove，不引入额外遍历。
- 玩家物品快照刷新仍复用原有扫描逻辑，只在 [LinkCommandSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkCommandSupport.java#L237) 增加别名和频道差异比较；对每个命中物品只多做一次字符串比较和一次 long 比较，性能影响可忽略。

## 3. 数据流或调用链
- 服务端真值到物品快照的主链路为：频道/连接真值读取 -> [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L382) 统一刷新物品快照 -> [PairableBlockItem.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/item/PairableBlockItem.java#L117) 读取快照生成 Tooltip。
- 频道编辑后的背包刷新链路为：[LinkCommandSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkCommandSupport.java#L237) 判定单件物品快照是否变化 -> 命中时走 `broadcastChanges()`；这样即使链接集合未变化，只要频道变了也能刷新客户端显示。
- 方块掉落转回物品的同步链路已统一改为调用物品快照同步入口，典型落点见 [LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L83)、[LinkButtonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkButtonBlock.java#L71)、[LinkRedstoneDustCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkRedstoneDustCoreBlock.java#L90)、[LinkSignalEmitterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSignalEmitterBlock.java#L74)、[LinkSyncLeverBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkSyncLeverBlock.java#L70)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 安全性：本次未新增网络入口或权限面，仍由现有服务端真值同步链路控制；相关写入仅发生在服务端物品快照更新与原有频道编辑后置刷新中，风险低。关键入口见 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L382)。
- 兼容性：`setSerial` 与聚合组改写现在会清理频道快照，分别位于 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L247) 和 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L575)，避免旧栈或聚合拆分时遗留脏频道值。
- 回归证据：新增单测覆盖频道字段读写与清理，见 [LinkItemDataTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkItemDataTest.java#L64)、[LinkItemDataTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkItemDataTest.java#L123)、[LinkItemDataTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkItemDataTest.java#L158)；另补了“链接不变但频道变化仍刷新物品快照”的回归，见 [LinkCommandSupportTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/command/link/LinkCommandSupportTest.java#L87)。
- 扩展建议：若后续需要为更多物品展示频道，不建议各处手写频道查询，应继续复用 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L382) 作为唯一快照入口，避免链接/别名/频道三类快照再次分叉。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）
- 共享状态：频道快照存储在单个 `ItemStack` 的 `CustomData` 中，写入入口集中在 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L364) 与 [LinkItemData.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/LinkItemData.java#L382)，没有新增全局静态缓存或跨线程共享容器。
- 读改写覆盖：本次把掉落路径统一改成完整快照同步，避免“先写序号、后只写链接、遗漏频道”的部分覆盖问题；代表入口见 [LinkCoreBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/LinkCoreBlock.java#L103)。
- 重入/线程边界：物品刷新仍沿用服务端命令/容器同步链路，差异判定位于 [LinkCommandSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkCommandSupport.java#L237)，没有引入异步回调或额外线程边界。当前风险等级为低。
- 建议：后续若出现更多“Tooltip 快照字段”扩展，应继续把差异比较收敛在 [LinkCommandSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/command/link/LinkCommandSupport.java#L237)，避免只比较单一字段导致客户端界面不同步。
