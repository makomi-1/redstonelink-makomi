## 2. 关键数据结构和算法性能分析
- `DueTickBucket` 仍保持目标级 `LinkedHashMap` 聚合，时间复杂度仍以单桶 `O(n)` merge / flush 为主；本次只是在 key 中增加 `activationMode` 维度，没有引入新的嵌套桶结构，因此不会把 flush 成本升级为额外层级遍历。[CoreDispatchBatchScheduler.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/CoreDispatchBatchScheduler.java#L462) [CoreDispatchBatchScheduler.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/CoreDispatchBatchScheduler.java#L474) [CoreDispatchBatchScheduler.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/CoreDispatchBatchScheduler.java#L552)
- full invalidation 的桶内覆盖规则现在会主动清掉更早的 `ACTIVATION` 条目，减少已经确定无效的 flush 负担；覆盖判断仍基于时间键、序列和固定优先级比较，不引入额外扫描条件分支之外的复杂度。[CoreDispatchBatchScheduler.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/data/CoreDispatchBatchScheduler.java#L487)
- `core` 端 activation batch mutation 沿用“批内记录、批末统一 recompute”模式，避免逐条 `toggle/pulse` 更新时重复执行 `recomputeSyncTruth/recomputePulseTruth/recomputeToggleTruth/recomputeAuthority`，把原本每条事件的重复重算压缩为每批一次统一提交。[ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L333) [ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L942) [ActivatableTargetBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/ActivatableTargetBlockEntity.java#L1029)

## 4. 安全、性能、兼容性、扩展性风险分析与建议
- 兼容性边界保持收敛：本次没有放开生命周期 replay 的 `toggle/pulse` 历史回放，只在 direct 与 ready-drain 上开放 batching，避免把“状态恢复”语义扩大为“事件历史回放”。这能降低旧世界/旧链路下的行为回归风险。[使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/使用说明.md#L1180)
- 配置层仍存在命名债：`crosschunk.directSyncBatching` 的键名保留历史 `sync` 命名，但行为已覆盖 direct `toggle/pulse`。本次已在说明文档中明确，但若后续继续扩展 direct batching 行为，建议单独规划配置重命名或别名迁移，避免长期误导使用者。[使用说明.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs_dev/使用说明.md#L1143)
- 回归覆盖已补三类关键点：调度器验证 `toggle/pulse` 同桶并存与 invalidation 覆盖 activation，目标端验证 activation batch 回放后的 `pulse -> toggle` 回落语义，direct gate 验证 `all_sync` 才开放 direct activation batching。当前自动化测试结果可作为本次回归证据，但后续若再扩展生命周期或配置命名，仍建议补端到端 bench case 观察 tick 级时序表现。[CoreDispatchBatchSchedulerTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/CoreDispatchBatchSchedulerTest.java#L83) [CoreDispatchBatchSchedulerTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/CoreDispatchBatchSchedulerTest.java#L134) [ActivatableTargetBlockEntityInternalTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/block/entity/ActivatableTargetBlockEntityInternalTest.java#L506) [LinkedTargetDispatchServiceTest.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/test/java/com/makomi/data/LinkedTargetDispatchServiceTest.java#L145)
