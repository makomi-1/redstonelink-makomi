## 1. 功能与语义、架构设计

本轮实现把“无线化原版件”拆成两层：
- 转化器层：独立的炉式机器，只负责配方、燃料、漏斗和容器交互，不承担节点身份。[WirelessConverterBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessConverterBlock.java#L29) [WirelessConverterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessConverterBlockEntity.java#L28)
- 节点层：把原版交互行为转接到 `triggerSource/core` 语义，节点身份只落在无线化物品与放置后的方块实体上。[WirelessBlockNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessBlockNodeSupport.java#L28) [WirelessCoreBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessCoreBlockEntity.java#L16) [WirelessSyncTriggerSourceBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessSyncTriggerSourceBlockEntity.java#L16)

最小原型的职责边界如下：
- `无线化拉杆 / 石按钮 / 石压力板` 统一走同步 `triggerSource`，保留原版自身的状态/脉冲特征，但不再向邻居输出红石，只向已连接 `core` 转发强度。[WirelessLeverBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessLeverBlock.java#L31) [WirelessStoneButtonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStoneButtonBlock.java#L34) [WirelessStonePressurePlateBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStonePressurePlateBlock.java#L36)
- `无线化活塞 / 红石灯` 统一走 `core`，只响应无线输入并执行原版“受电后表现”，不读取原版邻居红石输入。[WirelessPistonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessPistonBlock.java#L54) [WirelessRedstoneLampBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessRedstoneLampBlock.java#L30)

注册入口已经完整打通：
- 服务端初始化接入自定义配方类型和序列化器。[RedstoneLink.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/RedstoneLink.java#L61)
- 新方块、方块实体、物品和菜单类型都进入统一注册表。[ModBlocks.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlocks.java#L181) [ModBlockEntities.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModBlockEntities.java#L154) [ModItems.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModItems.java#L230) [ModMenuTypes.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModMenuTypes.java#L22)

## 2. 关键数据结构和算法性能分析

节点身份复用现有 `serial + PairableBlockItem + PairableNodeBlockEntity` 体系，没有引入新的世界级索引结构。公共放置/掉落/配对辅助被收敛到单一工具类，避免每个无线化原版件重复实现同样的序列号与掉落继承逻辑。[WirelessBlockNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessBlockNodeSupport.java#L34) [WirelessBlockNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessBlockNodeSupport.java#L55)

`triggerSource` 侧性能开销主要是状态变化时的一次 `forwardLinkedSignal` 调用，复杂度仍然取决于已连接目标数量，没有额外扫描邻居网络：
- 拉杆在 `pull` 时转发一次。[WirelessLeverBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessLeverBlock.java#L85)
- 按钮在按下与回弹各转发一次。[WirelessStoneButtonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStoneButtonBlock.java#L99) [WirelessStoneButtonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStoneButtonBlock.java#L112)
- 压力板只在状态变化时更新与转发，不做多余扇出。[WirelessStonePressurePlateBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStonePressurePlateBlock.java#L129)

`core` 侧没有引入新的轮询算法：
- 红石灯依赖现有目标实体的激活态回写 `LIT`。 [WirelessRedstoneLampBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessRedstoneLampBlockEntity.java#L16)
- 活塞在需要伸缩时复用了原版 `PistonStructureResolver` 与移动流程，成本与原版活塞相同量级；额外开销只有一次无线激活态读取。[WirelessPistonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessPistonBlock.java#L159) [WirelessPistonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessPistonBlock.java#L287)

转化器沿用 `AbstractFurnaceBlockEntity` 的三槽结构和缓存配方查询，新增成本很低：
- 自定义 `RecipeType/RecipeSerializer` 仅作为查表入口。[ModRecipeTypes.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModRecipeTypes.java#L12) [ModRecipeSerializers.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/registry/ModRecipeSerializers.java#L16)
- 燃料判断被缩窄成 `redstone_link_component`，避免普通燃料误入。[WirelessConverterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessConverterBlockEntity.java#L46) [WirelessConverterMenu.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/menu/WirelessConverterMenu.java#L34)

## 3. 数据流或调用链

- 无线化触发器交互或状态变化后，先写 `POWERED`/原版外显，再调用方块实体记录并转发输入强度。[WirelessLeverBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessLeverBlock.java#L85) [WirelessStoneButtonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStoneButtonBlock.java#L141) [WirelessStonePressurePlateBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStonePressurePlateBlock.java#L155)
- `WirelessSyncTriggerSourceBlockEntity` 复用现有同步来源实体链，把强度派发给已连接 `core`。[WirelessSyncTriggerSourceBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessSyncTriggerSourceBlockEntity.java#L16)
- `WirelessCoreBlockEntity` 在目标态变化时，把解析后的激活态同步回原版方块表现。[WirelessCoreBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessCoreBlockEntity.java#L32) [WirelessCoreBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessCoreBlockEntity.java#L46)

## 5. 并发冲突审查

风险等级：低。

共享状态主要仍然是现有节点序号、连接快照与目标派发状态，本轮没有引入新的跨线程容器：
- 放置继承、掉落回写和配对 GUI 打开全部复用服务端单线程世界上下文。[WirelessBlockNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessBlockNodeSupport.java#L34) [WirelessBlockNodeSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessBlockNodeSupport.java#L109)
- `core` 激活态回写仍然走方块实体生命周期，不额外创建异步任务；脉冲回落也只是调度世界 tick。[WirelessCoreBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessCoreBlockEntity.java#L46)
- 转化器沿用原版炉式容器与数据槽，不新增后台线程或跨线程缓存。[WirelessConverterBlockEntity.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/entity/WirelessConverterBlockEntity.java#L41)

可能的重入点主要在原版活塞事件和方块状态回写：
- 活塞 `triggerEvent -> moveBlocks` 链仍是原版世界线程语义，风险主要不是线程安全，而是未来上游逻辑升级导致的行为漂移。[WirelessPistonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessPistonBlock.java#L159)
- 按钮、压力板和拉杆在状态变化时会立即转发无线强度，若后续叠加更复杂的输入模拟系统，应优先沿用现有 `LinkTriggerSourceBlockEntity` 的重采样和 replay 机制，而不是在方块层二次缓存。[WirelessStoneButtonBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStoneButtonBlock.java#L141) [WirelessStonePressurePlateBlock.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/java/com/makomi/block/WirelessStonePressurePlateBlock.java#L155)

结论：
- 本轮改动没有发现新的线程边界违规、共享可变状态争用或跨线程写覆盖问题。
- 残余风险集中在“活塞逻辑随上游升级的同步维护成本”，不在并发正确性本身。
