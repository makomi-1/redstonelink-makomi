# Iris渲染兼容分支

## 1. 功能与语义、架构设计

- 本轮新增了独立的 Iris 兼容判定入口，统一用 `FabricLoader.isModLoaded("iris")` 作为客户端渲染分支切换条件，避免把非 Iris 路径一起改动。[IrisRenderCompatSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisRenderCompatSupport.java#L19)
- 定向箭头保留原有几何、颜色与 `triggerSource/core` 方向语义，只在 Iris 下把输出层切换为 vanilla `RenderType.lines()`，属于纯渲染兼容，不改真值逻辑。[DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L98) [DirectionalFaceVectorRenderSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorRenderSupport.java#L163)
- quick-link 兼容分支分三段处理：
  - `BLOCK_OUTLINE` 阶段在 Iris 下只负责拦截默认白框，不再实际绘制自定义描边。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L127)
  - `AFTER_TRANSLUCENT` 阶段在 Iris 下跳过 preview 线框绘制，避免现有自定义 line target 继续命中不稳定路径。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L180)
  - `LAST` 阶段在 Iris 下统一补绘当前命中描边与 preview 线框，并让第三形态连线改走兼容线层。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L225) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L776) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L820) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L851)

## 2. 关键数据结构和算法性能分析

- 本轮没有新增新的重型缓存结构，仍复用原有 `cachedPreviewOutlineState`、`cachedChannelPreviewState`、`visualizedObjects` 这组短 TTL / 本地显示缓存；兼容分支只是改变了它们的消费阶段，没有改变缓存生命周期。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L112)
- 定向箭头仍按“玩家周围若干区块 -> block entity -> 支持面集的节点”扫描，Iris 分支没有增加新的遍历层级，时间复杂度保持不变。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L37)
- quick-link preview 仍复用既有的边界线段缓存构建结果；Iris 下只是把绘制从 `AFTER_TRANSLUCENT` 延后到 `LAST`，不会额外触发新的全图扫描。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L207)
- 兼容层的新增计算开销主要是每帧一次 `isModLoaded("iris")` 和命中节点外形重绘，属于常数级开销，风险低。[IrisRenderCompatSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisRenderCompatSupport.java#L19)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮仅改客户端渲染分支，不涉及网络协议、存档结构或权限边界，安全风险低。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L225)
- 性能：Iris 分支把 preview 线框从 `AFTER_TRANSLUCENT` 改到 `LAST`，但仍复用同一套缓存数据；性能轮廓基本不变，主要是渲染阶段变化而不是计算量上升。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L820)
- 兼容性：当前兼容判断只看 `iris` 是否加载，不区分 shader pack 类型；这能快速规避已知问题，但不同 shader pack 仍可能存在观感差异，后续建议保留一次带实际 shader pack 的人工回归。[IrisRenderCompatSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisRenderCompatSupport.java#L19)
- 扩展性：兼容判断被收口到独立 helper，后续若要继续扩展到过滤器范围框、其它后置线型外显，可继续复用同一入口，不需要再把 `FabricLoader` 判断散落到每个 renderer。[IrisRenderCompatSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisRenderCompatSupport.java#L12)

## 5. 并发冲突审查

- 共享状态：
  - `QuickLinkWorldOverlayRenderer` 中的 `cachedPreviewOutlineState`、`cachedChannelPreviewState`、`visualizedObjects` 仍是本轮最主要的共享可变状态，但本轮没有新增新的共享容器，只改变了渲染分支对这些状态的读取阶段。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L112)
- 读改写覆盖：
  - Iris 兼容分支没有新增写入点，仍沿用既有的 payload 接收与渲染读取关系，因此不会额外引入新的“写后立刻读”覆盖风险。[QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L257) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L315)
- 重入 / 线程边界：
  - 本轮新增的 `IrisRenderCompatSupport` 为无状态工具类，不引入新的线程边界问题。[IrisRenderCompatSupport.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/IrisRenderCompatSupport.java#L12)
  - 渲染兼容分支仍在客户端世界渲染事件中执行，没有引入异步任务或后台线程，重入风险低。[DirectionalFaceVectorWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/DirectionalFaceVectorWorldOverlayRenderer.java#L28) [QuickLinkWorldOverlayRenderer.java](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/client/java/com/makomi/client/render/QuickLinkWorldOverlayRenderer.java#L248)
- 风险等级与建议：
  - 风险等级：低。
  - 建议：后续若继续扩展 Iris 兼容范围，优先复用当前“统一 helper + 世界后置阶段兼容绘制”的收口方式，避免回到分散的自定义 line target 路径。
