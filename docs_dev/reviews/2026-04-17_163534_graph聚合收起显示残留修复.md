# Graph 聚合收起显示残留修复

## 1. 功能与语义、架构设计（关键方法和入口）

- 本轮修复的核心是把 Graph 视图裁剪的顺序改成“先决定哪些真实边被摘要节点替代，再根据替代后的可见边反推实际可见节点”，避免收起逻辑已经成立但节点仍沿用原始 incident edge 口径继续留在画布中 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L348)。
- 摘要节点文案也同步从 `leaf cores` 调整为更贴近当前实现的 `hidden cores`，避免 UI 表达继续绑定旧的“仅叶子节点”语义 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L111)。
- 入口层不变：自动布局、画布点击、孤立节点池点击仍复用现有交互，只是它们背后的画布视图模型现在基于新的可见边口径生成 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1269) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1518) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1554) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1594)。

## 2. 关键数据结构和算法性能分析

- 关键数据结构仍是 `GraphCanvasView`，但其 `visibleActualNodeKeys` 现在不再直接从原始 `edgeCountByNodeKey` 推导，而是从“摘要替代后的 `visibleActualEdges`”重新推导，因此更符合最终画布状态 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L78) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L391) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L396)。
- 本轮新增 `hiddenEdgeKeys` 作为摘要替代边的中间集合，先把需要被收起的真实边标记出来，再统一过滤，复杂度仍保持在 `O(V + E)` 级别，没有引入更重的布局或图算法 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L357) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L391)。
- `buildEdges(...)` 继续基于最终 `graphCanvasView` 组装 ReactFlow 边集，因此摘要边、真实边和草稿差异边的组合方式没有被破坏 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L684)。

## 3. 数据流或调用链

- 数据流仍是 `baseGraphBundle + graphDraft -> effectiveGraphBundle -> graphCanvasView -> autoLayoutPositions -> ReactFlow`，但 `graphCanvasView` 内部的生成规则已经修正为“先隐藏边，再算节点”，这样后续布局、样式和交互都天然复用最终裁剪后的结果 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L348) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1269)。
- 交互链路没有改协议：点击 triggerSource 或摘要节点仍通过 `handleCanvasNodeClick(...)` 驱动展开/收起；点击孤立节点池仍通过 `handleRevealIsolatedNode(...)` 把节点拉回画布并聚焦 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1554) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1594)。
- 自动布局也仍然只消费当前画布视图模型，因此不会再把已经被摘要替代的真实节点重新带回主画布 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1518)。

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 这次修复只改前端视图裁剪顺序，没有改变服务端 graph 快照、草稿保存结构或 `triggerSource -> core` 的真实写入语义，因此兼容边界保持不变 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L348)。
- 摘要节点现在从“只表达叶子”切到“表达被视图隐藏的目标”，这比旧文案更准确；如果后续继续扩到频道模式，建议继续坚持“摘要节点只表达视图层隐藏对象”的边界，不要把它混入真实拓扑语义 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L111)。
- 验证上，本轮 `buildWebapp` 和 `test/testIntegration/testClient/testSlow` 全部通过，说明这次修复没有再触发之前那条慢测门限波动。

## 5. 并发冲突审查（共享状态、读改写覆盖、重入/线程边界、风险等级与建议）

- 本轮没有新增新的前端共享状态，只调整了 `buildGraphCanvasView(...)` 的派生逻辑，因此线程边界仍然维持在 React 单线程渲染范围内，风险低 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L348)。
- 节点和边的最终渲染仍然统一通过 `graphCanvasView` 派生，不存在“一套逻辑负责隐藏边、另一套逻辑负责显示节点”的分叉读改写路径，降低了视图裁剪结果不一致的风险 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L391) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L684)。
- 交互重入方面，展开/收起和自动布局继续通过既有状态驱动，不需要跨线程协调；当前剩余风险主要是用户真实数据分布可能继续暴露新的聚合策略边界，但不属于并发冲突问题，风险等级低 [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1518) [GraphViewer.tsx](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L1554)。
