## 2. 关键数据结构和算法性能分析

- 主题定义使用静态数组 `WEB_THEME_OPTIONS`，状态值仅为一个 `WebThemeId`，切换成本是常量级；主题切换本身不会引入新的复杂数据计算。[theme.ts](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/theme.ts#L15)
- graph 画布内部节点和边颜色被改为 CSS 变量字符串，浏览器在祖先 `data-theme` 变化时即可完成重算，不需要重新生成整张图的配色映射，性能成本较低。[canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L191) [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L303)
- recording 图表由于使用的是 canvas 绘制，不能直接消费 CSS 变量，因此新增了 `resolveThemeColor(...)` 在图表重建时按当前主题解析变量值；复杂度仍为每次重建时对少量变量做常量次读取。[RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L129) [RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L438)
- `themeId` 被显式传到 `RecordingViewer/RecordingChart`，确保主题切换时会触发图表重新取色，而不是停留在旧主题色板上，这避免了“UI 已切换但曲线仍然旧色”的一致性问题。[RecordingViewer.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L45) [RecordingViewer.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L299) [RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L26)

## 3. 数据流或调用链

- 主题切换链路是：`App` 持有 `currentThemeId` -> 页面组件把主题写入 `<main data-theme>` -> CSS token 与主题覆盖生效 -> graph/recording 组件读取新的视觉变量。[App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L35) [HomePage.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/HomePage.tsx#L51) [GraphPage.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/GraphPage.tsx#L53) [RecordingPage.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/RecordingPage.tsx#L49)
- 页面结构层通过 `ThemeSwitcher` 触发 `onThemeChange(themeId)`，业务数据请求与页面路由逻辑不受影响，因此主题切换与资产读取链路保持解耦。[ThemeSwitcher.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/ThemeSwitcher.tsx#L33) [App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L403)
- graph 颜色链路分两层：`app.css` 提供 graph token，`GraphViewer` 的背景和 minimap 使用这些 token，`canvas.tsx` 的节点/边样式也改为同源 token，从而保证图例、节点、边、minimap 同步换色。[app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L67) [GraphViewer.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2193) [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L206)
- recording 颜色链路是：`RecordingViewer` 提供基于 CSS 变量的系列色名，`RecordingChart` 在重建 uPlot 时解析这些变量和值班轴网格变量，再写入 canvas 配置。[RecordingViewer.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingViewer.tsx#L20) [RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L129) [RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L170)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性方面，本轮仅改前端视觉层和测试，不涉及服务端 API 协议、存储结构、权限或游戏内写入逻辑，风险较低。[App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L35)
- 性能方面，主题切换主要触发浏览器样式重算与 recording 图表重建；在当前页面规模下成本可接受，且已通过前端全量 Vitest 与 Gradle 全标签回归验证。[App.test.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.test.tsx#L29) [GraphPage.test.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app/GraphPage.test.tsx#L47)
- 兼容性方面，`color-mix(...)` 目前只用于 graph 节点局部视觉增强，这依赖较新的浏览器渲染能力；如果后续要兼顾更旧环境，建议把这些表达式进一步下沉成显式 token，避免依赖浏览器动态混色。[canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L225) [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L259)
- 扩展性方面，当前 token 已覆盖主框架、graph 与 recording 的主色域；后续若要继续加“纯白极简”“高饱和赛博”或“夜间低亮”模板，只需新增一个 `data-theme` 分支和少量元数据，不必再改页面结构。[app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L129) [app.css](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/app.css#L215)

## 5. 并发冲突审查

- 主题状态只有 `currentThemeId` 一个共享状态源，集中在 `App` 持有并通过 props 下发，避免了多个页面各自维护主题导致的状态分叉，风险等级低。[App.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/App.tsx#L35)
- graph 相关视觉切换基本依赖 CSS 变量，不新增额外共享可变缓存，也没有引入跨组件的读改写覆盖点，风险等级低。[GraphViewer.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/GraphViewer.tsx#L2193) [canvas.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/graphViewer/canvas.tsx#L206)
- recording 图表的主题变化通过显式 `themeId` 依赖触发 effect 重建，避免了旧图表实例继续持有旧颜色；这里没有并发写共享状态，只是一次性销毁重建 uPlot，风险等级低。[RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L111) [RecordingChart.tsx](/D:/OpenProjects/RedstoneLink/rl-release-no-mixin/webapp/src/components/RecordingChart.tsx#L237)
