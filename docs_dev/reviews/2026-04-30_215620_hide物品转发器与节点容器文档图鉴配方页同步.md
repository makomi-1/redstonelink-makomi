## 2. 关键数据结构和算法性能分析

本轮没有新增运行时数据结构，也没有改任何服务器或客户端热路径算法。主要影响的是静态页面的前端映射表：

- 图鉴页的 `textureOverridesByPath` 与 `items` 数组新增多个 `hide` 变种条目，仅在静态页面加载时参与一次性渲染，不影响游戏运行时性能：[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L544)、[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L758)

## 3. 数据流或调用链

本轮数据流是“运行时代码事实 -> 文档/静态页映射同步”：

1. `hide` 物品模型通过单层 `cube_all` 引用 `chunk_activator_hide` 贴图，供资源打包与客户端物品渲染使用：[hide_chunk_activator.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/hide_chunk_activator.json#L1)
2. 使用说明文档直接以自然语言描述当前实现，包括 `hide` 节点语义、转发器延迟规则与容器临时选取：[usage_guide_cn.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_cn.md#L41)、[usage_guide_en.md](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/usage_guide_en.md#L187)
3. 图鉴页通过 `items` 数据数组与贴图映射生成物品展示卡，展示 `hide` 变种、容器与转发器的最新说明：[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L544)、[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L783)
4. 配方页通过静态 HTML 卡片和 `classifyRecipeByOutput` 分类函数，把新 `hide` 配方正确落到 `triggerSource/repeater/filters/tools` 等栏目中：[recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L188)、[recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L1894)

## 4. 安全、性能、兼容性、扩展性风险分析与建议

- 安全性：本轮无网络协议、权限或持久化改动，安全风险低；只是把既有实现口径同步到用户可见文档与静态页，无新增攻击面。
- 性能：本轮仅改静态文档与前端映射表，对运行时无性能影响；Gradle 全量回归已通过。
- 兼容性：
  - 保持了 `hide_repeater` 贴图文件当前实际命名 `reapter_hide.png` 的现状，没有擅自重命名资源，因此不会破坏当前资源引用：[item_guide.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/item_guide.html#L558)、[recipe_sheet.html](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/docs/recipe_sheet.html#L709)
  - `hide_chunk_activator` 现在也与其它 `hide` 物品一样走单层贴图模型，避免图鉴/物品显示继续与实现不一致：[hide_chunk_activator.json](/d:/OpenProjects/RedstoneLink/rl-release-no-mixin/src/main/resources/assets/redstonelink/models/item/hide_chunk_activator.json#L1)
- 扩展性建议：
  - 后续如果再新增 `hide` 变种，应继续同步四个入口：`usage_guide_cn/en`、`item_guide.html`、`recipe_sheet.html` 与对应 item model
  - 如果未来修正 `reapter_hide.png` 的资源命名拼写，需要统一更新 item model、图鉴页和配方页的贴图映射，避免出现文档与资源路径错位
