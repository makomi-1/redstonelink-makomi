# graph保存预检与专用计费

## 阻塞点

- `RedstoneLinkRateLimitConfig` 新增 `graphWrite` 容量字段后，`RedstoneLinkServerConfigSnapshot.defaults()` 仍按旧构造参数个数初始化，导致 `compileJava` 直接失败。

## 解决方法

- 同步更新 `RedstoneLinkServerConfigSnapshot` 的默认限流构造参数顺序，并与 `RedstoneLinkConfigParser` / `RedstoneLinkConfigTemplate` 保持一致。
- 这类“record 字段扩容”改动不要只跑 `buildWebapp`；至少补一次 `compileJava` 或全量 Gradle 测试，否则很容易漏掉 Java 侧默认快照构造漂移。

## 复用建议

- 后续只要给配置 `record` 增字段，就把“解析器默认值、模板默认值、服务端默认快照”当成一个原子变更面一起检查。
