# 退役释放节点别名占用经验

## 阻塞点

使用 `Unsafe` 构造最小 `ServerLevel` SavedData 夹具时，退役协调器会触发展示同步和在线节点同步。最小服务器没有完整 `PlayerList` 与维度类型字段，导致测试先后在玩家列表遍历、`Level.isLoaded(...)` 上出现空指针。该失败不是退役别名释放设计本身的问题，而是测试夹具覆盖了无关的在线展示同步路径。

## 解决方法

- 实现层对 `NodeAliasServerSupport.syncOnlinePlayerItemAliases(...)` 增加 `PlayerList` 空保护，避免展示刷新失败阻断退役主流程。
- 测试层收窄用例，只验证别名释放和复用，不注册在线方块节点，避免无关的方块实体同步路径进入最小夹具。
- 后续编写 SavedData 级回归时，应先区分“持久化语义测试”和“在线方块实体同步测试”；前者尽量避免注册运行态节点，后者必须提供完整维度/区块/玩家列表夹具或改用游戏内测试。
