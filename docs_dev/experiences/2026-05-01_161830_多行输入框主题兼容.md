# 多行输入框主题兼容

## 阻塞点
- `1.21.11` 的 `MultiLineEditBox` 仍可同包继承，但滚动条相关辅助方法与旧版不同，`getMaxScrollAmount / scrollbarWidth / RenderSystem.enableBlend` 这类 `1.21.1` 时代可直接复用的写法在当前版本不再成立。
- 如果机械照搬旧版整套 `renderDecorations`，会直接编译失败。

## 解决方法
- 保留旧设计里“文本编辑行为走原版、外观层局部接管”的核心思路。
- 在 `net.minecraft.client.gui.components` 同包内新增兼容子类，继续接管：
  - 无阴影容量计数
  - 主题背景与边框
- 不再强行复刻旧版滚动条实现，而是调用 `super.renderDecorations(guiGraphics)` 保留 `1.21.11` 原版滚动装饰，再在其后覆盖容量计数字体表现。

## 适用条件
- 目标版本已经让 `builder` 级接口不足以恢复旧版主题，但仍允许在 Minecraft 同包下新增兼容子类。
- 需求重点是恢复主题色与无阴影计数，而不是 100% 接管新版内部滚动条细节。

## 注意事项
- 这类兼容层应尽量薄，只接管明确需要的视觉差异，不要把新版私有滚动逻辑整段重写。
- 若后续 Mojang/Fabric 再改同包内部方法名，优先保留 `super.renderDecorations(...)`，只追加最小视觉覆盖。
