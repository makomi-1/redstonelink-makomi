# 外显兼容四边形面剔除修复

## 阻塞点
- `1.21.11` 里为了适配新线段顶点格式，`Sodium/Iris` 兼容分支把描边、连线、箭头线段改成了细长四边形。
- 但当前兼容四边形管线没有显式关闭 cull，导致这些单面四边形在 `Sodium` 或 `Sodium + Iris` 下可能被更严格地整批剔除，看起来就是“外显完全不显示”。

## 解决方法
- 在兼容分支使用的穿透四边形管线里显式设置 `withCull(false)`。
- 保持其它语义不变：仍然禁用深度测试、仍然禁用深度写入、仍然走兼容分支的几何提交流程。

## 复用建议
- 只要某条兼容渲染路径把线段或轮廓改写成单面 quad，就要优先检查：
  - 是否被剔除
  - 是否需要显式 `no cull`
- 这个检查项在 `Sodium/Iris` 下比 vanilla 更关键，后续调试类似“某类 overlay 在兼容分支整批不可见”时应优先排查。
