# Gradle守护进程仍使用JDK21导致26.1编译失败

## 阻塞点

已经把构建基线切到 Java 25 后，直接执行 `.\gradlew.bat compileJava --no-daemon` 仍然报“`不支持发行版本 25`”，表现与代码迁移无关，而是构建 JVM 仍停留在 JDK 21。

## 原因

`java -version` 和 `JAVA_HOME` 看起来都已经是 JDK 25，但 `gradlew -version` 显示 daemon JVM 仍来自旧的 `org.gradle.java.home` 配置，导致编译任务实际跑在 JDK 21 上。

## 解决方法

执行编译时同时显式覆盖两处：

```powershell
$env:JAVA_HOME='C:\Program Files\Java\jdk-25'
& .\gradlew.bat 'compileJava' '--no-daemon' '-Dorg.gradle.java.home=C:\Program Files\Java\jdk-25'
```

## 复用建议

- 迁移到 26.1 后，所有需要 Java 25 的 Gradle 验证命令都优先沿用这组调用方式。
- 如果再次出现“明明切了 JDK 25 仍报 release 25 不支持”的症状，先看 daemon JVM，不要先怀疑源码改动本身。
