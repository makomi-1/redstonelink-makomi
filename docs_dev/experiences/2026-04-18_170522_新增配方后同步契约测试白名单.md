# 新增配方后同步契约测试白名单

## 阻塞点

新增 `graph visual editor` 配方后，全量测试在 `RecipeResourceLayoutTest` 失败。失败原因不是目录错放，而是该测试对白名单文件集合做了精确比对，新配方未同步进预期集合。

## 解决方法

在保持配方仍落于标准 `src/main/resources/data/redstonelink/recipe/` 目录的前提下，同步更新 `RecipeResourceLayoutTest` 的 `EXPECTED_RECIPE_FILES`，并把断言文案中的数量从 20 修正为 21。

## 复用提示

- 以后只要新增或删除运行时配方 JSON，都要同步检查 `RecipeResourceLayoutTest` 的白名单。
- 如果测试提示 `runtimeRecipesShouldLiveUnderStandardRecipeDirectory` 失败，先核对是目录错误，还是白名单未更新，不要直接怀疑配方加载逻辑。
