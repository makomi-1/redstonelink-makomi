# 26.1多行输入框主题兼容

## 阻塞点

- 迁移 `1.21.11` 的 GUI 输入框主题提交时，原方案尝试像旧分支一样通过同包子类化 `MultiLineEditBox` 接管背景与容量计数绘制。
- 但在 `26.1` 目标版本里，`MultiLineEditBox` 的构造器已经是私有入口，只保留了 `builder()`；因此无法直接新建子类实例，也无法按旧版做 `extractDecorations` 覆写。

## 解决方法

- 先用 `javap -p` 核对 `26.1` 命名 jar 的真实签名，确认 `MultiLineEditBox` 为私有构造，而 `Builder` 仍暴露 `setTextShadow / setShowBackground / setShowDecorations / setCursorColor` 等配置能力。
- 最终改为“原版输入框本体 + 屏幕层装饰”方案：
  - 输入框仍通过 `builder()` 创建；
  - 原版 `decorations` 关闭，避免带阴影容量计数重复绘制；
  - 主题边框与底色在 `Screen.extractBackground(...)` 层补画；
  - 无阴影容量计数在 `Screen.extractRenderState(...)` 末尾补画；
  - 单行 `EditBox` 的 hint 仍走本地主题控件自绘覆盖，关闭默认阴影路径。
- 这套方案在 `26.1` 下能保留原版编辑、滚动、选区和光标逻辑，同时复现迁移目标需要的 GUI 视觉表现。
