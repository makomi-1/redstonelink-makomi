# 单测初始化与覆盖率工具链双重兼容修复

## 阻塞点
- 26.1 下测试并不是单纯 `Bootstrap.bootStrap()` 就能稳定构造 `ItemStack`；默认组件绑定缺失会让大量 `*ItemDataTest` 直接在初始化阶段失败。
- 即使测试断言本身已经通过，Java 25 仍会让 JaCoCo 0.8.12 在 `jacocoTestReport` 阶段因 `Unsupported class file major version 69` 把构建打回失败。

## 解决方法
- 测试引导层不要继续依赖 `RegistryAccess.fromRegistryOfRegistries(...).freeze()`；在 26.1 里它缺 tag 视图，无法支撑 `DataComponentInitializers`。应改用 `VanillaRegistries.createLookup()` 再执行默认组件重绑定。
- 对测试期临时注册的物品/方块，必须在写窗关闭前重新绑定物品默认组件，否则新注册 holder 仍会在 `new ItemStack(...)` 时失败。
- Java 工具链升级到 25 后，要同步升级 JaCoCo 到支持 class file 69 的版本，否则会出现“测试通过但构建失败”的假失败。
