# hide物品块状贴图图集适配

## 阻塞点
- `hide` 物品在 `1.21.11` 下需要保持块状渲染，但直接沿用旧工作区的 `minecraft:block/cube_all -> redstonelink:item/*_hide` 会在客户端表现为紫黑缺贴图。
- 将模型临时改为 `item/generated` 虽然能避开紫黑，但会破坏原设计，因为 `hide` 物品本来就应保持块状显示，而不是平面物品显示。

## 解决方法
- 保留 `hide` 物品模型为 `minecraft:block/cube_all`。
- 将对应 `*_hide.png` 同步复制到 `textures/block/`，让块状模型走 `blocks` 图集。
- 把 `models/item/hide_*.json` 的贴图引用统一改成 `redstonelink:block/*_hide`。

## 复用建议
- 只要 `1.21.11` 里的物品模型继续使用块状 `block/*` 父模型，就优先检查它引用的贴图是否来自 `blocks` 图集，而不是直接复用 `textures/item/`。
- 当设计要求“物品保持块状渲染”时，不要用 `item/generated` 规避贴图问题，应先判断是否属于图集不匹配。
