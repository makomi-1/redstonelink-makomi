# 新增配方白名单测试同步

## 阻塞点

- 新增运行时配方后，全量测试被 `RecipeResourceLayoutTest.runtimeRecipesShouldLiveUnderStandardRecipeDirectory()` 拦住。
- 直接原因不是配方 JSON 位置错误，而是测试里的 `EXPECTED_RECIPE_FILES` 白名单没有同步新增的 `hide_core.json`、`hide_sync_trigger_source.json`、`directional_face_editor.json`。

## 解决方法

- 先确认实现设计：这三张配方属于正式运行时配方，应该继续放在 `src/main/resources/data/redstonelink/recipe/`。
- 再修测试而不是回退实现：把 `RecipeResourceLayoutTest` 的白名单集合补齐到当前配方清单，随后重跑全量回归。

## 复用建议

- 以后只要新增正式配方，除了补 JSON 和文档页，还要同步检查：
  - `docs/recipe_sheet.html` 的贴图/分类/双语名映射
  - `src/test/java/com/makomi/RecipeResourceLayoutTest.java` 的 `EXPECTED_RECIPE_FILES`
- 若构建只在资源布局测试上失败，优先先核对白名单是否漏同步，不要误判成目录放错。
