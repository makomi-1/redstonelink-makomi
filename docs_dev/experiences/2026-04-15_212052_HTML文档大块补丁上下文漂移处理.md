# HTML文档大块补丁上下文漂移处理

## 阻塞点

对 `docs/item_guide.html` 这类长文件直接做多对象、大跨度 `apply_patch` 时，容易因为上下文已经变化或抓取片段不精确而出现补丁上下文不匹配，导致整次补丁失败。

## 解决方法

1. 不直接对整段大范围内容下补丁，先用 `Select-String` 精确定位对象入口，例如 `path: 'link_send_filter'`、`path: 'quick_link_tool'`。
2. 再用 `Get-Content | Select-Object -Skip/-First` 读取每个对象的当前真实块内容。
3. 最后按对象分别做小块 `apply_patch`，只替换 `effect/usage/note` 等稳定字段，避免跨对象或跨远距离上下文。

## 适用建议

- 适用于 `docs/item_guide.html`、大型 JSON-like 前端数据文件、长 Markdown 章节批量替换。
- 如果一次补丁失败，不要继续硬套原补丁；先重读目标块，再拆成更小的补丁。
