# webapp依赖安装超时处理

## 阻塞点

在 `webapp` 目录执行前端测试依赖安装时，首次 `npm install --save-dev vitest jsdom @testing-library/react @testing-library/user-event @testing-library/jest-dom` 因超时中断，导致无法立即判断是否已经半落盘。

## 解决方法

1. 先读取 `webapp/package.json` 并检索 `package-lock.json`，确认依赖和 lockfile 都没有半成功写入。
2. 保持同一工作区与同一 `webapp` 目录不变，只把命令超时时间拉长后重跑安装。
3. 安装成功后再继续修改 `vite.config.ts`、`tsconfig.json` 与测试文件，避免在不稳定依赖状态下继续迭代。

## 复用建议

- 以后遇到 `npm install` 或 `npm ci` 超时，不要直接假定失败或继续编辑依赖相关文件。
- 先核对 `package.json/package-lock.json/node_modules` 的实际状态，再决定是重跑安装还是改为手动 patch。
- 对前端依赖安装这类可能受网络影响的步骤，默认给更长超时，能减少一次无效往返。
